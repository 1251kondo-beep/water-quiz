## 1. 土木工事の定義と施工法一般・仮設備工（テキスト p.200）

### (1) 土木工事の体系と土木施工法

土木工事とは、自然環境を適切に改変・利用し、ダム、道路、鉄道、橋梁、トンネル、河川構造物、港湾、都市インフラ、そして上水道・下水道施設などの社会資本（インフラストラクチャー）を構築する工事の総称である。

* **土木施工法の役割**:
  * 設計図書に示された構造物を、所定の工期内に、所定の品質・強度・水密性を確保し、かつ経済的・安全に築造するための一連の技術・管理体系である。
  * 仮設、土工、基礎、コンクリート、配管布設など、多岐にわたる専門工種を有機的に連携させて施工する。

---

### (2) 仮設備工（仮設工・テキスト p.200）

本設構造物の完成・引き渡しまでの間、工事を安全かつ円滑に進めるために一時的に設ける設備群である。工事完成後は原則としてすべて撤去・現状復旧される。

```
【主要な仮設備工の種類】
① 工事用進入路・迂回路 ──── 重機や資材搬入ダンプの安全な動線確保。
② 仮設ヤード（基地） ────── 管材・鋼材・骨材のストックヤード、加工場、機械置き場。
③ 現場事務所・宿舎 ──────── 施工管理技術者・作業員の執務・休憩・安全衛生施設。
④ 仮設受配電・照明設備 ──── 工事用動力電源、夜間照明（投光器）、受電盤。
⑤ 工事用給排水設備 ──────── 濁水処理プラント、工事用水配管、湧水排水ポンプ設備。
⑥ 仮囲い・防音フェンス ──── 第三者立入防止、騒音・粉じんの外部拡散防止。
```

* **計画上の留意点**:
  * 周辺住民の生活環境、交通影響、気象条件（台風・豪雨・積雪）を的確に予測し、過不足のない規模・配置計画を立てることが重大公害や公衆災害の防止に直結する。

## 2. 機械土工・事前調査手順・土留め工の安全基準（テキスト p.200〜201）

土工（土工事）とは、地山を掘り（掘削）、運搬し、埋め（盛土・埋戻し）、締め固める一連の土砂移動作業である。現代の土木工事は「機械土工」が標準であり、人力掘削は地下埋設物近接部や狭隘道路等に限定される。

### (1) 土工の事前調査3段階手順

地中には目に見えない障害物や軟弱層が潜んでいるため、掘削着工前に3段階の綿密な事前調査を実施する。

```
【土工事の事前調査フロー】
［第1段階：予備調査（机上調査）］
  ・地形図、地質図、過去の航空写真、周辺のボーリング柱状図（標準貫入試験 N値の把握）
  ・地下水位、既設埋設管路図面（水道・ガス・下水・電力・通信）の収集・整理
        │
［第2段階：現地踏査（現地調査）］
  ・周辺構造物・家屋の事前調査（クラックの有無、沈下懸念箇所の把握）
  ・進入路幅員、上空架線（高圧線）、昼間施工の可否（交通量）、夜間施工帯の確保検討
        │
［第3段階：本調査（土質・地質試験）］
  ・現地ボーリング調査、土質サンプリング（含水比、粒度分布、粘着力 c、内部摩擦角 φ）
  ・地盤の支持力算定、土留め設計計算条件の決定、発生残土の再利用性評価
```

---

### (2) 施工計画と工程・土量管理

* **工程管理（クリティカルパスの把握）**:
  * ネットワーク工程表（PERT/CPM）を作成し、遅延が即座に全体工期の遅延につながる最長経路（**クリティカルパス**）を特定して重点管理する。
  * 過去の気象統計から降雨・降雪による **「不働日数（作業不能日）」** をあらかじめ工期内に適切に見込む。
* **土量変化率の考慮（$L$値と$C$値）**:
  * 土は掘削してほぐすと空気を含んで体積が増加し（ほぐし率 $L > 1.0$）、転圧して締め固めると圧縮されて体積が減少する（締固め率 $C < 1.0$）。
  * ダンプトラックの手配台数や残土処分場への搬出量、埋戻し土の調達量は、**必ず「ほぐし土量」や「締固め土量」の変化率を考慮して厳密に算出** する（建設発生土はマニフェストによる適正処分管理を徹底）。

---

### (3) 地下水処理とドライワークの確保

掘削底面が地下水面下にある場合、土粒子が湧水とともに吹き上がる **「ボイリング現象」** や、不透水層が水圧で持ち上がる **「盤膨れ」** が発生し、土留めが崩壊する重大事故を招く。

* **対策工法**:
  * 掘削溝の周囲に集水管を配置して真空吸引排水する **「ウェルポイント工法」** や、深井戸を掘って水中ポンプで揚水する **「ディープウェル工法」** により、あらかじめ地下水位を掘削底面以下に低下させる。
  * 常に掘削溝底面を乾燥状態に保つ **「ドライワーク」** を確立した上で作業を進める。

---

### (4) 土留め工の厳格な安全基準（★労働安全衛生規則・最重要）

掘削溝内での地山崩壊は作業員の生き埋め死亡事故に直結するため、労働安全衛生規則等に基づき、深さに応じた厳格な土留め基準が定められている。

```
【掘削深さに応じる土留め工の基準（★必出）】
① 掘削深さ 1.5 m を超える場合 ──── 「原則として土留め工を施さなければならない。」
                                    （※1.5m未満でも地質が軟弱な場合は簡易土留めを設置）
② 掘削深さ 4.0 m を超える場合 ──── 「鋼矢板（シートパイル）や親杭横矢板等を用い、
   （または軟弱地盤での深掘削）      必ず構造計算（許容応力度・根入れ長検討）に基づく確実な
                                     土留め工・切梁・腹起しを施工しなければならない。」
```

```
【主な土留め工法の形式】
・簡易土留め工 ────── 軽量アルミ矢板や木製矢板に水圧サポート（ジャッキ）を当てる工法（浅層用）。
・親杭横矢板工法 ──── H形鋼を一定間隔で打設（親杭）し、掘削に伴い間に木製横矢板を挟み込む工法（地下水が少ない地盤）。
・鋼矢板工法（シートパイル） ─ 継手を噛み合わせたU形鋼矢板を連続打設する工法（高い水密性と剛性。油圧圧入機サイレントパイラー等で無騒音施工）。
・ライナープレート工法 ─ 深い円形立坑等において、波付けされた鋼製セグメントを内側からボルト組み立てしながら掘り進める工法。
```

## 3. 基礎工の種類と選定基準（テキスト p.201〜202）

構造物の自重、水重量、および地震荷重を安全に下部地盤へ伝達し、不同沈下や転倒を防止するための工法である。

```
【基礎工の分類体系】
［基礎工］
  ├─［直接基礎（浅い基礎）］ ── 地表面近くの良好な支持地盤に底版を直接設置。
  │     ├─ フーチング基礎 ── 柱や壁の直下に逆T字型のコンクリート底版を広げる形式。
  │     └─ ベタ基礎 ──────── 構造物の底面全体を一体の厚いRC耐圧版スラブとする形式（配水池等に多用）。
  │
  ├─［杭基礎（深い基礎）］ ──── 軟弱地盤を貫通し、深部の支持層または摩擦力で支持。
  │     ├─ 支持杭 ────── 杭先端を硬質な支持層（岩盤・密実な砂礫層）に確実に到達させる杭。
  │     └─ 摩擦杭 ────── 先端支持層が極めて深い場合、杭周面と地盤との周面摩擦力で支持する杭。
  │     （杭種：既製コンクリート杭［PHC杭］、鋼管杭、場所打ちコンクリート杭）
  │
  └─［ケーソン基礎］ ──────── 大型中空箱型コンクリート構造物を掘削沈下（取水塔・大深度ポンプ所等）。
```

## 4. コンクリート工法と施工管理基準・打込み時間制限（テキスト p.202〜203）

### (1) 「良いコンクリート」の定義とワーカビリティー

* **要求性能**: 所定の強度、耐久性、水密性を満たし、品質のばらつきが小さく、経済的であること。
* **ワーカビリティー（Workability：施工軟度・作業性）**:
  * 材料分離を起こすことなく、運搬、打込み、締固め、仕上げの各作業が容易かつ確実に行える施工性の度合いを示す。
  * スランプ試験（スランプ値）や空気量試験（一般に $4.5 \pm 1.5\%$）によって品質管理される。

---

### (2) 各プロセスの厳格な施工管理基準

```
【コンクリート施工プロセスの管理基準】
① 材料受入 ──── ポルトランドセメント、清浄な水（★海水は鉄筋腐食のため絶対使用禁止）、塩分皆無の良質骨材。
② 計量・混練 ── レディーミクストコンクリート工場で正確に計量。規定練混ぜ時間の「3倍以上」混練してはならない（骨材破砕防止）。
③ 運搬・打込み ─ 材料分離を防ぎ、外気温に応じた「打込み時間制限（★必出）」を厳守。
④ 締固め ──── 高周波棒状バイブレーターを鉛直に挿入し、連行空気を完全に排除（過振による材料分離に注意）。
⑤ 養生 ────── 打込み後、散水や湿潤マット被覆により所定材齢まで湿潤状態と適正温度（5℃以上）を保持。
⑥ 脱型 ────── 供試体の圧縮強度試験を行い、所定の脱型強度発現を確認してから型枠・支保工を解体。
```

* **運搬から打込み完了までの許容時間制限（★試験最重要数値）**:
  * セメントの水和反応の進行に伴うスランプ低下（硬化開始）やコールドジョイント（継ぎ目欠陥）を防止するため、レディーミクストコンクリートは **練混ぜから打込み完了までの時間** が厳密に規定されている。

```
【コンクリートの打込み許容時間制限（JIS A 5308 / 土木学会示方書）】
・外気温が 25℃ を超える場合（夏期） ─── 練混ぜから「1.5時間以内」に打込み完了。
・外気温が 25℃ 以下の場合（冬期・春秋） ─ 練混ぜから「2.0時間以内」に打込み完了。
```

## 5. 配管布設工法・路面覆工・水圧試験・埋設明示（テキスト p.203〜205）

### (1) 事前試掘調査の鉄則

道路下にはガス、下水、電力、通信などの地下埋設物が極めて稠密に錯綜している。
図面データのみを信じて掘削機械を作動させると、高圧ガス管や光ファイバーケーブルを破損させる大事故を招く。したがって、**本掘削に先立ち、人力掘削等による「試掘調査」を必ず実施し、地下埋設物の正確な埋設位置、深さ、離隔（30cm以上確保等）を目視・実測確認する** ことが配管施工の絶対原則である。

---

### (2) 路面覆工（テキスト p.203）

交通量の多い幹線道路や交差点で開削工事を行う場合、日中や作業終了後に一般交通へ路面を開放するため **「鋼製覆工板」** を設置する。

* **施工法**: 掘削溝の両側に受桁・主桁を架設し、その上に滑り止め加工を施した覆工板を敷き並べ、跳ね上がり防止金具で確実に固定する。
* **効果**: 毎日の土砂埋戻し・仮舗装復旧の手間を完全に省略でき作業効率が劇的に向上するほか、仮復旧アスファルトの段差による二輪車転倒事故を未然に防止する。

---

### (3) 管の運搬・吊り下ろし・外面塗膜保護

* **クレーン吊り下ろし（2点吊りの厳守）**:
  * トラックからの荷降ろしおよび掘削溝内への吊り下ろしは、**必ずナイロンスリングや養生ゴム被覆ワイヤーを用いた「2点吊り」で行う**。
  * **ワイヤー1本による「1点吊り」は、管が傾斜・回転して滑り落ちる致命的な落下事故の原因となるため絶対に禁止** されている。
  * 吊り荷の直下には誘導員を含め作業員を一切立ち入らせない。
* **外面防食塗膜の保護**:
  * 耐食塗装が施されたGX形ダクタイル鋳鉄管等は、地表で管を引きずったり、作業員が安全靴で管上を踏み歩いたりして外面塗膜を傷つけてはならない。万一傷がついた場合は、指定の外面補修塗料で即座に補修する。

---

### (4) 配管・接合の実務

* **配管順序（低い方から高い方へ）**:
  * 管路の敷設は、**原則として「低い方から高い方へ」向かって布設** する。
  * これにより、将来の充水・通水作業において、管内の空気が高所に向かってスムーズに自然排気され、エア溜まりによるウォーターハンマーや白濁水を防止できる。
* **ボルトの締付け管理（対角線締め）**:
  * メカニカル継手やフランジ接合のボルト・ナット締め付けは、一箇所を集中的に締め込むとゴム輪（ガスケット）が偏圧変形して漏水の原因となる。
  * 必ず **トルクレンチを用いて、規定トルク値に達するまで「対角線上の順番」に何段階かに分けて均等に締め込む**。

---

### (5) 既設管との連絡（切回し・断水）と濁水対策

* **断水連絡工事の標準手順**:

$$\text{仕切弁閉止} \longrightarrow \text{断水確認} \longrightarrow \text{既設管切断・撤去} \longrightarrow \text{管内清掃} \longrightarrow \text{連絡管据付・接合} \longrightarrow \text{スラスト防護} \longrightarrow \text{緩速充水・洗管・通水}$$

* **流向・流速の変化と濁水（赤水）対策**:
  * 連絡工事で管網を切り替えると、水流の方向が逆転したり流速が急増したりするため、管底に長年沈着していた錆粉やマンガンが巻き上げられて大規模な赤水事故が発生しやすい。
  * 事前の水理計算シミュレーションに基づき、影響を受ける住民へ広報チラシを配布し、通水時には近隣の消火栓や排水弁を開放して十分な洗管放水を行う。
* **不断水工法**: 断水が不可能な重要路線では、専用の不断水穿孔機を用いて水圧がかかったまま分岐管を取り出す「不断水分岐工法」や「不断水弁挿入工法」を適用する。

---

### (6) 異形管防護（スラストブロックと一体化長工法）

曲管（ベンド）、T字分岐管、管末部（仕切弁全閉時）には、管内水圧と運動量変化により管路を外側へ押し抜こうとする強大な「スラスト力（不平均力 $P$）」が発生する。

$$P = 2A \cdot p \cdot \sin\left(\frac{\theta}{2}\right) \quad (A:\text{管断面積},\; p:\text{水圧},\; \theta:\text{曲がり角度})$$

* **スラストブロック（コンクリート防護）**:
  * 異形管の背後（外側）の地山との間にコンクリートを打設し、地盤の受働土圧によってスラスト力に抵抗させる。
* **一体化長工法（防護コンクリートの縮減）**:
  * 異形管の前後に連続する直管の受口に **「スラストキー（専用ライナー）」** を装着して伸縮の遊びをロックし、複数本（数本〜十数本）の直管を剛結一体化させる。
  * これにより、直管外周面と周囲土壌との摩擦力でスラスト力に抵抗させ、打設困難な狭隘道路等における防護コンクリートの打設量を大幅に縮減または省略できる。

### (7) 水圧試験と管の二重明示（★最重要確認事項）

* **水圧試験の実施**:
  * 配管完了後、埋め戻しを行う前に、管路内に規定の試験水圧（**設計静水圧の1.5倍等、最低 $0.75\text{ MPa}$ 以上**）を一定時間（15分〜数時間）保持し、圧力降下（漏水）がないことを水圧試験器で確認・記録する。合格しなければ埋戻しは許可されない。
* **管の二重明示工法（他企業事故防止義務）**:
  * 道路管理者基準に基づき、将来の他企業（ガス・下水・電線等）による誤掘削・破損事故を防止するため、以下の二重明示を義務付ける。

```
【配水管の二重明示工法】
① 明示テープ ─── 配管本体の外周に直接、「水道（事業体名）」と明記した「青色テープ」を巻き付ける。
② 明示シート ─── 埋戻し土の途中（管頂から上方「約 30 cm」の位置）に「青色埋設標識シート」を連続敷設。
                  （※他企業のバックホウの爪がシートを引っ掛けることで、直下に水道管があることを覚知させる）
```

* **ポリピグ洗管工法**:
  * 新設管路の供用開始前には、管内に砲弾型のウレタン製スポンジ弾（ポリピグ）を装填し、水圧で管路内を走行させて管内面の土砂、切粉、スライムを掻き取り排出し、清潔な管路を確保する。

## 6. 特殊工法（非開削工法・更生工法・更新工法）（テキスト p.205〜206）

都市部の過密道路、軌道（鉄道）下横断、河川横断、大深度横断など、路面を開削できない条件下では特殊工法を採用する。

```
【管路の特殊工法体系】
［非開削新設工法］
  ├─ シールド工法 ─── 立坑からシールド掘進機で掘進し、機内でセグメントを環状に組み立ててトンネルを築造。
  │                    内部に大口径水道管を布設（大口径・長距離・大深度）。
  └─ 推進工法 ───── 発進立坑の油圧ジャッキで、先頭掘進機と後続管（推進管）を地中へ同時に圧入・押し込む。
                       （小中口径・短中スパン［数十〜200m］に適し、シールドより安価）。
［管路改良工法］
  ├─ 更生工法（非掘削内面再生） ─ ホースライニング工法（内面錆コブ研磨後、熱硬化性樹脂含浸ホースを
  │                              反転・温水加熱硬化させ、新管同等の平滑内壁を再生）。
  └─ 更新工法（パイプインパイプ工法） ─ 既設管をさや管として利用し、内部に一回り細い新管を引き込み、
                                       空隙にセメントミルク等の間詰め材を注入充填。
```

## 7. 工事管理の4大要素と安全衛生・公害防止対策（テキスト p.206〜208）

### (1) 施工管理の4大要素（PDCAサイクル）

土木工事の円滑な遂行には、計画（Plan） $\rightarrow$ 実施（Do） $\rightarrow$ 確認（Check） $\rightarrow$ 改善（Action）の管理サイクルを回し、以下の4要素を調和させることが不可欠である。

```
【施工管理の4大要素】
① 工程管理（Time） ── クリティカルパス工程表、進捗管理、遅延防止、工期遵守。
② 品質管理（Quality） ─ 材料試験、スランプ・空気量試験、水圧試験、出来形寸法管理。
③ 原価管理（Cost） ── 実行予算管理、歩掛管理、無駄な資材・重機回送ロスの排除。
④ 安全管理（Safety） ─ 労働災害ゼロ、公衆災害ゼロ、危険予知活動（KYK）、保護具着用。
```

---

### (2) 安全衛生管理と労働災害防止

* **法規順守**: 労働安全衛生法、酸素欠乏症等防止規則、道路交通法、建設業法。
* **地下ピット・立坑の安全対策（酸欠・硫化水素防止）**:
  * 深度のある立坑や管内作業では、入坑前に **必ず複合ガス検知器で酸素濃度（$18\%$ 以上確保）、硫化水素濃度（$10\text{ ppm}$ 以下）、可燃性ガスを測定** する。
  * 作業中は **可搬式送風機（ファン）による連続機械換気** を行い、地上に監視員を常駐配置する。
* **クレーン作業と玉掛け**: 有資格者による玉掛け、指差し合図の統一、旋回半径内立入禁止フェンスの設置。

---

### (3) 公害防止対策（環境保全）

* **騒音・振動防止（騒音規制法・振動規制法）**:
  * 低騒音型・低振動型建設機械（排ガス対策型バックホウ、油圧圧入機サイレントパイラー等）の使用。
  * 破砕作業における防音シート・遮音ボックスの設置、夜間静音作業の徹底。
* **濁水・粉じん対策**:
  * 洗管排水や掘削湧水は、直接側溝や河川へ流さず、中和槽・沈殿槽（仮設ノッチタンク）を通して浮遊物質（SS）を沈降させ、中和処理を行ってから排水する。
  * 仮復旧路面には定期的な散水を行い、散乱土砂を清掃して粉じんの飛散を防止する。

## 9. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：土留め工の安全基準）
* **問題形式**: `choice`
* **問題文**: 労働安全衛生規則等に基づく掘削工事における土留め工の施工基準に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 掘削深さが1.5mを超える場合は原則として土留め工を施さなければならない
  2. 掘削深さが10mを超える場合であっても構造計算に基づく土留め工は不要である
  3. 砂質地盤の掘削では深さに関わらず土留め工の設置は法令で全面的に禁止される
  4. 掘削深さが2m未満の現場では作業員の安全帯着用があれば土留め工を省略できる
* **正解**: 1（インデックス: 0）
* **解説**: 労働安全衛生規則等において、掘削深さが $1.5\text{ m}$ を超える場合は地山崩壊による作業員の土砂埋没事故を防ぐため、原則として土留め工を施さなければなりません。また深さ $4.0\text{ m}$ を超える場合や軟弱地盤では鋼矢板等を用い、構造計算に基づく強固な土留め・切梁工を施工することが義務付けられています。
* **日常のたとえ**: 砂場で深い穴を掘ると大人の腰の高さ（約1.5m）を超えたあたりで壁が突然ドサッと崩れてくるのと同じで、壁が崩れて人が埋まらないように板や鉄板でしっかり支え板をする安全ルールです。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.201／労働安全衛生規則

### 設問2（4択：コンクリートの打込み時間制限）
* **問題形式**: `choice`
* **問題文**: レディーミクストコンクリートの運搬から打込み完了までの許容時間制限に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 外気温が25℃を超える夏期等は練混ぜから1.5時間以内に打込みを完了する
  2. 外気温が25℃以下の冬期等は練混ぜから5時間以上経過後に打込みを開始する
  3. コンクリートの練混ぜ水として塩分を含む海水を積極的に用いて強度を高める
  4. 規定練混ぜ時間の5倍以上長時間練り混ぜることで骨材を微粉砕して均質化する
  5. 外気温に関わらず練混ぜから打込み完了までの許容時間は一律12時間である
* **正解**: 1（インデックス: 0）
* **解説**: コンクリート標準示方書およびJIS規格において、練混ぜから打込み完了までの許容時間は、外気温が $25^\circ\text{C}$ を超える場合は「1.5時間以内」、$25^\circ\text{C}$ 以下の場合は「2.0時間以内」と規定されています。海水の使用は鉄筋腐食のため絶対禁止であり、長時間の練り混ぜは骨材破砕を招くため禁止されています。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.202〜203

### 設問3（4択：配管布設の実務基準）
* **問題形式**: `choice`
* **問題文**: 配水管布設工事における施工実務および安全管理に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. クレーンによる管の吊り下ろしはバランスを保つため必ず2点吊りで行う
  2. 配水管の敷設方向は管内の空気を閉じ込めるため高い方から低い方へ布設する
  3. フランジ継手のボルト締め付けは円周に沿って時計回りの順序で一気に締め込む
  4. クレーン作業中は作業効率を高めるため吊り荷の直下に作業員を待機させる
* **正解**: 1（インデックス: 0）
* **解説**: 管のクレーン荷降ろし・吊り下ろしは、傾斜や滑落事故を防ぐため必ずスリング等を用いた「2点吊り」で行います（1点吊りは禁止）。配管は充水時の空気抜けを良くするため「低い方から高い方へ」布設し、継手ボルトは偏圧漏水を防ぐためトルクレンチで「対角線上の順番」に均等締めします。吊り荷直下への立入は厳禁です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.203〜204

### 設問4（4択・否定形：水道管埋設と他企業事故防止）
* **問題形式**: `choice`
* **問題文**: 道路下における配水管布設および他企業事故防止対策に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 埋設明示シートはバックホウ覚知のため管頂から上方10mの位置に埋設する
  2. 本掘削の着手前に人力掘削等による試掘調査を行い埋設物の正確な位置を確認する
  3. 他企業掘削による誤破損を防ぐため配管本体に青色の明示テープを巻き付ける
  4. 埋戻し土の途中である管頂から約30cm上方に青色埋設標識シートを敷設する
* **正解**: 1（インデックス: 0）
* **解説**: 埋設明示シートの敷設深さは、後年の他企業工事（ガス・下水等）の掘削機械（バックホウ）が管に到達する前にバケットの爪で引っ掛けて覚知できるよう、「管頂から約 $30\text{ cm}$ 上方」に設置します。上方10mとする記述は誤りです。試掘調査の実施や管体青テープ巻き付けは適切な施工実務です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.203〜205

### 設問5（4択：非開削工法と更新技術）
* **問題形式**: `choice`
* **問題文**: 開削工事が困難な交差点や河川横断部等に適用される特殊工法に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 推進工法は発進立坑の油圧ジャッキで掘進機と推進管を地中へ同時に圧入する
  2. シールド工法は小口径かつ数メートルの極めて短いスパンの配管にのみ適用される
  3. ホースライニング工法は老朽化した既設管を地上へ全て掘り出して撤去する工法である
  4. パイプインパイプ工法は既設管の内径よりも太い大口径新管を無理に圧入する工法である

* **解説**: 推進工法は、発進立坑に据えた油圧ジャッキの推進力により、先頭の掘進機と後続の推進管を同時に地中へ押し込む非開削工法であり、小中口径・短中スパンに適しています。シールド工法は大口径・長距離トンネル向けであり、ホースライニング工法は非掘削の内面樹脂ライニング工法、PIP工法は既設管内に一回り細い新管を通す工法です。
