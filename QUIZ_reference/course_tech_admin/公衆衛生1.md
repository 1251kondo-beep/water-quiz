## 2. 公衆衛生の定義と水道の役割

### (1) 公衆衛生の基本概念
* **定義（ウィンズロー教授 / 1920年・米エール大学）**:
  > 「共同社会の組織的な努力を通じて、疾病を予防し、寿命を延長し、身体的・精神的健康と能力の増進を図る科学であり技術である」
  * ※WHO（世界保健機関）も1949年に同様の定義を採用。
* **主な領域**: 環境保健、疾病予防、衛生行政など。

### (2) 疾病予防の3段階（リーベル＆クラーク / 1953年）
| 予防区分 | 定義・目的 | 具体例・水道の役割 |
| :--- | :--- | :--- |
| **一次予防（発症予防）** | 健康増進・環境改善による発症自体の防止 | **上水道・下水道の整備（環境整備）**、健康増進、予防接種 |
| **二次予防（早期発見・早期治療）** | 発症後の早期スクリーニングと悪化防止 | 健康診断、定期検診、臨床検査 |
| **三次予防（重症化防止・社会復帰）** | 機能低下防止と社会復帰支援 | 合併症予防、リハビリテーション |

* **水道の位置づけ**: 安全な飲料水の供給は、疾病予防の最上流に位置する**「一次予防（環境整備）」**の最重要インフラです。

### (3) 水道法第1条における目的
> 「この法律は、水道の布設及び管理を適正かつ合理的ならしめるとともに、水道の基盤を強化することによつて、清浄にして豊富低廉な水の供給を図り、もつて公衆衛生の向上と生活環境の改善とに寄与することを目的とする。」

* **所管官庁の移管**: 水道が公衆衛生を直接の目的とするため長年「厚生労働省」が所管していましたが、**令和6年（2024年）4月1日より「国土交通省」（事業・インフラ・管理）および「環境省」（水質基準・水源保全）へ移管**されました。
* **基盤強化への転換**: 平成30年（2018年）の法改正により、従来の「計画的な整備・事業育成」から「人口減少等を踏まえた基盤強化」へと重点が法文上シフトしています。

## 3. 疫学の基礎と近代水道の歴史

### (1) 疫学の役割とジョン・スノーのコレラ調査（1854年）
* **疫学の定義（ラスト）**: 健康関連の状態・事象の集団における分布や決定要因を研究し、健康問題の予防・管理へ応用する学問。
* **ロンドン・ブロードストリートのコレラ大流行（1854年）**:
  * **当時の医学常識**: コレラは悪臭や汚染された空気から感染するという「瘴気説（しょうきせつ）」が信じられていた（細菌説やロベルト・コッホによるコレラ菌発見より前の時代）。
  * **スノー医師の調査手法**: 
    1. 死亡者の発生場所をロンドン市街地図上にプロット（マッピング）。
    2. 発症者の聞き取り調査と、給水会社（サウスウォーク社・ボクスホール社等）ごとの水源と死亡率の統計的相関を分析。
  * **結論と対策**: 特定の水源から取水していた「ブロードストリートの公共ポンプ井戸」が汚染源であることを突き止め、**ポンプのハンドルを取り外して井戸を物理的に閉鎖**。流行の終息に成功した。
  * **歴史的意義**: 病原微生物が未解明であっても、緻密な状況観察と統計的分析（疫学的手法）によって感染症の蔓延を防止できることを実証し、**「近代疫学の祖」**および安全な近代水道整備の契機となりました。

### (2) 日本における近代水道の歩み
* **近代水道の3要件**:
  1. ろ過等の浄水処理を行った水であること
  2. 外部からの汚染を防ぐ密閉された管路を用いること
  3. 連続的かつ圧力を保って（有圧）個別給水すること
* **日本の普及率**: 令和5年度末時点で全国 **98.2%**（※101人以上の給水規模等）。
* **横浜水道の創設（明治20年 / 1887年）**: 開港に伴うコレラ等の水系感染症流行を受け、英人技師ヘンリー・スペンサー・パーマーの設計監理により**日本初の近代水道**が開通。
* **塩素消毒の義務化**: 第二次世界大戦後、GHQの指令等を契機に本格導入。昭和32年（1957年）の現行水道法制定により給水栓における残留塩素保持が義務付けられ、水系感染症や乳児死亡数が激減しました。

## 4. 衛生行政組織と保健所の連携

### (1) 衛生行政の3大体系（憲法第25条に基づく国家義務）
1. **一般衛生行政**: 地域住民の健康保持増進・環境衛生。**保健所**が中心となって所管。
2. **労働衛生行政**: 労働者の健康確保・作業環境管理。**労働基準監督署**などが所管。
3. **環境保健行政**: 公害対策・地球環境保全。**環境省**が推進。

### (2) 保健所と水道事業者の連携実務
* **水質異常・水系感染症発生時の初動連携**:
  * 水質異常やクリプトスポリジウム等の病原体汚染が疑われる場合、直ちに衛生部門（保健所等）と緊密に連携。
  * *実例*: 平成8年（1996年）の埼玉県越生町におけるクリプトスポリジウム集団感染事故では、町内小学校の異常な欠席者数急増を保健所がいち早く察知したことが事故発覚の発端となった。
* **小規模貯水槽水道（受水槽）の衛生管理指導**:
  * 水道法上の簡易専用水道（受水槽有効容量10立方メートル超）から外れる、**有効容量10立方メートル以下の受水槽施設**について、自治体の条例・要綱に基づき保健所等と連携して適正管理を指導。
  * *指導基準*: 年1回以上の受水槽清掃、施設定期点検、関係図書・記録の保管、必要に応じた水質検査等。

## 5. 健康危機管理体制

### (1) 健康危機管理の枠組み
* 事件・事故、自然災害、テロ等による飲料水水質被害に対応するため、厚生省（当時）が平成9年に「健康危機管理基本指針」を策定。飲料水は主要対象分野の一つに明確に位置付けられています。
* 省庁移管に伴い、現在は**「国土交通省 飲料水健康危機管理実施要領」**（令和6年7月1日制定）に基づき運用。

### (2) 国土交通省への重大事象報告基準（『業務必携』p.177〜 / 令和7年4月3日付 課長通知）
水道事業者は、以下の事象が発生した場合、速やかに国へ直接情報提供を行う必要があります。

1. **浄水の遊離残留塩素が 0.1 mg/L 未満となった場合**
2. **一般細菌、大腸菌、シアン化合物、水銀等について基準値を超過した場合**
3. **水質基準項目（健康関連項目1〜32を除く項目）における基準超過の継続**
4. **その他これらに準ずる水質異常（水質管理目標設定項目の超過継続が見込まれる場合など）**
5. **自然災害・異常渇水等による断水・主要施設被害の発生情報**

## 6. 水源の現況と水質汚染事故・異臭味問題

### (1) 日本の水源内訳（令和5年度）
* **表流水（河川・ダム等）**: 全体の**約4分の3（約75%）**
* **地下水・伏流水・井戸等**: 全体の**約4分の1（約25%）**
* *近年の傾向*: 総取水量は人口減少や節水機器普及に伴い減少傾向にある一方、自流河川からダム放流水への依存割合が増加しています。

### (2) 水質汚染事故の傾向と対策
* **発生状況**: 年間150〜200件程度で高止まり（令和5年度は151事業体が被害）。
* **事故原因物質**: **油の流出事故が全体の6割以上**を占める。
* **応急対策**: 取水停止、オイルフェンスの展張、オイルマット（ポリプロピレン等不織布）による吸着回収。
* **課題**: 原因不明（夜間の不法投棄や不審流出など原因者追跡困難）の割合が高く、取水地点での常時監視（魚類監視・水質計器）と流域自治体・消防等との連携が不可欠。
* **過去の重大事例**:
  * **平成24年（2012年）5月 利根川水系ホルムアルデヒド事故**: 産業廃棄物処理業者が排出したヘキサメチレンテトラミン（合成樹脂原料）が河川に流入。浄水場の塩素処理過程で反応し高濃度のホルムアルデヒドを生成。1都4県・8浄水場で取水停止・減水、千葉県等で大規模断水を引き起こした。

### (3) 生物由来の異臭味問題
* **発生機構**: 水源（湖沼・ダム・緩速河川等）の富栄養化や高水温に伴い、植物プランクトン（藍藻類・アナベナ、ミクロキスティス、オシラトリア等）が異常繁殖。
* **代表的異臭味物質**:
  * **ジェオスミン（Geosmin）**: 土臭・泥臭（藍藻類や放線菌が産生）
  * **2-MIB（2-メチルイソボルネオール）**: カビ臭（藍藻類が産生）
* **現況**: 令和5年度の異臭味影響人口は約214万人。従来のダム・湖沼だけでなく、河川流水部の付着藻類・着生藻類による発生事例も報告されています。粉末活性炭注入や高度浄水処理（オゾン＋粒状活性炭）により対応。

## 7. 水質基準体系の変遷と最新動向

### (1) 水質基準の歴史と体系
* **変遷**: 平成4年（1992年）以前は30項目未満だったが、平成5年12月施行の大改正で46項目へ拡充。
* **逐次改正方式**: 平成15年（2003年）以降は従来の10年周期の見直しを改め、最新の毒性知見や検出実態に応じて機動的に見直す「逐次改正方式」を導入。
* **最新の体系（全52項目）**:
  1. **人の健康に関する項目（32項目）**: 重金属、シアン、有機化学物質、消毒副生成物、PFOS/PFOAなど。
  2. **水道水が有すべき性状に関する項目（20項目）**: 色度、濁度、匂い、味、pH、残留塩素等生活利用上の支障防止。

### 水質管理の4層カテゴリー
| 区分 | 根拠・法的性格 | 義務・対応方針 |
| :--- | :--- | :--- |
| **水質基準項目（52項目）** | 水道法第4条に基づく厚生労働省令（現・環境省令）基準 | **完全遵守義務・定期検査義務**（超過時は給水停止や改善措置が必要） |
| **水質管理目標設定項目** | 将来の基準化や管理上留意すべき項目（目標値設定農薬115種を含む） | **努力義務・定期モニタリング**（評価値の算出・監視） |
| **要検討項目** | 毒性評価や国内検出知見が不十分な物質 | 国レベルでの調査・データ集積 |
| **浄水処理対応困難物質** | 通常の浄水処理で除去困難で、塩素と反応して有害物質を生成する物質 | 利根川ホルムアルデヒド事故を機に指定。排出源・流域機関連携 |

### (2) 有機フッ素化合物（PFAS：PFOS / PFOA）
* **特性**: 炭素骨格にフッ素原子が強固に結合した有機化合物（PFASは約1万種以上の総称）。撥水性・撥油性・耐熱性・化学的安定性に極めて優れる。泡消火薬剤、フッ素樹脂加工、半導体等に広く使用。
* **環境・健康懸念**: 自然界で極めて分解されにくく（「永遠の化学物質」）、生体内蓄積性と長距離移動性を持つ。
* **国内規制動向**:
  * 化審法（化学物質審査規制法）により、PFOS（2010年）、PFOA（2021年）の製造・輸入が原則禁止。
  * **令和8年4月より、水質管理目標設定項目（暫定目標値50ng/L）から「水質基準項目」（基準値：PFOS及びPFOAの量の和として 50 ng/L 以下）に格上げ施行**。
* **除去技術**: 粒状活性炭（GAC）吸着処理、イオン交換樹脂処理、逆浸透（RO）膜処理が有効。

### (3) 化学物質の総数と管理の難しさ
* **CAS登録番号**: 世界で登録されている化学物質は3億件を突破。
* **工業生産物質**: 約10万種（労働安全衛生法の名称等公表物質は約7万3,000種、リスクアセスメント・SDS交付義務対象は約2,900物質）。
* **農薬**: 国内有効成分ベースで約500〜600種。
* **水道管理への示唆**: 膨大な化学物質のすべてを末端で検査することは不可能なため、水源保全、水安全計画（WSP）、流域連携による統合的アプローチが不可欠。
