## 1. 水道資材の基準と選定方針（テキスト p.209〜213）

水道資材は、一度布設・設置されると数十年から100年以上にわたり地下や施設内で供用され、国民の生命・健康に直結する飲料水を輸送・貯留する。

### (1) 法的根拠と性能要件（水道法第5条および技術的基準省令）

水道法第5条において、水道施設および使用資材の構造要件が厳格に定められている。

> **水道法第5条（施設基準）抜粋**  
> 「水道施設は、原水の質及び量に応じて、清浄にして豊富低廉な水の供給を確実ならしめるため、…次に掲げる要件を備えなければならない。  
> 一　その位置は、原則として、清潔な場所でなければならない。  
> 二　**その構造は、水圧、土圧、地震力その他の荷重に対して十分な耐力を有し、かつ、水が汚染され、又は漏れるおそれがないものでなければならない。**」

さらに、「水道施設の技術的基準を定める省令」第4条において、管路および施設に使用する資材の具体的な性能要件が規定されている。

```
【水道用資機材に求められる5大基本要件】
① 耐荷重性・耐力 ──── 自重、内水圧、外土圧、活荷重（交通荷重）、地震力、水撃圧に対する構造耐力。
② 水密性・耐漏水性 ── 継手や管体から水が一切漏洩せず、外部からの地下水・汚水の浸入を阻止する性能。
③ 水質安全性（浸出性） ─ 飲料水と接触しても有害物質が溶出せず、味・臭気・色度・濁度に影響を与えない性能。
④ 耐久性・耐食性 ──── 水および周辺土壌・地下水・大気による腐食・経年劣化に対する長期抵抗性。
⑤ 施工性・維持管理性 ─ 現場での接合・据付が確実で、点検・補修・操作が安全かつ容易に行えること。
```

### (2) 規格体系（JIS規格とJWWA規格の相互補完関係）

水道資材の品質と互換性を保証するため、国家規格と専門団体規格が併用されている。

* **JIS規格（日本産業規格・Japanese Industrial Standards）**:
  * 経済産業省（日本産業標準調査会：JISC）が制定する国家規格。
  * 鉱工業品の品質改善、生産効率化、取引の単純公正化、互換性の担保を目的とする。
* **JWWA規格（日本水道協会規格・Japan Water Works Association Standards）**:
  * 公益社団法人日本水道協会が制定する団体規格。
  * **水道事業の極めて高度な水質保全性、耐震性、耐水圧性、現場施工性の実務要求に即し、JIS規格を補完・拡充した実務規格** である。
  * 日本水道協会の厳格な検査に合格した資器材には **「JWWA認証マーク（検査証印）」** が付与され、事業体の工事仕様書において標準指定される。

## 2. 水道用管種の特徴と変遷（テキスト p.213〜218）

### (1) 普通鋳鉄管（CIP）の脆性と早期全廃への道

* **普通鋳鉄管（ねずみ鋳鉄管・CIP）の構造的欠陥**:
  * 明治・大正から昭和初期にかけて日本の近代水道の黎明期を支えた主要管種。
  * 溶融鉄が冷え固まる際、炭素が **「片状黒鉛（薄片状のグラファイト）」** として析出する。
  * この片状黒鉛が金属地金内部で無数の微小な「切れ目（切欠き）」として作用するため、**引張力や衝撃曲げ応力を受けると粘り（伸び）が全くなく、ガラスのように脆性割れ・破断を起こす致命的な弱点** があった。
* **全国的な撲滅推進と事故事例**:
  * 地震動、地盤沈下、大型車交通荷重による破断・道路陥没事故の主原因であり、現在は製造されていない。
  * 近年でも、京都駅前の幹線道路下で昭和初期に布設された普通鋳鉄管が突然大破断し、駅前一帯が大規模冠水・断水する事故が発生した。
  * 国土交通省の耐震化推進施策に基づき、全国の事業体で最優先の更新・全廃が進められている。

---

### (2) ダクタイル鋳鉄管（DIP・テキスト p.215 ★超重要ポイント）

普通鋳鉄の脆さを克服するため、溶湯にマグネシウム（Mg）やセリウム（Ce）を微量添加し、**黒鉛を「球状」に結晶化させた革新的な鋳鉄管（球状黒鉛鋳鉄管）** である。

```
【ダクタイル鋳鉄管（DIP）の4大特徴（テキスト p.215★必出項目）】
① 耐食性が極めて大きい ──────── 鋳鉄本来が持つ優れた耐食性をそのまま保持している。
② 管体自体が極めて強靭である ───── 鋼（スチール）に匹敵する高い引張強度、耐衝撃性、耐水圧性を発揮。
③ 各種の継手（耐震継手等）が豊富 ── 施工性に優れ、直線・曲がり・不同沈下など応用範囲が極めて広い。
④ 維持管理上の安全性が高い ────── 経年劣化が少なく、長期間にわたり安全・安定した給水を維持できる。
```

* **内外管防食塗装の進化**:
  * **内面塗装**: 平滑性が高く赤水防止性能に優れる「エポキシ樹脂粉体塗装」が現在の標準（モルタルライニング管も併用）。
  * **外面防食**: 合成樹脂塗装、耐食性特殊塗装、および **「ポリエチレンスリーブ被覆（厚さ0.2mm）」**（土壌と管体を物理的・電気的に完全遮断する最も経済的で強固な防食工法）。

## 3. ダクタイル鋳鉄管の継手形式（耐震継手と非耐震継手・テキスト p.218〜221）

水道実務において「耐震管」とは、管体材料そのものではなく、**「管路の継手が耐震性能（伸縮・可とう・離脱防止機能）を備えているか」** によって厳格に定義される。

```
【ダクタイル鋳鉄管継手の体系】
［ダクタイル鋳鉄管継手］
  ├─［非耐震継手］ ── 抜け出し防止機構（ロックリング）なし。新設基幹管路では原則不採用。
  │     ├─ K形継手 ── メカニカル継手。受口と挿し口の間にゴム輪を挟み、押輪とボルトで締め付ける。遊びなし。
  │     └─ T形継手 ── タイトン継手。受口内にゴム輪を装着し、挿し口を滑り込ませるプッシュオン型。施工容易。
  │
  ├─［耐震継手］ ──── 「伸縮性・可とう性・離脱防止機構」を兼ね備え、大地震の地盤変動に追従。
  │     ├─ NS形継手 ── 受口内にロックリングを内蔵し挿し口突部と噛み合わせる。離脱防止力 3D kN（プッシュオン式）。
  │     ├─ GX形継手 ── 最新の主力耐震継手。ロックリングホルダー内蔵、現場組み立て不要、外面高耐食自己修復塗装。
  │     ├─ S形 / US形 ─ 大口径管用の耐震継手。大きな伸縮量と曲げ角度を有し幹線管路に適用。
  │     └─ P2形 / PN形 ─ 既設管内へ引き込むパイプインパイプ（PIP）工法専用の耐震継手。
  │
  └─［フランジ継手］ ── 管端フランジ同士をガスケットを挟んでボルト直結する剛結継手（弁類・弁栓類との接続専用）。
        ├─ RF形 ────── 全面座（平面ガスケット）を使用。
        └─ GF形 ────── 溝形ガスケット（溝にゴムリングがはまり込む構造）を使用。
```

* **NS形とGX形の違い**:
  * **NS形**: 現場でゴム輪をセットし、挿し口突部にロックリングを嵌め込んで接合する。
  * **GX形**: 工場出荷時にロックリングと樹脂製ホルダーが受口内に組み込まれているため、**現場でのパーツ組み立て作業が一切不要で、挿し口を押し込むだけで瞬時に耐震接合が完了** する。施工速度・安全性が飛躍的に向上した。

## 5. バルブ類（弁類・弁栓類）の多面的分類体系（テキスト p.228〜230 ★超重要ポイント）

管路内の水流を「止める（遮断）」「絞る（流量調整）」「減らす（減圧）」「抜く（空気・泥吐き）」ために配置される機械設備である。

### (1) バルブの5大多面的分類（★試験最重要）

テキスト p.228〜229 に記載されたバルブの分類法は、**試験で多角的に問われる最重要項目** である。

```
【バルブの多面的な分類体系】
① 構造（作動原理）による分類 ─ 仕切弁（ゲート弁）、バタフライ弁、逆止弁（チャッキ弁）、フロート弁、減圧弁、安全弁
② 据付け方向による分類 ──── 立型（通常の鉛直設置）、横型（大口径で土被りが不足する場合に採用）
③ 継手形状による分類 ────── フランジ形、受口形、挿し口形、ねじ込み形
④ 開閉動力方式による分類 ─── 手動弁（キャップ・手回しハンドル）、電動弁、空気圧作動弁、油圧作動弁
⑤ 付属設備（弁栓類） ────── 空気弁（急速空気弁）、消火栓（単口・双口）
```

---

### (2) 主要バルブの構造的特徴と実務上の留意点

* **1. 仕切弁（ゲート弁）**:
  * 流路に対して直角に弁体（くさび状の板）が上下昇降する構造。
  * **長所**: 全開時に弁体が流路から完全に退避するため、**圧力損失（水頭損失）が極めて小さく、完全止水・遮断性に最も優れる**。
  * **短所**: 大口径になると弁箱・スピンドルが高くなり、土被りが不足して道路上に飛び出す恐れがある。この場合は **「横型仕切弁」** を採用する。
  * **ソフトシール仕切弁**: 弁体をゴムライニングし、弁座底部の溝をなくした構造。砂や錆の噛み込みによる止水不良を防止する。
* **2. バタフライ弁**:
  * 流路内に配置された円盤状の弁体が、弁軸を中心に90度回転して開閉する構造。
  * **長所**: 面間寸法（厚み）が極めて薄く、軽量・コンパクト。大口径の流量調整弁や配水池流出弁に多用される。
  * **★実務上の重大留意点（ポリピグ洗浄との干渉）**:
    * **バタフライ弁は「全開状態」であっても、流路の中央に円盤状の弁体が板の厚みとして残る**。
    * したがって、**管内洗浄用のポリピグ（ウレタンスポンジ弾）を通水走行させると、ポリピグが弁体に激突して管路が完全に閉塞し、弁体が破損する**。
    * **ポリピグ洗浄を実施する配管区間には、絶対にバタフライ弁を設置してはならない（仕切弁を設置する）**。
* **3. 急速空気弁**:
  * 管路の頂部（高所）に設置され、充水時の大量排気、通水時の微量排気、および断水・管破損時の大量吸気（管の負圧座屈防止）を1基で自動的にこなす。
* **4. 消火栓と「補修弁」の併設**:
  * 消火栓や空気弁は、配水管から立ち上げたフランジ部に取り付けられるが、**その直下には必ず手動ボール弁構造の「補修弁」を併設する**。
  * 補修弁を閉じることで、**配水本管を断水させることなく、地上部の消火栓や空気弁の取り替え・点検・補修工事が可能** となる。

### 【第2の超重要項目】コンクリートの長所と短所（テキスト p.193）

```
★ 講義指定内容（長所・短所の対比）：
・長所： 形状寸法の自由度、材料の入手・施工性、諸耐性（耐火・耐水・耐震）、強アルカリ性による鉄筋防食保護。
・短所： 自重が大きい（2.3〜2.4 t/m³）、圧縮強度に比べて「引張強度・曲げ強度が著しく小さい（約1/10）」、
         水和熱や乾燥収縮によるひび割れの発生、硬化後の補修・解体（取り壊し）が困難。
```

```
★ 講義指定数値と管理基準：
・基準強度： 標準養生を行った「材齢28日」の圧縮強度（σck）を管理基準とする。
・骨材の役割： 容積の約7割を占める骨材の品質・粒度分布がコンクリート性能を決定づける。

```

| **仕切弁の特性** | **全開時圧力損失極小・高遮断性（横型は土被り対策）** | ソフトシール弁の底面溝なし異物噛み込み防止 |
| **バタフライ弁とポリピグ** | **全開時も弁体が流路中央に残るためポリピグ通過厳禁** | ポリピグ激突による管路閉塞・弁破損の防止 |

| **消火栓の補修弁** | **消火栓・空気弁の直下にボール弁構造補修弁を併設** | 本管を断水させずに地上部弁栓類を交換・点検 |

## 8. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：ダクタイル鋳鉄管の特徴）
* **問題形式**: `choice`
* **問題文**: 水道用配水管に使用されるダクタイル鋳鉄管（DIP）の特徴に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 組織中の黒鉛を球状化させることで鋼に匹敵する強靭性と耐食性を持つ
  2. 普通鋳鉄管に比べて引張強度や耐衝撃性が著しく低く割れやすい
  3. 内面塗装やライニングは不要であり常に無塗装のまま布設される
  4. 地震時の地盤変位に追従する耐震継手の種類は一切用意されていない
* **正解**: 1（インデックス: 0）
* **解説**: ダクタイル鋳鉄管は、マグネシウム等を添加して黒鉛を球状化させることで、鋳鉄本来の耐食性を保ちながら、鋼に匹敵する高い引張強度と靭性（粘り強さ）を兼ね備えています。内面にはエポキシ粉体塗装等が施され、NS形やGX形などの優れた耐震継手が豊富に用意されています。
* **日常のたとえ**: 鉛筆の芯のような炭素の粒をトゲトゲの薄片から丸いボール状に変えることで、金属の割れ目をなくし、ハンマーで叩いても簡単には割れない強靭なパイプにしたものです。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.215

### 設問2（4択：管材特性と異種金属接触腐食）
* **問題形式**: `choice`
* **問題文**: 水道配水管および給水管に使用される管材の特性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. ステンレス鋼管を鋳鉄管に接続する際は絶縁継手による絶縁処理が必須である
  2. ステンレス鋼管は腐食しやすいため管の内外面に厚いタール塗装を施す
  3. 硬質ポリ塩化ビニル管は冬期の極めて低い温度下で耐衝撃性が飛躍的に向上する
  4. 配水用ポリエチレン管の継手接合は接着剤を塗布して自然乾燥させる
* **正解**: 1（インデックス: 0）
* **解説**: ステンレス鋼管を鋳鉄管や鋼管等の異種金属と直接接続すると、電位差により相手側金属が急速に腐食（ガルバニック腐食）するため、絶縁継手（絶縁フランジ等）による電気的絶縁処理が必須です。ステンレス管は塗装不要であり、塩ビ管は低温期に脆化し、ポリエチレン管はEF融着接合を行います。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.226〜228

### 設問3（4択・否定形：バルブ類の構造と実務上の留意点）
* **問題形式**: `choice`
* **問題文**: 水道管路に設置される各種バルブの構造および機能に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. バタフライ弁は全開時も弁体が流路中央に残るためポリピグ洗浄区間に適する
  2. 仕切弁は全開時に弁体が流路外へ退避するため圧力損失が極めて小さい
  3. 大口径仕切弁で土被りが不足して弁頭が突出する場合は横型仕切弁を用いる
  4. 消火栓の直下には本管を断水させずに交換点検ができるよう補修弁を設ける
* **正解**: 1（インデックス: 0）
* **解説**: バタフライ弁は全開状態であっても流路の中央に円盤状の弁体が残るため、管内洗浄用のポリピグを通すと弁体に衝突して管路閉塞や弁破損を引き起こします。したがって、ポリピグ洗浄を実施する区間にバタフライ弁を設置してはなりません。全開時の仕切弁の低圧損、横型仕切弁の採用、補修弁の併設はすべて正しい記述です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.228〜230

### 設問4（4択：総復習・コンクリート施工基準）
* **問題形式**: `choice`
* **問題文**: 土木材料としてのコンクリートの性質および施工管理に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. レディーミクストコンクリートは外気温25℃超の環境下では1.5時間以内に打ち込む
  2. コンクリートの引張強度は一般に圧縮強度の約5倍以上と極めて大きい
  3. コンクリートの設計基準強度は打込み直後の材齢1日強度を基準として管理する
  4. コンクリートの練混ぜ水として塩分を含む海水を混合することが推奨される
* **正解**: 1（インデックス: 0）
* **解説**: コンクリートの練混ぜから打込み完了までの許容時間は、外気温が $25^\circ\text{C}$ を超える場合は「1.5時間以内」、$25^\circ\text{C}$ 以下の場合は「2.0時間以内」と規定されています（★超重要項目第3）。コンクリートの引張強度は圧縮強度の「約1/10」しかなく、設計基準強度は「材齢28日」の圧縮強度を基準とし、海水の使用は鉄筋腐食のため絶対禁止です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.193〜194, 202〜203

### 設問5（4択：総復習・埋設管路の明示工法）
* **問題形式**: `choice`
* **問題文**: 道路下における水道配水管の埋設明示工法に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 配管本体への青色テープ巻き付けと管頂約30cm上方への青色シート敷設を行う
  2. 埋設明示シートは他企業の目視確認を避けるため管底の直下に敷設する
  3. 水道管の埋設明示シートは下水道管と同一の茶色のシートを使用する
  4. 配水管本体が耐震管である場合は法令に基づく管の明示工法を一切省略できる
* **正解**: 1（インデックス: 0）
* **解説**: 他企業掘削による水道管の誤破損（他企業事故）を防ぐため、配管本体に直接「青色の明示テープ」を巻き付け、さらに埋戻し土の途中である「管頂から約 $30\text{ cm}$ 上方」に「青色の埋設標識シート」を連続敷設する二重明示が義務付けられています（★超重要項目第4）。下水は茶色、ガスは緑色、電力は橙色など識別されています。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.204〜205
