## 1. 導入：水道技術管理者の法定業務と水道施設体系（テキスト p.189）

水道土木材料・施工法の本題に入る前提として、水道技術管理者（CTO）に課せられた法定職務および水道施設全体の機能体系を整理する。

### (1) 水道法第19条に基づく技術管理者の7大法定責務

水道法第19条第2項に基づき、水道技術管理者は水道の布設・維持管理において以下の業務を一手に統括・管理する法的義務を負う。

```
【水道技術管理者の7大法定責務（水道法第19条第2項）】
① 施設基準適合検査（法第5条） ─── 取水から配水までの全施設が国の構造・技術基準に適合しているかの検査。
② 新設・改造時検査（法第13条第1項） ─ 施設の新設・増設・改造工事完了後、給水開始前の水質・施設検査の実施。
③ 給水装置基準適合確認（法第16条） ─ 需要家の給水装置（屋内配管等）が政令で定める構造・材質基準に適合しているかの確認。
④ 定期水質検査（法第20条） ──── 供給水が法定水質基準（51項目）に適合しているかの定期的な検査管理。
⑤ 従事者の健康診断（法第21条） ── 浄水場等で水や施設に直接接触する作業従事者への定期健康診断（検便等）の実施。
⑥ 衛生上の措置（法第22条） ──── 浄水場の清潔保持、塩素消毒設備の適正運用、施錠・防犯等の衛生保全管理。
⑦ 給水停止・緊急停止（法第23条） ─ 水質汚染事故等により人の健康を害する恐れがある場合の迅速な給水緊急停止判断。
```

### (2) 水道法上の「水道施設」の体系（上流から蛇口まで）

土木材料が適用される水道施設は、水循環のプロセスに応じて以下のように体系化されている。

```
【水道施設の機能体系】
［水源］ ──→ ［取水施設］ ──→ ［導水施設］ ──→ ［浄水施設］ ──→ ［送水施設］ ──→ ［配水施設］ ──→ ［給水装置］
                │              │              │              │              │              │
              取水堰          導水管         着水井         送水管         配水池         給水管
              取水塔          導水渠         沈殿池         送水ポンプ所   配水塔         水道メーター
              深井戸                         ろ過池                        配水本管・支管
```

* **取水施設**: 水源（河川・ダム・地下水）から必要な原水を取り入れる施設（堰、塔、枠、浅井戸・深井戸等）。
* **貯水施設**: 渇水時にも安定取水できるよう原水を貯留する施設（ダム、貯水池）。
* **導水施設**: 取水した「原水」を浄水場まで運ぶ管路・水路（導水管、導水渠）。
* **浄水施設**: 原水を沈殿・ろ過・消毒等により水道水質基準に適合する「浄水」に処理する施設。
* **送水施設**: 浄化された「浄水」を浄水場から各地域の配水池へ送る施設（送水管、送水ポンプ所）。
* **配水施設**: 配水池に貯留した浄水を、給水区域の各需要者へ適切に分配・供給する施設（配水池、配水塔、配水ポンプ、配水本管・支管）。

## 2. 土木材料の分類と基本概念（テキスト p.189〜190）

### (1) 土木材料の定義と過酷な環境条件

土木材料とは、ダム、トンネル、浄水池、配水池、橋梁、道路、埋設管路などの土木構造物を築造・構築するすべての材料の総称である。

* **力学的役割**:
  * 構造物自体の重さ（自重）、人や車両の重さ（積載荷重）、周囲の土圧・水圧、地震力、風圧力、水撃圧（ウォーターハンマー）などの外力を受け、材料内部に応力（圧縮、引張、せん断、曲げ等）を発生させてこれに抵抗する。
* **過酷な気象・外象作用（建築材料との決定的相違）**:
  * 屋内で使用されることが多い建築内装材料と異なり、土木材料は **常に風雨、直射日光（紫外線）、激しい温度変化、乾湿の繰り返し、凍結融解、地下水や土壌の酸・アルカリ、塩分（除雪剤・海水）といった「気象作用（外象作用）」に直接晒され続ける**。
  * したがって、単なる強度だけでなく、極めて高い「耐久性（耐候性・耐食性・耐凍害性）」が要求される。

---

### (2) 近代土木工法の画期：1824年ポルトランドセメントの発明

土木工法の歴史において最大の転換点となったのは、**1824年にイギリスの煉瓦積み職人ジョセフ・アスプディン（Joseph Aspdin）が「ポルトランドセメント」の特許を取得したこと** である。
石灰石と粘土を微粉砕・混合して高温焼成することで、水と反応して水中でも極めて強固に硬化する水硬性セメントの量産が可能となった。これにより、巨大なダム、浄水池、橋梁、海底トンネルなどの近代コンクリート構造物の築造が可能となり、土木技術は飛躍的な進化を遂げた。

---

### (3) 材料選定の基本原則（適材適所）

土木構造物の設計・施工においては、構造物の要求供用期間（耐用年数）、使用環境（土壌腐食性、気象、荷重条件）、施工性、維持管理性、環境負荷、そしてライフサイクルコスト（LCC）を総合的に勘案し、**「適材適所」** で材料を選定することが絶対原則である。

```
【土木材料の化学的組成による大分類】
［土木材料］
  ├─［無機材料］
  │     ├─［金属材料］
  │     │     ├─ 鉄鋼材料 ─── 鋼（スチール）、鋳鉄（普通鋳鉄、ダクタイル鋳鉄）、ステンレス鋼
  │     │     └─ 非鉄金属材料 ─ アルミニウム、銅、鉛、亜鉛
  │     └─［非金属材料］ ───── 石材、粘土製品（レンガ、陶管）、セメント、コンクリート
  │
  └─［有機材料］
        ├─ 木材 ───────── 木材（力学的異方性、比強度大）
        ├─ 高分子材料 ───── プラスチック（塩化ビニル、ポリエチレン、FRP）、合成ゴム、合成繊維
        └─ 歴青材料 ─────── アスファルト、タール
```

## 3. 材料の基本特性（機械的・物理的・化学的性質）

材料の適正な選定と構造計算を行うため、材料が持つ3大性質を科学的に理解する必要がある。

### (1) 機械的性質（変形と強さ）

外力が作用したときの変形挙動や破壊に対する抵抗性を示す。

* **弾性と塑性**:
  * **弾性（Elasticity）**: 外力を加えると変形するが、**外力を取り除くと完全に元の形状・寸法に戻る性質**（フックの法則が成立する領域）。
  * **塑性（Plasticity）**: 外力を取り除いても変形が元に戻らず、**永久変形（残留ひずみ）が残る性質**。
* **強さ（強度）の分類**:
  * **静的強さ**: 緩やかな一定速度で荷重を1回加え、破壊に至るときの最大応力（圧縮強度、引張強度、曲げ強度、せん断強度）。
  * **疲れ強さ（疲労強度）**: 静的強度よりはるかに小さい応力であっても、**長期間にわたり繰り返し変動荷重（交番荷重）を受けることで微細な亀裂が発生し、突然破壊に至る現象（疲労破壊）に対する抵抗限界**（水管橋の風振動や道路下埋設管の交通荷重等で極めて重要）。
  * **硬さ（硬度）**: 物体の表面が、他の硬い物体による圧入、摩擦、引っかき傷に対して抵抗する度合い。

---

### (2) 物理的性質（密度・含水・熱挙動）

* **比重**: 材料の質量と、それと同体積の $4^\circ\text{C}$ の純水の質量との比（無次元数）。
* **単位体積重量（密度）**: 単位体積あたりの重量（$\text{t/m}^3$ または $\text{kg/m}^3$）。
* **含水率（$\%$）**: 材料中に含まれる水の質量を、炉乾燥させた「絶乾状態」の固形材質量で割った百分率。
* **比熱**: 物質 $1\text{ g}$ の温度を $1^\circ\text{C}$（$1\text{ K}$）上昇させるのに必要な熱量（$\text{J/(g}\cdot\text{K)}$）。
* **熱伝導率**: 材料内部の熱の伝わりやすさを示す係数。
* **熱膨張係数（線膨張係数）**: 温度が $1^\circ\text{C}$ 上昇したときの単位長さあたりの伸び率。
  * ※鉄筋とコンクリートの熱膨張係数は **ほぼ等しい（約 $1.0 \times 10^{-5}/\text{K}$）**。この熱力学的物性の一致が、温度変化による熱応力破壊を起こさず「鉄筋コンクリート（RC）」として強固に一体化できる決定的な理由である。

---

### (3) 化学的性質（耐久性）

酸・アルカリ・塩分に対する耐薬品性、大気中の酸素・水分・紫外線に対する耐候性、そして水を含んだ材料が凍結と融解を繰り返すことによって組織が破壊される現象への抵抗性（**耐凍害性**）など、長期的な寿命を決定づける。

## 4. 無機材料（金属材料）の特徴

### (1) 鉄鋼材料の分類と特徴

鉄鉱石を高炉で精錬した「銑鉄」から炭素量（C）を調整することで製造される。

```
【鉄鋼材料の炭素含有量と特性】
・鋼（スチール）： 炭素量 約 0.02% 〜 2% ─── 高強度、高靭性（粘り強い）、延性大、加工性優れる。
・鋳鉄（アイアン）： 炭素量 約 2% 以上 ───── 融点が低く鋳造性に優れるが、硬くて脆い。
```

* **1. 鋼（鋼材・スチール）**:
  * 引張強度・圧縮強度ともに極めて高く、外力に対して塑性変形しながら粘り強く耐える「靭性（じんせい）」に富む。
  * 圧延加工により、鋼板、H形鋼、等辺山形鋼、鉄筋、および水道用塗覆装鋼管（SP）として用いられる。
* **2. 普通鋳鉄（ねずみ鋳鉄）**:
  * 炭素が「片状黒鉛（薄片状のグラファイト）」として金属組織内に析出している。
  * 黒鉛の切欠き効果により、**引張力や衝撃曲げに対して極めて脆く、ガラスのように割れやすい致命的な欠点** を持つ。過去の水道管路事故（道路陥没等）の主原因であり、現在は耐震管への更新・全廃が進められている。
* **3. ダクタイル鋳鉄（球状黒鉛鋳鉄）**:
  * 溶湯にマグネシウム（Mg）やセリウム（Ce）を添加し、**黒鉛を球状に結晶化させた鋳鉄**。
  * 片状黒鉛のような応力集中が起きないため、**引張強さ、曲げ強さ、耐衝撃性、伸び（靭性）が普通鋳鉄の3.5〜4倍と飛躍的に向上** している。現在の水道用配水管・送水管の主力管種（DIP）である。
* **4. ステンレス鋼（SUS）**:
  * 鉄にクロム（Cr、10.5%以上）やニッケル（Ni）を添加した高合金鋼。
  * 大気中の酸素とクロムが反応し、表面に数ナノメートルの極めて緻密で自己修復性を持つ **「不働態皮膜（不動態皮膜）」** を形成する。
  * **特長**: 赤錆の発生を恒久的に防ぎ、内外面の塗装やライニングが不要。
  * **水道用途**: **波状ステンレス鋼管（給水管の標準仕様）**、配水池のステンレス配管・パネル水槽、水管橋配管。

---

### (2) 非鉄金属材料

* **鉛（Pb）**:
  * 非常に柔らかく塑性加工性（曲げ加工）に優れ、腐食しにくいため、かつては給水管（鉛給水管）として日本全国で標準的に埋設された。
  * しかし、水中に微量溶出する鉛の体内蓄積性・健康毒性（神経系への影響）が明らかとなり、**現在は水道用給水管としての新設が完全禁止** されている（残存鉛管の計画的解消を推進中）。
* **アルミニウム（Al）およびその合金**:
  * 軽量で比強度が高く、大気中では酸化皮膜により耐食性を示す。
  * ただし、**銅や鉄などの異種金属と直接接触した状態で水分（電解質）が存在すると、著しい電位差によりアルミニウム側が急速に腐食する「異種金属接触腐食（ガルバニック腐食・マクロセル腐食）」** を起こすため、絶縁パッキン等による絶縁処理が必須である。

## 5. 無機材料（非金属材料：セメント・コンクリート・石材・粘土）

### (1) セメント（水硬性結合材）

セメントは、水と接触すると化学反応（水和反応）を起こし、発熱（水和熱）しながら針状結晶を生成して強固に硬化する「水硬性」を持つ。

* **ポルトランドセメントの製造**:
  * 主原料の石灰石（CaO）、粘土（$\text{SiO}_2$, $\text{Al}_2\text{O}_3$, $\text{Fe}_2\text{O}_3$）、珪石、酸化鉄を混合し、ロータリーキルン（回転窯）内で約 $1,450^\circ\text{C}$ の高温で焼成して半溶融状態の **「クリンカー」** をつくる。
  * このクリンカーに、凝結時間（固まる速度）を適正に調整するための **「石膏（硫酸カルシウム）」** を少量（数%）加えて微粉砕することで完成する。
* **主要なセメントの種類**:
  * **普通ポルトランドセメント**: 最も汎用的な標準セメント。
  * **早強ポルトランドセメント**: 初期強度の発現が早く、緊急復旧工事や冬期工事に適用。
  * **中庸熱・低熱ポルトランドセメント**: 水和熱の発生が穏やかで、ダムや大型配水池などのマスコンクリートの温度ひび割れ防止に適用。
  * **高炉セメント**: 製鉄所の副産物である高炉スラグ微粉末を混合。長期強度、水密性、耐海水性に優れ、温室効果ガス削減にも寄与。

---

### (2) コンクリートの構成用語の厳密な定義

```
【コンクリート構成要素の体系】
① セメントペースト ＝ セメント ＋ 水
② モルタル ────── ＝ セメント ＋ 水 ＋ 細骨材（砂）
③ コンクリート ──── ＝ セメント ＋ 水 ＋ 細骨材 ＋ 粗骨材（砂利・砕石） ＋（混和材料）
```

* **骨材（Aggregate）の重要性**:
  * 骨材はコンクリート全体の容積の **約7割（65〜75%）** を占める。
  * 骨材は単なる「増量材」ではなく、水和熱や乾燥収縮を抑え、コンクリートの強度と耐久性を担保する骨格である。有害な微粒分（泥）や有機不純物、塩分を含まず、適度な粒度分布（大小の粒が隙間なく噛み合う級配）を持つ良質な骨材の使用が不可欠である。

## 6. コンクリートの長所と短所（★最重要ポイント）

水道施設（浄水場、配水池、管路防護ブロック等）の基幹を成すコンクリートの特性について、長所と短所を対比して完全に理解・暗記する。

### (1) コンクリートの4大長所

```
【コンクリートの長所】
① 形状・寸法の自由度 ── 型枠を組むことで、複雑な形状や任意の寸法の構造物を一体築造できる。
② 材料の入手性と経済性 ─ 主原料（水、砂、砂利、セメント）が安価で容易に入手・運搬可能。
③ 優れた耐久性と諸耐性 ─ 耐火性、耐水性、耐候性、耐水圧性に極めて優れている。
④ 内部鉄筋の腐食保護 ── セメントペーストが強アルカリ性（pH 12〜13）を示し、鋼材表面に不動態皮膜を形成して錆を半永久的に防止する。
```

---

### (2) コンクリートの4大短所（および克服工法）

```
【コンクリートの短所と克服策】
① 自重（重量）が大きい ──────── 単位体積重量が約 2.3〜2.4 t/m³（RCで約 2.45 t/m³）と極めて重い。
                                  → 軟弱地盤での基礎杭の大型化、橋梁支間長の制約。
② 引張強度が著しく小さい（★超重要） ─ 圧縮強度の「約 1/10 程度」しか引張強度がない。
                                  → 引張側に応力を負担する鉄筋を配置した「鉄筋コンクリート（RC）」や、
                                     あらかじめ圧縮応力を導入する「プレストレストコンクリート（PC）」で克服。
③ 乾燥収縮によるひび割れ ────── 水分の蒸発収縮や水和熱の温度応力によりクラックが発生しやすい。
                                  → 適切な配合（W/C抑制）、膨張材、目地配置、湿潤養生の徹底。
④ 補修・解体（破砕）が困難 ───── 硬化後は強固な一体構造となるため、解体・撤去に多大な労力と騒音・振動、
                                     大量の産業廃棄物（コンクリート塊）が発生する。
```

---

### (3) 硬化コンクリートの品質管理基準

* **材齢28日強度（設計基準強度 $\sigma_{ck}$）**:
  * コンクリートの強度は一般に「圧縮強度」を指し、標準養生（$20 \pm 2^\circ\text{C}$ 水中養生）を行った **「材齢28日」の発現強度を設計基準強度** として品質管理を行う。
* **水セメント比（W/C）の法則**:
  * コンクリートの強度は、セメントに対する練混ぜ水の重量比である **「水セメント比（W/C）」が小さいほど高く、緻密で耐久性・水密性に優れたコンクリート** となる。
* **施工プロセスの重要性**:
  * どんなに優れた配合であっても、打込み時の **「十分な締固め（高周波棒状バイブレーターによる空気泡の排除）」** と、硬化初期の **「湿潤養生（散水・養生マットによる乾燥防止と適正温度維持）」** を怠ると、強度は半減し耐久性・水密性が損なわれる。

## 7. 有機材料（木材・高分子材料・歴青材料）

### (1) 木材の特徴と力学的異方性（テキスト p.202）

* **比強度（強度／密度）が大きい**:
  * 単位体積重量が約 $0.4 \sim 0.8\text{ t/m}^3$ と水に浮くほど軽量である割に強度が高い。
* **力学的異方性（最大の構造的制約）**:
  * 木材は樹木の成長方向に繊維が走っているため、**「繊維方向」と「繊維直角方向」で強度が劇的に異なる**。
  * 健全な木材の繊維方向の引張強度は圧縮強度よりも大きいが、**節（ふし）、繊維の傾斜（目通り不良）、含水率の変動、腐朽菌による腐朽、シロアリ等の食害により強度のばらつきが極めて大きい**。
  * このため、土木構造物の信頼性が要求される主要な引張構造部材として木材を恒久利用することは極めて困難である（主に型枠材、仮設矢板、修景木道等に利用）。

---

### (2) 高分子材料（プラスチック・合成樹脂・合成ゴム）

石油化学工業の発展によって生まれた、分子量1万以上の高分子化合物である。

* **金属材料と比較した4大特長**:
  1. 水、酸、アルカリ、塩分に対して極めて優れた **耐食性・耐薬品性** を示す（錆びない）。
  2. 電気および熱の不良導体であり、**優れた電気絶縁性と断熱性** を有する（電食を受けない）。
  3. 比重が小さく（約 $0.9 \sim 1.4$）**極めて軽量** であり、運搬・配管施工性に優れる。
  4. 成形性・可とう性（柔軟性）に富み、工場での大量・均質生産が可能。
* **土木・水道施設での代表的用途**:
  * **管路材**:
    * **硬質ポリ塩化ビニル管（VP/HIVP）**: 耐食性、内面平滑性、耐酸耐アルカリ性に優れる。
    * **水道配水用ポリエチレン管（PE管）**: 優れた耐震性・柔軟性、融着継手（EF接合）による完全一体化管路。
    * **下水道用強化プラスチック複合管（FRPM管）**: ガラス繊維補強樹脂による大口径高強度管。
  * **水密材料（合成ゴム）**:
    * ダクタイル鋳鉄管の継手に使用される **「ゴム輪（SBR/EPDMガスケット）」**、弁座パッキン、Oリング。
    * 橋梁や耐震管の **ゴム支承・可とう伸縮継手**。
  * **ジオテキスタイル（合成繊維シート）**:
    * 軟弱地盤対策、斜面保護、路盤の分離補強・排水シート。

---

### (3) 歴青材料（アスファルト・タール）

炭化水素を主成分とする黒色・粘稠な結合材料。

* **石油アスファルト**:
  * 原油を減圧蒸留した際の最終残渣として製造される。
  * **熱可塑性**: 常温では半固体〜固体であるが、加熱すると流動化し、冷却すると再び固化する。
  * **水密性・接着性**: 水に全く溶けず、砕石や砂と強固に結合する。
* **土木での主な用途**:
  * **アスファルト混合物（道路舗装）**: 水道管を布設した後の道路掘削跡の本復旧舗装。
  * **アスファルト乳剤**: 舗装層間の接着を高めるプライムコート・タックコート、養生皮膜。
  * **構造物防水層**: 配水池の頂版遮水工、目地注入材。

## 9. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：コンクリートの力学的性質）
* **問題形式**: `choice`
* **問題文**: コンクリートの力学的性質および鉄筋コンクリートの基本原理に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. コンクリートの引張強度は圧縮強度の約10分の1程度と著しく小さい
  2. コンクリートは圧縮強度よりも引張強度や曲げ強度がはるかに大きい
  3. 鉄筋コンクリートが成立するのは鋼材とコンクリートの比重が等しいためである
  4. セメントペーストは酸性を示すため内部に配置された鉄筋の腐食を促進する
* **正解**: 1（インデックス: 0）
* **解説**: コンクリートは圧縮力に強い反面、引張強度は圧縮強度の約10分の1程度と著しく小さい弱点があります。この引張力を補うために引張側に鉄筋を配置したものが鉄筋コンクリート（RC）です。鋼材とコンクリートの一体化は「熱膨張係数（線膨張係数）がほぼ等しい」こと、および強アルカリ性ペーストが鉄筋の錆を防ぐことにより成立しています。
* **日常のたとえ**: チョークのように上から押しつぶす力には強いけれど、引っ張ったり横から曲げたりすると簡単にポキッと折れてしまう性質を、引っ張りに強い鉄の骨（鉄筋）を入れて補っている構造です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.199〜201

### 設問2（4択：金属土木材料の特性）
* **問題形式**: `choice`
* **問題文**: 水道施設に使用される各種金属材料の特性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. ダクタイル鋳鉄は黒鉛を球状化させることで高い引張強度と靭性を持つ
  2. 普通鋳鉄は組織内の黒鉛が球状であるため衝撃曲げに対して極めて割れにくい
  3. ステンレス鋼は表面に多孔質な錆層を形成することで内部の腐食を促進する
  4. 鉛は人体に対する安全性が極めて高いため現在も給水管の新設が義務付けられる
* **正解**: 1（インデックス: 0）
* **解説**: ダクタイル鋳鉄はマグネシウム等を添加して黒鉛を球状化させることで応力集中を排除し、普通鋳鉄の3.5〜4倍の引張強度と優れた靭性を発揮します。普通鋳鉄は片状黒鉛のため脆く割れやすい欠点があります。ステンレス鋼はクロムによる「不働態皮膜」で防食され、鉛管は毒性のため新設禁止です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.193〜195

### 設問3（4択・否定形：コンクリートの長所と短所）
* **問題形式**: `choice`
* **問題文**: 土木材料としてのコンクリートの長所および短所に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 一度硬化すると解体や補修が極めて容易であり産業廃棄物も発生しない
  2. 型枠を用いることにより任意の形状や寸法の構造物を一体的に築造できる
  3. 硬化時の水和熱や水分の蒸発に伴う乾燥収縮によってひび割れが生じやすい
  4. 主原料である水や砂利やセメントが比較的容易かつ安価に入手できる
* **正解**: 1（インデックス: 0）
* **解説**: コンクリートは一度硬化すると強固な一体構造となるため、解体・取り壊しには多大な労力と費用を要し、大量の産業廃棄物（コンクリート塊）が発生することが大きな短所です。形状の自由度、乾燥収縮ひび割れの発生、材料の入手性・経済性の記述はすべて正しい内容です。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.200〜201

### 設問4（4択：有機材料の特性）
* **問題形式**: `choice`
* **問題文**: 土木構造物に使用される高分子材料および木材の特性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 高分子材料は酸やアルカリに対する耐食性に優れ電気の不良導体である
  2. 木材は力学的に等方性であり繊維方向と直角方向で強度が完全に一致する
  3. プラスチック管は金属管と比較して比重が極めて大きく運搬施工性が劣る
  4. アスファルトは常温で完全な液体であり加熱すると硬化する熱硬化性を持つ
* **正解**: 1（インデックス: 0）
* **解説**: 高分子材料（プラスチック・ゴム）は、酸・アルカリ・水に対する優れた耐食性を持ち、電気および熱の不良導体（絶縁体）であるため電食を受けません。木材は繊維方向と直角方向で強度が著しく異なる「力学的異方性」を持ちます。アスファルトは加熱で流動化し冷却で固化する「熱可塑性」を有します。
* **出典**: 講義テキスト 土木材料及び施工法・水道資材 p.202〜205

### 設問5（4択：水道技術管理者の法定責務）
* **問題形式**: `choice`
* **問題文**: 水道法第19条等に規定される水道技術管理者の法定責務および権限に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 水質汚染等により人の健康を害する恐れがある場合は給水を緊急停止できる
  2. 水道施設の定期水質検査は水道事業者の義務であり技術管理者の責務ではない
  3. 浄水場で作業に従事する職員に対する定期検便等の健康診断は任意である
  4. 水道施設の新設工事完了後であっても給水開始前の施設検査は省略できる
* **正解**: 1（インデックス: 0）
* **解説**: 水道技術管理者は、水源汚染等により供給水が人の健康を害する恐れがある場合、水道法第23条に基づき自らの判断で直ちに給水停止を命じる権限と責務を有します（★重要法定責務）。新設・改造時の検査（法第13条）、定期水質検査（法第20条）、従事者健康診断・検便（法第21条）はいずれも法令上の厳格な義務です。
* **出典**: 水道法 第19条、第21条、第23条／講義テキスト p.189
