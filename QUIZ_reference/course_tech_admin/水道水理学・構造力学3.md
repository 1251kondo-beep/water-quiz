## 1. 構造物の具備すべき条件と特質（テキスト p.176）

### (1) 安全性と安定性の定義
* **安全性（Safety）**:
  * 構造物が自重および作用する外力に対して、**破壊や永久変形（有害な残留変位）を生じない** 性質。
  * 材料の強度（引張強さ、圧縮強さ、せん断強さ）や応力度照査によって担保される。
* **安定性（Stability）**:
  * 構造物が力学的・幾何学的に **倒壊、転倒、滑動（すべり）、沈下、浮上を起こさず、原形および所定の位置を保ち続ける** 性質。
  * 基礎地盤との相互作用や全体のつり合いによって担保される。

### (2) 【事例紹介】ピサの斜塔にみる地盤と安定性の教訓
* **建設背景と地盤条件**:
  * イタリア・ピサの斜塔は、海に近い湿地帯（ラグーン）の極めて軟弱なシルト・粘土質地盤上に建設された。
  * 基礎の深さはわずか **約 $3\,\text{m}$** しかなく、高さ $56\,\text{m}$・総重量約 $14{,}500\,\text{t}$ の石積構造物を支えるには決定的に不足していた。
* **傾斜の原因（地下水位の偏りと不同沈下）**:
  * 敷地の **南側の地下水位が北側より高かった** ため、南側の軟弱地盤が局所的に弱体化・圧密沈下を起こし、南側へ大きく不同沈下した。
  * 着工後わずか5年で傾き始め、傾斜を根本的に修復しないまま上層階を垂直に積み増したため、偏心モーメントがさらに増大した。
* **倒壊を免れた構造的要因と現代の補強対策**:
  * 塔が中空円筒形で重心が低かったこと、肉厚約4mの頑丈な石積構造であったこと、長年の沈下で直下地盤が徐々に圧密強化されたことにより、奇跡的に倒壊を免れた。
  * 現代の補強工事では、傾斜と反対側の北側地盤から土を少しずつ抜き取る「**土抜き工法（アンダーピニング）**」やカウンターウェイトの設置により傾斜角を安全域まで是正。今後300年間は倒壊の危険がないと評価されている。土木構造物において基礎と地盤の安定性照査がいかに重要であるかを示す代表例である。

### (3) 土木構造物の固有の特質
1. **規模が大きく、建設期間と費用が膨大である**: 失敗した際の社会的・経済的損失が極めて大きい。
2. **大部分が公共用途である**: 公金（税金・水道料金）によって建設・維持され、社会的責任を伴い、超長期にわたって供用される。
   * 法定耐用年数：大規模コンクリート構造物（配水池・沈殿池等）は **60年**、管路は **40年** と定められているが、実際には適切な維持管理・更新を行いながらそれ以上の超長期にわたり運用される。
3. **自然環境との関わりが大きい**: 地形・地質・気象（豪雨・地震・気温変化）の影響を直接受ける。水源ダムや取水施設では河川生態系や自然環境への十分な配慮が欠かせない。

## 2. 土木構造物および水道施設の具備要件（テキスト p.176〜177）

### (1) 土木構造物に求められる4大基本要件
1. **安全性・安定性**: 想定される設計供用期間中、あらゆる外力に対して破壊・倒壊せず安全であること。
2. **使用性（機能性・利便性・公害防止）**:
   * 本来の使用目的に適合し、使いやすく、維持管理や修繕が容易であること。
   * 有害なひび割れ・たわみ・漏水を生じず、利用者に不安を与えないこと。
   * 周辺環境や住民に対して、騒音・振動・水質汚濁等の公害・悪影響を及ぼさないこと（直接的要件だけでなく社会的間接要件も包括）。
3. **経済性（ライフサイクルコストの最小化）**:
   * 初期の建設工事費（イニシャルコスト）の縮減だけでなく、将来の点検・修繕・更新費を含めた **ライフサイクルコスト（LCC / トータルコスト）を最小化** すること。
4. **美観（景観との調和）**:
   * 地域の景観・自然環境に調和し、良好な都市景観を形成すること。水管橋の塗色選定や配水塔の意匠設計などが該当する。

### (2) 水道施設の具備すべき要件（水道施設の技術的基準を定める省令）
「水道施設の技術的基準を定める省令」における主要基準項目：
* **所要水圧・水量の確保**: 必要量の水を所定の清澄水圧で常時供給できること。
* **耐荷重・耐震性**: 自重、土圧、水圧、および地震力に対して構造耐力上安全であること。
* **水密性**: 貯留水が外部へ漏水しない構造であること。
* **防汚性（水質汚染の防止）**: 外部からの雨水、地下水、汚泥等の浸入による水質汚染の恐れがないこと。
* **耐災害性と速やかな復旧性**: 被災の影響を最小限にとどめ、迅速に機能回復できること。
* **維持管理性**: 清掃、点検、弁操作、補修が安全かつ容易に行えること。

### (3) 設計における不確定要素と安全率（安全係数）
* 設計実務においては、以下の不確定要素を考慮し、材料の降伏点や破壊強度に対して **安全率 $n$（安全係数）** を見込んで設計を行う。
  1. 外力の変動（気象条件や異常水圧等の予測変動）
  2. 材料強度のばらつき（コンクリートの打設品質や鋼材の材質誤差）
  3. 施工精度の不均一（現場寸法や配筋寸法の誤差）
  4. 構造解析・力学モデル化に伴う近似仮定の誤差

## 3. 構造物の安定性照査（4大チェック項目）（テキスト p.177〜178）

水道構造物（配水池、擁壁、ポンプ井等）の基礎・躯体設計では、以下の4大安定条件を照査する。

```
              【構造物の4大安定性照査】
  ┌───────────────┬────────────────┬────────────────┬───────────────┐
  │ ① 転倒に対する │ ② 滑動に対する │ ③ 地盤支持力に │ ④ 浮力に対する │
  │    安定性     │    安定性      │    対する安定性│    安定性     │
  │ (ミドルサード)│ (底面摩擦抵抗) │ (許容支持力)   │ (水抜き自重照査)│
  └───────────────┴────────────────┴────────────────┴───────────────┘
```

### (1) 転倒に対する安定性（ミドルサードの原則）
* 擁壁や高架水槽など、水平力（土圧・水圧・地震力）を受ける構造物が転倒しないための照査。
* **ミドルサード（中央1/3）の原則**:
  * 鉛直荷重 $P_V$ と水平力 $P_H$ の合力 $P$ の作用線が、**基礎底面の中央 $1/3$（ミドルサード）の範囲内を通過していれば、底面に引張応力が一切生じず、転倒に対して安全である**。
  * 合力がミドルサードを外れると、底面端部に有害な引張応力（浮き上がり）が生じ、転倒の危険が高まる。

### (2) 滑動（すべり）に対する安定性
* 水平外力（土圧・水圧等）によって構造物が基礎底面に沿って水平方向にすべり出さないための照査。
* **照査条件**: 底面の摩擦抵抗力 $F$ が、作用する水平力 $P_H$ を上回る必要がある。
  $$F = \mu \cdot P_V > P_H$$
  * $\mu$: 基礎地盤と構造物底面コンクリートとの摩擦係数
  * $P_V$: 全鉛直荷重（自重等）
  * $P_H$: 水平外力の合力
* 設計安全率は一般に **1.5 以上** を確保する。

### (3) 地盤支持力に対する安定性
* 構造物の全鉛直荷重およびモーメントによる最大接地圧が、基礎地盤の **許容支持力** 以下であることを確認する。
* 地盤の支持力が不足すると、構造物全体の沈下、不同沈下、傾斜、躯体のひび割れ・漏水を招く。軟弱地盤では杭基礎工法や地盤改良工法を併用する。

### (4) 浮力に対する安定性
* 地下水位が高い場所に築造された地下式配水池やポンプ井、下水管きょ等において、地下水による浮力に対抗するための照査。
* **最悪条件（清掃・点検用水抜き時）での照査**:
  * 満水時は内部の水の重量によって安定しているが、**定期清掃や点検で内部の水を完全に抜いた「空虚時」には自重が大幅に軽くなる**。
  * この空虚時の構造物自重 $W$ が、最高地下水位による浮力 $F$ を上回らなければならない（$W > F$）。
  * 不足する場合は、底版の拡幅（ウイング）、ウエイトコンクリート打設、グラウンドアンカー等の浮上防止対策を実施する。

## 4. 構造力学の基礎理論と梁の計算（テキスト p.178〜180）

### (1) 2次元静的つり合いの3条件
静止状態にある構造物に外力が作用しているとき、任意の断面において以下の3つのつり合い式が同時に成立する。
1. **水平方向のつり合い**: $\sum H = 0$（左右方向の力の総和がゼロ）
2. **鉛直方向のつり合い**: $\sum V = 0$（上下方向の力の総和がゼロ）
3. **モーメントのつり合い**: $\sum M = 0$（任意の点まわりの回転モーメントの総和がゼロ）

### (2) 応力-ひずみ曲線と材料特性（軟鋼）
* **弾性域**: 外力を除荷すると元の形状・寸法に戻る可逆領域。フックの法則（$\sigma = E \cdot \varepsilon$）が成立。
* **塑性域**: 降伏点を超えると、除荷しても元に戻らない永久ひずみ（塑性変形）が残る領域。
* **降伏点（降伏強度）**: 応力を増やさなくてもひずみが急激に増大し始める限界点。
* **引張強さ $f_u$**: 材料が破断に至るまでに耐えうる最大引張応力。
  * 例：一般構造用圧延鋼材「**SS400**」の「400」は、**引張強さの下限値が $400\,\text{N/mm}^2$** であることを表している。

### (3) 単純梁（等分布荷重）に生じる内力と反力の計算式
支間長（スパン）$L$ の単純梁に等分布荷重 $w$（単位長さあたりの自重等）が載荷された基本モデル：

```
       w (等分布荷重: N/m)
  ↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓↓
  ▲────────────────────▲
  支点A       L        支点B
  (RA)                 (RB)
```

1. **支点反力 $R_A, R_B$**:
   左右対称であるため、全荷重 $w \cdot L$ が均等に両支点へ分配される。
   $$R_A = R_B = \mathbf{\frac{w \cdot L}{2}}$$
2. **曲げモーメント $M_x$ と最大値**:
   支点Aから距離 $x$ の任意位置における曲げモーメント：
   $$M_x = R_A \cdot x - w \cdot x \cdot \frac{x}{2} = \frac{w}{2}(Lx - x^2)$$
   * 曲げモーメントは **梁の中央点（$x = L/2$）で最大** となる。
   $$M_{\max} = \mathbf{\frac{w \cdot L^2}{8}}$$
3. **せん断力 $S_x$ と最大値**:
   任意位置 $x$ におけるせん断力：
   $$S_x = R_A - w \cdot x = w\left(\frac{L}{2} - x\right)$$
   * せん断力は **両支点（$x = 0$ および $x = L$）で最大** となり、**中央点（$x = L/2$）でゼロ** となる。
   $$S_{\max} = \mathbf{\frac{w \cdot L}{2}}$$

### (4) 鉄筋コンクリート（RC）梁の力学的補強原理
* 単純梁に下向きの鉛直荷重が作用すると、**梁の上側には「圧縮応力」**、**下側には「引張応力」** が生じる。
* **コンクリートの性質**: 圧縮力には極めて強いが、引張力には極めて弱い（引張強度は圧縮強度の約 $1/10$）。
* **合理的な補強配筋**:
  * 最大引張応力が発生する **梁の下側に「引張主鉄筋」** を配置して引張力を受け持たせる。
  * 最大せん断力が発生する **支点付近の両端部に「せん断補強筋（スターラップ・帯鉄筋）」** を密に配筋して斜め引張ひび割れを防ぐ。
  * このようにコンクリートが圧縮を、鉄筋が引張を受け持つことで、極めて頑丈で合理的な複合部材を形成する。

### (5) 梁部材の構造設計手順
1. **外力・断面力計算**: 作用荷重から最大曲げモーメント $M_{\max}$ および最大せん断力 $S_{\max}$ を算出する。
2. **所要断面係数の算定**: 材料の許容曲げ応力度 $\sigma_a$ から必要な断面係数 $Z = \frac{M_{\max}}{\sigma_a}$ を求める。
3. **仮定断面の設定**: 所要断面係数を満たす部材寸法（管厚、梁幅、梁せい）を仮定する。
4. **応力度の照査**: 発生応力度 $\sigma, \tau$ が許容値以下であることを確認する（$\sigma \leqq \sigma_a, \tau \leqq \tau_a$）。
5. **たわみ・変形照査**: たわみ量が使用限界値以下であることを確認して部材断面を確定する。

## 5. 許容応力度設計法と安全性確認（テキスト p.181）

### (1) 許容応力度設計法の基本原則
部材内に外力によって発生する応力度（曲げ応力度 $\sigma$、せん断応力度 $\tau$）が、材料ごとに規定された限界値である「許容応力度」以下であることを確認する。
$$\sigma \leqq \sigma_a \quad \text{かつ} \quad \tau \leqq \tau_a$$

### (2) 許容応力度の決定方法
許容応力度 $\sigma_a$ は、材料固有の基準強度（降伏強度または引張強さ）を安全率 $n$（$n > 1$）で除して決定される。
$$\sigma_a = \frac{\text{基準応力度（降伏強度・基準強度）}}{\text{安全率 } n}$$
* 常時（固定荷重＋積載荷重＋水圧等）に対する許容応力度と、地震時・暴風時などの「割増許容応力度（許容応力度を $1.5$ 倍等に割り増す）」が指針等により規定されている。

## 6. 水道施設の耐震設計（テキスト p.182〜184）

### (1) 耐震設計の基本方針と指針の改訂経緯
* 水道施設はあらゆる巨大地震に対して完全に無被害を保つことが理想であるが、経済性・実現性の観点から、**「施設の重要度」** と **「想定地震動のレベル」** を組み合わせた性能規定（性能設計）が採用されている。
* **耐震工法指針の改訂の歩み**:
  * **1997年（平成9年）発刊**: 1995年阪神・淡路大震災での未曾有の水道被害を契機に『水道施設耐震工法指針・解説 1997』策定。「レベル1・レベル2地震動」の概念を初導入。
  * **2009年（平成21年）改訂**: 2007年中越沖地震や2008年岩手・宮城内陸地震等の知見を踏まえ改訂。施設重要度区分の見直しと性能設計体系の本格化。
  * **近年の改訂**: 2011年東日本大震災（津波・広域液状化）、2016年熊本地震、2024年能登半島地震等の知見を反映した継続的見直し。

### (2) 要求性能と設計地震動レベル（L1・L2）

| 地震動レベル | 地震動の定義・発生確率 | 構造物に求められる要求性能・限界状態 |
| :--- | :--- | :--- |
| **レベル1地震動**<br>（L1地震動） | 施設の供用期間中に **1〜2度発生する確率が高い、強度の高い地震動**。 | **「使用性」の確保**<br>構造部材は原則として **健全な弾性範囲内** に留まり、地震後も無被害または軽微な補修のみで直ちに給水機能を継続できる状態（限界状態1）。 |
| **レベル2地震動**<br>（L2地震動） | 発生確率は低いが、当該地点で想定される **最大規模の強さを持つ地震動**（プレート境界型巨大地震や内陸直下型断層地震）。 | **「復旧性」および「安全性」の確保**<br>部材の一定の **塑性変形（損傷）は許容するが、人命に危険を及ぼす致命的崩壊・転倒を防止** し、被災後も速やかに応急給水・早期復旧が可能な状態（限界状態2・3）。 |

### (3) 施設重要度区分（ランクA1・A2・B）
水道施設はその役割と代替性の有無に応じて3つにランク分けされ、重要度に応じた耐震性能が要求される。

* **ランクA（基幹施設）**:
  * 取水施設、導水施設、浄水施設、送水施設、配水池、主要な配水本管など、停止した場合の影響が極めて甚大な施設。
  * **ランクA1（代替性のない基幹施設）**:
    * 当該施設が被災・停止すると直ちに広範囲が断水する、代替ルートのない最重要幹部施設。
    * **最も高い耐震性能が要求され、レベル1地震動に対して機能を完全保持（使用性確保）するとともに、巨大なレベル2地震動に対しても速やかな復旧が可能でなければならない**。
  * **ランクA2（代替性のある基幹施設）**:
    * 二重化（複数系列化）や連絡管によるバックアップ機能、代替ルートが確保されている基幹施設。
* **ランクB（一般施設）**:
  * 上記以外の一般的な配水管（小口径配水枝管網）や末端給水施設など。

## 7. 【問題作成のための重要ポイント・キーナンバーまとめ】

| 項目 | 重要数値・公式・定義 | 試験・ドリル出題ポイント |
| :--- | :--- | :--- |
| **安全性と安定性** | 安全性＝破壊・永久変形防止、安定性＝倒壊・移動・転倒防止 | 2つの基本条件の定義の違い |
| **ピサの斜塔の事例** | 基礎深さわずか3m、南側地下水位高による不同沈下 | 基礎地盤と不同沈下の教訓 |
| **土木構造物4大要件** | 安全性、使用性（公害防止含む）、経済性（LCC）、美観 | ライフサイクルコストと公害防止の包含 |
| **法定耐用年数** | コンクリート構造物 **60年**、水道管路 **40年** | 法定耐用年数の基本数値 |
| **ミドルサードの原則** | 合力作用線が **底面中央1/3** 以内 $\to$ 引張応力ゼロ | 転倒に対する安定条件 |
| **浮力安定照査** | **清掃・点検用水抜き時（空虚時）** の自重 $W >$ 浮力 $F$ | 内部水重量のない最悪条件での検討 |
| **2次元つり合い3条件** | $\sum H = 0, \;\sum V = 0, \;\sum M = 0$ | 静的平衡の基本式 |
| **SS400の意味** | 引張強さの下限値が **$400\,\text{N/mm}^2$** | 降伏点ではなく引張強さである点 |
| **単純梁の等分布荷重** | 支点反力 $R = \mathbf{\frac{wL}{2}}$、最大曲げモーメント $M_{\max} = \mathbf{\frac{wL^2}{8}}$ | 公式の計算・最大値の発生位置（中央） |
| **RC梁の補強原理** | 下側に **引張主鉄筋**、支点付近に **せん断補強筋（スターラップ）** | コンクリート＝圧縮、鉄筋＝引張の役割分担 |
| **許容応力度設計法** | $\sigma \leqq \sigma_a$、$\sigma_a = \text{基準応力度} / n$（安全率） | 応力度照査の基本不等式 |
| **レベル1地震動（L1）** | 発生確率高 $\to$ **「使用性」確保**（弾性範囲・機能継続） | L1とL2の要求性能の違い |
| **レベル2地震動（L2）** | 発生確率低・最大規模 $\to$ **「復旧性」「安全性」確保**（塑性変形許容） | 致命的崩壊防止と早期復旧 |
| **重要度ランクA1** | **代替ルート・施設のない基幹施設** | 最も厳格な耐震性が求められる区分 |
