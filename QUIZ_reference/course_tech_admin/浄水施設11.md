## 1. 紫外線処理設備（テキスト p.467〜470）

### (1) 目的と不活化メカニズム
* **目的**:
  * 塩素耐性病原原虫（**クリプトスポリジウム**および**ジアルジア**）の汚染リスクがある水源において、物理的に病原体を不活化（感染性を喪失）させる設備。
  * 「水道におけるクリプトスポリジウム等対策指針」に基づき、表流水を水源としない地下水等、または急速ろ過池等の後段に設置される。
* **不活化メカニズム**:
  * 紫外線ランプ（低圧・中圧水銀ランプ）から放射される**波長 253.7 nm 付近の紫外線（UV-C）**を照射する。
  * 微生物の核酸（DNA/RNA）のチミン塩基が紫外線を吸収してチミン二量体を形成し、**遺伝子の複製・増殖機能を阻害（不活化）**する。
* **光回復現象への配慮**:
  * 一部の細菌・原虫は紫外線照射後に可視光線（日光）を浴びると酵素作用でDNAを自己修復する「光回復現象」を示すが、所定の照射量を確保すれば感染性は不可逆的に喪失する。

### (3) 維持管理と人体安全衛生管理
1. **ランプスリーブのスケール洗浄**:
   * 石英ガラススリーブ表面に原水中の鉄・マンガン・カルシウムが析出・付着（スケーリング）すると紫外線透過率が著しく低下する。
   * 自動メカニカルワイパー（機械的スクレーパー）または酸洗浄液による定期洗浄を実施する。
2. **通水停止時の消灯管理（空焚き防止）**:
   * 紫外線ランプは高温で作動するため、通水停止中に点灯を続けると水温上昇やスリーブ破損を招く。通水停止と連動して消灯し、消灯後もしばらく冷却通水を継続する。
3. **人体への直接被曝防止（労働安全衛生）**:
   * 紫外線（254nm）を直接目視すると、眼球の水晶体タンパク質が変性して**白内障**や急性角膜炎・結膜炎を引き起こす。皮膚被曝は重度の**紅斑（日焼け・熱傷）**を招く。
   * 点検・保守時は必ず**「完全消灯」**を確認する。やむを得ず点灯確認を行う場合は、**紫外線防護マスク、UVカット保護メガネ、遮光手袋**を着用する。

## 2. 海水淡水化施設（テキスト p.470〜473）

### (1) 目的・特徴と適用状況
* **目的**:
  * 周囲を海に囲まれた離島（沖縄県等）や、陸水水源（ダム・河川）の新規開発が限界に達した大都市圏（福岡地区水道企業団「海の中道奈多海水淡水化センター：まみずピア」等）において、無尽蔵の海水を淡水化して安定給水を確保する。
* **長所**:
  * 降雨・天候に全く左右されない絶対的な安定水源。
  * ダム建設等に比べ工期が短い。
* **短所・課題**:
  * **高電力消費**: 浸透圧を超える超高圧ポンプを運転するため電気代・造水コストが割高。
  * **濃縮海水（ブライン）の環境影響**: 排水される高濃度塩分水（通常海水の約1.5〜2倍濃度）の海域放流対策が必要。
  * **高耐食性材料の必須性**: 配管・弁類に二相系ステンレス（SUS329J4L等）やチタン等の高級耐食金属が必要。

## 3. 排水処理システム（テキスト p.473〜480）

### (1) 目的と基本的処理フロー
* **目的**:
  * 薬品沈殿池の沈殿汚泥（排泥スラッジ）および急速ろ過池の逆流洗浄排水を回収し、**「清澄な分離水（回収水）」**と**「脱水ケーキ（固形分：浄水発生土）」**に固液分離する。
  * 回収水は着水井へ返送して再利用（クローズドシステム）するか、排水基準を満たして河川等へ放流する。

```
【浄水場排水処理の標準プロセス】
［沈殿池排泥］ ────→ 【排泥池】 ──────┐
                                        ├─→ 【濃縮槽（シックナー）】
［ろ過池逆洗水］ ──→ 【排水池】 ──────┘         │ (上澄水: 原水着水井へ返送)
                                                    ↓ (濃縮スラッジ: 濃度数%〜10%)
                                            【脱水設備（加圧脱水機等）】
                                                    │
                                ┌───────────────────┴───────────────────┐
                                ↓                                       ↓
                        【分離液（脱水ろ液）】                   【脱水ケーキ（浄水発生土）】
                        （排水池または原水へ返送）               （含水率60%前後：再資源化）
```

### (4) コージェネレーション廃熱を利用した「スラッジ加温脱水システム」
* **背景と課題**:
  * 冬期に原水水温が低下すると、濃縮汚泥の粘性が増大し、脱水機のろ過抵抗が高くなって脱水効率が著しく悪化する（ケーキ含水率上昇・処理速度低下）。
* **加温脱水システムの仕組み（東村山浄水場等の導入実績）**:
  * 常用自家発電設備（ガスタービン発電機等）から排出される高温排熱（コージェネレーション廃熱）を回収し、蒸気または温水熱交換器を介して濃縮スラッジを**「加温槽」**で加温する。
  * スラッジ温度の上昇により汚泥の粘性が低下し、脱水速度が大幅に向上（脱水処理能力が約1.5〜2倍に増大、ケーキ含水率低減）。

### 設問1（4択：紫外線処理設備の設計基準と運転停止基準）
* **問題形式**: `choice`
* **問題文**: 水道における紫外線処理設備に関する記述として、水道施設の技術的基準を定める省令に照らして**最も適切なもの**はどれですか？
* **選択肢**:
  1. クリプトスポリジウム等を 99.9% 以上不活化するため、有効紫外線照射量 10 mJ/cm² 以上を確保し、濁度2度超過または紫外線透過率75%未満で直ちに通水を停止する
  2. 紫外線処理設備は濁質による光の遮蔽影響を全く受けないため、原水濁度が 50度 を超過した場合でも通水を継続して何ら支障はない
  3. 紫外線処理装置は点灯直後に手作業でランプスリーブを磨く必要があり、作業員は保護具を着用せずに直視して点灯を確認するのが義務付けられている
  4. 紫外線処理を行えば配水管網の末端まで強力な残留殺菌効果が持続するため、後段における塩素消毒の注入は法律上完全に免除される
* **正解**: 1（インデックス: 0）
* **解説**: 紫外線処理は耐塩素性原虫を「99.9%以上」不活化し、「有効紫外線照射量 10 mJ/cm² 以上」を常時確保します。照射効果を担保するため、「濁度2度超過、色度5度超過、紫外線透過率75%未満」のいずれかで自動停止します（1が正解）。濁度が高いと光が遮蔽され不活化できません。紫外線直視は白内障等の眼障害を招くため保護具着用が必須です。紫外線には残留効果がないため、水道法第22条に基づく塩素消毒の代替にはならず、塩素消毒の併用が必須です。
* **日常のたとえ**: 濁った泥水に懐中電灯（紫外線）を当てても光が奥まで届かないのと同じで、水が澄んでいる（濁度2度以下）ときだけ確実にバイキンを退治できるシステムです。
* **出典**: 講義テキスト 浄水施設 p.467〜470 / 水道施設の技術的基準を定める省令

### 設問2（4択：海水淡水化施設の構造と運用）
* **問題形式**: `choice`
* **問題文**: 海水淡水化施設（逆浸透法：RO法）に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 海水の自然浸透圧（約2.5MPa）を超える高圧（5〜7MPa）を印加して淡水を分離し、ホウ素基準（1.0mg/L以下）達成のため2段RO処理等を用いる
  2. 逆浸透膜（RO膜）は重力による自然流下水頭（約1m）のみで海水の塩分を100%完全分離できるため、動力ポンプは一切不要である
  3. 浸透取水方式は、海面表層の海水を直接吸い込む方式であり、クラゲや流木などの浮遊物を大量にそのまま取り込む特徴を持つ
  4. 海水淡水化によって生じる濃縮海水（ブライン）は淡水と同等の塩分濃度であるため、河川上流部の水源地域へ放流して再利用する
* **正解**: 1（インデックス: 0）
* **解説**: 海水淡水化RO法は海水の浸透圧（約2.5MPa）を超える 5〜7 MPa の超高圧を高圧ポンプで印加して淡水を取り出します。また、ホウ素基準（1.0mg/L以下）を満足させるため2段RO処理が多用されます（1が正解）。浸透取水方式は海底砂層下に取水管を埋設し、砂層の自然ろ過で清澄海水を得る方式です。濃縮海水は通常海水の約1.5〜2倍の塩分を含むため、環境影響に配慮して海底深層拡散放流等を行います。
* **日常のたとえ**: 濃い塩水を特殊な極小網（RO膜）に当て、ものすごい腕力（高圧ポンプ）で力任せに押し絞ることで、真水だけをピュッと搾り出すハイテク装置です。
* **出典**: 講義テキスト 浄水施設 p.470〜473

### 設問3（4択：浄水場排水処理に関わる環境関連法規）
* **問題形式**: `choice`
* **問題文**: 浄水場の排水処理施設に適用される環境関連法規（水質汚濁防止法および廃棄物処理法）に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 浄水能力 10,000 m³/日 以上の沈殿施設は水質汚濁防止法上の「特定施設」に該当し、脱水能力 10 m³/日 超の汚泥脱水施設は廃棄物処理法上の「産業廃棄物処理施設」に該当する
  2. 浄水処理過程で生じた脱水ケーキ（浄水発生土）は、家庭ごみと同じ「一般廃棄物」に分類されるため、マニフェストによる管理は一切不要である
  3. 水質汚濁防止法に基づく排出基準は、工場・事業場のみに適用され、地方公営企業である水道事業の浄水場排水は一切適用除外とされる
  4. 廃棄物処理法における産業廃棄物処理施設の指定基準は、脱水能力「1,000,000 m³/日 以上」の大規模施設に限定されている
* **正解**: 1（インデックス: 0）
* **解説**: 浄水能力「10,000 m³/日 以上」の沈殿施設は水濁法の特定施設に指定され排出基準が適用されます。また、脱水能力「10 m³/日 超」の脱水施設は廃掃法の産業廃棄物処理施設に該当します（1が正解）。浄水発生土は「無機性汚泥（産業廃棄物）」でありマニフェスト管理が義務付けられています。水道事業であっても水濁法の適用除外にはなりません。
* **日常のたとえ**: 「浄水能力1万トンで排水チェック（水濁法）」、「脱水10トン超で産廃施設登録（廃掃法）」という、水道技術管理者が絶対に暗記すべき2大数値基準です。
* **出典**: 講義テキスト 浄水施設 p.474 / 水質汚濁防止法 / 廃棄物処理法

### 設問4（4択：濃縮槽および機械脱水機の構造・管理）
* **問題形式**: `choice`
* **問題文**: 浄水場の濃縮施設（シックナー）および機械脱水施設に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 重力濃縮槽のスラッジ滞留時間は 24〜48時間 を標準とし、池底勾配は汚泥収集を円滑にするため 1/10 以上とする
  2. 加圧脱水機（フィルタープレス）は、真空脱水機や遠心脱水機に比べて脱水ケーキの含水率が最も高くなり、泥水状態で排出される
  3. 天日乾燥床は機械脱水機に比べて所要敷地面積が極めて狭くて済み、豪雨時であっても乾燥日数に全く影響を受けない
  4. 重力濃縮槽の汚泥掻寄機は、槽内のスラッジを完全に巻き上げて均一な懸濁状態を保つため、高速回転で激しく攪拌する構造である
* **正解**: 1（インデックス: 0）
* **解説**: 重力濃縮槽の計画スラッジ滞留時間は「24〜48時間」、底勾配は「1/10以上」、池数は「2池以上」を標準とします（1が正解）。加圧脱水機（フィルタープレス）は最も高圧搾できるため、ケーキ含水率を最も低く（約60%前後）できます。天日乾燥床は広大な敷地を要し降雨・気候に大きく左右されます。濃縮槽の掻寄機は沈降したスラッジを巻き上げないよう極めて低速で回転します。
* **日常のたとえ**: 泥水を一晩じっくり静かに寝かせて（濃縮槽24〜48時間）、底に溜まったドロドロの泥を油圧プレス機（フィルタープレス）でギューッと強力に絞っておせんべい状（ケーキ）にするプロセスです。
* **出典**: 講義テキスト 浄水施設 p.475〜478 / 水道施設設計指針

### 設問5（4択：スラッジ加温脱水システム）
* **問題形式**: `choice`
* **問題文**: 浄水場におけるコージェネレーション廃熱等を活用したスラッジ加温脱水システムに関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 冬期の水温低下に伴う汚泥の粘性上昇を防ぐため、排熱蒸気等でスラッジを加温して粘性を低下させ、脱水速度と効率を向上させる
  2. スラッジを加温すると汚泥中の水分が膨張してろ布を破断させるため、脱水機へ送る直前に汚泥を氷点下まで急速冷却するのが標準である
  3. スラッジ加温システムは夏期の高温期専用の設備であり、冬期の寒冷時には凍結防止のため温水ボイラーを停止させる規定がある
  4. 汚泥を加温しても脱水速度やケーキ含水率には物理学的に何ら影響を与えないため、省エネルギーの観点から国土交通省により設置が禁止されている
* **正解**: 1（インデックス: 0）
* **解説**: 冬期に汚泥温度が下がると粘性が高まり脱水抵抗が増大して効率が落ちます。常用発電設備等のコージェネレーション廃熱等を利用してスラッジを加温すると、粘性が低下して脱水速度が大幅に向上（約1.5〜2倍）し、ケーキ含水率も低減します（1が正解）。
* **日常のたとえ**: 冷蔵庫で冷えて固まったカレー（粘性が高い泥）を電子レンジで温めるとサラサラになって濾しやすくなるのと同じ原理です。
* **出典**: 講義テキスト 浄水施設 p.478〜480
