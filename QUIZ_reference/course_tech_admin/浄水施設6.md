## 1. 急速ろ過池の点検整備・ろ層更生工事とマッドボール（テキスト p.407, p.420）

### (1) ろ過池の点検・調査基準（維持管理指針）
急速ろ過池は、長期間の運転に伴いろ材の摩耗・流出、濁質の蓄積、支持砂利の乱れが生じるため、定期的な点検と計画的な更生工事が不可欠である。

### (2) ろ層更生工事（サンド・リハビリテーション）の標準手順
ろ層更生工事は、ろ過池を一定期間停止し、ろ材・支持砂利を取り出して洗浄・篩い分け・再充填する大規模修繕工事である。

```
【ろ層更生工事の施工フロー】
① 現状調査 ────── ろ層厚の測定、層面の不陸（波打ち）、マッドボールの深さ・分布の確認
      ↓
② ろ材の搬出 ──── バキューム車やサンドポンプでろ砂・アンスラサイトを池外へ排出
      ↓
③ ろ材の洗浄分級 ─ 場外または場内の仮設砂洗浄機で濁質を除去し、規格外微粒・粗粒を篩い分け
      ↓
④ 下部集水装置点検 砂利を全量撤去後、集水ブロック・ストレーナーの破損、目詰まり、ボルト緩みを点検補修
      ↓
⑤ 支持砂利の敷設 ─ 下層から大粒（粗粒）→ 上層に小粒（細粒）の順に設計層厚どおり厳密に水平敷設
      ↓
⑥ ろ材の再充填 ── 砂（複層の場合は砂→アンスラサイト）を敷き均し、層厚と水平度を検測
      ↓
⑦ ならし逆洗 ──── 数回の逆流洗浄を行い、微粉末を洗い流して自然な粒度成層（水力分級）を完了
```

### (3) マッドボール（泥球）の発生メカニズムと弊害
* **定義と性状**:
  * 洗浄不良により、逆流洗浄で排出しきれなかった微細フロック（懸濁濁質）が、砂粒を核として団子状に結合・凝縮した泥の塊。
  * 大きさは大豆大（数mm）から、放置すると**直径 50 mm（5 cm）以上の巨大な球塊**へと成長する。
* **発生しやすい箇所**:
  * 表面洗浄水が届きにくい**池の四隅・壁際・洗水トラフ下部**。
  * 多層ろ過池における**アンスラサイト層とケイ砂層の境界面（インターフェース）**。
* **進行と沈降のプロセス**:
  1. 表層付近で形成されたマッドボールは、粘土・金属水酸化物を取り込んで次第に高密度化する。
  2. マッドボールの見掛け密度（比重）が、流動状態にあるろ材の密度を上回ると、逆洗の流動・膨張のたびに**ろ層内を徐々に沈降**していく。
  3. 最終的に**支持砂利層の境界付近（ろ層最深部）に沈着**し、そこで多数が合体して扁平な板状泥層（マッドケーキ）を形成する。
* **もたらされる重大な障害**:
  * **有効ろ過面積の減少**: 板状マッドボール部分が通水不能となり、ろ過面積が大幅に狭まる。
  * **局部的高速ろ過（ショートパス）**: 閉塞部を迂回した水が特定箇所に集中し、局所的な流速過大から濁質漏出（ブレークスルー）を引き起こす。
  * **支持砂利の乱れ**: 沈降したマッドボール周りの偏流噴流により、支持砂利層が噴き上げられて撹乱される。

## 2. 多層（複層）ろ過池の構造・機能と運転管理（テキスト p.407〜408）

### (1) 多層ろ過池の原理と特徴
従来の砂単層ろ過池では、逆流洗浄を行うと水力分級によって「上層が細粒、下層が粗粒」となり、ろ過水が上から流れるため表層数センチで大半の濁質が捕捉され、表層閉塞を起こしやすい。  
これに対し、**多層ろ過池（二層ろ過池）**は比重と粒径の異なるろ材を組み合わせ、**水流方向に「粗粒 $\rightarrow$ 細粒」となる理想的な逆粒度構成（深層ろ過）**を実現する。

```
【単層砂ろ過 vs 多層ろ過（二層）の構造対比】

    ［単層砂ろ過］                     ［多層（二層）ろ過］
 流入水 ↓                           流入水 ↓
┌─────────────────────────┐         ┌─────────────────────────┐
│ 細粒砂（有効径 0.5mm）  │←表層閉塞│ 粗粒アンスラサイト      │←深層捕捉
│ 比重 2.65               │しやすい │ (有効径1.0mm, 比重1.5)  │  (空隙大)
├─────────────────────────┤         ├─────────────────────────┤
│ 粗粒砂（有効径 0.8mm）  │         │ 細粒ケイ砂              │←微細濁質
│ 比重 2.65               │         │ (有効径0.5mm, 比重2.65) │  最終捕捉
└─────────────────────────┘         └─────────────────────────┘
     ↓ ろ過水                            ↓ ろ過水
```

├──────────────────┼────────────────────────────────────────────────────────┤

### (2) 多層ろ過池の維持管理上の重要留意点
1. **アンスラサイトの流出・飛散防止**:
   * アンスラサイトは比重が小さいため、逆流洗浄時の流速が過大になると洗水トラフから容易に系外へ流出する。
   * 逆洗水量を厳密に制御するとともに、必要に応じてアンスラサイトを定期補充する。
   * 水中気泡がアンスラサイト粒子に付着すると浮上流出するため、逆洗前に気泡を脱気する配慮が必要。
2. **洗浄方式（界面洗浄の強化）**:
   * アンスラサイトとケイ砂の境界面にマッドボールが発生しやすいため、**アンスラサイト表面とケイ砂表面を同時に洗える「2段式回転表面洗浄装置」**、または**「空気洗浄＋水逆洗」**を併用する。

## 3. 自然平衡型急速ろ過池（グリーンリーフ型等）（テキスト p.408〜410）

### (1) 定義と作動原理
* **定義**:
  * 各ろ過池への流入水量と流出水量が水理学的に自然平衡する方式の急速ろ過池。
  * 代表例として「自己逆流洗浄型（グリーンリーフ型等）」がある。
* **主要な構造と作動メカニズム**:
  * **流出制御弁の省略**: 個々の池出口に複雑な自動流量調節弁を設けず、流入サイフォンや堰により均等分配し、水位変化に応じて自然流出させる。
  * **自己逆流洗浄（ポンプレス逆洗）**:
    * 共通のろ過水流渠を複数のろ過池（通常4〜6池以上）で共有する。
    * ある1池を逆流洗浄する際、**稼働中の他の健全な池群が生産した清澄ろ過水**が共通流渠を経由して洗浄対象池の底部に押し上げられ、水頭差によって逆流洗浄を行う。
    * **逆洗用高架水槽や大型逆洗ポンプが完全に不要**となる。

```
【自然平衡型ろ過池のメリット・デメリット】
┌─────────────────────────────────┬─────────────────────────────────┐
│ メリット（長所）                │ デメリット（留意事項）          │
├─────────────────────────────────┼─────────────────────────────────┤
│ ・逆洗ポンプ・高架水槽が不要    │ ・他池のろ過水で洗浄するため、  │
│ ・配管・電動調節弁が簡素で省保守│   十分な池数（最低4池以上）必要 │
│ ・動力エネルギー消費が極めて少  │ ・共通流渠で全池が連結されるため│
│ ・機械故障による全停止リスク低  │   区画仕切弁等によるリスク分散要│
└─────────────────────────────────┴─────────────────────────────────┘
```

## 4. 圧力式急速ろ過池（テキスト p.410〜412）

密閉型の耐圧鋼製タンク内に支持床・支持砂利・ろ材（ケイ砂、アンスラサイト、マンガン砂等）を充填し、ポンプの送水圧力を直接利用してろ過を行う装置である。

### (2) 接触酸化ろ過による除鉄・除マンガン
* 地下水中の溶解性鉄（$\text{Fe}^{2+}$）およびマンガン（$\text{Mn}^{2+}$）を除去するため、圧力式ろ過池に**マンガン砂**を充填して処理する。
* **反応メカニズム**:
  $$\text{Mn}^{2+} + \text{NaClO} + \text{H}_2\text{O} \xrightarrow{\text{MnO}_2\text{触媒}} \text{MnO}_2\downarrow (\text{不溶化}) + \text{NaCl} + 2\text{H}^+$$
* **維持管理の要件**:
  * マンガン砂の触媒活性を維持するため、**流入水中に常時「遊離残留塩素」を存在（前塩素注入）**させることが絶対条件である。塩素注入が途絶えるとマンガンが剥離・漏出する。
  * 毎月1回以上、原水・処理水・排水中の鉄・マンガン濃度を試験測定する。

## 5. 直接ろ過方式（ダイレクトフィルトレーション）（テキスト p.412〜413）

### (1) 定義と処理フロー
* **定義**:
  * 原水に微量の凝集剤（PAC等）を注入・急速混和した後、**フロック形成池および薬品沈殿池を経由せず、直接急速ろ過池に通水**して濁質を除去する方式。
* **処理フローの対比**:
  * 通常処理: 着水井 $\rightarrow$ 薬品混和池 $\rightarrow$ **フロック形成池** $\rightarrow$ **薬品沈殿池** $\rightarrow$ 急速ろ過池
  * 直接ろ過: 着水井 $\rightarrow$ 薬品混和池 $\rightarrow$ **（直行バイパス）** $\rightarrow$ 急速ろ過池（多層ろ過池が望ましい）

### (2) メリットと適用条件
1. **メリット**:
   * 沈殿池が不要なため、**建設敷地面積および初期設備投資費を劇的に削減**できる。
   * 発生する排泥量が極めて少なく、汚泥処理コストが低減する。
   * 低濁度・低水温時において、沈殿池で沈降しない微細なマイクロフロックをろ層内で直接捕捉できる。
2. **採用のための必須条件（指針基準）**:
   * **年間を通じて原水濁度が極めて低く（概ね10度以下）、水質が長期的に安定**していること。
   * 原水水質悪化時に備え、通常の「凝集沈殿処理」へ即座に切り替えられる予備設備またはバイパス系統を有すること。

### (3) 直接ろ過方式の適用限界（★試験頻出の弱点）
```
【直接ろ過を適用できない水質条件】
┌──────────────────┬────────────────────────────────────────────────────────┐
│ 水質要因         │ 適用不適の理由と現象                                   │
├──────────────────┼────────────────────────────────────────────────────────┤
│ ① 高濁度時       │ ろ層が瞬時に濁質で飽和し、急激な損失水頭上昇と濁質漏出 │
│    （豪雨・出水）│ （ブレークスルー）を引き起こすため、通常沈殿に切替要。 │
├──────────────────┼────────────────────────────────────────────────────────┤
│ ② 藻類多発時     │ 原水濁度が低くても、ケイ藻類等のプランクトンがろ材表面 │
│                  │ を目詰まりさせ、著しいろ過閉塞を引き起こす。           │
├──────────────────┼────────────────────────────────────────────────────────┤

│    が高い原水    │ 多量の水酸化物フロック形成・沈殿分離が必須なため不適。 │
└──────────────────┴────────────────────────┴──────────────────────────────────────┘
```

## 8. 想定問題集（4択ドリル用プロトタイプ問題）

### 設問1（4択：ろ過池の点検整備とろ層更生工事）
* **問題形式**: `choice`
* **問題文**: 急速ろ過池の点検整備およびろ層更生に関する記述として、水道施設維持管理指針に照らして**最も適切なもの**はどれですか？
* **選択肢**:
  1. ろ層の汚れはろ過継続時間に直結するため、少なくとも年1回はろ材厚、有効径、均等係数、マッドボールの発生状況を調査する
  2. 支持砂利層および下部集水装置は半永久的に健全性が保たれるため、通水期間中に掘削調査を行う必要は一切ない
  3. 逆流洗浄によるろ材の流出や摩耗に伴うろ材補充は、規定のろ層厚より 50% 以上減少した段階で行うのが標準である
  4. ろ層更生工事でろ材を再充填した直後は、直ちに最大ろ過速度で給水通水を開始し、水圧で砂層を締め固める
* **正解**: 1（インデックス: 0）
* **解説**: ろ材の有効径、均等係数、ろ層厚、マッドボールの発生状況などは「少なくとも年1回」調査します（1が正解）。支持砂利層および下部集水装置は「10年に1回程度」調査・整備が必要です。ろ材補充は規定層厚より「10%程度減少」した段階を目安に行います。更生後はならし逆洗（微粉末除去と水力分級）を行ってから通水を開始します。
* **日常のたとえ**: 自動車のオイル交換（年1回点検・10%減で補充）と、10万キロごとのタイミングベルト・エンジン分解オーバーホール（10年ごとの支持砂利・集水装置点検）の関係と同じです。
* **出典**: 講義テキスト 浄水施設 p.407, p.420 / 水道施設維持管理指針

### 設問2（4択：マッドボールの発生と弊害）
* **問題形式**: `choice`
* **問題文**: 急速ろ過池におけるマッドボール（泥球）に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. マッドボールは、表面洗浄水が届きにくい池の四隅や、多層ろ過池のアンスラサイトとケイ砂の境界面に発生しやすい
  2. マッドボールの見掛け密度がろ材の流動密度を超えると、逆流洗浄を繰り返すうちにろ層内を徐々に沈降していく
  3. マッドボールが支持砂利層の境界付近に沈着して板状の塊を形成すると、有効ろ過面積が減少し偏流による濁質漏出の原因となる
  4. マッドボールは比重が水より極めて小さいため、逆流洗浄を行うたびに水面に浮上して洗水トラフから自然に全量排出される
* **正解**: 4（インデックス: 3）
* **解説**: マッドボールは砂粒を中心に微細濁質が凝縮したもので、次第に密度が増大し、逆流洗浄時の流動に伴って「下層へ沈降」していきます。水面に浮上して自然排出されることはなく、支持砂利層付近で巨大化・板状化して偏流や濁質漏出（ブレークスルー）の原因となります（4が誤り）。
* **日常のたとえ**: 洗濯機で泥まみれの靴下を洗った際、泥がほぐれずに固まって「泥団子」になり、重くなって洗濯槽の底に沈んでモーターに挟まるようなトラブルです。
* **出典**: 講義テキスト 浄水施設 p.407〜408

---

### 設問3（4択：多層ろ過池の構造と機能）
* **問題形式**: `choice`
* **問題文**: アンスラサイトとケイ砂を用いた多層（複層）ろ過池に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 上層に比重が小さく粒径の大きいアンスラサイト、下層に比重が大きく粒径の小さいケイ砂を配置し、深層ろ過を実現する
  2. アンスラサイトはケイ砂よりも比重が大きいため、逆流洗浄を行っても絶対にトラフから流出することはない
  3. 多層ろ過池の標準的なろ過速度は、ろ過抵抗を低減させるため砂単層ろ過池の半分である 60〜80 m/日 とする
  4. 多層ろ過池はシネドラやメロシラ等のケイ藻類が原水に含まれている場合、砂単層ろ過池よりも容易に表層閉塞を起こす
* **正解**: 1（インデックス: 0）
* **解説**: 多層ろ過池は、比重が小さく粗粒のアンスラサイト（比重1.4〜1.6、有効径0.7〜1.5mm）を上層に、比重が大きく細粒のケイ砂（比重2.65、有効径0.45〜0.7mm）を下層に配置することで「粗 $\rightarrow$ 細」の逆粒度深層ろ過を実現します（1が正解）。アンスラサイトは軽いため逆洗時の流出に注意が必要です。標準ろ過速度は「200〜240 m/日」と高速化でき、ケイ藻類によるろ過閉塞を起こしにくい長所を持ちます。
* **日常のたとえ**: 掃除機のフィルターで、手前に目の粗いプレフィルター（アンスラサイト）を置き、奥に目の細かい微粒子フィルター（ケイ砂）を置くことで、プレフィルターで大きなゴミを捕まえて目詰まりを防ぎ、長持ちさせる仕組みと同じです。
* **出典**: 講義テキスト 浄水施設 p.407〜408 / 水道施設設計指針

### 設問4（4択：圧力式急速ろ過池および直接ろ過方式）
* **問題形式**: `choice`
* **問題文**: 圧力式急速ろ過池および直接ろ過方式に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 圧力式急速ろ過池は完全密閉された遮光構造であるため、池内での藻類の光合成・繁殖が発生しない利点がある
  2. 圧力式急速ろ過池のタンク内面防食塗装には、安価で密着性に優れたコールタールエポキシ樹脂塗料を使用するのが標準である
  3. 直接ろ過方式は、豪雨等により原水濁度が著しく急上昇した際や、ケイ藻類が大量発生した際に最も安定した処理水質を発揮する
  4. マンガン砂を用いた除鉄・除マンガン圧力式ろ過池では、マンガンの溶解を防ぐため流入水中の残留塩素を完全除去して通水する
* **正解**: 1（インデックス: 0）
* **解説**: 圧力式ろ過池は密閉鋼製タンクのため光が入らず、藻類が繁殖しない利点があります（1が正解）。タンク内面塗装にはタールエポキシは有害性のため使用禁止であり「水道用エポキシ樹脂塗料」を用います。直接ろ過は高濁度時や藻類多発時にはろ過閉塞や漏出を起こすため不適です。マンガン砂ろ過では接触酸化触媒機能を維持するため常時「遊離残留塩素」の存在が不可欠です。
* **日常のたとえ**: 圧力式ろ過池は「魔法瓶・圧力鍋」のようなもので、外の光を完全に遮断して中身を守りつつ、ポンプの力で一気に水を押し通すシステムです。
* **出典**: 講義テキスト 浄水施設 p.410〜413

### 設問5（4択：水道水源における障害生物）
* **問題形式**: `choice`
* **問題文**: 水道水源に発生する障害生物とその影響に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. ケイ藻類のシネドラ（*Synedra*）やフラギラリア（*Fragilaria*）は、硬いケイ酸殻を持つため急速ろ過池のろ過閉塞の主要原因となる
  2. ラン藻類のアナベナ（*Anabaena*）は、硬い殻でろ過閉塞を起こすが、カビ臭原因物質を産生することはない
  3. フォルミディウム（*Phormidium*）等のラン藻類が産生するカビ臭物質（2-MIB等）は、通常の急速砂ろ過のみで完全に除去できる
  4. クリプトスポリジウムのオーシストは、通常の塩素消毒濃度（0.1mg/L）で数分以内に完全に死滅・不活化される
* **正解**: 1（インデックス: 0）
* **解説**: シネドラ、フラギラリア、メロシラ、アステリオネラ等のケイ藻類はケイ酸質の外殻を持ち、砂層表面にマットを形成して著しいろ過閉塞を引き起こします（1が正解）。アナベナやかび臭産生ラン藻はジェオスミンや2-MIBを産生し、これらは通常の砂ろ過では除去できず粉末活性炭やオゾン・生物活性炭が必要です。クリプトスポリジウムは耐塩素性原虫であり、塩素消毒では死滅しません（ろ過出口濁度0.1度以下維持や紫外線処理が必須）。
* **日常のたとえ**: ケイ藻類は「ガラスの微細な破片」のような殻を持っているため、フィルターの網目にびっしり張り付いて水をせき止めてしまいます。
* **出典**: 講義テキスト 浄水施設 p.414〜420
