## 1. 高速凝集沈殿池の原理と構造（テキスト p.396〜397）

### (1) 高速凝集沈殿池の基本的特徴
* **定義と歴史的背景**:
  * 薬品混和、フロック形成、沈殿分離の一連の操作を単一の装置（円形池等）内に集約し、**わずか 1.5 〜 2時間（1〜2時間程度）の極めて短い滞留時間**で処理を完結させる高効率凝集沈殿施設である。
  * 従来の横流式沈殿池（滞留時間3〜4時間）に比べ、**所要敷地面積を大幅に縮小（数分の一）できる**画期的な施設として1950〜60年代に広く導入された。
* **メリットとデメリット（現代の評価）**:
  * **メリット**: 施設が極めてコンパクト、初期建設面積が小さい、薬品使用量が比較的少なくて済む。
  * **デメリット**: 内部構造が複雑、スラリー（汚泥層）濃度の維持管理に高度な熟練を要する、原水の水量・水質急変（低濁度・低水温・高濁度）に対する緩衝能力が小さい。
  * **現況**: 運転管理が容易な「傾斜板沈殿池」の普及に伴い、現在では特殊な敷地制約がある場合を除き新設されることはほとんどない。

```
【横流式沈殿池 vs 高速凝集沈殿池の主要諸元対比】
┌──────────────────┬────────────────────────┬────────────────────────┐
│ 項目             │ 横流式薬品沈殿池       │ 高速凝集沈殿池         │
├──────────────────┼────────────────────────┼────────────────────────┤
│ 滞留時間         │ 3 〜 4 時間            │ **1.5 〜 2.0 時間**    │
├──────────────────┼────────────────────────┼────────────────────────┤
│ **表面負荷率**   │ **15 〜 30 mm/分**     │ **40 〜 60 mm/分**     │
│                  │ ($21.6 \sim 43.2\text{ m/日}$)│ ($57.6 \sim 86.4\text{ m/日}$)│
├──────────────────┼────────────────────────┼────────────────────────┤
│ 適応原水濁度     │ 変動に強い             │ **10度以上、最高1,000度以下**│
├──────────────────┼────────────────────────┼────────────────────────┤
│ 構造構成         │ 混和・凝集・沈殿が独立 │ **単一装置内に一体集約**│
└──────────────────┴────────────────────────┴────────────────────────┘
```

### (3) 高速凝集沈殿池の運転管理とスラリー管理（テキスト p.397）
1. **スラリー界面の適正維持**:
   * スラッジブランケット型では、スラリー層の上面（スラリー界面）の高さを一定範囲に厳密に保つ。
   * **スラリー界面が高すぎる場合**: スラリーが上澄水へ溢れ出し、**フロックのキャリーオーバー（流出）**が発生して急速ろ過池を即座に閉塞させる。
   * **スラリー界面が低すぎる場合**: ブランケット層の濁質捕捉機能が失われ、清澄な上澄水が得られない。
2. **排泥（スラリー排出）の管理**:
   * 排泥水は通常の横流式沈殿池に比べて濃度が薄く水量が多い（薄いスラッジ）ため、**間欠的に短時間ずつ頻繁に排泥弁を開閉**して排出する。1日1回以上スラリー濃度・界面を測定する。
3. **水温逆転層（夜間のキャリーオーバー現象）**:
   * 夏期の夜間、放射冷却により水面付近の水温が下がり、下層の水温が高いままとなる「水温逆転層」が生じると、下層の温かい水が上昇流となってスラリーブランケットを破壊・巻き上げ、大規模なキャリーオーバーを引き起こす。界面を低めに管理する等の警戒が必要である。

## 2. 急速ろ過方式の目的と浄化メカニズム（テキスト p.397〜398）

### (1) 急速ろ過の定義と最終安全防壁としての役割
* **定義**:
  * 凝集沈殿処理を経た水（沈殿池上澄水）を、比較的粗い砂層（またはアンスラサイト＋砂層）に高速（日速 $120 \sim 150\,\text{m}$）で通過させ、残留する微細フロックや懸濁物質を分離除去する**浄水処理プロセスの最終浄化工程**である。
* **耐塩素性原虫（クリプトスポリジウム）対策**:
  * 急速ろ過池は、塩素消毒が効かないクリプトスポリジウム等の病原微生物を物理的に阻止・排除する決定的な防壁である。
  * **「ろ過池出口濁度 常時 0.1度以下」** を達成・維持することが法令・指針上の絶対要件である。

```
【急速ろ過の2大浄化メカニズム】
① 付着作用（吸着作用） ── 砂粒とフロック間の静電気力・分子間引力により、砂粒表面にフロックが付着。
② ふるい分け作用       ── 砂粒同士が形成する間隙（隙間）に、フロックが物理的に挟まり捕捉される。
```

### (3) アンスラサイトと複層ろ過（多層ろ過）
* **アンスラサイト（Anthracite）の性質**:
  * 高品位の無煙炭を破砕・整粒したろ材。
  * **ケイ砂に比べて比重が小さく（砂：約 $2.65$、アンスラサイト：約 $1.4 \sim 1.6$）、空隙率が大きい（約 $50\%$）**。
* **複層ろ過（Dual-Media Filtration）の構造**:
  * **上層**: 粒径の大きいアンスラサイト（有効径 $0.8 \sim 1.2\,\text{mm}$、層厚 $25 \sim 40\,\text{cm}$）
  * **下層**: 粒径の小さいケイ砂（有効径 $0.45 \sim 0.6\,\text{mm}$、層厚 $25 \sim 35\,\text{cm}$）
* **複層ろ過の決定的メリット**:
  1. **理想的な深層ろ過（粗 $\rightarrow$ 密）**: 水流の上流側に粗粒、下流側に細粒が配置されるため、濁質が砂層全体に立体的に分散捕捉され、表面閉塞が起きにくい。
  2. **高流速化とろ過継続時間の延伸**: ろ過速度を **$200 \sim 240\,\text{m/日}$** まで高速化でき、損失水頭の上昇が緩やかになる。
  3. **逆洗時の自動復元**: 水逆洗で砂層が激しく流動・攪拌されても、**比重差（アンスラサイトが軽く、砂が重い）により、洗浄終了後に自然とアンスラサイトが上層、砂が下層へと完全に分離・復元**する。

### (4) 支持砂利層の配置基準
* **役割**:
  * ろ過砂が下部集水装置の孔から漏出・流出するのを防ぐとともに、逆洗浄水を池底全面に均一に分散させる。
* **層構成（★最頻出引っかけ）**:
  * **「下層（最底部）ほど大粒の粗粒砂利（径 $30 \sim 50\,\text{mm}$）、上層（砂との境界面）に向かうに従って小粒の細粒砂利（径 $2 \sim 4\,\text{mm}$）」** を水平・均一に多段（通常 $20 \sim 40\,\text{cm}$）敷き詰める。

## 4. 下部集水装置とろ材上水深（テキスト p.403）

### (1) 下部集水装置（Underdrain System）
* **機能**: ろ過工程ではろ過水を池底全面から均等に集水し、洗浄工程では高圧の逆洗水（および空気）を偏流なく均一に吐出させる。
* **代表的形式**:
  * 有孔ブロック式（ホイーラーブロック式、レオポルドブロック式等）
  * ストレーナーブロック式（有孔ノズル式）
  * 有孔管式（ヘッダー・ラテラル管式）

### (2) ろ材上水深とエアーバインディング（Air Binding）防止
* ろ過の進行に伴い砂層内の損失水頭が増大すると、ろ層内部の圧力が大気圧以下（負圧）になることがある。
* 負圧になると、水中に溶存していた空気が気泡として析出し、砂粒の間隙を気泡が塞いで通水を完全に阻害する**「エアーバインディング（気泡閉塞現象）」**が発生する。
* これを防ぐため、**ろ材面上の水深は常に「1.0 m 以上（通常 1.5〜2.0 m）」を確保**する。

## 5. 急速ろ過池の洗浄設備と方式（テキスト p.404〜406）

急速ろ過池は、目詰まりした濁質を洗い流す「逆洗浄」を適切に行わなければ機能が維持できない。

```
【急速ろ過池の洗浄システム構成】
┌─────────────────────────────────┬─────────────────────────────────┐
│ ① 逆流洗浄（水逆洗 / Backwash）│ ② 補助洗浄（表面洗浄 or 空気洗浄）│
├─────────────────────────────────┼─────────────────────────────────┤
│ 下部集水装置から清浄水を逆噴射し│ 砂層の表面または内部を強力に攪拌│
│ 砂層全体を 20〜30% 膨張・流動化 │ し、砂粒同士を摩擦させて付着泥膜│
│ させて濁質を剥離・浮上させる。  │ を機械的にこすり落とす。        │
└─────────────────────────────────┴─────────────────────────────────┘
```

### (1) 洗浄設備の主要設計基準（『水道施設設計指針』）
1. **洗浄水質の絶対原則**:
   * 洗浄水には、**必ず「浄水（塩素消毒済みの安全な清浄水）」を使用**する（未ろ過水や沈殿水を用いると下部から病原菌・濁質が侵入し汚染されるため厳禁）。
2. **洗浄水源**:
   * **高架水槽（高架水タンク方式）**: 地形高低差またはタワータンクからの自然重力流下で水圧・水量を供給（停電時も洗浄可能、水圧安定）。
   * **逆洗ポンプ方式**: ポンプ動力で直接加圧して送水。
3. **逆洗水量と時間**:
   * 洗浄時間: **「4 〜 6分間」**。
   * 逆洗水流速: **$0.6 \sim 0.9\,\text{m}^3/(\text{m}^2\cdot\text{分})$**（砂層膨張率 $20 \sim 30\%$）。
4. **洗浄排水トラフ（洗水トラフ）の構造諸元**:
   * 洗浄時に浮上した濁質排水を溢流させて排水路へ流すトラフ。
   * **ろ材表面からトラフ上縁（天端）までの高さ**: **「40 〜 70 cm」**（低すぎると砂が越流流出、高すぎると濁水が抜けきらない）。
   * **トラフの水平度**: トラフ上縁は完全な水平・同一高さに据え付ける。

## 6. 急速ろ過池の運転管理と洗浄判定（テキスト p.405〜407）

### (1) 洗浄を開始する3大判定基準（★試験超頻出）
ろ過運転を停止し、逆洗浄を開始するタイミングは以下の3つの基準のいずれかに達した時である。

```
【逆洗浄を開始する3大判断基準】
① 水質基準：ろ過池出口の濁度が許容目標値（「0.1度」）に達した時（ブレークスルー）
② 損失水頭：ろ過損失水頭が設定限界（通常「1.5 〜 2.0 m」）に達した時
③ 継続時間：ろ過継続時間が設定上限（通常「48 〜 72時間」、最大96時間）に達した時
```

---


### (3) 洗浄終了基準とスロースタート（初流濁質漏出防止）
* **洗浄終了の判定**:
  * 逆洗排水の濁度が低下し、**排水濁度が「2度以下（できれば1度以下）」** に達した時点で逆洗を終了する。
* **スロースタート（Slow Start / 緩速通水開始）の絶対的必要性（★最頻出）**:
  * 逆洗浄終了直後の砂層内間隙には微細な濁質が浮遊残留しており、また砂粒の配列も不安定である。
  * **通水再開直後にいきなり全速力でろ過を開始すると、残留濁質が一気にろ過水出口へ抜け出る「初流濁水（濁質漏出ピーク）」が発生**し、水質基準やクリプト基準（0.1度）を超過してしまう。
  * したがって、通水再開時は**「弁を徐々に開き、時間をかけてゆっくりとろ過速度を立ち上げる（スロースタート）」**か、通水開始後数分〜十数分間の初流ろ過水を排水（捨水）しなければならない。
  * ろ過停止時も急激な水頭変化による濁質吸い出しを防ぐため**「スローダウン（Slow Down）」**を行う。

### 設問1（4択：急速ろ過池の設計諸元とろ材規格）
* **問題形式**: `choice`
* **問題文**: 『水道施設設計指針』に基づく急速ろ過池の構造およびろ材の規格に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 砂単層急速ろ過池のろ過速度は 120〜150 m/日 を標準とし、ろ材の有効径は緩速ろ過砂よりも粗い 0.45〜0.70 mm が用いられる
  2. 急速ろ過池の均等係数は、粒径のばらつきが大きいほど良好なため 3.0 以上と規定されている
  3. 洗浄の均等性を高めるため、急速ろ過池の1池あたりのろ過面積は 500 m² 以上と極力大きく設計する
  4. 砂単層急速ろ過池におけるろ材の有効層厚は、15〜20 cm 程度を標準とする
* **正解**: 1（インデックス: 0）
* **解説**: 砂単層急速ろ過池の標準諸元は、ろ過速度「120〜150 m/日」、ろ材有効層厚「60〜70 cm」、有効径「0.45〜0.70 mm」（緩速は0.30〜0.45mm）、均等係数「1.7 以下」（小さいほど粒径均一）、1池面積「150 m² 以下」です。
* **日常のたとえ**: ドリップコーヒーのフィルターで、お湯がサラサラ通り抜けるよう粒の揃った粗挽き豆を使うのが急速ろ過、じっくり時間をかけて抽出する細挽き粉が緩速ろ過です。

### 設問2（4択：複層ろ過および支持砂利層の構造）
* **問題形式**: `choice`
* **問題文**: 急速ろ過池におけるアンスラサイトを用いた複層ろ過および支持砂利層に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 複層ろ過池は、比重が小さく粒径の大きいアンスラサイトを上層に、比重が大きく粒径の小さいケイ砂を下層に配置する
  2. 支持砂利層は、上層（ろ材境界面）ほど粗い大粒の砂利を敷き、下層（池底部）ほど細かい小粒の砂利を配置する
  3. アンスラサイトはケイ砂よりも比重が重いため、逆流洗浄を行うとケイ砂の下層へと沈降する
  4. 複層ろ過池の標準的なろ過速度は、砂単層ろ過池よりも遅い 60〜80 m/日 程度に制限される
* **正解**: 1（インデックス: 0）
* **解説**: 複層ろ過（アンスラサイト＋砂）は、比重が小さく粗粒のアンスラサイト（比重約1.4〜1.6）を上層に、比重が大きく細粒のケイ砂（比重約2.65）を下層に配置して深層ろ過（粗 $\rightarrow$ 密）を行います。ろ過速度は 200〜240 m/日まで高速化可能です。支持砂利層は「下層ほど大粒、上層ほど小粒」を配置するのが鉄則です。
* **出典**: 講義テキスト 浄水施設 p.401〜403

### 設問3（4択：急速ろ過池の洗浄設備と維持管理）
* **問題形式**: `choice`
* **問題文**: 急速ろ過池の洗浄設備および運転管理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:

  2. 洗浄不良が継続すると、ろ材の有効径が著しく微細化して目詰まりが完全に解消される
  3. 急速ろ過池の逆流洗浄には、コスト削減のため薬品混和池の未ろ過原水をそのまま用いるのが一般的である
  4. 洗浄排水トラフの上縁は、ろ材面と全く同一の高さ（0cm）に設置して砂の流出を促す
* **正解**: 1（インデックス: 0）
* **解説**: ろ過池洗浄水には必ず「浄水」を使用します（沈殿水や原水は厳禁）。洗浄不良が起きるとマッドボールの発生、ろ層の亀裂、ろ材表面への付着による「ろ材の粗大化」が発生します。洗水トラフ上縁は砂の流出を防ぐためろ材表面から「40〜70 cm」の高さに水平に設置します。

### 設問4（4択：洗浄開始判定とスロースタート操作）
* **問題形式**: `choice`
* **問題文**: 急速ろ過池の洗浄判定および通水再開操作に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 逆洗浄終了直後は間隙に濁質が浮遊残留しているため、通水再開時は徐々にろ過速度を立ち上げる「スロースタート」を行う
  2. 急速ろ過池の出口濁度がクリプトスポリジウム対策基準である 0.1度 を超過した場合でも、損失水頭が限界に達するまで洗浄してはならない
  3. 逆流洗浄は、洗浄排水の濁度が 20度以上 の高濁度を維持している段階で速やかに終了するのが望ましい
  4. 洗浄終了直後は砂層が完全に清澄化されているため、直ちに設計最大速度で通水を開始するのが最も安全である
* **正解**: 1（インデックス: 0）
* **解説**: 逆洗直後は砂層間隙に濁質が残留し砂の配列も不安定なため、再開直後に「スロースタート（緩速通水開始）」を行わないと初流濁質漏出（ブレークスルー）を招きます。出口濁度が0.1度に達した際は直ちに洗浄を行います。逆洗排水濁度は「2度以下（目標1度以下）」まで洗い流します。
* **出典**: 講義テキスト 浄水施設 p.405〜407

### 設問5（4択：高速凝集沈殿池の特性と管理）
* **問題形式**: `choice`
* **問題文**: 高速凝集沈殿池の原理および運転管理に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. 高速凝集沈殿池は原水濁度や水量の急激な変動に対する緩衝能力が極めて大きく、熟練を要さずに無人自動運転が容易である
  2. スラッジブランケット型では、スラリー界面が高くなりすぎるとフロックがキャリーオーバーしてろ過池を閉塞させる恐れがある
  3. 高速凝集沈殿池の滞留時間は 1.5〜2.0時間 程度であり、横流式沈殿池に比べて大幅に短い
  4. 高速凝集沈殿池の標準的な表面負荷率は 40〜60 mm/分 であり、横流式沈殿池の約2倍である
* **正解**: 1（インデックス: 0）
* **解説**: 高速凝集沈殿池は滞留時間が短くスラリー濃度を一定に保つ必要があるため、原水の水質・水量変動に対する緩衝能力が小さく、運転管理に高度な熟練を要することが大きな短所です（無人自動運転が容易とする記述は誤り）。滞留時間1.5〜2時間、表面負荷率40〜60mm/分、キャリーオーバーのリスクの記述はすべて適切です。
* **出典**: 講義テキスト 浄水施設 p.396〜397
