## 1. 地下水取水の基本的要件（テキスト p.241）

### (1) 地下水水源の選定条件
1. **水質基準の適合**: 地表汚染（生活排水・農薬・揮発性有機化合物等）や塩水化の恐れがない、良質な帯水層を選定する。
2. **帯水層の通水性と厚さ**: 地層の透水係数や帯水層の層厚が十分であり、地盤沈下や出水障害を引き起こさない構造とする。
3. **計画1日最大取水量の安定確保**: 事前に現地で透水試験や揚水試験を実施し、渇水期でも必要水量を恒常的・安定的に採取できることを確認する。

### (2) 地下水の賦存形態の比較
* **不圧地下水（自由地下水）**:
  * 地表面から第1不透水層までの間に存在し、大気圧に接する自由水面を持つ。
  * 主に「浅井戸」で取水。地表汚染を受けやすく、降水量に連動して水位が変動しやすい。
* **被圧地下水**:
  * 上下を難透水層（粘土層・岩盤等）に挟まれた帯水層に満たされ、水圧（被圧水頭）を受けている。
  * 主に「深井戸」で取水。地表汚染を受けにくく、水質・水量・水温が年間を通じて極めて安定している。

## 2. 地下水の取水施設の種類と構造（テキスト p.241〜243）

地下水の取水施設には、水源の深さや地層条件に応じて主に以下の3種類がある。

```
              【地下水取水施設の3大形式】
  ┌────────────────┬────────────────┬────────────────┐
  │ ① 集水埋渠    │ ② 浅井戸       │ ③ 深井戸       │
  │ (伏流水・河床下)│ (不圧層・ケーソン│ (被圧層・深度30m│
  │ フィルター砂利 │  放射状集水井)  │  ストレーナー)  │
  └────────────────┴────────────────┴────────────────┘
```

### (1) 集水埋渠（しゅうすいまいきょ：伏流水の取水）
* **対象水源**: 河川の河床下や旧河道などの砂礫層中を浸透・流動している **伏流水（ふくりゅうすい）**。
* **構造と特徴**:
  * 河床下または高水敷（河川敷）の砂礫層中に、多数の小孔またはスリットを設けた **有孔管（集水埋管：ステンレス鋼管、有孔鉄筋コンクリート管等）** を横断的または縦断的に敷設する。
  * 目詰まり防止および細砂の流入を防ぐため、**管の周囲にフィルター材（洗浄砂利）を充填・被覆** する。
  * 集水した水を下流端の「集水井」へ自然流下で集め、ポンプで揚水する。
* **長所と短所**:
  * 河川水が自然の砂礫層でろ過されるため、表流水に比べて水質・水温が極めて安定しており、清澄な原水が得られる。
  * 河川の渇水期には伏流水の水位・流量も連動して低下する。

### (2) 浅井戸（あさいど：浅層地下水の取水）
* **対象水源**: 地表面直下の不圧帯水層（自由地下水）。
* **構造と特徴**:
  * 掘削深度は通常 **$8 \sim 20\,\text{m}$ 程度**（第1不透水層の上部まで）。
  * 内径数メートル規模の円筒形鉄筋コンクリート造（オープンケーソン工法で沈設）が多い。
  * 水の取り入れ方式：
    * **底面取水型**: 井戸の底部から湧出・流入させる方式（底面に砂利層を敷設）。
    * **側面取水型**: 井戸側壁にストレーナー（集水孔）を設けて側面から流入させる方式。
  * 土砂の吸い込みを防ぐため、流入流速が過大にならないよう開口面積を大きく確保する。
* **放射状集水井（ラジアルウェル・伏流水多量取水）**:
  * 大容量の水を採取するための大規模浅井戸構造。
  * 中央に大口径の集水井（立坑）を沈設し、その底部から周囲の帯水層へ向けて **放射状に多数のストレーナー管（集水管）を水平推進ジャッキで圧入・設置** する。
  * 巨大な立坑構造となるため、高地下水位時の **浮力に対する安定照査が必須** である。

### (3) 深井戸（ふかいど：深層地下水の取水）【最重要】
* **対象水源**: 難透水層（不透水層）の下にある被圧帯水層。
* **構造と部材（最重要ポイント）**:
  * 口径は比較的小さく（$\phi 200 \sim 500\,\text{mm}$ 程度）、**深度は通常 $30\,\text{m}$ 以上、深いものでは数百メートル** に達する。
  * **ケーシングパイプ**: 掘削孔の崩壊を防ぎ、浅層汚染水の浸入を遮断する鋼管等の管体。非帯水層部には無孔管を用いる。
  * **ストレーナー（集水管）**: 良好な被圧帯水層の位置に合わせて配置される、多数のスリット孔を持つ採水部（耐食性に優れたステンレス製等）。周囲に豆砂利（グラベルパイル）を充填して砂の流入を防止する。
  * **沈砂部（砂溜まり）**: ケーシングパイプの **最下部に無孔管として設けられる空間**。ストレーナーを通過して管内にわずかに流入した砂粒子を沈積・堆積させ、水中ポンプの摩耗を防ぐ。

## 3. 地下水調査とさく井（掘削）工法（テキスト p.243〜244）

### (1) 地下水の事前物理探査
* **電気探査（地上探査）**:
  * 地表面に複数の電極を配置して地中に通電し、地盤の見かけ比抵抗値の空間分布を測定。帯水層（砂礫層：中〜高比抵抗）と難透水層（粘土層：低比抵抗）の境界を非破壊で推定する。
* **電気検層（孔内探査）**:
  * テストボーリング孔内に電極プローブを吊り降ろし、深度ごとの比抵抗や自然電位を連続記録。帯水層の正確な深度・層厚・水質境界をミリ単位で精密に特定する。

### (2) 井戸の掘削（さく井）工法

| さく井工法 | 掘削機構・特徴 | 長所・短所・適用地盤 |
| :--- | :--- | :--- |
| **パーカッション工法**<br>（打撃式） | 重い掘削ビット（刃先）をワイヤーロープで吊り上げ、**上下に反復落下させて地層を衝撃破砕** し、バケットで掘屑を汲み出す。 | ・設備が簡素で施工コストが安価。<br>・比較的軟弱な地盤に適するが、大深度や硬岩の掘削には時間を要する。 |
| **ロータリー工法**<br>（回転式） | ドリルパイプ先端のビットを **機械的に高速回転させて地層を切削** し、ベントナイト泥水を循環供給して掘屑を地上へ連続排出する。 | ・大深度掘削や硬質岩盤に適する。<br>・狙った帯水層の位置へ正確・垂直に掘削可能。<br>・孔壁に泥膜（マッドケーキ）が形成されるため、後工程の洗浄が必須。 |

* **オープンホール工法とケーシング工法**:
  * **オープンホール工法**: 比重・粘性を調整したベントナイト泥水で孔内を満たし、泥膜（マッドケーキ）の被膜圧力で孔壁崩壊を防ぎながら裸孔で掘進する。
  * **ケーシング工法**: 鋼製ケーシングパイプを油圧等で圧入・先行させ、内部を掘削して物理的に壁面を防護する。
* **孔壁の泥水除去（仕上げ作業・井戸洗浄）**:
  * ロータリー工法等で孔壁に形成されたベントナイト泥膜（マッドケーキ）を放置すると、帯水層が目詰まりして著しい取水障害を引き起こす。
  * そのため、井戸完成後にピストン運動による水流往復（**スワビング**）や高圧ジェット洗浄、分散剤の注入を繰り返し、**孔壁・ストレーナー周辺の泥膜と細砂を完全に洗い流し・排泥する仕上げ作業（井戸洗浄）が不可欠** である。

## 4. 揚水試験と適正揚水量の算定（テキスト p.245〜247）【最重要】

井戸掘削後、その井戸から恒常的に安全に汲み上げられる水量を確定するため、以下の3大揚水試験を実施する。

```
              【井戸の3大揚水試験】
  ┌────────────────┬────────────────┬────────────────┐
  │ ① 段階揚水試験  │ ② 連続揚水試験  │ ③ 水位回復試験  │
  │ (5〜6段階ステップ│ (24時間以上連続 │ (ポンプ停止後の │
  │  限界揚水量把握)│  平衡水位の確認)│  水位復帰推移)  │
  └────────────────┴────────────────┴────────────────┘
```

### (1) 3大揚水試験の手順と目的
1. **段階揚水試験**:
   * 揚水量を段階的（通常 **5〜6段階程度**）にステップアップさせ、各ステップで水位が平衡に達した時の「水位低下量（ドローダウン）」を測定する。
   * 揚水量 $Q$ と水位低下量 $s$ の関係曲線を作成し、水理的限界である「**限界揚水量**」を特定する。
2. **連続揚水試験**:
   * 段階揚水試験の結果から定めた一定の揚水量で、**通常24時間以上連続して揚水を継続** する。
   * 時間経過に伴って水位低下が安定した平衡状態に達するかを確認し、帯水層の連続供給能力および周囲への影響圏を把握する。
3. **水位回復試験**:
   * 連続揚水試験の終了と同時にポンプを停止し、**低下した井戸水位が元の自然水位（静水位）へ復帰していく時間的推移を精密測定** する。
   * 帯水層の透水量係数や貯留係数を解析する。

### (2) 限界揚水量と適正揚水量の決定基準（最重要ポイント）
* **限界揚水量（Critical Yield）**:
  * 揚水量を増大させていく過程で、水位低下量が急激に跳ね上がり始める変曲点（水理的限界点）における揚水量。
* **適正揚水量（Safe Yield）**:
  * 限界揚水量を超えて揚水すると、急激な水位低下、井戸の枯渇、砂の吸い込み、揚水ポンプの気蝕（キャビテーション）、広域的な地盤沈下を引き起こす。
  * したがって水道実務では、安全率を見込み、**限界揚水量のおおむね 70% 程度を「適正揚水量」の上限** として設定・運用する。

### (3) 【実例】過剰揚水による地盤沈下と「抜上り井戸」
* **歴史的背景**:
  * 高度経済成長期、工業用水やビル冷房用として地下水を無秩序に過剰汲み上げした結果、全国の平野部で深刻な地盤沈下が発生。
  * 東京都江東区などのゼロメートル地帯では累計で **約4m以上沈下** し、沈下しない強固な支持層に打ち込まれた井戸のケーシングパイプだけが地上へ数メートルも突き出る「**抜上り井戸（ぬけあがりいど）**」が多発した。
* **法規制の成果**:
  * 工業用水道法や建築物用地下水採取規制法の施行、水道水源の河川表流水・ダム水への転換により、現在では全国的に地下水位が回復し、沈下は沈静化・安定傾向にある。

## 5. 取水施設の維持管理基準（テキスト p.247〜248）

### (1) 地表水取水施設の維持管理
* **共通管理項目**:
  * 計画取水量を確保するための河川流量・取水量の常時監視および記録。
  * 流入口スクリーンの塵芥（流木・落ち葉・ゴミ）の定期的な掻き揚げ・除塵。
  * **原水の水質連続監視（濁度、pH、電気伝導率、油膜検知等）**: 油流出事故等の早期発見と、水系内水道事業者・関係機関への迅速な通報連絡体制の維持。
  * 河川法に基づく「操作規程」の遵守と、取水ゲート・電気設備の定期点検。
* **各形式の維持管理留意点**:
  * **取水堰**: 堰上流側の堆砂状況を監視し、土砂吐きゲート操作や定期的な堆砂浚渫を実施。
  * **取水塔**: 水質状況（表層アオコ・底層濁水）に応じた最適なゲートの **選択取水操作** と水密パッキンの保守。
  * **取水枠**: 河床での目詰まりを解消するための **定期的な逆洗（圧縮空気・加圧水）** と、船舶衝突防止標識（灯浮標）の保守。
  * **沈砂池**: 2池交互運用による計画的な排砂・清掃。油臭・異臭味流入時の粉末活性炭注入。

### (2) 地下水取水施設の維持管理
* **水量の適正管理**:
  * 揚水試験で定めた **適正揚水量（限界揚水量の約70%以内）を厳格に遵守** する。
  * 日々の揚水量、静水位（ポンプ停止時）、動水位（揚水稼働時）を継続的に自動記録し、水位低下傾向や揚水障害の兆候を早期発見する。
* **水質管理と新たな化学物質への対応**:
  * 浅井戸は地表汚染を受けやすいため水質連続監視を徹底する。
  * 近年、全国で環境問題となっている **有機フッ素化合物（PFOS/PFOA）** や硝酸態窒素などの化学物質汚染に注視し、定期的な精密水質試験を行う。
* **保安・警備と防護体制（テロ対策・防犯）**:
  * 飲料水の水源としての重要性に鑑み、毒物混入やテロ・不法侵入を防止するため、**井戸建屋の施錠管理、防護柵（フェンス）の設置、監視カメラによる常時監視体制** を確保する。
* **集水埋渠の保守**:
  * 洪水時の高濁度原水取水を防止・抑制する。
  * 集水管内の目詰まり・砂閉塞に対しては定期的な管内高圧洗浄を実施する。
