## 1. 凝集沈殿プロセスの全体体系と機能分担（テキスト p.386）

### (1) 3段階の機能分担と役割
急速ろ過方式における「凝集沈殿プロセス」は、原水中のコロイド・懸濁質をフロック化して粗分離し、後続の急速ろ過池への濁質負荷を劇的に軽減する最も中核的な工程である。  
この工程は、水理学的・物理化学的な役割に応じて以下の3つの単位施設から構成される。

```
【凝集沈殿プロセスの3段階フロー】

                      (混和池)               (凝集池)                 (沈殿池)                 │
                      ・急速攪拌             ・緩速攪拌               ・静穏重力沈降           ▼
                      ・滞留 1〜5分          ・滞留 20〜40分          ・滞留 3〜4時間     ［急速ろ過池へ］
                      ・荷電中和完了         ・フロック粗大成長       ・フロック分離除去
```

```

├──────────────┼──────────────────┼────────────────────────────────────────┤
│ ① 薬品混和池 │ 急速攪拌         │ 注入薬品を瞬時に均等拡散させ、原水粒子 │
```

### (2) 水道法第19条・施設基準における要求事項
* **凝集池**: 凝集剤を原水に適切に混合させることにより、フロックが良好に形成される構造であること。
* **沈殿池**: 懸濁物質を有効に沈殿させることができ、かつ沈殿したスラッジ（排泥）を容易に排出・排除できる構造であること。

## 2. 沈殿の理論と表面負荷率（テキスト p.386〜388）

### (1) 表面負荷率（水面積負荷：Surface Loading Rate）の定義
沈殿池の処理能力と沈殿効率を決定づける最も重要な設計諸元である。沈殿池の水面積 $A$ に対する処理流量 $Q$ の比として定義される。

$$v_0 = \frac{Q}{A}$$

* **単位**: $\text{m}^3/(\text{m}^2\cdot\text{日}) = \text{m/日}$、または実務で多用される $\text{mm/分}$。
  * ※換算例：$1\,\text{mm/分} = 1.44\,\text{m/日}$（$15\,\text{mm/分} = 21.6\,\text{m/日}$、$30\,\text{mm/分} = 43.2\,\text{m/日}$）。
* **標準的な表面負荷率の基準値（『水道施設設計指針』）**:
  * **単層式 横流沈殿池**: **$15 \sim 30\,\text{mm/分}$**（$21.6 \sim 43.2\,\text{m/日}$）。
  * **多層式（二層折り返し）沈殿池**: **$15 \sim 25\,\text{mm/分}$**。
  * **水平流式 傾斜板沈殿池**: **$4 \sim 9\,\text{mm/分}$**。
  * **上向流式 傾斜板沈殿池**: **$7 \sim 14\,\text{mm/分}$**。

---

### (2) ハゼン・キャンプ（Hazen-Camp）の理想沈殿理論

```
【理想沈殿池における粒子の沈降挙動】
  流入端                                               流出端
  ┌────────────────────────────────────────────────────────┐ ── 水面
  │＼ 粒子軌道 A (沈降速度 v ≧ v₀) ──→ 完全沈殿捕集       │
  │  ＼                                                    │
  │    ＼                                                  │
  │      ＼                                                │
  │        ＼ 粒子軌道 B (v < v₀) ──→ 一部越流流出 (キャリーオーバー)
  └────────────────────────────────────────────────────────┘ ── 池底
  │◄─────────────────── 有効長 L ───────────────────────►│
```

* **完全除去条件**:
  * 理想的な矩形沈殿池において、フロック粒子の沈降速度を $v$、表面負荷率を $v_0$ とすると、**$v \ge v_0$ であるすべての粒子は100%完全に沈殿除去される**。
* **除去率の計算**:
  * $v < v_0$ の遅い粒子であっても、水深の低い位置から流入した粒子は一部沈殿し、その除去効率 $E$ は次式で表される。

$$E = \frac{v}{v_0} = \frac{v \cdot A}{Q}$$

---

### (3) 沈殿効率を向上させる3大アプローチ（★試験頻出）
上記理論式より、沈殿効率 $E$ を高める（＝より小さな微細フロックまで落とす）ための工学的手法は以下の3点に集約される。

```
【沈殿効率向上の3大アプローチ】
① 水面積 A を増大させる ── 多層式（二層式）沈殿池、傾斜板・傾斜管沈殿池の導入（浅層沈殿）
② 粒子の沈降速度 v を大きくする ─ 凝集剤注入の最適化、高比重フロック形成、高速凝集沈殿池
③ 処理流量 Q を抑制・平準化する ─ 負荷の平準化、中間引き抜き方式
```

## 3. 薬品混和池の構造基準と運転管理（テキスト p.391）

### (1) 混和池（Flash Mixing Basin）の構造基準
* **目的**: 注入された凝集剤を水流全体へ瞬時に均一拡散させ、原水の負電荷粒子と激しく衝突させて荷電中和を完了させる。
* **滞留時間**: 計画一日最大浄水量に対して **「1 〜 5分間」** を標準とする（テキスト p.391）。
* **構造上の必須要件**:
  * 死水域（滞留部）や短絡流（ショートサーキット）を生じさせない構造とする。
  * 点検・清掃時にも給水を継続できるよう、原則として**2池以上**とするかバイパス管を設ける。

---

### (2) 混和方式の分類
1. **機械攪拌方式（フラッシュミキサー）**:
   * モーター直結の高速回転パドル・プロペラ羽根によって強力に攪拌する方式。
   * 水量変動に関わらず一定の攪拌強度（G値）を維持でき、インバータ等で回転数を制御可能。
2. **水理攪拌方式（水流段差・邪魔板・跳水）**:
   * 越流堰の落差（水頭差）や邪魔板（バッフル壁）による水流の乱れを利用する方式。
   * 動力費がかからないが、処理水量が低下すると攪拌力が弱まる欠点がある。
3. **拡散ポンプ混和方式（ジェット混和）**:
   * 着水井からポンプで加圧した水流の中に薬品を混注し、ジェット噴流で瞬時に拡散・混合させる方式。

---

## 4. フロック形成池の構造基準と運転管理（テキスト p.391〜392）

### (1) フロック形成池（フロキュレーター）の構造基準
* **設置場所**: 薬品混和池と薬品沈殿池の間に位置し、水流を乱さないよう**沈殿池と一体構造**とする。
* **形状**: 長方形。
* **滞留時間**: 計画一日最大浄水量の **「20分 〜 40分間」** を標準とする（テキスト p.391）。

---

### (2) 攪拌方式と流速・周速基準

### (3) テーパード攪拌（Tapered Flocculation / 攪拌強度漸減の原則）（★最重要）
* **原理**:
  * 流入直後（上流・前段）は、微細フロック同士の衝突頻度を高めるため**攪拌強度を強め**にする。
  * 流下に伴いフロックが大きく成長した下流側（後段）では、成長したフロックが水流のせん断力によって破壊・微細化（再分散）するのを防ぐため、**攪拌強度を段階的に弱く（漸減）させる**。
* **機械式の場合**: 前段パドルの回転数を速くし、後段パドルの回転数を遅くする。
* **紆流式（水理式）の場合**: 下流に行くに従って**隔壁（バッフル）の間隔や流路幅を徐々に広げ**、流速を落とす。

---

### (4) 運転管理・日常点検の留意点
* **処理水量変動時の対策**:
  * 紆流式では、処理水量が計画値と大きく乖離すると攪拌流速が狂うため、可動邪魔板の開度調整や流路断面積の変更を行う。
* **スラッジ堆積による起動時破損事故（再掲）**:
  * 長期停止後は底部に沈降・堆積したスラッジにより、パドルやチェーンに過大な抵抗トルクがかかる。**必ず堆積汚泥を清掃・排除した後に起動**する。

### (2) 多孔整流壁（有孔壁）の機能
* 多数の小孔（オリフィス）が一面に開けられた壁。
* 孔を通過する際の適度な抵抗水頭（圧力損失）により、幅方向・深さ方向の水流を完全に均等化し、**理想的な押出し流れ（ピストンフロー）**を作り出して短絡流や死水域を根絶する。

---

### (3) 排泥設備とスラッジ管理
* **機械式かき寄せ機**:
  * チェーンフライト式、台車走行（トラベリングブリッジ）式、水中自走式など。
  * 沈降したフロックを巻き上げないよう、**毎分数十センチ以下の極低速**で池底の排泥ピットへ掻き寄せる。
* **スラッジの再浮上（スカム化）防止**:
  * 池底の汚泥を長期間放置すると、嫌気性発酵によってメタンガスや窒素ガスが発生し、汚泥がガスを抱き込んで水面へ浮上（スカム形成）し、上澄水を著しく汚染する。定期的な連続排泥または間欠排泥を行う。

---

### (4) 年1回の水抜き清掃と「地下水浮力」の重大リスク
* **定期清掃**: 年1回程度池を完全に空にして、高圧水等で壁面・底面の付着スライムや沈積泥を清掃し、かき寄せ機を点検する。
* **地下水による浮上（浮き上がり）事故（★重要警戒事項）**:
  * 地下水位が高い敷地にある沈殿池を空にすると、**池底にかかる地下水の上向き浮力（揚圧力）が空池の自重を上回り、巨大なコンクリート構造物が丸ごと押し上げられて破損・ひび割れを起こす事故**が発生する。
  * 対策として、事前に揚水井で地下水位を低下させるか、池底に設けた「浮力防止弁（アンチフロート弁）」が正常に作動することを確認する。

## 6. 傾斜板・傾斜管沈殿池（テキスト p.394〜396）

### (1) 構造と浅層沈殿のメカニズム
* **浅層沈殿理論（ハゼンの理論）**:
  * 沈殿効率は水深に関係なく水面積に比例する。水深を極端に浅くすれば、粒子が池底（板面）に到達するまでの時間が劇的に短縮される。
  * 沈殿池内に**傾斜角 $60^\circ$** の平板（傾斜板）や六角ハニカム管（傾斜管）を多数並列配置し、板面を滑落させて下部へ沈降・集泥させる。
* **メリット**: 既設沈殿池の処理能力増強、または新設池の敷地面積の大幅縮小（通常池の数分の一）。

```
【水平流式 vs 上向流式 傾斜板沈殿池の比較】
┌──────────────┬────────────────────────────────┬────────────────────────────────┐
│ 形式         │ 水平流式 傾斜板沈殿池          │ 上向流式 傾斜板（傾斜管）沈殿池│
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 水流の方向   │ 板の間を水平方向に流れる       │ 板・管の間を下から上へ上昇通過 │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ **表面負荷率**│ **4 〜 9 mm/分**               │ **7 〜 14 mm/分**              │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 装置の段数   │ 数段（多段重ね）               │ **1段**                        │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 傾斜角度     │ **水平に対して 60度**          │ **水平に対して 60度**          │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 平均流速基準 │ 平均水平流速 0.6 m/分 以下     │ 平均上昇流速 80 mm/分 以下     │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 設置面積割合 │ ─                              │ **沈殿池面積の 90% 以上**（80%以上）│
└──────────────┴────────────────────────────────┴────────────────────────────────┘
```

### (2) 傾斜板沈殿池の特有課題と維持管理（★超頻出）
1. **藻類繁殖による閉塞対策**:
   * 夏期に傾斜板表面に日光が当たると藻類（アオミドロ等）が大繁殖し、板と板の間の狭い流路を完全に閉塞させる。
   * **対策**: **前塩素処理**による藻類殺滅、または池上面への**遮光シート（遮光ネット・覆蓋）の展張**。
2. **水抜き時の破損防止（塩ビ製装置の保護）**:
   * 傾斜板本体は塩化ビニル製であり、機械的強度が比較的小さい。
   * 排水時に急速に水位を下げると、**内外の水位差圧や堆積汚泥の偏荷重により傾斜板が座屈・圧壊**する。必ずスラッジを洗浄・排泥しながら緩速排水する。
3. **風圧・紫外線対策**:
   * 空池時には強風による風圧破損や、直射日光（紫外線）による塩ビの脆化・熱変形に注意する。

## 7. 高速凝集沈殿池（テキスト p.390〜391）

* **概要**:
  * 混和・フロック形成・沈殿の各プロセスを別々の池に分けず、**単一の装置（円形池等）の内部で一体的に行う高効率装置**（スラッジブランケット型、スラリ循環型）。
* **滞留時間**: 通常の凝集沈殿池が3〜4時間要するのに対し、**「1 〜 1.5時間程度」** と極めて短時間・省スペース。
* **メカニズム（スラッジブランケット型）**:
  * 池底部に高濃度の汚泥層（スラッジブランケット：汚泥毛布層）を浮遊状態に保ち、下から上へ通水する。
  * ブランケット層が一種のフィルターとして機能し、流入する微細フロックを接触・吸着させて粗大化し、上澄水を清澄化する。
* **短所**: 水量・水質の急激な変動に対する緩衝能力（キャパシティ）が小さく、運転管理に高度な自動制御技術を要する。

## 9. 【想定問題集（ドリル実装用プロトタイプ問題）】

### 設問1（4択：フロック形成池の設計と攪拌条件）
* **問題形式**: `choice`
* **問題文**: 『水道施設設計指針』等に基づく「フロック形成池（凝集池）」の構造および運転管理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. フロック形成池では、成長したフロックのせん断破壊を防ぐため、下流に向かうに従って攪拌強度を段階的に弱くする「テーパード攪拌」を行う
  2. フロック形成池の標準的な滞留時間は、計画一日最大浄水量に対して「1〜5分間」とされている
  3. フロックを強固にするため、下流側にいくほどパドルの回転速度を速くして攪拌力を強めるのが原則である
  4. 機械攪拌式（フロキュレーター）におけるパドル羽根の外周周速は、毎秒 15〜80 m が標準である
* **正解**: 1（インデックス: 0）
* **解説**: フロック形成池では、成長したフロックが水流のせん断力によって再破壊されるのを防ぐため、下流へ向かうに従って攪拌強度を漸減させる「テーパード攪拌（Tapered Flocculation）」を行います。滞留時間は「20〜40分間」が標準です（1〜5分は混和池）。フロキュレーターのパドル外周周速は「毎秒 15〜80 cm」です。
* **日常のたとえ**: 泡立てたメレンゲを作るとき、最初は激しく泡立て、角が立ってきたら泡を潰さないように優しく混ぜ合わせるのと同じ力加減のコントロールです。
* **出典**: 講義テキスト 浄水施設 p.391〜392／『水道施設設計指針』

### 設問2（4択：沈殿理論と表面負荷率）
* **問題形式**: `choice`
* **問題文**: 薬品沈殿池の沈殿理論および表面負荷率に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 理想沈殿池において、フロック粒子の沈降速度が表面負荷率以上であれば、その粒子は理論上100%完全に沈殿除去される
  2. 表面負荷率は池の有効水深を滞留時間で割った値であり、沈殿池の水面積とは一切関係がない
  3. 沈殿効率を高めるためには、沈降面積を極力小さくして表面負荷率をできる限り大きくする必要がある
  4. ハゼンの理論によれば、沈殿池の有効水深を2倍に深くすれば表面負荷率は半分になり沈殿効率は2倍に向上する
* **正解**: 1（インデックス: 0）
* **解説**: ハゼン・キャンプの理論によれば、理想沈殿池において粒子の沈降速度 $v$ が表面負荷率 $v_0$（$= Q/A$）以上（$v \ge v_0$）であれば、その粒子は100%完全に沈殿除去されます。表面負荷率は水面積あたりの流量であり水深には依存しません。沈殿効率を高めるには水面積 $A$ を大きくして表面負荷率 $v_0$ を小さくする必要があります。
* **出典**: 講義テキスト 浄水施設 p.386〜388

### 設問3（4択：横流式薬品沈殿池の構造諸元）
* **問題形式**: `choice`
* **問題文**: 横流式薬品沈殿池の構造および設計諸元に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 長方形池を標準とし、長さは幅の「3倍〜8倍」、平均水平流速は底泥の巻き上げを防ぐため「0.4 m/分 以下」とする
  2. 有効水深は 1.0〜1.5 m とし、汚泥堆積深さは考慮せず池底は完全に水平平坦に築造する
  3. 単層式横流沈殿池における標準的な表面負荷率は 150〜300 mm/分 である
  4. 流入部に設置される有孔整流壁は、水流を激しく攪拌させてフロックを微細化させることを目的としている
* **正解**: 1（インデックス: 0）
* **解説**: 横流式薬品沈殿池の標準諸元は、長幅比「3倍〜8倍」、平均水平流速「0.4 m/分 以下」、有効水深「3.0〜4.0 m」、汚泥堆積深さ「30 cm 以上」、池底排泥勾配設置、表面負荷率「15〜30 mm/分」です。有孔整流壁は偏流や短絡流を防ぎ均等なピストンフロー（押し出し流れ）を形成する設備です。

### 設問4（4択：傾斜板沈殿池の特徴と維持管理）

### 設問5（4択：沈殿池の維持管理と安全管理）
* **問題形式**: `choice`
* **問題文**: 沈殿池の日常管理および清掃点検における留意事項として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. 沈殿池を空にして清掃する際、地下水位が高い敷地であっても地下水の浮力（揚圧力）によって池体が浮上・破損する危険はない
  2. 池底に沈積したスラッジを長期間放置すると、嫌気性発酵によりガスが発生して汚泥がスカムとして水面に再浮上する恐れがある
  3. 機械式かき寄せ機を運転する際は、沈降したフロックを巻き上げないよう極めて緩やかな低速で運行させる
  4. 混和池の滞留時間は、計画一日最大浄水量に対して「1〜5分間」を標準とする
* **正解**: 1（インデックス: 0）
* **解説**: 地下水位が高い場所にある沈殿池を空にすると、池底にかかる地下水の上向き浮力（揚圧力）が空池自重を上回り、池体全体が浮き上がって破損・クラックを生じる「地下水浮上事故」の重大なリスクがあります。事前に地下水位を下げるか浮力防止弁を確認する必要があります。スラッジ再浮上防止、かき寄せ機低速運行、混和池滞留時間1〜5分の記述はすべて適切です。
* **出典**: 講義テキスト 浄水施設 p.391〜394
