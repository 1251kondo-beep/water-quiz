## 1. 塩素処理方式の区分と不連続点塩素処理（テキスト p.437〜439）

### (1) 塩素注入箇所の3大区分（前塩素・中間塩素・後塩素）
浄水処理プロセスにおける塩素注入は、その目的と注入段階に応じて3つに大別される。

├───────────┼──────────────┼────────────────────────┼────────────────────────┤
│ ① 前塩素  │ 着水井、     │ ・原水中の鉄・マンガン │ ・原水中のフミン質等と │
│    処理   │ 薬品混和池   │   の酸化不溶化         │   反応し、**トリハロメ │
│           │              │ ・アンモニア態窒素酸化 │   タン（THM）等の消毒  │
│           │              │ ・藻類・微生物の殺滅   │   副生成物を大量生成** │
│           │              │ ・凝集補助（除藻）     │ ・塩素消費量が多い     │

---

### (2) 中間塩素処理導入時の留意事項
前塩素処理から中間塩素処理へ移行する場合、以下の技術的課題について事前検討と対策が求められる。
1. **消毒接触時間の確保**: 沈殿池出口から急速ろ過池までの流達時間が短いため、配管・流入渠での十分な急速混和が必須。
2. **沈殿池内の藻類繁殖（除藻機能の喪失）**: 前塩素を停止すると沈殿池や傾斜板に藻類が繁殖し、フロック形成阻害や閉塞を招く。対策として**間欠的な前塩素注入**や遮光設備の設置を行う。
3. **マンガン除去障害**: 急速ろ過池での接触酸化ろ過（マンガン砂）に必要な遊離塩素濃度が不足しないよう、中間注入率を厳密に制御する。

### (3) 不連続点塩素処理（ブレークポイント塩素処理：Breakpoint Chlorination）
原水中にアンモニア態窒素（$\text{NH}_4^+$）が存在する場合、塩素を徐々に添加していくと特異な塩素消費曲線を示す。

```
【不連続点塩素処理の反応曲線モデル】

 残留塩素濃度
   ↑
   │             (極大点)
   │               /\
   │              /  \
   │             /    \          (極小点：ブレークポイント)
   │            /      \                \
   │           /        \                \       ／ (遊離残留塩素)
   │          / 結合塩素 \                \     ／
   │         /  (クロラミン)               \   ／
   │        /              \                \ ／
───┼───────/────────────────\────────────────v───────────────────→ 塩素注入量
   │      ［第Ⅰ領域］       ［第Ⅱ領域］       ［第Ⅲ領域］
```

```
【3つの反応領域のメカニズム】
┌───────────┬────────────────────────────────────────────────────────┐
│ 反応領域  │ 化学反応と現象                                         │
├───────────┼────────────────────────────────────────────────────────┤

│ （極大点）│ クロラミン NH₂Cl、ジクロラミン NHCl₂）**が生成。注入量 │
│           │ の増加に伴い残留塩素濃度が上昇し、極大点に達する。     │
├───────────┼────────────────────────────────────────────────────────┤

│           │ 減少し、アンモニアが完全に酸化消失する**「不連続点（ブ │

## 2. エアレーション設備（曝気設備）（テキスト p.439〜442）

### (1) 目的と4大浄水機能
地下水や伏流水等を原水とする浄水場において、水と空気を効率的に気液接触させ、揮発性成分の放散（ストリッピング）および被酸化性物質の酸化促進を行う。

```
【エアレーション設備の4大浄水機能】
① 遊離炭酸（CO₂）の放散除去 ── 水中CO₂を追い出してpHを上昇させ、配水管の腐食性
                                （ランゲリア指数）を改善・防食。
② 揮発性有機化合物（VOC）の除去 トリクロロエチレン、テトラクロロエチレン等の除去。
③ 異臭味ガスの放散除去 ──── 硫化水素（H₂S：腐卵臭）等の悪臭物質を放散。
④ 溶解性鉄（Fe²⁺）の酸化促進 ─ 水中溶存酸素を飽和させ、鉄の酸化・不溶化を促進。
```

---

### (2) 装置の形式と充填塔の通風管理（ローディング点とフラッディング点）
* **形式**:
  * **噴水式（散水式）**: ノズル噴射や段落ちカスケードにより大気中へ飛散（簡易・開放型）。
  * **充填塔式（パッキングタワー）**: 垂直円筒塔内に高空隙率の充填材（ラシヒリング、テラレット等）を充填し、上部から散水、下部から送風機で送風する向流接触式（高効率・省スペース）。

```
【充填塔の通風限界特性（ローディング点とフラッディング点）】
┌──────────────────┬────────────────────────────────────────────────────┐
│ 特性点           │ 現象と運転基準                                     │
├──────────────────┼────────────────────────────────────────────────────┤
│ ① **ローディング │ 送風量を増加させていくと、上昇気流により流下水が塔 │
│    点（A点）**   │ 内に滞留し始め、圧力損失が急激に増大し始める点。   │
├──────────────────┼────────────────────────────────────────────────────┤
│ ② **フラッディン │ 風速が限界を超え、水が自重で流下できずに塔頂から溢 │
│    グ点（B点）** │ れ出し、通水・気液接触が完全に破綻する点（氾濫点）│
├──────────────────┼────────────────────────────────────────────────────┤
│ ③ **適正運転基準 │ 充填塔の送風量は、**「フラッディング流速の 60 〜   │
│    （設計指針）**│ 75 % 程度（ローディング点付近）」**で運転する。    │
└──────────────────┴────────────────────────┴──────────────────────────────────────┘
```

## 3. 活性炭吸着設備（粉末活性炭 PAC vs 粒状活性炭 GAC）（テキスト p.443〜447）

### (1) 活性炭の基礎特性と吸着メカニズム
* **原料と賦活（ふかつ）**: 木材、ヤシ殻、石炭等を炭化後、高温水蒸気等で賦活処理し、内部に無数の微細細孔（ミクロ細孔：直径2nm以下）を発達させた炭素材料。
* **比表面積**: **700 〜 1,100 m²/g**（わずか 1g でテニスコート数面分〜野球場相当）。
* **吸着対象**: 分子量数十〜数百の微量溶解性有機物（かび臭原因物質［ジェオスミン、2-MIB］、トリハロメタン前駆物質、界面活性剤、フェノール類、農薬、PFAS等）。

---

### (2) 粉末活性炭（PAC）設備の設計と運用
突発的な水質事故（油・化学物質流出）やかび臭発生時に、短期的・応急的に水中に注入・懸濁させる方式。

```

├──────────────────┼────────────────────────────────────────────────────┤

│                  │ ・**ドライ炭**: 乾燥粉末、ローリー・サイロ貯蔵、自動│
├──────────────────┼────────────────────────────────────────────────────┤

│                  │ 最上流部（着水井・導水路・取水施設）**に注入する。 │
├──────────────────┼────────────────────────────────────────────────────┤
│ ③ **塩素との競合 │ ・活性炭は塩素を還元消費する（活性炭1gあたり塩素約 │

## 4. 生物活性炭吸着設備（BAC：Biological Activated Carbon）（テキスト p.447〜453）

### (1) 生物活性炭（BAC）の原理と「生物再生作用」
粒状活性炭（GAC）層に通水し、その表面および細孔周辺に**好気性微生物（細菌群）を自然定着・増殖**させた高度浄水処理技術である。

```
【生物活性炭（BAC）の2大浄化機能】
① 物理吸着作用 ──── 活性炭本来の細孔による微量有機物質（かび臭・農薬等）の吸着。
② 生物分解・生物再生 微生物が吸着された有機物を捕食・酸化分解することにより、
                      活性炭の吸着サイトが再生（バイオ・リジェネレーション）され、
                      吸着寿命が飛躍的に長期持続する。
```

---

### (2) 「オゾン処理 ＋ 生物活性炭（BAC）」の相乗効果
東京都水道局（金町浄水場等）をはじめとする主要高度浄水施設では、**オゾン接触池の後段にBAC吸着池を直列配置**するハイブリッドシステムを標準採用している。

```
【オゾン ＋ BAC の相乗効果メカニズム】
［原水・沈殿水］
      ↓
┌──────────────────────┐
│ ① オゾン接触池      │ ──・強力な酸化力でフミン質等の難分解性有機物を低分子化
│                      │     （生分解しやすい有機酸等へ改質）。
│                      │   ・オゾン溶解により水中の溶存酸素（DO）濃度が飽和上昇。
└──────────────────────┘
      ↓
┌──────────────────────┐
│ ② 生物活性炭（BAC） │ ──・豊富な溶存酸素の供給を受け、好気性微生物が猛烈に活性化。
│    吸着池            │   ・低分子化された有機物を微生物が高速分解（徹底除去）。
│                      │   ・かび臭物質（ジェオスミン/2-MIB）を100%完全除去。
└──────────────────────┘
      ↓
［清澄な高度浄水（急速砂ろ過・浄水池へ）］
```

## 6. 想定問題集（4択ドリル用プロトタイプ問題）

### 設問1（4択：中間塩素処理および不連続点塩素処理）
* **問題形式**: `choice`
* **問題文**: 浄水処理における塩素処理方式および不連続点塩素処理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 中間塩素処理は、凝集沈殿池でフミン質等の有機物を除去した後に塩素を注入するため、トリハロメタン等の生成を大幅に低減できる
  2. 原水中のアンモニア態窒素に塩素を注入すると、直ちに遊離残留塩素のみが生成され、結合残留塩素は一切生じない
  3. 不連続点（ブレークポイント）に達した時点では、原水中のアンモニア態窒素濃度が最大となり、カルキ臭も最も強烈になる
  4. 中間塩素処理を導入すると、薬品沈殿池内の藻類繁殖が完全に防止されるため、前塩素処理設備は永久に撤去できる
* **正解**: 1（インデックス: 0）
* **解説**: 中間塩素処理は沈殿池で前駆物質を除去した後に注入するため、前塩素処理に比べてトリハロメタン生成を大幅に抑制できます（1が正解）。アンモニア含有水に塩素を加えるとまず結合残留塩素（クロラミン）が生成します。不連続点ではアンモニアが完全に酸化消失し、カルキ臭も極小となります。前塩素を停止すると沈殿池で藻類が繁殖しやすくなるため、間欠注入等の配慮が必要です。
* **日常のたとえ**: 泥水に直接塩素を入れると泥と反応して嫌な副産物（トリハロメタン）ができるので、泥を沈めて澄んだ水にしてから塩素を入れるのが「中間塩素処理」です。
* **出典**: 講義テキスト 浄水施設 p.437〜439

### 設問2（4択：エアレーション設備の機能と運転管理）
* **問題形式**: `choice`
* **問題文**: エアレーション（曝気）設備に関する記述として、水道施設設計指針に照らして**最も適切なもの**はどれですか？
* **選択肢**:
  1. 水中の遊離炭酸を大気中へ放散除去してpHを上昇させ、配水管網における水の腐食性（ランゲリア指数）を改善する
  2. 充填塔式エアレーション設備における送風量は、塔頂から水が溢れ出す「フラッディング流速以上」で運転するのが標準である
  3. エアレーション処理は水中の溶存酸素を完全にゼロ（無酸素状態）にするため、溶解性鉄の酸化沈殿を阻止する目的で用いられる
  4. トリクロロエチレン等の揮発性有機塩素化合物（VOC）は水への溶解度が極めて高いため、曝気処理による除去は一切期待できない
* **正解**: 1（インデックス: 0）
* **解説**: エアレーションは遊離炭酸（$\text{CO}_2$）を放散除去してpHを上昇させ、防食性を改善します（1が正解）。充填塔の適正送風量は「フラッディング流速の60〜75%（ローディング点付近）」です。エアレーションは溶存酸素を飽和させて鉄の酸化を「促進」します。VOCは揮発性物質であるため曝気ストリッピングにより効果的に除去できます。
* **日常のたとえ**: 炭酸水のペットボトルを開けて激しく振るとシュワシュワと炭酸ガス（酸性）が抜けて酸っぱさが消えるように、水から炭酸ガスを追い出して水をマイルド（中性〜弱アルカリ性）にする装置です。
* **出典**: 講義テキスト 浄水施設 p.439〜442 / 水道施設設計指針

### 設問3（4択：粉末活性炭の特性と注入管理）
* **問題形式**: `choice`
* **問題文**: 粉末活性炭（PAC）設備に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 塩素と粉末活性炭を同一箇所に同時注入すると、活性炭による塩素消費が生じるだけでなく、吸着されたかび臭物質が再放出される恐れがある
  2. 粉末活性炭は凝集沈殿池の出口に注入し、急速ろ過池の砂層表面に厚い炭層を形成させてろ過閉塞を起こさせるのが標準運用である
  3. 粉末活性炭は常温で大量の酸素ガスを放出して室内を満たすため、活性炭貯槽内部を点検する際の酸欠事故の心配は全くない
  4. かび臭原因物質である2-MIBやジェオスミンは、通常の急速ろ過のみで100%除去できるため、粉末活性炭を注入する必要はない
* **正解**: 1（インデックス: 0）
* **解説**: 塩素と活性炭が共存すると、活性炭1gあたり約0.25gの塩素を消費する上、一度吸着された2-MIB等の異臭味物質が水中に再放出（脱着）されるため「同時注入は厳禁」です（1が正解）。注入位置は接触時間を確保するため混和池以前の最上流部とします。活性炭は空気中酸素を吸着するため密閉貯槽内は「酸欠」の危険があり換気が必要です。2-MIB等は通常の砂ろ過では除去できません。
* **日常のたとえ**: 活性炭（冷蔵庫の脱臭剤）に塩素（漂白剤）をぶっかけると、せっかく吸い取った悪臭を吐き出してしまい、脱臭剤自体もボロボロになってしまう現象と同じです。
* **出典**: 講義テキスト 浄水施設 p.443〜447

### 設問4（4択：生物活性炭BACの浄化メカニズムとオゾン処理）
* **問題形式**: `choice`
* **問題文**: オゾン処理および生物活性炭（BAC）による高度浄水処理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 前段のオゾン処理により難分解性有機物が易分解性に改質され、溶存酸素が供給されることで、BACの好気性微生物分解活性が高まる
  2. 生物活性炭吸着池は生物膜を保護するため、逆流洗浄を行わずに数年間連続通水するのが維持管理上の絶対原則である
  3. 粒状活性炭に定着した微生物は嫌気性菌が主体であるため、流入水中の溶存酸素濃度が高くなると直ちに死滅・分解停止する
  4. 生物活性炭吸着池の新炭充填時は、通水開始の初日から微生物群集が100%完成しており、ならし運転期間は一切不要である
* **正解**: 1（インデックス: 0）
* **解説**: オゾンの酸化力で有機物が低分子化され溶存酸素が供給されるため、後段BACの好気性微生物活性が飛躍的に高まります（1が正解）。BACは微小動物の異常繁殖や損失水頭上昇を防ぐため「3〜4日に1回程度」逆流洗浄を行います。BAC微生物は「好気性」です。新炭充填後は生物膜形成のため「20〜30日程度」のならし運転期間が必要です。
* **日常のたとえ**: 硬い大きな肉（難分解性有機物）をオゾンという包丁で細かく一口大に刻み、酸素という調味料をたっぷり加えることで、微生物たちがモリモリ食べて水がキレイになる連携プレーです。
* **出典**: 講義テキスト 浄水施設 p.447〜453

### 設問5（4択：生物活性炭吸着池の構造諸元と維持管理）
* **問題形式**: `choice`
* **問題文**: 生物活性炭（BAC）吸着池の設計諸元および運転管理に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. 生物活性炭吸着池の好気性微生物は水温 5℃ 以下の極低水温時において最も活発に有機物を酸化分解する
  2. 固定床式生物活性炭吸着池の空塔接触時間（EBCT）は、通常 6〜12分（空塔基準で10〜20分程度）を標準とする
  3. 生物活性炭層から炭粉や繁殖した微小動物（センチュウ・ワムシ等）が処理水へ漏出するのを防ぐため、後段に急速砂ろ過池を配置する
  4. 粒状活性炭の吸着性能は経年劣化するため、水質状況に応じて 4〜7年程度 で新炭への交換または加熱再生を行う
* **正解**: 1（インデックス: 0）
* **解説**: 好気性微生物の至適温度は「20〜30 ℃」であり、冬期の低水温下では生物活性が著しく低下します（1が誤り）。接触時間（EBCT 6〜12分）、微小動物漏出防止のための後段砂ろ過配置、4〜7年での活性炭更新・加熱再生の記述はすべて適切です。
* **日常のたとえ**: 水槽のバクテリアも真冬の冷水では動きが鈍くなるのと同じで、生物活性炭の微生物も暖かい季節（20〜30℃）が一番活発に働きます。
* **出典**: 講義テキスト 浄水施設 p.448〜453 / 水道施設設計指針
