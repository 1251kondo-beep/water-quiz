## 1. 監視制御システム・計装技術の変遷（テキスト p.590付近）

水道施設における計装・監視制御システムは、半世紀以上にわたり劇的な技術的進化を遂げてきた。

```
【監視制御システムの歴史的変遷】
① 1950〜60年代：直接操作ライン（直装ライン）
   ・制御盤・配電盤面にスイッチや押しボタンを直接配置し、物理的リレーシーケンスで操作。
② 1970〜80年代：グラフィックパネル（グラパネ）と集中監視の黎明
   ・プラントフローを描いた巨大な盤面（グラパネ）に計器・ランプ・操作スイッチを配置。
   ・直装ラインと電子式計装の併用期を経て、CRT（ブラウン管）端末による集中監視へ移行。
③ 1990〜2000年代：DCS（分散制御システム）とPLC・PC監視制御への完全移行
   ・グラパネは撤去され、液晶ディスプレイ（LCD）を備えた監視卓・SCADAが主流に。
   ・盤内には横長・モジュール式のプログラマブルロジックコントローラ（PLC）を多用。
④ 2010年代以降〜現代：ICT・DX・クラウドの進展
   ・保全管理データ・施設台帳・帳票のクラウド管理化。
   ・ただし基幹プラントの監視制御自体は、堅牢性・セキュリティの観点からオンプレミス（閉域網）運用が基本。
```

## 2. 取水・貯水・導水施設の計装制御と保守管理（テキスト p.591〜594）

取水場や導水ポンプ所は、浄水場本体から数km〜十数km離れた遠隔地（河川・ダム湖周辺）に立地することが多く、過酷な自然環境に晒される。

### (1) 環境管理と設備防護対策
* **温湿度管理と換気ファンの重要性**:
  * 電子機器・PLCの寿命・故障率は温度と湿度に極めて大きく左右される。
  * **【実務教訓：換気ファン故障による熱暴走】**:
    * 遠隔ポンプ所の電気室・計装盤内にある換気ファン（冷却ファン）が経年劣化で停止し、盤内温度が急上昇してテレメータや制御CPUが熱破損する事故が多発する。
    * 換気ファンは安価な消耗品であるため、故障を待たずに**時間計画保全（TBM）で定期交換**することが鉄則。
* **落雷・雷サージ対策（避雷器 / アレスター / SPD）**:
  * 河川沿いや山間部の取水・導水施設は落雷を受けやすい。通信回線や電源線に避雷器（サージ防護デバイス：SPD）を確実に設置し、接地抵抗値を定期測定する。
* **耐浸水・水没防止対策**:
  * 集中豪雨・河川氾濫による計装盤・ピット・ポンプ室の水没防止対策（止水板、高所配置、排水ポンプ確認）。

### (2) 取水プロセスの監視制御と緊急対応

```
【取水・導水施設における最重要監視ポイント】
［河川・水源］──────［取水口スクリーン］──────［沈砂池・導水ポンプ所］──────［浄水場（着水井）］
  ・濁度・水温        ・ITV（カメラ）監視          ・油面検知器                     ・着水井水位計
  ・取水堰水位        ・差圧検知（目詰まり）        ・オイルフェンス                 ・テレメータ伝送
                      ・自動除塵機連動            ・吸込水位/吐出圧力
```

* **取水スクリーン・除塵機の監視**:
  * 流木・ゴミ・落ち葉によるスクリーンの目詰まりを前後水位差（差圧）やITV監視カメラで常時検知し、自動除塵機（ロータリースクリーン・レーキ）を連動起動。
* **★油流入事故対策（オイルフェンスと油面検知器）の危機管理**:
  * 農業機械、交通事故、工場排水等による河川への油流出事故への対応。
  * 取水口・沈砂池に**「油面検知器」**を設置し、油膜を検知した際は直ちに警報を発報。
  * オイルフェンスを展開し、オイルマットで吸着回収。導水ポンプの取水量を絞る、または取水を緊急停止する。
  * **【最重要教訓】油が沈殿池を突破して「ろ過池」に達した場合、ろ過砂層全体が油汚染され、全面砂入替を行わなければ浄水が再開できず、数週間に及ぶ大断水に直結する。油は必ず導水ポンプ所・沈砂池の手前で捕捉・遮断しなければならない。**
* **ポンプ変速制御（インバータ / VVVF）の保守**:
  * 取水・導水ポンプの回転速度制御にインバータ（パワー半導体素子）を使用。パワー半導体デバイスは10〜15年程度で経年劣化・突然故障のリスクが高まるため、計画的更新が必要。

## 3. 浄水処理施設の計装制御と保守管理（テキスト p.594〜596）

浄水処理工程は、凝集・沈殿・ろ過・高度処理（オゾン・活性炭）・消毒が連続する中枢プラントであり、計測制御項目が最も多い。

### (1) 分散制御システム（DCS）の役割
* 単一のCPUが停止してもプラント全体が共倒れしないよう、系統ごと（凝集沈殿系、急速ろ過系、薬品注入系、送配水系）に制御装置（PLC/コントローラ）を機能分散配置する。

### (2) 腐食性ガス対策（水道特有の過酷環境・テキスト p.594下〜595）
水道プラントは、消毒用の**塩素ガス、次亜塩素酸ナトリウム（分解時に微量塩素ガス発生）、オゾン、凝集剤（PAC・硫酸バンド）、硫酸（pH調整）**など、極めて強力な腐食性物質を扱う。

| 障害現象 | 原因物質 | 発生部位・機器への影響 | 実務的防護・保全対策 |
| :--- | :--- | :--- | :--- |
| **電気接点の接触不良・誤動作** | 塩素ガス、オゾン、硫化水素 | 計装盤内のリレー接点、電磁開閉器（コンダクター）、端子台、コネクタ | * 電気室・計装盤室への腐食性ガス侵入防止（気密構造・陽圧化換気）。<br>* 制御盤内の防湿・防食処置。 |
| **電子基板のパターン腐食・短絡** | 高湿度＋微量腐食性ガス | PLC基板、電源基板、センサ変換器のプリント配線 | * **盤内スペースヒータ（加温）**による結露防止。<br>* 基板コーティング（防湿絶縁処理）。 |
| **金属配管・構造物の腐食** | 薬品蒸気、薬液漏洩 | 薬注室配管、バルブステム、金属ダクト | * 耐食材料（PVC、PVDF、PTFE、SUS316等）の採用。<br>* 定期的な防食塗装、漏液センサの設置。 |

* **脱泡槽（気泡抜き水槽）の定期清掃**:
  * 水質計器（濁度計・残留塩素計等）の採水ラインに設けられる脱泡槽は、汚れ、藻、固形夾雑物が堆積しやすい。定期的に清掃しないと採水配管が閉塞し、計器指示が狂う原因となる。

## 4. 送水・配水施設の計装制御（テキスト p.596〜598）

### (1) 配水池・送配水ポンプの制御
* **台数制御とインバータ回転速度制御**:
  * 需要量（昼間のピーク需要・夜間の最低需要）に応じて、送配水ポンプの運転台数および回転速度（インバータ）を組み合わせ、適正送水量を高効率に維持する。
* **配水区域の系統分離（高区・中区・低区ブロック）**:
  * 配水区域内の高低差が大きい場合、過大水圧（漏水・管破損原因）や出水不良（水圧不足）を防ぐため、高区（ポンプ圧送）・中区・低区（自然流下＋減圧弁）に圧力区分して計装制御を行う。

## 5. 各種流量計の測定原理と保守管理（テキスト p.599〜603）

流量計は水道施設において「水量の計量」「薬品注入比率の決定」「有収率・漏水解析」を左右する最も重要な計測器である。

```
【水道施設で使用される4大流量計の比較】
┌── 堰式流量計 ────── 開水路用（四角堰・三角堰）、液位から換算、下水・沈砂池
├── 差圧式流量計 ──── 管路絞り機構（オリフィス・ベンチュリ管）、空気混入厳禁、直管部必要
├── 電磁式流量計 ──── ファラデーの電磁誘導、圧力損失ゼロ、高精度、要接地、要バイパス管
└── 超音波式流量計 ── 伝搬時間差、クランプオン（外付け可能）、気泡・乱流に弱い、要直管部
```

### (1) 堰式（せきしき）流量計（テキスト p.599）
* **測定原理**: 開水路に堰（刃型堰、三角堰、四角堰）を設置し、越流する水頭（液位 $h$）を測定して流量 $Q$ を算出する（$Q \propto h^{5/2}$ または $h^{3/2}$）。
* **用途と特徴**: 沈砂池、原水開水路、排水処理工程などに使用。構造は単純だが、開水路にしか適用できず、水頭損失が生じる。

### (2) 差圧式流量計（オリフィス、ベンチュリ管等）（テキスト p.599〜601）
* **測定原理**: 管路内に絞り機構（オリフィス板、ベンチュリ管、フローノズル）を挿入し、流速増加に伴って生じる前後の**差圧（$\Delta P$）**を差圧伝送器で測定して流量を算出する（ベルヌーイの定理：$Q \propto \sqrt{\Delta P}$）。
* **★保守管理上の最重要留意事項（テキスト赤線箇所）**:
  1. **導圧管への空気混入（エア噛み）防止**:
     * 差圧を取り出す導圧管内に空気が混入すると、液柱圧が変動して著しい指示誤差（ゼロ点ズレ）が生じる。
     * **定期的な空気抜き（エアパージ）作業が必須**である。
  2. **十分な直管長（直管部）の確保**:
     * 絞り機構の上流側・下流側に偏流・渦流を抑制するための十分な直管部が必要である（上流側にバルブやベンドがある場合は特に長い直管長を要する）。

### (3) 電磁式流量計（★試験最頻出・最重要）（テキスト p.601〜602）
* **測定原理（ファラデーの電磁誘導の法則）**:
  * 磁界（磁束密度 $B$）の中に導電性流体（水）が流速 $v$ で流れると、管径 $D$ の両端電極間に流速に比例した起電力 $E$ が発生する。

$$E = k \cdot B \cdot D \cdot v$$

* **特徴**:
  * 小口径（2.5mm）から超大口径（1,000mm以上）まで対応可能。
  * **管内に障害物がなく、圧力損失が完全にゼロ。**
  * 高精度（$\pm 0.5\%$程度）で安定性が高く、**正流・逆流の双方向測定が可能**。導電率が一定以上あれば密度・温度・粘度の影響を受けない。
* **★保守管理上の最重要留意点（下線指定箇所）**:
  1. **確実な接地（アース工事）の施工**:
     * 発生する起電力信号が数ミリボルト（$\mathrm{mV}$）と極めて微弱であるため、商用電源ノイズや迷走電流の影響を受けやすい。検出器および変換器に**基準接地（D種接地等）を確実に施工**しなければならない。
  2. **ピット設置時の水没防止**:
     * 地下ピット内に設置されることが多いため、浸水・水没による端子台・基板の絶縁低下がないか定期点検する。
  3. **★バイパス管の設置（取り替え・ゼロ点校正対策）**:
     * 電磁流量計の取り替え・点検・ゼロ点校正を行う際には、**管路の流れを完全に停止（ゼロ流速状態）にする必要がある**。
     * 連続通水が求められる送配水幹線では、**必ず「バイパス管」と前後仕切弁を常設**しておくことが設計・維持管理上の絶対要件となる。

### (4) 超音波式流量計（テキスト p.602〜603）
* **測定原理（超音波伝搬時間逆数差方式）**:
  * 配管内を流れる水に対して斜めに超音波を発射し、流れの順方向と逆方向の伝搬時間差（$\Delta t$）から平均流速を測定する。
* **特徴**:
  * **外付け（クランプオン式）が可能**: 既設配管の外側に検出器（振動子）をベルトや金具で取り付けるだけで測定可能。**管を切断したり断水したりする必要が一切ない**（ポータブル型流量計として管路調査・漏水調査に多用）。
  * 圧力損失ゼロ。大口径配管でも機器コストが跳ね上がらない。
* **★保守管理上の最重要留意点（下線指定箇所）**:
  1. **気泡・乱流・固形物の影響**:
     * 配管内に気泡（エアー）が混入している場合や、激しい乱流が生じている場合、超音波が散乱・減衰して**測定精度が著しく低下し、極端な場合は測定不能**となる。
  2. **十分な直管長（直管長確保）の必須性**:
     * 流速分布の乱れに敏感であるため、検出器の上流側・下流側に**規定の直管長（上流側10D以上、下流側5D以上等）が不可欠**。
  3. **既設管内面の錆コブ・スケール**:
     * 経年管の内面に厚い錆コブやモルタル剥離があると、音波が減衰・散乱して測定できない場合がある。

## 6. 各種水位計の測定原理と保守管理（テキスト p.603〜606）

水位計は、水源ダム、着水井、凝集沈殿池、ろ過池、配水池などのプロセス水位監視・自動発停制御に用いられる。

```
【代表的水位計の測定方式と特徴】
┌── フロート式 ──── 浮子の上下変位（ワイヤー・プーリー）、構造単純、可動部摩耗あり
├── 差圧式 ──────── 水底静圧（P=ρgh）、密閉タンク・薬品タンクにも適用可能
├── 投込み式 ────── 水中圧力センサ（半導体ダイヤフラム）、設置容易、要・静水筒保護管
└── 超音波式 ────── 気中から超音波反射、非接触で保守容易、水面波立ち・温度変化（要補正）
```

### (1) フロート式（浮子式）水位計
* 浮子（フロート）を水面に浮かべ、ワイヤーとプーリーを介して機械的にポテンショメータやセルシンに伝達。
* 機械的可動部が多いため、ワイヤーの素線切れ、滑車の固着・摩耗、スケール付着に対する定期的な給油・点検が必要。

### (2) 投込み式水位計（水圧式水位計）（テキスト p.604）
* **測定原理**: ダイヤフラム式圧力センサを内蔵した検出端をケーブルで水底近くに吊り下げ、受圧する水頭静圧から水位を測定する。
* **特徴と留意点**:
  * 水槽の上部からケーブルで吊り下げるだけで設置でき、土木工事や採水配管が不要で扱いやすい。
  * **流速・波立ちの影響**: 水流が激しい場所や流入部付近では検出端が揺れて指示が不安定になるため、**「静水筒（保護パイプ）」の内部に投入する**などの防護措置が必要。
  * スラッジ・泥の堆積による受圧部閉塞を防ぐため、定期的に引き上げて洗浄する。

### (3) 超音波式水位計（テキスト p.605）
* **測定原理**: 水槽上部に設置したセンサから水面へ超音波を発信し、反射して戻るまでの往復時間を計測して非接触で液面距離を測定する。
* **特徴と留意点**:
  * 測定液に直接触れない（非接触）ため、腐食性薬品タンクや原水・汚水にも適用でき、メンテナンス性が極めて高い。
  * **音速の温度補償**: 空気中の音速は気温によって変動する（$v = 331.5 + 0.6t$ m/s）ため、必ず温度センサによる補正演算を行う。
  * 水面の激しい波立ち、泡の発生、水蒸気の結露によって反射波が減乱するため、設置環境に応じた感度調整や静水筒の併用が必要。

## 7. 各種圧力計の測定原理と保守管理（テキスト p.606〜608）

### (1) ブルドン管式圧力計
* ブルドン管（扁平なC字状金属管）に圧力が加わると管が真円に近づこうとして先端が外側へ変位する機械的性質を利用。
* 電源不要で現場指示針として最も広く普及しているが、ポンプの吐出脈動や振動で歯車機構が摩耗・劣化しやすいため、指針狂いが発生したものは消耗品として定期交換する。

### (2) 圧力伝送器（ダイヤフラム式・半導体センサ）（テキスト p.606下）
* **測定原理**: 受圧ダイヤフラム（金属・シリコン）に加わる圧力を、ピエゾ抵抗効果や静電容量変化として検出し、4-20mAの電気信号に変換して遠隔伝送する。
* **特徴**: 可動部が極めて微小であり、耐震性・耐衝撃性に優れ、脈動圧による金属疲労が少なく高精度・長寿命。

### (3) ろ過池損失水頭測定と逆洗浄管理（実務上の重要点・テキスト p.607）

```
【急速ろ過池における損失水頭と逆洗制御】
［ろ過開始初期］：砂層が清浄 $\rightarrow$ ろ過抵抗（損失水頭）小（約0.2〜0.3m）
      ↓ （ろ過継続に伴い濁質捕捉・砂層目詰まり進行）
［損失水頭上昇］：入口水頭と出口水頭の差圧が徐々に増大
      ↓
［限界到達］    ：損失水頭が設定限界値（約1.5〜2.0m）または規定継続時間（48〜72h）に到達
      ↓
［自動逆洗浄］  ：ろ過池流入停止 $\rightarrow$ 表面洗浄 $\rightarrow$ 逆洗水圧送（砂層展開・濁質排出） $\rightarrow$ 捨て水 $\rightarrow$ ろ過再開
```

* **損失水頭の測定方式**:
  * 液柱式（水頭マノメータ管）や差圧伝送器を用いて、ろ過池水面（流入側）とろ過水集水管（流出側）の圧力差を連続測定する。
* **逆洗浄のタイミング管理**:
  * 損失水頭が過大になると、砂層内部が負圧（大気圧以下）となり、水中に溶存していた空気が気泡化して砂層内に滞留する**「エアバインディング（空気障害）」**が発生し、ろ過機能が著しく低下・破壊される。
  * したがって、損失水頭の正確な計装監視と、確実な自動逆洗シーケンスの作動が浄水管理の要となる。

## 8. 【問題作成用】試験最頻出ポイント総まとめ・論点整理

本講義録（テキスト p.590〜608）から出題される4択問題・正誤判定問題の作成用キーワード対比表：

| 分野・計測器 | 正しい記述（正肢のポイント） | 誤りとして出題されやすい引っかけパターン |
| :--- | :--- | :--- |
| **監視制御システムの変遷** | 過去の直接操作ライン（直装ライン）やグラフィックパネルは撤去され、**PLCとPC/SCADAによる集中監視制御が主流**。 | 「現代の水道施設でも、信頼性確保のため全ポンプが壁面の巨大グラフィックパネルから直接スイッチ操作されている」（×：CRT/LCD端末移行済） |
| **油流入事故対策** | 水源に油が流出した場合、**ろ過池に到達すると砂層全体が汚染され壊滅的となるため、導水ポンプ所等で阻止する**。 | 「油が沈殿池やろ過池に流入しても、通常の塩素消毒によって完全に分解・無害化できる」（×：砂層汚染で浄水停止） |
| **腐食性ガス対策** | 塩素やオゾン等の腐食性ガスから電子機器を守るため、**換気・気密化のほか、盤内結露を防ぐスペースヒータを設置**する。 | 「腐食性ガスが存在する電気室では、機器を冷却するために盤内ヒーターの使用は一切禁止されている」（×：スペースヒータで加温結露防止） |
| **差圧式流量計** | オリフィス等の差圧式流量計では、導圧管内の**空気混入（エア噛み）が著しい誤差原因となるため空気抜きが必須**。 | 「差圧式流量計の導圧管には、緩衝作用を持たせるために常に多量の空気を意図的に封入しておく」（×：空気混入厳禁） |
| **電磁式流量計の接地** | 発生する起電力信号が微弱であるため、商用ノイズや迷走電流による障害を防ぐ**確実な接地（アース）が不可欠**。 | 「電磁流量計は自己完結型の計測器であるため、外部アース（接地工事）を接続してはならない」（×：確実な接地が必須） |
| **電磁式流量計の保守** | 取り替えやゼロ点校正には流れを止める（ゼロ流速）必要があるため、**管路にバイパス管を設ける**。 | 「電磁流量計は通水中でも完全なゼロ点調整が可能なため、バイパス管を設ける必要は全くない」（×：バイパス管が不可欠） |
| **超音波式流量計の利点** | 検出器を配管外部に挟み込む（クランプオン式）ことができ、**管を切断せず不断水で設置可能**である。 | 「超音波流量計を設置する際は、必ず管路を断水して管体内部に超音波発振子を埋め込まなければならない」（×：外付け可能） |
| **超音波式流量計の弱点** | 配管内の**「気泡混入」や「激しい乱流」により超音波が散乱・減衰し、測定誤差や測定不能が生じやすい**。 | 「超音波流量計は、管内に大量の気泡や激しい渦流が存在するほど測定精度が高くなる」（×：気泡・乱流は大敵） |
| **投込み式水位計** | 圧力検出器を水中に投込む方式であり、水流の激しい場所では**「静水筒（保護管）」を設けて揺れを防ぐ**。 | 「投込み式水位計は、水流が激しく水面が大きく波立つ場所ほど正確な測定ができる」（×：静水筒等で防護） |
| **ろ過池損失水頭** | 砂層の目詰まりに伴い損失水頭が上昇するため、**所定水頭（1.5〜2.0m）に達した時点で自動逆洗浄を実施**する。 | 「損失水頭が上昇しても砂層ろ過に支障はないため、ろ過水が出なくなる限界まで逆洗を行わずに運転する」（×：エアバインディング等の障害） |
