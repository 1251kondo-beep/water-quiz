## 1. 消火栓の構造・機能と設置基準（テキスト p.289）

消火栓は、消防法に基づく消火活動の命脈であると同時に、水道の日常的な維持管理においても極めて重要な役割を担う基幹付属設備である。

### (1) 消火栓の多面的な役割（★最重要ポイント・出題最頻出）

テキスト289ページ「（4）消火栓」の「ⅰ」は、試験対策および実務における最重要マーカー箇所である。

> **★最重要ポイント（テキスト p.289：マーカー箇所）**
> **「消火栓は消防水利としてはもとより、水圧・水質の測定、洗管排水、管内状況調査など多様な役割を担う設備である。」**
> ※**「常時その機能が十分に発揮できるよう、適切に維持管理・整備しておく必要がある。」**

消火栓は単なる「火災のときに消防車が使う設備」ではない。日常の水道維持管理において以下の多様な目的で多面的に活用されるため、水道事業者は常時適正に機能を発揮できるよう点検・維持管理する義務を負う。

```
【消火栓の4大役割】
① 消防水利 ───── 火災発生時の初期消火および本格消火活動への大流量供給。
② 水圧・水質測定 ─ 配水管網の末端水圧測定、残留塩素・濁度・水温等のサンプリング。
③ 洗管排水 ───── 新設管通水時の洗管、事故・工事後の濁水（赤水）排除・泥吐き。
④ 管内状況調査 ── サンプリング弁やカメラを挿入し、管路内部の腐食・錆コブ状況を調査。
```

### (2) 構造形式と設置基準

```
【消火栓の形式分類】
・設置位置 ── 地上式消火栓（視認性良、積雪地等）／ 地下式消火栓（道路下ボックス内、都市部の主流）
・放水口数 ── 単口消火栓（放水口1箇所）／ 双口消火栓（放水口2箇所：母管φ300mm以上に設置）
```

| 項目 | 規定数値・技術基準 | 理由・実務上の留意点 |
| :--- | :--- | :--- |
| **放水口口径** | **$65\,\text{mm}$** | 消防機関が使用する標準消防用ホースの結合金具規格（65mm）に適合。 |
| **配置間隔** | 市街地・建物密集地で **概ね $100 \sim 200\,\text{m}$ 間隔** | 消防用ホースの標準延長距離（ホース展張能力）を考慮して消防機関と協議決定。 |
| **母管口径（原則）** | 取り付ける配水管の口径は **原則「$\phi 150\,\text{mm}$ 以上」** | 消火活動時に毎分 $1\,\text{m}^3$（毎秒 $16.7\,\text{L}$）以上の大流量を放水するため。 |
| **母管口径（特例）** | **条件付きで「$\phi 100\,\text{mm}$」への設置可能** | 管網が格子状・ループ状に構成され、**両側から通水される有利な水理条件** が確保されている区域。 |
| **双口消火栓の母管** | **「$\phi 300\,\text{mm}$ 以上」の配水管** | 同時に2線（2本）のホースへ大量送水するため、十分な通水容量を持つ大口径幹線に限定。 |
| **管路上の配置位置** | **管路の縦断勾配における「頂部（山部）」** | 充水・洗管作業時に **「空気抜き（エア抜き）」** として併用・機能させるため。 |
| **補修弁の併設** | 消火栓直下に **「補修弁（仕切弁）」を必ず併設** | 消火栓本体のパッキン交換や点検補修時に、**配水管を断水させずに安全に作業** するため。 |
| **寒冷地・積雪対策** | **不凍式消火栓**、**表示ポール（標識板）** | 凍結破損の防止、積雪時・夜間でも消火栓の位置を一目で発見可能にする措置。 |

## 2. 減圧弁と付属設備（テキスト p.289〜292）

配水管網の健全性を保ち、事故を未然に防ぐために各種の付属設備が適材適所に配置される。

### (1) 減圧弁（テキスト p.289）
* **設置目的**:
  * 起伏の激しい地域において、高台の配水池から自然流下で配水する場合、低地部や谷部では静水圧・動水圧が極端に高くなる。
  * **過大水圧の弊害**: 管路の継手部からの **漏水量増大**、給水器具（給湯器、便器洗浄弁等）の破損、急閉止時の激しいウォーターハンマー（水撃圧）を誘発する。
* **機能**:
  * パイロット作動弁やコーン弁を用い、上流側の高い水圧を下流側で設定した **適正水圧（概ね $0.2 \sim 0.4\,\text{MPa}$ 程度）へ自動減圧・一定保持** する。
* **維持管理**:
  * パイロット管の目詰まりや弁座摩耗による調圧不良を防ぐため、定期的な分解点検・整備が欠かせない。

---

### (2) 流量・水圧測定設備と水質自動測定計器（テキスト p.290）

水道管網の「健康状態」をリアルタイムで遠隔監視するためのセンサー網である。

```
【リアルタイム監視ネットワーク（東京都水道局の事例）】
① 配水本管テレメーター（約300箇所以上） ── 1分単位で水圧・流量を自動測定、遠隔監視。
② 水質自動測定計器（約130箇所） ──── 色度・濁度・残塩・pH・導電率を自動連続測定。
```

* **配水本管テレメーター**:
  * 幹線管路の約300箇所に設置。**1分単位で水圧・流量データを自動計測** し、給水管理センターへ伝送。突発的な管破断事故や漏水兆候を早期覚知する。
* **水質自動測定計器**:
  * 配水支管末端等を中心に都内約130箇所に設置。
  * **水道法第22条に基づく法定基準（給水栓水における残留塩素 $0.1\,\text{mg/L}$ 以上）が管網末端まで常時保持されているか** を24時間厳格に監視する。

---

### (3) 排水設備（泥吐き設備）（テキスト p.292）

新設管の通水前洗浄、管路更新・修繕工事、事故時の管内水抜きを迅速に行うための設備である。

#### ① 河川への放流基準
* **放流口高さ**: 河川の **計画高水位（HWL）よりも高い位置** に設け、増水時の逆流を防ぐフラップゲート等を設置する。
* **脱塩素処理（中和）の徹底（最重要）**:
  * 水道水に含まれる残留塩素は、河川生態系（特にアユ・サケ等の魚類）に対して猛毒であり、直接放流すると大量死を招く。
  * 放流時は、必ず **チオ硫酸ナトリウム等の還元中和剤を用いて残留塩素を完全に中和（無害化）** してから放流しなければならない。

#### ② 下水道への放流基準
* 管内の高圧水が直接下水管に吹き込むと、下水管路の継手やマンホールを破損・噴発させる恐れがある。
* そのため、必ず一度大気圧に開放する **「排水室（ドロップマンホール・消能室）」** を介して流速・圧力を減衰させ、自然流下で接続する。

---

### (4) 人孔（マンホール）と伸縮継手管

* **人孔（テキスト p.292）**:
  * **管径 $\phi 800\,\text{mm}$ 以上の大口径配水本管** に設置。
  * 通常はボルト締めフランジ蓋で密閉され、断水・水抜き後の維持管理時に点検員や洗管用ロボットが管内に出入りできるようにする。
* **伸縮継手管（テキスト p.292）**:
  * 軟弱地盤地帯、不等沈下予想箇所、水管橋の橋台取付部、コンクリート構造物と地中埋設管の境界部など、**温度変化による熱伸縮や地震動による不同変位が集中する箇所** に配置し、管路の破断を防止する。

## 3. 水圧試験と管の明示（テキスト p.294）

### (1) 水圧試験（耐圧・水密性試験）

管路の布設工事完了後、**「埋め戻しを行う前（※曲管部等のスラストコンクリート防護完了後）」** に、継手接合部の水密性と管体の耐圧性能を現地で確認する。

* **小口径管路**:
  * 弁間区間全体に水を満たし、所定の試験水圧（通常、設計水圧の $1.5$ 倍等）をポンプで加圧し、一定時間（数十分〜数時間）保持して水圧降下や漏水がないかを確認。
* **中大口径管路（テストバンド試験）**:
  * 大口径管で全区間を加圧すると膨大な水量・水抜き時間が必要となるため、管内側から継手部をゴムパッキンで挟み込んで局所的に加圧する **「テストバンド（内面水圧試験機）」** を用い、継手1箇所ずつピンポイントで水密性を確認する手法が広く用いられる。

---

### (2) 地下埋設管の明示（埋設明示テープ）

道路下は様々な地下ライフラインが網の目のように交差している。将来、他企業（ガス・電気・通信・下水等）が道路を掘削した際に、誤って水道管をバックホウのバケット等で破損する事故を防ぐため、**管頂から約 $30\,\text{cm}$ 上部に「埋設明示テープ（シート）」を敷設** する。

```
【道路下インフラの統一標識カラー】
・水道管 ────── 青色（水色）
・ガス管 ────── 緑色
・電力線 ────── オレンジ色
・通信線 ────── 赤色
・下水道管 ──── 茶色
```

## 4. 特殊横断部（河川・鉄道等）の布設（テキスト p.294〜295）

河川、鉄道軌道、高速道路などの障害物を横断する工法には、大きく「上越し」と「下越し」がある。

```
【特殊横断の工法分類】
・上越し横断 ── 水管橋（水道専用橋梁）、橋梁添架（道路橋の桁下・側面にブラケット支持）
・下越し横断 ── 推進工法、シールド工法（大深度地下横断）、伏越し（河床下埋設）
```

### (1) 各工法の特徴と防食対策
* **水管橋・橋梁添架（上越し）**:
  * 外気に露出するため、日射・気温変化による熱伸縮を吸収する伸縮管や、耐候性塗装・保温材（凍結防止）が必要。
* **鉄道軌道横断（電食対策）**:
  * 直流電化鉄道のレールから地中に漏れ出す「迷走電流」が金属管を腐食させるため、鞘管（さやかん）推進工法を採用し、管と鞘管の間に **絶縁材を挟む完全絶縁構造や電気防食** を施す。

### (2) 近年のトレンド：上越しから「下越し（非開削大深度横断）」への転換
* **背景（激甚化する気象災害と巨大地震）**:
  * 過去の台風（令和元年東日本台風・台風19号等）では、河川の氾濫・流木激突により道路橋そのものが落橋・流失し、添架されていた水道管が破断して広域断水が発生した。また、大地震時にも橋台部の破壊リスクが高い。
* **東京都水道局の施策方針**:
  * 重要幹線管路を中心に、従来の **「水管橋や橋梁添架（上越し）」から、推進工法・シールド工法による「大深度地下横断（下越し）」への再構築** を優先的に推進し、耐災害性を抜本的に強化している。

## 5. 管路の更新・耐震化とアセットマネジメント（テキスト p.296）

### (1) アセットマネジメントによる計画的更新（★最重要ポイント）

テキスト296ページ「4.1.10 管路の更新・耐震化」の記述は、試験対策および水道経営・技術管理における最重要論点である。

> **★最重要ポイント（テキスト p.296：マーカー箇所）**
> **「管路の更新には多額の費用と長期にわたる工事期間が必要となるため、アセットマネジメントによる実践活動が求められる。すなわち、施設の重要度、健全度、耐震性能などを総合的に評価し、財源的な裏付けのある更新計画を策定し、計画的かつ継続的に管路を更新していくことが重要である。」**

```
【管路アセットマネジメントの基本三要素】
① 施設の重要度 ── 導送水幹線、病院・避難所への供給ルート、大口径管。
② 施設の健全度 ── 布設年度（経年化）、過去の漏水修繕履歴、土壌腐食性環境。
③ 耐震性能 ──── 非耐震継手（K形等）か、耐震継手（NS・GX等）か。
   ➔ これらを総合評価・スコアリングし、投資効果を最大化する優先順位を決定！
```

* **更新の現実と課題**:
  * 東京都水道局の管路総延長（約 $28{,}000\,\text{km}$）をもってしても、年間に更新できるのは **全体の約 $1\%$ 程度（約 $200 \sim 300\,\text{km}$）** にすぎない。
  * 単純計算で全管路を一巡更新するには **約 100 年** を要する。
  * したがって、「壊れたら直す（事後保全）」ではなく、科学的なアセットマネジメントに基づき、限られた財源・技術職員の中で計画的に更新していく「予防保全」が不可欠である。

---

### (2) 管路更新がもたらす5大効果

管路を最新の耐震継手ダクタイル鋳鉄管等へ更新することは、単なる老朽化対策にとどまらず、水道システム全体に劇的な改善効果をもたらす。

1. **漏水・破裂事故の防止**: 地下空洞化による道路陥没事故を未然に防ぎ、道路交通と都市の安全を確保する。
2. **通水能力の回復と赤水（濁水）の撲滅**:
   * かつて布設された無内面ライニング鋳鉄管（CIP）は、管内部に巨大な **「錆コブ（結節）」** が成長し、内径が狭まって通水能力が著しく阻害され、赤水事故を頻発させていた。
   * エポキシ樹脂粉体塗装やモルタルライニングを施した現代の管へ更新することで、通水断面が回復し、濁水が完全に解消される。
3. **残留塩素の低減化（「おいしい水」の供給）**:
   * 管内の錆コブや堆積物は、水中の残留塩素を激しく消費する。
   * 従来は末端での濃度（0.1mg/L）を死守するため、浄水場出口で高濃度の塩素を投入せざるを得ず、浄水場近傍住民から「カルキ臭が強い」と苦情が出ていた。
   * 管路が健全化すれば塩素消費が極小化するため、**浄水場での塩素注入率を必要最低限に抑えることができ、カルキ臭のない「おいしい水」を全域に届けることが可能** となる。
4. **水圧ロスの低減と直結給水区域の拡大**:
   * 管内面の平滑化（C値の向上）により摩擦損失水頭が激減し、末端の水圧が保持されるため、直結直圧・直結増圧給水が可能なエリアが大幅に広がる。
5. **耐震性能の大幅な向上**:
   * 耐震継手化により、大地震時にも管路が鎖のように繋がり、離脱・破断被害を防ぐ。

### (3) 水道施設の技術的基準省令（平成20年改正）と優先整備対象

平成20年3月の省令改正により、水道施設は重要度に応じた耐震性能の確保が義務付けられた。管路更新における優先整備対象は以下の通り規定されている。

1. **上流側に位置する施設（導水管・送水管等）**: 破損した場合、後段の浄水場や配水池全体が停止し、被害が広域化するため。
2. **代替性（二重化・バックアップ系統）のない基幹幹線管路**。
3. **重要施設への供給管路**:
   * **災害拠点病院（救急指定病院）、避難所、応急給水拠点**。
   * 復旧活動の拠点となる **警察署、消防署、市役所・区役所**。
   * **発電所、変電所、清掃工場、下水処理場** などの都市重要インフラ。
   * ※東京都水道局では、これらの重要施設へ至る供給管路について、**配水本管から受水槽受水点までを一筆書きで確実に耐震化し、周辺管路が破損してもバルブ遮断で影響を隔離できる（縁切りできる）耐震化整備を先行完了** させている。

## 6. 管路の信頼性強化（ネットワーク化・多重化）（テキスト p.297）

単一の管路が地震に強くても、配管網の構造が脆弱であれば大断水を防ぐことはできない。ネットワーク全体としての「冗長性（リダンダンシー）」を確保する。

### (1) 管種ごとの耐震対策
* 軟弱地盤地帯や断層変位部などの地層変化点には、伸縮可とう管や耐震継手管を重点配置する。
* 脆性破壊を起こしやすい **石綿セメント管（ACP）、普通鋳鉄管（CIP）、初期の硬質塩化ビニル管、鉛管（LP）は最優先で早期全廃** を図る。
* 給水管には、可とう性に優れる「波状ステンレス鋼管」や「配水用ポリエチレン管」を標準採用する。

---

### (2) 複数系統化と環状化（ループ化）

```
【樹枝状配管 vs 環状ループ配管】
① 樹枝状（枝状・片送り）配管 ── 事故箇所より下流がすべて断水！水が滞留しやすい。
② 環状（ループ状）配管 ──── 複数方向から水が回るため、事故箇所だけをバルブで
                               隔離でき、他のすべての需要家へ給水を継続できる！
```

* **樹枝状配管の欠点**: 水が一方向からしか流れないため、上流の1箇所で漏水・破断が起きると、それより下流の全世帯が即座に断水する。また、管末部で水が滞留しやすく残留塩素が低下しやすい。
* **環状（ループ）配管の利点**: 網の目状に管を連絡させることで、事故時にも反対方向からバックアップ通水が可能となり、**バルブ操作によって破損箇所のみを局所遮断（隔離）し、断水区域を最小限に限定** できる。また、管網全体の動水圧が均一化・安定化する。

---

### (3) 配水ブロック化（ブロックシステム）

配水区域全体を、幹線道路や河川・地形の境界に合わせて **独立した「適正規模のブロック（給水区）」に分割・管理** する近代的水運用手法である。

* **ブロック化のメリット**:
  1. 各ブロックの流入点に流量計・水圧計・減圧弁を配置することで、**日常の水圧コントロールが容易になり、無駄な高水圧を抑えて漏水量を大幅に削減** できる。
  2. 夜間最小流量の測定により、**どのブロックで漏水が多発しているかをピンポイントで特定** できる。
  3. 災害時や突発事故時、被害を受けたブロックだけをバルブで瞬時に切り離し（隔離）、他のブロックへの被害波及を完全に食い止めることができる。
* **実務上の留意点（過度な細分化の弊害）**:
  * ブロックをあまりにも細かく分割しすぎると、日常工事における断水調整や、隣接ブロックからの緊急融通バルブ操作が極めて複雑化し、運用性が著しく低下する。
  * 各事業体の幹線ネットワークの形態や職員体制に見合った **「適正なブロック規模の設定・見直し」** が重要となる。

## 8. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：消火栓の機能と維持管理【最頻出】）
* **問題形式**: `choice`
* **問題文**: 水道配水施設に設置される消火栓の役割および維持管理に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 消防水利のほか水圧水質測定や洗管排水など多様な役割を担う
  2. 消防活動専用の施設であるため水道事業者による日常点検は不要である
  3. 消火栓を取り付ける母管の口径はいかなる場合も75mm以下とする
  4. 消火栓本体の補修点検時には配水本管全体を必ず断水させて作業する
* **正解**: 1（インデックス: 0）
* **解説**: 消火栓は消防水利のみならず、水圧・水質の測定、濁水発生時の洗管排水、管内状況調査など多様な役割を担う重要設備であり、常時機能を発揮できるよう適切な維持管理が求められます。母管口径は原則150mm以上であり、本体直下には断水せずに補修できる補修弁を併設します。
* **日常のたとえ**: 商業ビルの非常階段と同じで、火災時の避難（消火）だけでなく、日頃の点検搬入経路や清掃（洗管・水質測定）にも使える多目的安全インフラです。
* **出典**: 講義テキスト 導送配水施設 p.289

### 設問2（4択・否定形：付属設備・排水設備）
* **問題形式**: `choice`
* **問題文**: 配水管路の付属設備および維持管理に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 洗管排水を河川へ排出する際は水道水をそのまま無処理で直接放流する
  2. 起伏地帯の低地部では過大水圧による漏水等を防ぐため減圧弁を設置する
  3. 管径800mm以上の配水本管には点検員が出入りできる人孔を設置する
  4. 下水道へ排水を接続する際は高圧噴射を防ぐため大気開放の排水室を介する
* **正解**: 1（インデックス: 0）
* **解説**: 水道水には消毒用の残留塩素が含まれているため、そのまま河川へ放流すると魚類がへい死します。河川放流時は必ずチオ硫酸ナトリウム等の還元中和剤を用いて残留塩素を脱塩素処理（中和）しなければなりません。
* **出典**: 講義テキスト 導送配水施設 p.289〜292

### 設問3（4択：埋設深さと明示基準）
* **問題形式**: `choice`
* **問題文**: 地下埋設管の事故防止対策および明示に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 他企業による掘削事故を防ぐため管頂約30cm上部に青色の明示テープを敷設する
  2. 水道管の埋設明示テープは全国共通の統一規格として緑色を使用する
  3. 水道管を布設した後はスラストコンクリートの打設前に水圧試験を実施する
  4. 他企業埋設物が輻輳していても道路下の埋設深さを0.6mに緩和することはできない
* **正解**: 1（インデックス: 0）
* **解説**: 地下埋設管の誤破損を防ぐため、管頂から約30cm上部に明示テープを敷設します。事業体統一カラーは「水道：青（水色）」「ガス：緑」「電力：橙」「通信：赤」「下水：茶」です。水圧試験はスラスト防護完了後に実施し、埋設深さは協議により0.6mまで浅層緩和が可能です。
* **出典**: 講義テキスト 導送配水施設 p.294

### 設問4（4択：アセットマネジメント・管路更新）
* **問題形式**: `choice`
* **問題文**: 水道管路のアセットマネジメントおよび計画的更新に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 施設の重要度や健全度および耐震性能を総合評価して更新計画を策定する
  2. 耐用年数を超過した管路は健全度や漏水履歴に関わらず全数を一律更新する
  3. 管路更新の優先順位は給水末端の小口径配水支管を最優先とする
  4. 財源不足を回避するため漏水事故が発生した箇所のみを事後修繕で対応する
* **正解**: 1（インデックス: 0）
* **解説**: 管路の更新には多額の費用と長期の工事を要するため、施設の重要度、健全度（経年・漏水履歴）、耐震性能などを総合評価し、財源的裏付けのある計画を策定して計画的・継続的に更新するアセットマネジメントが不可欠です。優先整備対象は上流の基幹施設や重要避難所・病院等です。
* **日常のたとえ**: 自動車の車検や予防整備と同じで、壊れて動かなくなってから直すのではなく、年式や走行距離、重要部品の劣化度を総合診断して、予算に合わせて優先順位を決めて計画的に部品交換する手法です。
* **出典**: 講義テキスト 導送配水施設 p.296

### 設問5（4択：管路更新の効果）
* **問題形式**: `choice`
* **問題文**: 老朽化した無内面ライニング鋳鉄管を最新の耐震継手管へ更新することによる効果として、最も適切なものはどれですか？
* **選択肢**:
  1. 内部の錆コブ解消により塩素消費が抑えられ低濃度注入でおいしい水が届く
  2. 管内流速が著しく低下するため水頭損失が増大し末端動水圧が減衰する
  3. 水道メーターの検定有効期間が従来の8年間から16年間に自動延長される
  4. 浄水場における薬品凝集沈殿池の濁度除去率が自動的に飛躍的向上する
* **正解**: 1（インデックス: 0）
* **解説**: 無ライニング鋳鉄管内の錆コブは残留塩素を激しく消費するため、従来は浄水場で高濃度の塩素を注入せざるを得ずカルキ臭の原因となっていました。管路更新により塩素消費が抑えられるため、低濃度注入による「おいしい水」の供給が可能になります。また通水能力回復、水圧保持、耐震性向上が図られます。
* **日常のたとえ**: 錆びてドロドロに詰まったキッチンの排水パイプを新品のツルツルなパイプに取り替えると、流れが良くなるだけでなく、嫌な臭いや汚れの吸着（塩素の無駄な消費）がピタッとなくなるのと同じです。
* **出典**: 講義テキスト 導送配水施設 p.296
