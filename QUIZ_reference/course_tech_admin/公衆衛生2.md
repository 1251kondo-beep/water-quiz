## 2. 耐塩素性病原微生物（クリプトスポリジウム等）対策（p.873〜）

### (1) クリプトスポリジウムおよびジアルジアの特徴
* 水道水質管理上、最も厳重な警戒が求められる耐塩素性病原原虫。
* **極めて強い耐塩素性**: オーシスト（厚い殻に包まれた休眠体）を形成するため、**通常の浄水処理で用いられる遊離残留塩素濃度（0.1〜1.0 mg/L 程度）では死滅（不活化）しません**。
* **法令上の位置付け**: 水質基準項目や水質管理目標設定項目とは別枠で、厚生労働省通知（現・国交省/環境省通知）**「水道水におけるクリプトスポリジウム等対策指針」**に基づき、施設要件や運転管理基準が詳細に規定されています。

### (2) 埼玉県越生町における集団感染事故（平成8年 / 1996年）
* **事故概要**: 町立小中学校の児童生徒を中心に激しい下痢・腹痛・発熱等の集団感染が発生。町民約14,000人中、約 **8,800人（人口の約6割超）** が罹患した日本最大の水系原虫感染事故。
* **原因機構**:
  1. 水源上流の集落で保菌者の排泄物が農業集落排水処理施設を経て放流。
  2. 取水口付近の伏流水原水が高濃度に汚染。
  3. 急速ろ過方式の浄水場であったが、**低濁度原水であったため凝集剤の常時注入を行っていなかった**。
  4. 原虫がろ過砂層をそのまま通り抜け、給水区域全域に配水された。
* **事後対応**: 給水停止・煮沸勧告、県営受水（別水源）への切り替え、配水管の全面フラッシング（洗浄排水）を経て約1か月後に収息。恒久対策として**膜ろ過設備**が導入された。
* **教訓**: 本事故を契機に国の「暫定対策指針」が策定され、全国の水道施設において原虫対策が義務化されました。

### (3) リスクレベル分類と求められる対策
原水種別および指標菌（大腸菌・嫌気性芽胞菌）の過去の検出実績に基づき、4段階のリスクレベルが設定されています。

| リスクレベル | 判定基準 | 義務付けられる対策 |
| :--- | :--- | :--- |
| **レベル4** | **表流水を原水**とし、指標菌の検出歴がある | **施設対策が必須**（ろ過設備、紫外線処理等） |
| **レベル3** | **表流水以外（地下水・伏流水等）**であるが、指標菌の検出歴がある | **施設対策が必須**（ろ過設備、紫外線処理等） |
| **レベル2** | 表流水以外で指標菌検出歴はないが、周辺状況から汚染の恐れがある | 定期的な指標菌検査、水源井戸の密閉・衛生点検 |
| **レベル1** | 深井戸等で汚染のおそれが極めて低い | 定期的な指標菌検査の継続 |

### (4) 浄水工程における運転管理基準
* **ろ過池出口の濁度管理**: 原虫の物理的捕捉を確実に担保するため、**「常時 0.1 度以下」を厳格に保持**することが義務付けられています。
* **凝集処理の徹底**: 急速ろ過方式を採用している場合、**原水がいくら低濁度であっても凝集剤（PAC等）の常時適正注入が必須**（越生町の反省）。
* **紫外線（UV）処理設備の導入要件**: 薬品に耐性のあるクリプトスポリジウムを不可逆的に不活化する技術。
  * *適用可能水質*: **濁度 2 度以下**、**色度 5 度以下**、**紫外線透過率 75% 以上**（濁度が高いと紫外線が遮断されるため、適切な前処理が必要）。

## 3. 水安全計画（Water Safety Plan: WSP）の導入（『業務必携』p.193〜）

### (1) 策定背景
* 1993年の米国ミルウォーキー市における大規模クリプトスポリジウム事故（約40万人感染）等を契機に、WHO（世界保健機関）が提唱。
* 食品製造分野の衛生管理手法**「HACCP（ハサップ）」**の概念を水道システムに導入したリスクマネジメント手法。

### (2) 従来型水質管理とWSPの比較
* **従来型の水質管理**:
  * 給水栓（蛇口）での水質検査を中心とした**「最終製品評価（結果系の確認）」**。
  * 異常が判明した時点では、既に汚染水が配水・飲用されているリスクを排除できない。
* **水安全計画（WSP）**:
  * **「水源から給水栓に至る全工程」**において危害（ハザード）をあらかじめ特定。
  * 各工程の**重要管理点（CCP）**と許容限界値（管理基準）を設定し、連続的にモニタリング・制御を行う**「工程内予防管理」**。

### (3) WSPの期待される効果
1. 水道水の安全性と市民の信頼性の飛躍的向上
2. 浄水・配水プロセスの日常運転維持管理水準の向上
3. **ベテラン技術者の暗黙知・経験則の形式知化（マニュアル化）と技術継承**
4. 需要者・市民に対する安全性確保プロセスの説明責任（アカウンタビリティ）の確立
5. 水源保護から給水栓管理までの一元的・統合的管理体制の構築

## 4. 環境基準と排水基準（環境行政との連携）（p.853〜）

水道技術管理者は、水源となる公共用水域の水質保全のため、環境法令の基準体系を深く理解しておく必要があります。

| 区分 | 根拠法 | 性格 | 対象・基準値の概要 |
| :--- | :--- | :--- | :--- |
| **環境基準** | **環境基本法** | 行政上の維持が望ましい目標（努力目標） | ・**人の健康の保護に関する環境基準**（全国一律 / 27項目）<br>・**生活環境の保全に関する環境基準**（水域ごとに類型指定。<br>　河川はAA〜Eの6類型。水道1級適合のAA類型はBOD 1 mg/L以下） |
| **排水基準** | **水質汚濁防止法** | 特定施設を設置する工場・事業場に対する**法的義務（直罰規定あり）** | ・**有害物質**（環境基準値のおおむね **10倍濃度** を基本に設定。ダイオキシン類は別法規制）<br>・**生活環境項目**（15項目）<br>※自治体条例による「上乗せ基準」が広く設定される |

### 指定物質の規制（水質汚濁防止法）
* **定義**: 有害物質に準じ、事故等により公共用水域に多量に排出された場合に人の健康や生活環境に被害を生ずるおそれがある物質。
* **対象物質**: ホルムアルデヒド前駆物質（ヘキサメチレンテトラミン）、近年のPFOS・PFOA等。
* **事業者の義務**: 破損・流出事故発生時は、**直ちに応急措置を講じるとともに、都道府県知事等へ速やかに届け出る義務**があります。

## 5. 水道施設における労働安全衛生管理（p.861〜）

水道現場は、有害薬品（次亜塩素酸、ポリ塩化アルミニウム、硫酸等）の注入、高圧電気受変電設備、高速回転機械、深部ピット・高所作業、マンホール内酸欠・硫化水素危険、道路上配管工事など多種多様な危険源を抱えています。

### (1) 水道技術管理者の所掌事務（水道法第19条・第21条・第22条）
特に安全衛生・公衆衛生管理に関わる2大法定事項：

#### 1. 定期および臨時の健康診断（水道法第21条 / 規則第16条 / 『業務必携』p.25）
* **対象者**: 浄水場等の水道施設業務従事者、施設敷地内居住者、および頻繁に出入りする関係受託者等。
* **検査内容**: **検便による水系感染症病原体の検査（年1回以上）**。
  * *法定対象菌*: **赤痢菌、チフス菌、パラチフス菌** を基本。
  * *臨時追加菌*: 地域での流行状況等に応じ、コレラ菌、アメーバ赤痢、病原性大腸菌、サルモネラ等を臨時に追加実施。

#### 2. 衛生上の措置と残留塩素保持（水道法第22条 / 規則第17条）
* **施設の衛生管理**: 施設周辺の清浄保持、部外者の立ち入り防止柵・施錠、施設定期点検。
* **給水栓における残留塩素濃度の法定保持基準**:
  * **平常時**:
    * 遊離残留塩素: **0.1 mg/L 以上**
    * 結合残留塩素の場合: **0.4 mg/L 以上**
  * **病原体等による汚染のおそれがある場合（濃度引き上げ義務）**:
    * 遊離残留塩素: **0.2 mg/L 以上**
    * 結合残留塩素の場合: **1.5 mg/L 以上**
  * *引き上げ適用状況の具体例*:
    1. 給水区域内または水源近隣で消化器系感染症が流行しているとき
    2. 大地震、豪雨、台風等の自然災害による被災時
    3. 配水管工事や大規模断水後の給水再開時
    4. 原水水質悪化や異臭味、水質異常が発生したとき

### (2) 化学物質の自律的管理体制とリスクアセスメント（p.864〜）
労働安全衛生法関係政省令の改正（平成28年義務化、令和6年4月完全施行）により、従来の個別規制中心から**「事業者自らがリスクを評価し管理する自律的管理方式」**へと抜本的転換が図られました。

* **リスクアセスメントの義務化**:
  * 安全データシート（SDS）交付対象物質（現在約2,900物質）を製造・取り扱う全事業場において、危険性・有害性の調査とリスク低減措置の策定が義務。
* **化学物質管理者（専任）の選任義務**:
  * 製造業のみならず、**対象物質を取り扱うすべての事業場（凝集剤・消毒剤・pH調整剤等を取り扱う浄水場も該当）**において専任が義務化。
  * **職務**: SDS情報の確認、リスクアセスメントの実施総括、ばく露防止措置・保護具管理、作業記録の保存、従事者への安全教育。
