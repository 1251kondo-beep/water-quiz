## 1. 導入：SNS・AIを活用した漏水覚知システム（FastAlert）

夜間や休日の突発的な路上漏水事故において、従来の「住民からの電話通報待ち」から、デジタル技術を駆使した「プロアクティブな早期覚知」へと管理体制が進化している。

* **FastAlert（ファストアラート）の導入実態**:
  * 東京都水道局をはじめとする先進水道事業体で導入されているSaaS型AIリスク情報解析サービス。
  * **仕組み**: X（旧Twitter）などのSNS上に投稿される「道路冠水」「水道管破裂」「マンホールから水が噴出」といった市民のテキストや画像・動画情報を、AIが自然言語処理・画像解析により24時間365日リアルタイムに収集・フィルタリング。
  * **効果**: 位置情報や現場写真とともに当直管理者・現場担当者の業務用スマートフォンへプッシュ通知されるため、電話通報が寄せられる前、あるいは電話通報と照合しながら、**直ちに現場へ急行して初動対応（バルブ閉止・交通規制）を開始することが可能** となっている。

## 2. 管路更新の手順と劣化診断（テキスト p.297）

計画的な管路更新を推進するためには、感覚的な判断ではなく、科学的な劣化診断に基づく「管路更新計画」の策定が不可欠である。

```
【管路更新計画策定の2大評価軸】
① 物理的健全度評価 ── 管路が現在どの程度劣化しているか（残存寿命の科学的予測）
② 更新優先度評価 ──── 事故時の断水人口、病院・避難所への影響、道路交通への影響度
   ➔ 健全度が低く、かつ社会的重要度が高い路線から最優先で事業着手！
```

---

### (1) 間接診断と直接診断の比較

地中に埋設された膨大な管路の劣化度を評価するため、「間接診断」と「直接診断」を組み合わせて運用する。

| 診断分類 | 手法の定義・特徴 | 主な調査・評価項目 | メリット・実務上の適用 |
| :--- | :--- | :--- | :--- |
| **間接診断** | 管路を掘り起こさず、日常の維持管理データや台帳情報を統計的・解析的に処理して劣化度を予測する手法。 | ・布設経過年数（布設年次）<br>・**過去の漏水事故率（件数/km/年）**<br>・管種・口径・継手形式<br>・土壌の腐食環境（地盤種別）<br>・水圧履歴・水圧変動幅<br>・出水不良や濁水等の苦情履歴 | ・**全路線を対象に机上で低コストかつ網羅的にスクリーニング可能**。<br>・優先調査路線の絞り込みに必須。 |
| **直接診断** | 実際に管路を掘削・露出させ、抜管（サンプリング切断）等を行って物理的・化学的に劣化度を直接測定する手法。 | ・**内面錆コブの発生状況**<br>・内面塗装・モルタルライニングの剥離度<br>・**外面の孔食（ピッティング）深さ**<br>・残存管厚（超音波厚さ測定）<br>・有効通水断面積の縮小率<br>・ボルト・ナットの減肉・腐食状況 | ・劣化状況を最も正確・確実に把握可能。<br>・掘削・断水コストがかかるため、**他工事による露出機会や更新工事時の撤去管を活用して実施** し、結果を周辺路線へフィードバックする。 |

### (2) 土壌腐食性とポリエチレンスリーブによる防食（テキスト p.297）

地盤環境（土壌の比抵抗、含水比、pH、酸化還元電位等）は、金属管の外面腐食速度を決定づける最重要因子である。

```
【東京都区部における地盤構造と管路外面腐食の傾向】
・東側低地部（下町エリア：荒川・隅田川流域） ➔ 沖積層（軟弱地盤・地下水高・腐食性強）
   ※外面腐食による漏水事故が多発！
・西側台地部（山手・多摩エリア：武蔵野台地） ➔ 洪積層（関東ローム層・良好地盤・腐食性弱）
   ※外面腐食は比較的少ない。
```

* **ポリエチレンスリーブ（外面防食）の標準化**:
  * 腐食性の高い土壌からダクタイル鋳鉄管を半永久的に保護するため、**昭和62（1987）年頃から「ポリエチレンスリーブ（厚さ約 $0.2\,\text{mm}$ の筒状フィルム）」で管体を完全に包み込んで埋設する工法が標準化** された。
  * **防食メカニズム**: スリーブと管体の間に侵入したわずかな水分は、初期に微小な錆を発生させて酸素を消費した後は「無酸素状態」となり、以後の電気化学的腐食反応が停止する。安価でありながら極めて高い防食効果を発揮し、外面腐食事故を激減させた。

## 3. 東京都における管種・継手の変遷と更新実態

東京都水道局における配水管の技術的変遷は、日本の水道技術史そのものを反映している。

```
【採用管種・継手の歴史的変遷】
① 〜昭和40年代前半 ── 普通鋳鉄管（CIP）・高級鋳鉄管（引張強度が低く脆性割れ多発）
② 昭和40年代前半〜 ── ダクタイル鋳鉄管（DIP）本格採用（球状黒鉛で靭性向上）
③ 昭和60年代〜 ──── ポリエチレンスリーブ被覆の標準化（外面土壌腐食防止）
④ 平成9（1997）年〜 ── 阪神・淡路大震災を契機に「耐震継手管（NS形）」本格採用
```

* **更新の現状と「取替困難管」の解消手法**:
  * 耐震継手管の本格採用から約30年が経過したが、総延長が約 $28{,}000\,\text{km}$ と膨大なため、現在でも耐震継手化率は全体の半分程度である。
  * 残存する経年管（普通鋳鉄管等：残り0.数％）は、交通量が極めて激しい大幹線交差点の直下や、鉄道軌道横断部など、物理的に再掘削が困難な場所に集中している。
  * **解消手法（縁切り・残置）**:
    * こうした箇所では無理に旧管を掘り起こして撤去しようとせず、別のルートに最新の耐震管を新設して通水を切り替えた後、**旧管を管網から完全に切り離して通水を止める「縁切り（残置）」** を行うことで、確実かつ安全に経年管をゼロにする取り組みが進められている。

## 4. 基本計画・実施計画と特殊施工技術（テキスト p.298〜301）

### (1) 実施計画と不断水工法（テキスト p.299）

管路更新の実施にあたっては、地域の社会条件に応じた工法選定が求められる。

* **新管布設更新 vs 更生工法**:
  * 抜本的な耐震化を図る場合は道路を開削して新管を布設するが、掘削が困難な場所や耐震性能を問わない路線では、管内を洗浄してライニングを施す「更生工法」が比較検討される。
* **断水が社会的に許容されない路線での「不断水工法」**:
  * **適用対象**: 人工透析を行う大病院、救急指定病院、データセンター、夜間飲食店街、大規模商業地域など。
  * **工法概要**: 配水管内に **水を通水したまま（水圧・流量を保持したまま）**、特殊な密閉作業弁・穿孔機を用いて管体に穴を開けて分岐したり（**不断水分岐工法**）、既設管を切断して仕切弁を挿入する（**不断水バルブ設置工法**）。断水による社会的影響を完全に回避できる。

---

### (2) 既設管内布設工法（非開削・低開削工法）（テキスト p.300〜301）

道路上の掘削面積や交通規制を最小限に抑えるため、地中の既設管（古くなった管）を「さや管（案内管）」として利用し、その内部に新しい管を通す特殊工法が開発されている。

```
【主な既設管内布設工法の比較】
① パイプインパイプ(PIP)工法 ── 既設管内に小口径新管を引き込み、間詰めモルタル充填。
② SDF工法 ──────────── 波状（蛇腹）ステンレス鋼管を連続挿入。曲管部通過可能！
③ 巻き込み鋼管工法 ────── 大口径管でポスター状に丸めて挿入し、管内で拡径全周溶接。
```

| 工法名称 | 適用口径 | 施工メカニズム・特長 | 留意点・制約事項 |
| :--- | :--- | :--- | :--- |
| **パイプインパイプ工法**<br>（**PIP工法**） | 口径 **$\phi 400\,\text{mm}$ 以上** の配水本管 | ・発進・到達立坑のみを開削。<br>・既設管内に $1 \sim 2$ サイズ口径の小さい新管（DIP・SP等）を引き込み、**既設管と新管の隙間に間詰めモルタルを充填・一体化**。 | ・口径が $1 \sim 2$ ランク縮小する。<br>・**曲管部（ベンド）があると新管が通過できない**（直線区間に限定）。<br>・給水管が多数分岐する配水支管には適用困難。 |
| **SDF工法**<br>（ステンレス・フレキシブル） | 口径 **$\phi 150\,\text{mm}$ 以上** | ・可とう性・伸縮性に富んだ **「波状（蛇腹状）ステンレス鋼管」** を既設管内に連続挿入する工法。<br>・**曲管部（ベンド）に追従してスムーズに通過可能**。 | ・材料費が比較的高価。<br>・給水管取り出しのない路線に好適。 |
| **巻き込み鋼管工法** | 口径 **$\phi 800\,\text{mm}$ 以上** の大口径管 | ・口径縮小を極限まで防ぎたい大幹線に適用。<br>・工場で端部を重ね合わせた **「ポスター状に丸めた縮径鋼管」** を管内に引き込み、管内で拡径ジャッキにより円形に押し広げ、**内面から突合せ部を全周溶接**。 | ・極めて高度な施工管理が必要。<br>・作業員が管内に入れる超大口径管に限定。 |

## 5. 管路施設とバルブ類の維持管理（テキスト p.302〜304）

### (1) 路線管理と仕切弁台帳の即日更新（テキスト p.302）

配水幹線網の維持管理は、バルブからバルブまでの区間を1つの **「路線」** として管理する。

* **仕切弁台帳（本弁台帳）の管理項目**:
  * 管理番号、口径、バルブ形式、開閉方向（右開き／左開き）、全開・全閉回転数、設置年月日、直近の点検・操作履歴。
* **操作履歴の「即日更新」の徹底（最重要実務）**:
  * 夜間工事や漏水修繕等で仕切弁を開閉操作した作業員は、**現場終了後、事務所に戻った直後に必ず台帳（GIS・電子マッピングシステム）へ操作履歴・現在開度を登録・更新** する。
  * 台帳更新を怠ると、以後の断水作業で水が止まらなかったり、誤って常時閉止弁を開放して濁水を発生させるなど、致命的な事故を引き起こす原因となる。

---

### (2) 水圧・水量・水質の3大測定体系（テキスト p.302）

管網の安定供給を保証するため、3つの時間軸で測定・監視を実施する。

1. **常時測定**: 配水本管テレメーター（水圧・流量：1分値）および自動水質計器（残塩・濁度等）による24時間リアルタイム遠隔監視。
2. **定期測定**: 各配水ブロックの代表地点（末端・高所・結節点等）において、月1回などの頻度で定点水圧測定を実施し、季節変動や経年的な水圧低下傾向を把握。
3. **随時測定**: 市民から「水が出ない」「水圧が弱い」「水が濁っている」といった通報が寄せられた際、現地へ自記水圧計や濁度計を設置して詳細調査を実施。

---

### (3) バルブの点検整備と誤操作防止明示板（テキスト p.303〜304）

* **機能点検**:
  * 弁棒の回転トルクが重くなっていないか、異物噛み込みがないか、弁室・弁筐内に地下水や泥水が滞留していないかを確認。
* **誤操作防止明示板（プレート）の現地設置（出題ポイント）**:
  * 配水ブロックの境界に位置する仕切弁は、水圧の異なるブロック同士を遮断するため **「常時閉止（常時閉）」** として運用される。
  * これを誤って開放すると、隣接ブロックから急激に水が逆流し、管内の沈積物を巻き上げて **大規模な広域赤水（濁水）事故や異常減圧事故** を引き起こす。
  * そのため、現地バルブのスピンドル軸等に **「常時閉（赤色表示板）」** や **「開度制限（黄色表示板）」** などの物理的プレートを取り付け、現場作業員が一目で誤操作を防止できる対策を徹底する。

## 6. 地下構造物作業における安全管理（酸欠・可燃性ガス・硫化水素）

バルブ室、排水室、人孔（マンホール）などの地下密閉空間に立ち入る作業は、一歩間違えれば作業員が命を落とす危険作業である。

```
【地下ピット作業における3大災害リスク】
① 酸素欠乏症（酸欠） ── 金属の錆び・微生物呼吸で酸素激減。18%未満で危険！
② 可燃性ガス爆発 ──── メタン等の滞留。火花やハシゴ交換作業で引火爆発！
③ 硫化水素中毒 ────── 下水・汚水の嫌気分解。嗅覚麻痺、一呼吸で失神・死亡！
```

---

### (1) 酸素欠乏症（酸欠）の危険性と生理作用

大気中の通常酸素濃度は **約 $21\%$** である。密閉された地下室では、鉄蓋の隙間からの換気はほとんど期待できず、金属の酸化（鉄の錆び）や土壌微生物の呼吸によって酸素が消費され、容易に酸欠空気が生成される。

```
【酸素濃度と人体の危険度ステップ】
・21% ── 通常の大気
・18% ── 安全限界（労働安全衛生法基準：18%未満は立入禁止！）
・16% ── 呼吸・脈拍増加、頭痛、悪心
・12% ── めまい、筋力低下（自力でハシゴを登れなくなる！）
・10%以下 ─ 意識喪失、痙攣、昏睡 ➔ 数分で脳死・死亡
```

* **深さに関係のない危険性（実務教訓）**:
  * 昭和55年に発生した事案では、**わずか深さ $2 \sim 3\,\text{m}$ の浅いバルブ室** であっても作業員が酸欠で死亡している。
  * 「浅いから」「顔を少し出すだけだから」という油断は極めて危険である。
* **酸欠防止の3大必須ルール**:
  1. 入室前に必ずマンホール上部から検知管・ガス測定器を下ろし、**酸素濃度が「$18\%$ 以上」あることを測定・確認** する。
  2. 作業中は **送風機（ファン）による強制機械換気を常時継続** する。
  3. マンホール地上部に必ず **「監視員」** を常駐させ、万一の際に救助体制を確保する。

---

### (2) 可燃性ガスによる爆発事故

* **東京都水道局における重大爆発事故（令和4年）**:
  * 河川放流用排水室（地下ピット）内において、ハシゴ交換作業中に滞留していた **可燃性天然ガス（メタン等）に引火・爆発** し、作業員が死亡する大事故が発生した。
* **教訓と安全対策**:
  * 泥炭地や沖積低地など、地下水や地層から可燃性ガスが湧出するリスクがある地域では、**「火気厳禁」の徹底、防爆型照明・防爆型送風機の使用、可燃性ガス濃度（爆発下限界LEL）の常時監視** が義務付けられている。

---

### (3) 硫化水素（$\text{H}_2\text{S}$）中毒の恐怖

* **埼玉県八潮市下水道マンホール死亡事故（令和7年8月）**:
  * 管路点検中にマンホール内で発生した高濃度硫化水素により、救助に向かった二次災害も含め作業員4名が命を落とす痛ましい事故が発生した。
* **硫化水素の特性と危険性**:
  * 有機物が嫌気性分解されることで発生する。
  * **比重が空気より重い（約1.19倍）** ため、マンホールや排水室の **「最底部（足元）」に高濃度で滞留** する。
  * 低濃度では腐った卵の臭い（腐卵臭）がするが、**濃度が上がると嗅覚神経が瞬時に麻痺して臭いを感じなくなる**。高濃度（数千ppm）では **「一呼吸（ワン・ブレス）」で意識を失い、呼吸停止（即死）** に至る。
* **安全対策**:
  * 汚水流入のリスクがあるピットでは、**換気ホースの吸込口・送風口をピットの「床面最底部」まで確実に下ろして滞留ガスを強制排気** する。作業員は複合ガス検知器（酸素・可燃性ガス・硫化水素・一酸化炭素）を必ず携行する。

## 7. 水管橋および橋梁添架管（テキスト p.307）

河川、運河、鉄道等を横断して地上空間に管路を布設する構造形式である。

```
【水管橋の4大形式】
① パイプビーム形式 ── 管自体の曲げ剛性でスパンを渡す（小中口径・短スパン向け）
② トラス補強形式 ── 鋼製トラス骨組みの中に管を配置（中長スパン向け）
③ アーチ補強形式 ── アーチリブから管を吊り下げ（大スパン・良好な河川景観）
④ 斜張橋形式 ──── 主塔から斜材ケーブルで管を吊り支持（超長スパン・近代的意匠）
```

### (1) 水管橋の構造形式
1. **パイプビーム形式**: 水道管（鋼管）自体の断面係数・曲げ剛性のみを利用して両岸の橋台間に架設する。構造が最もシンプルで経済的だが、支間長（スパン）に限界がある。
2. **補強水管橋形式（トラス・アーチ・斜張橋）**:
   * 大河川を渡るロングスパンでは、管自体の耐力だけでは自重や水重量・風荷重を支えきれないため、外部に鋼構造の補強桁を設ける。
   * **アーチ形式**: 力学的に安定しており、都市景観や河川景観に美しく調和するため、市街地の大架橋で広く採用される。

---

### (2) 橋梁添架配管の設計留意点

道路橋等の道路構造物に水道管を抱き込ませて添架する方式である。

* **メリット**: 水管橋を単独で一から建設するのに比べ、**建設費・維持管理費を飛躍的に抑制** できる。道路管理者と添架協定を結び、添架料を支払う。
* **実務上の2大設計制約（出題ポイント）**:
  1. **地震時の挙動差と変位吸収**:
     * コンクリート道路橋と鋼製水道管では、自重や固有周期が全く異なるため、地震時に激しい位相差（ズレ）が生じる。
     * そのため、添架部ブラケットには滑り支承を設け、橋台と地中埋設管の接続部には **「伸縮可とう継手」を配置して相対変位を確実に吸収** させなければならない。
  2. **将来の「増径（口径拡大）」が原則不可能**:
     * 道路橋の設計段階で、水道管の死荷重（管材重量＋満水重量）を橋梁の許容耐力に算入して設計されている。
     * したがって、将来の管路更新時に **「需要が増えたからといって、当初より太い管（重い管）へ増径すること」は橋梁の耐力上絶対に認められない**。設計段階で将来の最終需要を慎重に見極める必要がある。

## 9. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：劣化診断手法）
* **問題形式**: `choice`
* **問題文**: 水道管路の物理的健全度評価における「間接診断」の項目として、最も適切なものはどれですか？
* **選択肢**:
  1. 過去の漏水事故率や布設経過年数および土壌腐食環境
  2. 掘削抜管した試験体における内面の錆コブ発生状況
  3. 超音波厚さ計を用いて直接測定した管体の残存管厚
  4. 管体を切断してマイクロメーターで測定した外面孔食深さ
* **正解**: 1（インデックス: 0）
* **解説**: 間接診断は、管路を掘削・抜管することなく、台帳や維持管理履歴から得られる布設年数、漏水事故率、管種、土壌環境等を統計的に解析して劣化度を予測する手法です。残存管厚や錆コブ、外面孔食深さを直接測定するのは「直接診断」です。
* **日常のたとえ**: 病院の診察に例えると、問診票や年齢、過去の既往歴から病気のリスクを推測するのが「間接診断」で、実際に胃カメラやCTスキャンで体内を撮影して病変の大きさを直接測るのが「直接診断」です。
* **出典**: 講義テキスト 導送配水施設 p.297

### 設問2（4択：特殊施工技術・PIP工法）
* **問題形式**: `choice`
* **問題文**: 既設管をさや管として利用する「パイプインパイプ（PIP）工法」の施工特性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 直線区間に好適であり曲管部が存在する箇所には適用できない
  2. 既設管内に太い新管を圧入するため更新後の通水能力が向上する
  3. 各戸への給水管引き込みが多数存在する配水支管に広く適用される
  4. 既設管と新管の隙間は空隙のまま残置して施工を完了させる
* **正解**: 1（インデックス: 0）
* **解説**: PIP工法は既設管内に1〜2サイズ小さい直管を引き込むため、曲管部（ベンド）があると通過できません（曲がり部にはSDF工法等が用いられます）。また、口径は縮小し、隙間には間詰めモルタルを充填するため、給水管引込のある配水支管には適用が困難です。
* **出典**: 講義テキスト 導送配水施設 p.300〜301

### 設問3（4択・否定形：地下作業安全管理・酸欠）
* **問題形式**: `choice`
* **問題文**: バルブ室等の地下構造物内における作業安全管理に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 深さ2〜3m程度の浅い地下室であれば酸素欠乏症の危険は生じない
  2. 入室前にガス測定器を用いて酸素濃度が18%以上あることを確認する
  3. 作業中は送風機等を用いて地下室内の強制的な機械換気を継続する
  4. 万一の事態に備えて地上開口部付近には必ず監視員を配置しておく
* **正解**: 1（インデックス: 0）
* **解説**: 酸欠事故は構造物の深さに関係なく発生します。過去には深さ2〜3m程度の極めて浅いバルブ室でも酸素濃度低下による死亡事故が発生しています。「浅いから安全」という認識は重大な誤りです。
* **出典**: 講義テキスト 導送配水施設 p.305〜306（安全管理規程）

### 設問4（4択：地下作業安全管理・有害ガス）
* **問題形式**: `choice`
* **問題文**: 地下構造物内で発生する「硫化水素（H₂S）」の危険性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 空気より重いため最底部に滞留し高濃度では嗅覚が瞬時に麻痺する
  2. 空気より軽いため直ちに大気中へ放散し密閉ピット内には蓄積しない
  3. 高濃度になるほど腐卵臭が強烈に刺激するため嗅覚で確実に察知できる
  4. 吸入しても人体への毒性は低くコンクリート管を腐食させるのみである
* **正解**: 1（インデックス: 0）
* **解説**: 硫化水素は空気より比重が重いため、ピットやマンホールの最底部に高濃度で滞留します。低濃度では腐卵臭がしますが、濃度が上がると嗅覚神経が即座に麻痺して臭いを感じなくなり、一呼吸で失神・死亡する猛毒ガスです。
* **日常のたとえ**: 見えない落とし穴のようなガスで、階段の下や窪地の底に水のように溜まり、しかも危険な高濃度になると鼻がバカになって臭いすら感じなくなるため、必ず足元まで換気ホースを伸ばして測定・排気する必要があります。
* **出典**: 講義テキスト 導送配水施設 p.306

### 設問5（4択：橋梁添架管の設計制約）
* **問題形式**: `choice`
* **問題文**: 道路橋に水道管を添架する「橋梁添架配管」の設計および維持管理に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 将来の管路更新時に橋梁の許容耐力を超えて口径を拡大することはできない
  2. 道路橋と水道管は一体構造物であるため地震時の変位挙動差は生じない
  3. 水管橋を単独で新設する場合に比べて初期建設費が大幅に高騰する
  4. 橋梁添架管には保温材や防食塗装などの外気保護対策は一切不要である
* **正解**: 1（インデックス: 0）
* **解説**: 橋梁添架管は道路橋の許容耐力（荷重制限）の範囲内で設計・添架協定が結ばれているため、将来の更新時に当初の重量制限を超えて口径を拡大（増径）することは橋梁の安全上認められません。また、地震時の挙動差を吸収する伸縮管の設置や、外気に露出するための防食・凍結防止対策が必須です。
* **出典**: 講義テキスト 導送配水施設 p.307
