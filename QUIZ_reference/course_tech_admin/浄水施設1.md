## 1. 浄水施設の基本概念と水道技術管理者の責務（テキスト p.351）

### (1) 浄水施設の目的と重要性
* **浄水施設の基本的役割**:
  * 水道法および「水道水質基準」に適合した、人が生涯にわたり安全に飲用・利用できる清浄な水道水を、**常に不足なく（安定した水量で）生産・供給する施設**である（テキスト p.351）。
* **運転管理の重要性**:
  * 浄水施設の維持管理が不十分であると、直ちに供給水の水質悪化や給水量不足を招き、人々の健康や社会経済活動に致命的な打撃を与える。
  * また、水質基準は科学的知見の進展や新たな化学物質の出現（例：PFAS等）に伴い適宜改正・強化されるため、従来の管理を踏襲するだけでなく、**新たな基準に常時適合できるよう適切な施設改良や運転管理技術の高度化**を図らなければならない。

```
【浄水処理の基本機能】
［水源原水］ ──→ ［浄水施設（沈殿・ろ過・高度処理・消毒）］ ──→ ［安全な水道水］
                 ・水質基準への完全適合（安全性確保）
                 ・計画給水量の安定的確保（過不足ない生産）
                 ・水質基準改正・新汚染物質への機敏な対応力
```

---

### (2) 水道法第19条第2項に基づく水道技術管理者の6大法定責務
水道法第19条第2項において、水道技術管理者は以下の6項目に関する事務に従事し、かつこれらの事務に従事する職員を直接監督しなければならないと明確に規定されている。

```
【水道技術管理者の6大法定責務（水道法第19条第2項）】
① 施設基準適合検査（法第5条） ──── 水道施設が技術的基準（構造・耐震・設備基準等）に適合しているかの検査
② 給水開始前の検査（法第13条） ─── 施設の新設・増設・改造工事完了後、通水前の水質検査及び施設検査の実施
③ 水質検査の実施（法第20条） ───── 供給水が水質基準を満たしているかの「定期水質検査」および「臨時水質検査」
④ 従事者の健康診断（法第21条） ──── 水を取り扱う業務従事者に対する定期（概ね6ヶ月ごと検便等）・臨時の健康診断
⑤ 衛生上の措置（法第22条） ────── 浄水場の清潔保持、塩素消毒の適正実施、施設の施錠管理など衛生上必要な措置
⑥ 給水の緊急停止（法第23条） ───── 供給水が人の健康を害するおそれがある場合の直ちなる給水緊急停止措置
```

* **健康診断の具体的要件（法第21条・施行規則第16条）**:
  * 浄水場等で水や浄水施設に直接接触する作業に従事する職員は、**おおむね6ヶ月ごとに、病原体が主に糞便中に排泄される感染症（細菌性赤痢、腸チフス、パラチフス等）の保菌者検査（検便）を含む定期健康診断**を受けなければならない。
* **給水の緊急停止権限（法第23条）**:
  * 原水の急激な油流出・有害物混入や消毒機能喪失などにより、水が人の健康を害するおそれがあると判断したときは、**経営判断を待たずに技術的責任において直ちに給水を緊急停止する**権限と義務を負う。

### (3) 水道技術管理者の心得5箇条
浄水施設を直接・間接に統括する技術管理者は、常に以下の5原則を銘記して日常業務に当たらなければならない。
1. **生命の安全確保への自覚**: 市民の生命と公衆衛生に直結する重責であることを常に認識すること。
2. **目的と稼働実態の完全把握**: 施設ごとの設置目的、設計諸元、維持管理状態を正確に把握すること。
3. **現場管理職員への周知徹底**: 直接運転・点検に当たる現場職員に対し、施設の構造、機能、標準操作法を周知徹底させること。
4. **能力不足・欠陥の即時是正**: 施設の能力不足や構造上の欠陥を発見した場合は、速やかに補修、整備、増強改良等の措置を講じること。
5. **事故対策・緊急連絡網の確立**: 突発事故や災害に備え、通報連絡、応急措置の計画を策定し、関係職員に訓練・周知しておくこと。

## 2. 原水水質と浄水システム選定の基本原則（テキスト p.351〜355）

### (1) 浄水システム選定における総合評価軸
最適な浄水システム（水処理フロー）を決定するにあたっては、単に水質の除去性能のみならず、以下の諸条件を総合的かつ多角的に検討・比較しなければならない。
* **原水水質と処理目標**: 原水に含まれる不純物の種類・濃度・変動幅と、達成すべき浄水水質目標値。
* **水量の規模**: 計画一日最大給水量、将来の需要変動、ピーク対応能力。
* **用地条件**: 確保可能な敷地面積、地形、標高差（自然流下の可否）。
* **維持管理の難易度**: 職員配置、自動化・遠隔制御の可否、薬品調達性、運転員の技術水準。
* **経済性（コスト）**: 初期建設費（イニシャルコスト）および維持管理・薬品・電力費（ランニングコスト）。
* **環境負荷**: 省エネルギー性能、薬品使用量、排水・発生土（脱水スラッジ）の処理・処分性。

---

### (2) 浄水処理フロー選定の2段階ステップ
浄水処理は、水中に存在する物質の物理化学的性状に応じ、以下の順序でプロセスを組み立てるのが基本原則である。

```
【浄水処理フロー選定の基本2段階ステップ】
┌────────────────────────────────────────────────────────┐
│ 第1ステップ：不溶解性成分（懸濁物質・濁度・粗大粒子等）の分離・除去    │
│ └── 沈殿池（普通沈殿・凝集沈殿）、ろ過池（急速・緩速）、膜ろ過（MF/UF）  │
└────────────────────────────────────────────────────────┘
                           ▼ （さらに必要な場合）
┌────────────────────────────────────────────────────────┐
│ 第2ステップ：溶解性成分（溶存有機物・カビ臭・トリハロメタン前駆物質等）の除去│
│ └── 高度浄水処理（オゾン酸化、生物活性炭BAC、粉末/粒状活性炭、エアレーション）│
└────────────────────────────────────────────────────────┘
```
* **従来処理の限界**: 沈殿と砂ろ過を中心とする「従来処理（Conventional Treatment）」は、濁度や浮遊粒子の除去には極めて高い性能を発揮するが、**水に完全に溶け込んでいる微量有機物質（カビ臭原因物質、溶解性色度成分、農薬等）の除去は原理的に困難**である。そのため、原水水質の悪化に応じて高度浄水処理を後段または前段に付加する必要がある。

### (3) 日本における水源内訳と浄水処理方式の採用割合
日本の水道における水源種別および採用されている浄水処理方式の統計的実態は、試験における定番の比較ポイントである。

```
【日本の水道水源の内訳】
・地表水（河川表流水・ダム水）：約 2/3（約 67%） ── 水量豊富だが水質変動大・高濁度リスク
・地下水・伏流水・その他     ：約 1/3（約 33%） ── 水質良好・安定だが水量に制約
```

```
【日本の浄水処理方式の採用割合（給水量ベース）】
┌───────────────────────────┬───────────┬────────────────────────────────────────┐
│ 処理方式                  │ 採用割合  │ 特徴・適用背景                         │
├───────────────────────────┼───────────┼────────────────────────────────────────┤
│ ① 急速ろ過方式           │ 約 80%    │ 日本の主流。表流水の高濁度・水質変動に対応│
│ ② 消毒のみ（塩素消毒等） │ 約 16.7%  │ 水質が極めて良好な深井戸・地下水に適用   │
│ ③ 緩速ろ過方式           │ 約 3%     │ 良質な原水・低濁度水、広大な敷地のある地域 │
│ ④ 膜ろ過方式             │ 約 3%     │ 小規模浄水場、山間部・無人自動化施設等   │
└───────────────────────────┴───────────┴────────────────────────────────────────┘
```

### (4) 水中物質の粒子サイズと適用処理技術
水中に存在する不純物は、その粒径（サイズ）によって挙動と除去手法が根本から異なる。

```
【水中物質の大きさと分離技術の対応関係】
 粒子径 (m)   10⁻³(mm)   10⁻⁶(μm)   10⁻⁸(10nm)   10⁻⁹(1nm)   10⁻¹⁰(Å)
              ───────┬──────────┬──────────┬──────────┬─────────
 物質分類     粗大浮遊物 │ 微細懸濁質 │ コロイド │ 高分子有機物│ 低分子・イオン
              (シルト・砂)│(粘土・細菌)│(ウイルス)│(フミン酸)  │(塩分・金属)
              ───────┼──────────┼──────────┼──────────┼─────────
 分離技術     普通沈殿   │ 凝集沈殿 │ 凝集ろ過 │限外ろ過(UF)│逆浸透(RO)
              沈砂池     │ 急速ろ過 │ 膜ろ過(MF)│活性炭吸着 │オゾン酸化
                         │ 緩速ろ過 │          │生物活性炭 │イオン交換
```

* **コロイド領域（$10^{-9} \sim 10^{-6}\,\text{m}$ / 約 $1\,\text{nm} \sim 1\,\mu\text{m}$）**:
  * 水中で負の静電気（ゼータ電位）を帯びて互いに反発し合っているため、**自然放置しても永久に沈殿しない**。
  * このコロイド粒子を沈殿・ろ過可能にするためには、アルミニウム塩等の凝集剤を添加して**表面電荷を中和（荷電中和）し、フロック（巨大な綿状の塊）を形成**させる必要がある。
* **溶解性物質（$10\,\text{nm}$ 以下・低分子物質）**:
  * 水分子と同等に振る舞うため、通常の砂ろ過では物理的に通過してしまう。オゾンによる化学的酸化分解や、活性炭の微細孔による物理吸着が不可欠となる。

## 3. 代表的な4大浄水処理方式の構造と特性（テキスト p.355〜358）

### (1) 消毒のみの方式（テキスト p.355）
* **適用条件**:
  * 年間を通じて水質が極めて良好かつ安定している深井戸水、被圧地下水等を水源とする場合にのみ採用される。
* **長所**:
  * ろ過池や沈殿池が不要であり、水処理プロセスが最も単純で建設費・維持管理費が極小。
  * 汚泥が発生しないため、**排水処理設備（排泥池・脱水機等）が一切不要**。
* **重大な制約（不適用条件）**:
  * **クリプトスポリジウム等の病原原虫に汚染されるおそれがある水源では、絶対に採用してはならない**。
* **採用するための厳格な2大要件（出題最頻出）**:
  1. 水源の集水域・上流域または周辺に、**し尿処理施設、下水処理場、家畜糞尿処理施設などの排出汚染源が存在しないこと**。
  2. 水道原水から、**大腸菌および指標菌（嫌気性芽胞菌・大腸菌群等）が一切検出されないこと**。

### (2) クリプトスポリジウムの特徴と対策基準（テキスト p.355）

#### ① 病原原虫の生態と過去の被害事例
* **病原体**: 単細胞の寄生性原虫（*Cryptosporidium*）。直径約 $4 \sim 6\,\mu\text{m}$ の強固な殻（オーシスト）に包まれて外界に存在する。
* **病態**: 経口摂取されると小腸の上皮細胞に寄生・増殖し、**激しい水様性下痢、腹痛、発熱、脱水症状**を引き起こす。免疫不全者では重症化・致命的となる。
* **平成8年（1996年）埼玉県越生町集団感染事故**:
  * 町営水道の深井戸水（消毒のみの方式）がクリプトスポリジウムに汚染され、**町民の約7割（約8,800人）が集団発症**した近代水道史上最悪の生物テロ的事故。
* **決定的な特徴（★最重要）**:
  * **塩素消毒耐性**: 厚いオーシスト壁を持つため、**通常の水道用塩素消毒（遊離残留塩素 $0.1 \sim 1.0\,\text{mg/L}$ 程度）では全く死滅・不活化できない**。
  * **水質基準外項目**: 生物学的同定・測定が困難なため「水質基準（51項目）」には含まれず、厚生労働省（現・国交省/環境省）の「暫定対策指針」に基づき管理される。

#### ② クリプトスポリジウム対策指針の構造要件（★試験必出）
水道原水がクリプトスポリジウムに汚染されるおそれがある場合、水道事業者は以下のいずれかの設備を整備・運用しなければならない。

```
【クリプトスポリジウムの2大対策基準】
┌────────────────────────────────────────────────────────┐
│ ① ろ過設備の濁度管理基準                               │
│    急速ろ過、緩速ろ過、膜ろ過の各ろ過池出口において、   │
│    濁度を常時「0.1度以下」に維持・管理できる設備を有すること。│
└────────────────────────────────────────────────────────┘
                           または
┌────────────────────────────────────────────────────────┐
│ ② 紫外線処理設備（UV照射）の導入                       │
│    クリプトスポリジウム等の原虫を「99.9%以上」不活化できる│
│    紫外線照射設備を設置すること（地下水等で濁度管理困難な場合等）│
└────────────────────────────────────────────────────────┘
```

#### ③ リスクレベル分類（レベル1〜4）
* **レベル4・3（表流水など、汚染リスク高・中）**: 適切な頻度で原水中のクリプトスポリジウム等原虫および指標菌の定期検査を実施し、ろ過出口濁度0.1度以下を厳格管理。
* **レベル2（地下水等、当面汚染可能性が低い）**: 3ヶ月に1回以上の指標菌検査を実施。
* **レベル1（汚染可能性が極めて低い深井戸）**: 年1回以上の大腸菌等検査、3年に1回以上の井戸内部・ストレーナーの健全度点検を実施。

### (3) 緩速ろ過方式（テキスト p.356）
* **原理とメカニズム**:
  * 原水を凝集剤を用いずに、細かなろ砂層に極めてゆっくりと通過させる方式。
  * 砂層の表面数ミリ〜数センチに形成される**「生物ろ過膜（シュムツデッケ：藻類、原生動物、細菌類の共生体膜）」**の働きにより、浮遊物質を物理的に捕捉するとともに、**溶解性有機物質を微生物の代謝によって酸化・分解・資化**する。
* **標準ろ過速度**: **$4 \sim 5\,\text{m/日}$**（急速ろ過の約30分の1の極低速）。
* **適用条件**: 原水水質が年間を通じて良好で、**濁度が低く（平常時10度以下、最大でも20〜30度程度）安定している水源**に限定される。
* **長所**:
  * 凝集剤などの薬品を使用しないため、薬品費がかからず運転が極めて自然で安全。
  * 細菌、浮遊物質のほか、**アンモニア態窒素、微量の異臭味物質、マンガン、フェノール類、陰イオン界面活性剤**を生物分解・除去できる。
* **短所と弱点（★頻出）**:
  * **フミン質（植物遺骸が分解した腐植物質）由来の色度は除去しにくい**（残存すると後段の塩素消毒で発がん性トリハロメタンを生成する原因となる）。
  * ろ過速度が遅いため、**急速ろ過の約30倍という広大な敷地面積**が必要。
  * 目詰まり時の再生において、逆洗浄ができず、**砂層表面を数センチ削り取る「削開（削り取り）作業」と砂洗浄・補充に多大な人力と労力を要する**。高濁度水が流入すると即座に目詰まりを起こす。

---

### (4) 急速ろ過方式（テキスト p.356〜357）
* **原理とシステム構成**:
  * 緩速ろ過では対応できない高濁度原水、水質変動の激しい河川水、敷地制約のある大都市に適用される。
  * **「着水井 $\rightarrow$ 薬品混和池（混和池） $\rightarrow$ フロック形成池（凝集池） $\rightarrow$ 薬品沈殿池 $\rightarrow$ 急速ろ過池」** の一連のプロセスから成る。
* **標準ろ過速度**: **$120 \sim 150\,\text{m/日}$**（緩速ろ過の約30倍の高速流動）。
* **ろ過材**: 緩速ろ過よりも粗い粒径のケイ砂（有効径 $0.45 \sim 0.7\,\text{mm}$ 程度）やアンスラサイト（無煙炭塊）を用いた複層ろ過。
* **凝集メカニズムと前処理の重要性（★最重要）**:
  * 硫酸アルミニウム（硫酸バンド）や**ポリ塩化アルミニウム（PAC）**を注入し、原水中の懸濁粒子・コロイドを直径数ミリの「フロック」に成長させて沈殿池で粗分離する。
  * **前処理（凝集・沈殿）の良否が急速ろ過全体の成否を完全に決定づける**。凝集剤の注入率が過小でも過大でもフロックが形成されず、ろ過池に過剰な濁質が流出して閉塞やブレークスルー（濁質漏出）を引き起こす。
  * 適正な薬品注入率を決定するため、**毎日・水質変動ごとに「ジャーテスト（Jar Test）」を実施することが運転管理の基本**である。
* **急速ろ過池の洗浄**:
  * 砂を削り取るのではなく、ろ過水を逆流させる**「逆洗浄（水逆洗＋空気逆洗）」**により、砂層を流動・膨張させて付着濁質を短時間（数分〜十数分）で洗い流す。
* **変法**:
  * **直接ろ過法（マイクロフロック法）**: 低濁度・低水温期に、フロックを大きく成長させずに沈殿池を経由せず、混和池から直接急速ろ過池へ通水して砂層内で捕捉する省スペース方式。
  * **高速凝集沈殿池**: スラッジブランケット（汚泥毛布層）や傾斜板・傾斜管を用いて、上昇流速を高めて設置面積を縮小した沈殿池。

---

### (5) 膜ろ過方式（テキスト p.358）
* **原理**:
  * 砂層の代わりに高分子膜（中空糸膜・平膜等）を用い、膜の微細孔によって水中の懸濁物・病原微生物を**物理的にふるい分け（膜分離）**する方式。
* **膜の分類と阻止対象**:
  * **精密ろ過膜（MF膜）**: 孔径 約 $0.1 \sim 1\,\mu\text{m}$。クリプトスポリジウム、細菌、微粒子を阻止。
  * **限外ろ過膜（UF膜）**: 孔径 約 $0.001 \sim 0.05\,\mu\text{m}$（分画分子量数千〜数十万）。ウイルス、高分子コロイドを阻止。
  * **ナノろ過膜（NF膜）**: 2価イオン、硬度成分、農薬、着色物質を阻止。
  * **逆浸透膜（RO膜）**: 塩分（NaCl）、重金属、全溶解物質を阻止（海水淡水化の主流）。
* **長所**:
  * クリプトスポリジウム等の病原微生物を完全かつ確実に物理排除できる（安全性が極めて高い）。
  * 機器点数・可動部が少なく、**自動化・遠隔監視制御（SCADA）が極めて容易**。
  * 施設が極めてコンパクトであり、山間部や島しょ部などの**小規模無人化施設**に最適。
* **短所**:
  * 膜表面の目詰まり（ファウリング）が発生するため、**定期的な逆圧洗浄および次亜塩素酸・クエン酸等による薬品洗浄**が不可欠。
  * 膜モジュールには寿命（数年〜十数年）があり、定期的な**高額の膜交換費用**が発生する。
  * 膜を透過してしまう溶解性物質（異臭味、溶解性鉄・マンガン等）は除去できないため、前処理（凝集・粉末活性炭等）や後処理が必要。

## 4. 高度浄水処理と個別物質対応（テキスト p.359）

### (1) 高度浄水処理の定義と導入目的
通常処理（凝集沈殿・急速砂ろ過）では十分に除去できない、水中の微量有害物質、異臭味原因物質、トリハロメタン前駆物質等を、物理化学的または生物学的手法を付加して高度に除去する処理方式である。

```
【高度浄水処理の主要プロセス】
［急速沈殿水］ ──→ ［オゾン接触池］ ──→ ［生物活性炭吸着池（BAC）］ ──→ ［急速ろ過池］
                   ・強力な酸化分解       ・物理吸着（細孔）
                   ・難分解物質の易分解化  ・付着微生物による生分解
```

### (2) 主な除去対象物質と処理技術
1. **カビ臭（異臭味物質）**:
   * 富栄養化したダムや湖沼で藍藻類（アナベナ、ミクロキスティス等）や放線菌が産生する**ジェオスミン（Geosmin）**や**2-メチルイソボルネオール（2-MIB）**。
   * **対策**: **オゾン処理＋粒状/生物活性炭（BAC）**、または突発時には着水井等への**粉末活性炭（PACn）注入**。
2. **トリハロメタン前駆物質（フミン質等）**:
   * 塩素消毒時に塩素と反応してクロロホルム等の発がん性物質（総トリハロメタン THMs）を生成する溶存有機物（前駆物質）。
   * **対策**: オゾンによる高分子有機物の酸化開環・低分子化 ＋ 生物活性炭による吸着・生物分解。
3. **鉄・マンガン**:
   * 嫌気性の地下水やダム底部から溶出する溶解性の2価の鉄（$\text{Fe}^{2+}$）およびマンガン（$\text{Mn}^{2+}$）。水道水の赤水・黒水障害を引き起こす。
   * **対策**: **前塩素処理**または**接触ばっ気（エアレーション）**により酸化不溶化して沈殿除去、あるいは**マンガン砂ろ過池**（二酸化マンガンの接触触媒作用）での酸化捕捉。
4. **遊離炭酸（腐食性二酸化炭素）**:
   * 金属管路を腐食させる遊離炭酸に対し、**エアレーション（曝気）**を行って大気中へ放散させ、pHを中性側に回復させる。
5. **PFAS（有機フッ素化合物：PFOS / PFOA）**:
   * 難分解性で環境残留性が高い有害化学物質。水質管理目標設定項目（合算 $50\,\text{ng/L}$ 以下）から基準化への移行が進む。
   * **対策**: **粒状活性炭（GAC）**や**粉末活性炭（PACn）**による吸着処理、または**イオン交換樹脂**の導入検討。

---

## 5. 塩素消毒の原理と法定基準（テキスト p.360）

### (1) 塩素消毒が義務付けられている2大根本理由
水道法第22条に基づき、いかなる浄水方式を採用する場合であっても、水道水は必ず塩素消毒を行わなければならない。その理由は以下の2点に集約される。
1. **残存病原微生物の完全死滅**:
   * 沈殿や砂ろ過プロセスを経ても、水中に残存する微細な病原細菌（コレラ菌、チフス菌、赤痢菌等）やウイルスを完全・確実に死滅（不活化）させるため。
2. **送配水管網内での「残留効果（自衛力・二次汚染防止）」**:
   * 浄水場を出た水が長い配水管を通り家庭の蛇口に届くまでの間に、管の継手からの地下水浸入、負圧による逆流、貯水槽内の汚染等のリスクが存在する。
   * 水そのものに殺菌力（残留塩素）を持たせておくことで、**管網内での細菌の再増殖や二次汚染をリアルタイムで防除・自衛**させるため。

---

### (2) 法定残留塩素濃度の基準値（水道法施行規則第17条第1項第3号）
試験において極めて頻出する絶対的暗記数値である。

```
【給水栓（蛇口）における残留塩素の法定基準値】
┌─────────────────────────────────┬───────────────────┬───────────────────┐
│ 区分                            │ 遊離残留塩素      │ 結合残留塩素      │
├─────────────────────────────────┼───────────────────┼───────────────────┤
│ ① 通常時（平常時）             │ 0.1 mg/L 以上     │ 0.4 mg/L 以上     │
│ ② 感染症流行時・断水復旧時等   │ 0.2 mg/L 以上     │ 1.5 mg/L 以上     │
│    （病原菌汚染のおそれがある時）│                   │                   │
└─────────────────────────────────┴───────────────────┴───────────────────┘
```
* ※「おいしい水」の観点から設定されている水質管理目標設定項目では、残留塩素の上限目標値として **$1.0\,\text{mg/L}$ 以下** が推奨されている。

```
・総残留塩素（Total Residual Chlorine） ＝ 遊離残留塩素 ＋ 結合残留塩素
```

```

┌──────────────┬────────────────────────────────┬────────────────────────────────┐

├──────────────┼────────────────────────────────┼────────────────────────────────┤

├──────────────┼────────────────────────────────┼────────────────────────────────┤

├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 水道実務     │ 一般に「残塩」といえば遊離型を指す│ 配水管路が極端に長い場合等に活用│
└──────────────┴────────────────────────────────┴────────────────────────────────┘
```

## 6. 排水処理設備と環境・公害法規（テキスト p.360〜361）

### (1) 浄水排水処理の必要性
浄水場では、原水から分離された濁質が「排泥水（沈殿池底部から引き抜かれる泥水）」および「ろ過池逆洗浄排水」として大量に発生する。これらを無処理で近隣河川等へ放流すると、水域の白濁や生態系破壊を招くため、適切な濃縮・脱水・回収処理を行わなければならない。

```
【浄水排水処理フロー】
［沈殿池排泥・逆洗水］ ──→ ［排水池・排泥池］ ──→ ［排泥濃縮槽］ ──→ ［天日乾燥床 or 機械脱水機］ ──→ ［脱水ケーキ（浄水発生土）］
                                                │
                                                └── 上澄水回収 ──→ ［着水井へ返送（クローズドシステム）］
```

---

### (2) 関連法令と適用規模（★試験頻出）

#### ① 水質汚濁防止法（公害防止）
* **特定施設の指定**:
  * **浄水能力が「$10{,}000\,\text{m}^3/\text{日}$ 以上」の浄水施設**（沈殿施設、ろ過施設等）は、水質汚濁防止法上の**「特定施設」**に指定されている。
* **規制内容**:
  * 特定施設を設置する浄水場から公共用水域へ排出される排水（上澄水等）には、国の排水基準（pH、SS［浮遊物質量］、BOD/COD、濁度等）および都道府県の上乗せ基準が直接適用され、違反には直罰規定が及ぶ。

#### ② 廃棄物の処理及び清掃に関する法律（廃棄物処理法）
* **産業廃棄物処理施設の指定**:
  * 汚泥処理施設のうち、**脱水能力が「$10\,\text{m}^3/\text{日}$ を超える」脱水施設**（加圧脱水機、遠心脱水機等）は、法に基づく**「産業廃棄物処理施設」**に該当する。
* **浄水発生土の法的性質**:
  * 脱水処理によって排出される脱水ケーキ（浄水スラッジ）は、法律上の**「産業廃棄物（無機性汚泥）」**に該当する。
  * マニフェスト（産業廃棄物管理票）の交付・管理、法に基づいた適正な最終処分（埋立処分）またはリサイクルが義務付けられている。
  * 近年は資源循環の観点から、園芸用土、グラウンド土、セメント原料、道路路盤材・盛土材としての有効利用が積極的に推進されている。

## 7. 浄水システム全体の運転管理・安全・省エネルギー（テキスト p.361〜364）

### (1) システム全体の有機的一体性とボトルネック解消
* **全体調和の原則**:
  * 浄水場は、着水井から薬品混和・凝集・沈殿・ろ過・消毒・浄水池に至る一連の単位プロセスが連動する「一つの統合システム」である。
  * どれか一つのプロセスが突出していても、**どこか一箇所にボトルネック（能力不足や機能不全）が存在すれば、浄水場全体の給水信頼性が決定的に損なわれる**。
* **耐震性・機能診断**:
  * 単位プロセス間の連絡管渠、受変電設備、非常用自家発電機を含め、施設全体として大規模地震（レベル2地震動）に耐えうる耐震性能と危機耐性を備えているかを総合診断しなければならない。

---

### (2) 安全工学設計：フェールセーフとフールプルーフ（★最重要概念）
水道の自動化・遠隔制御システムにおいて、事故や人的ミスを未然に防ぐため、以下の2大設計思想が組み込まれている。

### (3) 省エネルギー化とコスト縮減
* **水道における電力消費実態**:
  * 水道事業は**日本全国の総電力消費量の約 0.9% 弱**を消費する巨大なエネルギー多消費インフラである。
  * そのうち、**送配水ポンプの消費電力が全体の約 6割**を占めている。
* **具体的省エネ・脱炭素施策**:
  1. **自然流下の最大活用**: 高低差を利用し、ポンプ動力に頼らない水運用設計。
  2. **高効率ポンプの導入**: 更新時期を捉えたインバータ制御・省エネ型高効率ポンプへの更新。
  3. **水圧の適正管理**: 送配水圧力を必要最小限に制御し、余剰揚程・電力ロスを削減。
  4. **排水リサイクル（クローズドシステム）**: ろ過池逆洗排水の上澄水を着水井へ返送・再処理し、水源原水費を削減。

---

### (4) 予備力（冗長性・レジリエンス）の確保
* **施設能力の系列化（複数系列化）**:
  * 計画一日最大浄水量を処理する際、1系列のみの単一構造にせず、原則として**2系列以上に分割**する。1系列が点検・清掃・改修・突発事故で停止しても、残る系列で一定の給水能力を維持できるようにする。
* **予備機の日常運転（ローテーション稼働）**:
  * 予備のポンプや薬品注入機を「故障時用として長期間放置」してはならない。いざという時の固着や起動不能を防ぐため、**日常的に常用機と予備機をローテーション運転**させ、常に即応可能な状態を確認しておく。
* **水系間連絡管（浄水場間ネットワーク）**:
  * 複数の浄水場を有する事業体では、相互に送水連絡管を整備し、一方の浄水場が被災・水質事故で停止した場合でも他水系から融通送水できる広域的予備力を確保する。

---

### (5) 浄水施設の総合的・科学的管理
* **経験と勘からの脱却**:
  * 熟練職員の「勘や経験」にのみ依存した運転管理から、**水質オンライン計器（濁度計、残留塩素計、アルカリ度計等）のデータに基づく科学的・定量的管理**への移行が必須である。
* **標準化とPDCAサイクル**:
  * ジャーテストによる薬品注入率の決定手順、異常水質発生時の初動マニュアルを標準化し、実績データを検証・フィードバックして運転管理手順を継続的に見直す。

### 設問1（4択：水道技術管理者の法定責務）
* **問題形式**: `choice`
* **問題文**: 水道法第19条第2項等に規定されている「水道技術管理者の責務および権限」に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 水質汚染等により供給水が人の健康を害するおそれがあるときは、技術管理者の責任と判断において直ちに給水を緊急停止しなければならない
  2. 浄水場で直接水を取り扱う業務に従事する職員に対する定期検便等の健康診断は、水道事業者の任意業務であり法定責務ではない
  3. 水道施設の技術的基準への適合検査は、都道府県知事が行うものであり水道技術管理者の監督職務には含まれない
  4. 施設の新設や増設工事が完了した際、緊急時であれば給水開始前の水質検査および施設検査を省略して通水できる
* **正解**: 1（インデックス: 0）
* **解説**: 水道技術管理者は、水道法第23条に基づき、供給水が人の健康を害するおそれがある場合は、自らの判断で直ちに給水を緊急停止する重大な権限と義務を有します。従事者の健康診断（法第21条、概ね6ヶ月ごとの検便等）、施設基準適合検査（法第5条・第19条第2項）、給水開始前の検査（法第13条）はいずれも水道法に定められた厳格な法定職務であり、省略や任意化は認められません。
* **日常のたとえ**: 飲食店の衛生責任者が、食材に毒物混入の疑いがある際に経営者の指示を待たずに即座に料理の提供をストップするのと同様の、絶対的な安全ブレーキ権限です。
* **出典**: 水道法 第19条第2項、第21条、第23条／講義テキスト p.351

### 設問4（4択：塩素消毒の法的基準と化学的特性）
* **問題形式**: `choice`
* **問題文**: 水道水の塩素消毒および残留塩素に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 水道法施行規則により、給水栓（蛇口）における遊離残留塩素濃度は平常時において 0.1 mg/L 以上 保持することが義務付けられている
  2. 結合残留塩素は遊離残留塩素に比べて酸化力・殺菌力が数十倍強力であり、水質汚染時に即効性の高い消毒効果を発揮する
  3. 病原菌による汚染のおそれがある異常時であっても、給水栓における残留塩素基準値は平常時と同一である
  4. 浄水場を出た水道水は配水管内で再汚染される可能性が一切ないため、末端給水栓での残留塩素保持は不要である
* **正解**: 1（インデックス: 0）
* **解説**: 水道法施行規則第17条に基づき、給水栓において遊離残留塩素 0.1 mg/L 以上（結合残留塩素の場合は 0.4 mg/L 以上）を保持しなければなりません。病原菌汚染のおそれがある場合は遊離 0.2 mg/L 以上（結合 1.5 mg/L 以上）へと引き上げられます。結合残留塩素（クロラミン）は遊離型に比べて殺菌力は緩やかですが残留性が高い特徴を持ちます。残留塩素の保持は管網内での二次汚染防止に不可欠です。
* **出典**: 水道法施行規則 第17条／講義テキスト p.360

### 設問5（4択：浄水場の安全工学設計と運転管理）
* **問題形式**: `choice`
* **問題文**: 浄水施設の運転管理および安全工学設計に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 計測器の故障や停電時にシステムが自動的に安全側（遮断・停止等）へ動作する設計思想を「フェールセーフ」と呼ぶ
  2. 運転員の誤操作を防ぐために注入口の形状を物理的に変える工夫は「フェールセーフ」の代表例である
  3. 浄水場の予備機（ポンプ等）は機器寿命を延ばすため、常用機が故障するまで一切通電・運転させてはならない
  4. 水道事業における電力消費量は極めて小さく、その中でも送配水ポンプが占める割合は全体の1割未満である
* **正解**: 1（インデックス: 0）
* **解説**: 計測器の故障や停電時に自動的に安全側に作動する設計は「フェールセーフ（Fail-Safe）」です。人間の誤操作による事故を防ぐ物理的工夫（注入口形状変更やインターロック等）は「フールプルーフ（Fool-Proof）」と呼びます。予備機はいざという時の起動不能を防ぐため日常的に常用機と「ローテーション運転」を行う必要があります。水道は国内電力の約0.9%弱を消費し、送配水ポンプがその約6割を占めています。
* **出典**: 講義テキスト 浄水施設 p.361〜364
