## 1. 水管橋・橋梁添架管の維持管理と事故事例（テキスト p.307）

地上空間（河川上空や道路上空）に架設される水管橋および橋梁添架管は、埋設管と異なり直接外気や外力に晒されるため、特有の維持管理上の課題と脆弱性を抱えている。

### (1) 点検・維持管理の難しさと劣化要因

```
【水管橋・添架管を取り巻く3大過酷環境】
① 絶え間ない振動 ──── 車両通行、鉄道振動、強風による風圧振動。
② 激しい「結露」 ──── 管内の冷たい水道水（10〜15℃）と夏場の高温多湿外気による結露水滴。
③ 塩害・紫外線 ───── 海風・潮風による腐食、強烈な直射日光による塗膜劣化。
```

* **点検手法の制約**:
  * 河川や谷、高速道路の上空に位置するため、日常の地上巡視では下流側や桁下の目視が困難である。
  * **船上調査、高所作業車、ドローン（UAV）を活用した近接目視点検** など、計画的かつ専門的な点検手法を講じる必要がある。
* **激しい「結露」による腐食進行**:
  * 地中から送られてくる水道水は夏場でも冷たく、外気温との間に大きな温度差が生じる。
  * このため、**管体表面や支持金具に年間を通じて大量の結露水滴が付着** し続け、塗装の剥離部から急速に赤錆が進行する。
* **塗替え・補修の遅延課題**:
  * 塗装の耐用年数は通常10年前後であるが、河川管理者や道路管理者・警察署との長期協議、高額な足場設置費用、交通規制の制約から、塗り替えが後手に回りがちである。
  * 漏水箇所に「漏水補修クランプ（バンド）」を巻き付けたまま長期間放置されている事例も散見される。

### (2) 2021年 和歌山市・六十谷（むそた）水管橋崩落事故の教訓

2021（令和3）年10月、和歌山市を流れる紀の川を横断する水管橋が突如崩落し、全国に衝撃を与えた。

```
【六十谷水管橋事故の概要】
・施設概要: 紀の川横断、口径 φ900mm、ランガー形式（アーチ補強型）水管橋（昭和50年築造）
・被害規模: 市北部約6万世帯（約13万8千人：市全体の約4割）で約1週間にわたり全面断水！
・応急復旧: 隣接する県道道路橋の路面に仮設ポリエチレン管を「転がし配管」して仮通水。
```

* **直接の事故原因（吊り材の腐食破断）**:
  * アーチリブから管体を吊り下げて支えていた **「鋼製吊り材（斜材・鉛直材）」が長年の腐食により著しく減肉・破断** した。
  * 過去の目視点検で腐食自体は記録されていたものの、「直ちに落橋には至らない」と判断され、**適切な錆落とし・再塗装や部材交換が行われないまま放置** された結果、自重と水重量を支えきれずにドミノ倒し的に崩落した。
* **事故後の水道界への影響と改善**:
  * **国の点検ガイドライン抜本改定**: 厚生労働省（現・国土交通省）は全国の水道事業体に対し、水管橋の緊急点検と吊り材等の重要部材の近接目視点検を義務付けた。
  * **「いずれ更新する」という先送り意識の排除**:
    * 東京都水道局でも、将来的な道路橋架替え時に地中化（シールドによる下越し）を計画している路線について、「いずれ撤去するから」と現況水管橋の塗装補修を後回しにしていた事例が反省点として共有された。
    * 地中化が完了して廃止される最後の日まで、水管橋の構造健全性を確実に維持する補修計画が再徹底された。

## 2. 水運用と配水調整（テキスト p.309〜310）

水道システムを安全かつ経済的に稼働させるため、「広域の水運用」と「現場の配水調整」が役割分担して行われている。

```
【「水運用」と「配水調整」の明確な役割分担】
[上流：水源・浄水場] ─────(水運用：広域・上流〜中流)─────→ [中流：給水所・配水池]
                                                               │
                                                               ▼ (配水調整：地域・末端)
                                                    [下流：配水本管・支管・蛇口]
```

### (1) 定義と業務内容の違い

| 区分 | 管理範囲・主な対象施設 | 業務内容・運用目的 |
| :--- | :--- | :--- |
| **水運用**<br>（広域・上流） | ・取水施設、導水路、浄水場<br>・送水管、給水所（配水池） | ・河川からの取水量、浄水場の日量造水量の決定。<br>・各給水所への送水量および配水池水位のコントロール。<br>・**全事業体規模でのエネルギー効率最大化と水系間融通**。 |
| **配水調整**<br>（現場・末端） | ・給水所出口ポンプ、配水本管<br>・配水支管、減圧弁、仕切弁網 | ・給水区域内の末端需要者に対し、**適正な水量・動水圧（0.15〜0.74MPa）を過不足なく安定供給** する。<br>・仕切弁開度調整、管網切り替え、赤水発生防止。 |

---

### (2) 水運用の基本原則（テキスト p.309）

1. **施設総合能力の最適化**: 取水・導水・浄水・送水施設の各能力を総合的に勘案し、最も電力コストの低い運転パターンを組む。
2. **位置エネルギー（自然流下）の最優先活用**: 高低差を利用してポンプ加圧を極力減らし、CO2排出量と電気代を削減する。
3. **良質水源の優先使用**: 水質の良好な原水を優先的に取り入れることで、浄水場における凝集剤（PAC）や塩素等の薬品注入コストおよび環境負荷を低減する。
4. **水系間連絡施設（ネットワーク）の活用**: 複数水系を有する大都市では、水系間原水連絡管や送水連絡管を活用し、特定水系の渇水や水質事故に際して迅速にバックアップ相互融通を行う。

---

### (3) 配水調整の手段と配水ブロック化（テキスト p.309〜310）

給水区域内の動水圧は、法令基準（**最低 $0.15\,\text{MPa}$ 〜 最大 $0.74\,\text{MPa}$**）を常時死守しなければならない。

#### ① 配水調整の3大手段
1. **バルブ操作による調整**:
   * 制御弁や仕切弁を中間開度で絞る。
   * ※**実務上の厳重注意**: 夜間の低需要時に水圧が上がったからといって弁を絞りすぎると、**翌朝のピーク時に下流で急激な水圧不足を招いたり、流速急変によって管内の錆コブが剥離して大規模な濁水（赤水）事故を引き起こす**。弁操作後は必ず翌日のピーク水圧を追跡確認する。
2. **管網整備による調整**:
   * 通水能力の不足している配水支管を増径（口径拡大）するか、行き止まり管を環状化（ループ化）して水理抵抗を低減する。
3. **機器による調整**:
   * 高台への「増圧ポンプ」設置、低地部への「減圧弁」設置。

#### ② 配水区域のブロック化（ブロックシステム）
* 地形（高低差）や行政界に合わせて配水管網を適正規模のブロックに分割・独立運用する。
* **メリット**:
  * ブロック内の標高が揃うため水圧が均一化し、無駄な高水圧による漏水を削減できる。
  * ブロックごとの夜間最小流量測定により漏水箇所の絞り込みが容易。
  * 事故・濁水発生時にバルブ遮断で影響をブロック内に封じ込め（隔離）できる。
* **運用の実情（見直し議論）**:
  * 過度にブロックを小さく細分化しすぎると、日常工事の断水調整や他ブロックからの緊急融通バルブ操作が極めて煩雑化し、管網の柔軟性が損なわれる。そのため、幹線レベルで相互補完できる適正規模への再編・見直しも進められている。

## 3. 出水不良の原因と対策（テキスト p.311）

### (1) 増圧ポンプの設置（★最重要ポイント・出題最頻出）

テキスト311ページ上段「（4）出水不良の対策」の記述は、水道技術管理者試験において極めて頻出の最重要マーカー箇所である。

> **★最重要ポイント（テキスト p.311：マーカー箇所）**
> **「広範囲に設定した配水区域の末端部や、高台の地域などにおける水圧低下による出水不良に対しては、管路の途中に『増圧ポンプ』を設置する。この場合、配水区域内の管本体や給水装置の耐圧性能を事前に確認する。」**
> ※「増圧ポンプ」という正式名称を確実に定着させる（減圧弁や空気弁との引っかけに注意）。

```
【末端・高台地域における増圧ポンプの役割】
[配水池] (自然流下) ───→ [平坦地需要家] (0.2〜0.3MPa：良好)
                             │
                             ▼ (水頭損失・高低差で水圧低下！)
                         [高台・遠隔末端部] (0.1MPa未満：出水不良！)
                             │
                      ┌──────┴──────┐
                      │  増圧ポンプ  │ ◄── 管路の途中に設置して水圧をブースト！
                      └──────┬──────┘
                             ▼
                         [高台地域需要家] (0.2MPa確保：安定給水！)
   ※注意：ポンプ直下流の管本体・給水器具が破損しないよう「耐圧性能」を事前確認！
```

* **出水不良の主因**:
  * 配水区域が広大で管路延長が長いために生じる「摩擦損失水頭の累積」。
  * 丘陵地や高台などの「地形的高低差（位置水頭の不足）」。
* **耐圧性能の事前確認義務**:
  * 増圧ポンプを運転すると、ポンプ下流側の水圧が強制的に跳ね上がる。
  * 既設の古い配水管や各家庭の給水用具（給湯器・電磁弁等）に老朽箇所があると、**急激な昇圧によって管破断や漏水・器具破損を引き起こす恐れがあるため、事前に耐圧性能（設計耐圧）を確認・点検することが必須要件** となる。

#### 【実務実例】高尾山（山岳地域）における多段増圧と多段減圧
* 東京都八王子市の高尾山（標高約 $600\,\text{m}$）山頂への給水では、麓から1台の超高圧ポンプで一気に圧送すると途中の管体が破壊するため、**「第1増圧ポンプ所 ➔ 第2増圧ポンプ所 ➔ 第3増圧ポンプ所」と3段階に分けて段階的にブースト揚水** し、山頂配水池へ貯水する。
* 山頂配水池から麓へ向かって自然流下で配水する際は、今度は下部で水圧が高くなりすぎてしまうため、**途中に「減圧弁」を多段配置して適正水圧に落としながら給水** している。

## 4. 金属管の腐食と防食対策（テキスト p.311）

地中に埋設された金属管（ダクタイル鋳鉄管、鋼管等）の劣化・漏水を引き起こす腐食機構は、大きく「電食」と「自然腐食」に分類される。

```
【地中金属管の腐食分類】
① 電食（電気腐食） ── 直流電化鉄道からの迷走電流（漏洩電流）による急速腐食。
② 自然腐食 ──── 土壌環境や金属間の電池作用による化学的・電気化学的腐食。
      ├─ ミクロセル腐食 ─ 酸性土壌、硫酸塩還元菌による局所微小電池。
      └─ マクロセル腐食 ─ 通気差腐食、異種金属接触腐食、コンクリート・土壌境界。
```

---

### (1) 電食（電気腐食）のメカニズム
* **直流電化鉄道（JR・私鉄・地下鉄等）のレールから地中へ漏れ出した「迷走電流」** が金属管に侵入する。
* 電流が管に入り込む箇所（カソード：陰極）では腐食は起きないが、**電流が管から再び土壌へ抜け出す箇所（アノード：陽極）において、金属（鉄）がイオンとなって激しく溶出（孔食・貫通）** する。
* **対策**: 排流器の設置、絶縁継手による迷走電流の流入遮断、非金属管（PE管等）の採用。

---

### (2) 自然腐食（ミクロセルとマクロセル）

#### ① ミクロセル腐食
* 土壌中の水分、溶存酸素、塩分、酸性度（pH）、あるいは湿地帯の **「硫酸塩還元バクテリア（嫌気性菌）」** などの作用により、金属表面に微小な陽極・陰極が無数に形成され、斑点状・均一に進行する腐食。

#### ② マクロセル腐食（巨視的な電池作用）
離れた2点間の電位差によって大きな腐食電流が流れる現象。

1. **通気差マクロセル腐食（異種土壌間）**:
   * 通気性が良く酸素の多い「砂質土（高電位）」と、通気性が悪く酸素の少ない「粘土層（低電位）」の境界において、**酸素の少ない粘土層側の管体がアノードとなって急速に腐食** する。
2. **コンクリート・土壌マクロセル腐食**:
   * 配水池のコンクリート壁体を貫通する管路において、高アルカリ環境のコンクリート内（高電位）と、地中の土壌環境（低電位）との間で巨大な電池が形成され、**壁から土中へ出た直後の管外面が激しく腐食** する。
   * **対策**: 鉄筋との完全絶縁、および **「外部電源法による電気防食装置」**（直流電源装置から逆向きの防食電流を流して腐食電流を相殺する。電極寿命は約30年）。
3. **異種金属接触腐食（ガルバニック腐食）**:
   * ステンレス鋼（貴な金属・高電位）とダクタイル鋳鉄や普通鋼（卑な金属・低電位）を水中で直接接続すると、電位の低い鉄側が激しく腐食・減肉する。
   * **対策**: 接合部に **絶縁フランジ、絶縁ボルト、絶縁パッキン（絶縁継手）** を介して電気的に完全に絶縁遮断する。

---

### (3) ポリエチレンスリーブ工法の実効性と寿命評価（東京都の事例）

* **工法**: ダクタイル鋳鉄管外面を厚さ約 $0.2\,\text{mm}$ のポリエチレン製フィルム筒で被覆し、土壌との接触を断つ。
* **実耐用年数への絶大な効果**:
  * 法定耐用年数は一律40年と定められているが、東京都水道局の劣化診断実績では、土壌とスリーブの有無で寿命に倍近い差が生じている。
  * **良好地盤（武蔵野台地）＋ スリーブ被覆あり**: **約 90 年** の供用に耐え得ると評価。
  * **腐食性地盤（東部沖積低地）＋ スリーブなし（裸管）**: **約 50 年** 程度で腐食限界に達する。
  * したがって、アセットマネジメントにおける管路更新優先度の決定において、**「ポリエチレンスリーブ施工履歴の有無」** が極めて重要な判定指標となっている。

## 5. 漏水事故と緊急出動・初期対応（テキスト p.312〜315）

### (1) 大規模漏水事故と道路陥没（環八平和台交差点事故の教訓）

平成17（2005）年、東京都練馬区の環状8号線（平和台交差点）において、昭和35年布設の旧規格普通鋳鉄管（口径 $\phi 600\,\text{mm}$）が破裂し、甚大な都市災害が発生した。

```
【環八平和台交差点漏水事故のメカニズム】
[昭和35年布設 普通鋳鉄管]（靭性がなく脆い旧管）
   │ 外面腐食や荷重で微小な小孔（ピンホール）が発生！
   ▼
[高圧水噴出] ──→ 周囲の路盤砂を巻き込んで激しく噴射！
   │              ➔ 「サンドブラスト現象」により管の破口が一気に拡大・脆性破断！
   ▼
[大量漏水噴出] ─→ 地下路盤土砂がすべて流失し、巨大空洞化！
   │
   ▼
【大規模道路陥没】 環八全面通行止め、電柱倒壊、近隣スーパー・民家への浸水大被害！
```

* **事故の教訓**:
  * 普通鋳鉄管は衝撃や曲げに極めて脆く、高圧漏水が土砂を巻き込む「サンドブラスト現象」で一気に大規模破断に至る。
  * 現在の球状黒鉛ダクタイル鋳鉄管（DIP）であれば高い靭性を持つため、このような脆性破断や瞬時の破口拡大は発生しない。
  * 幹線道路下に残存する旧規格管の早期更新・解消の重要性を全国に知らしめた事例である。

### (2) 突発事故に対する初動対応4原則（テキスト p.315）

漏水や管破裂事故は、夜間・休日を問わず突発的に発生する。初動の遅れは被害を幾何級数的に拡大させるため、以下の4原則に基づく迅速な対応が義務付けられている。

```
【突発事故初動対応の4ステップ】
① 現場確認・二次災害防止 ── 交通規制、道路陥没・感電・浸水の防止、安全確保。
② 断水作業（直近弁閉止） ── バルブを閉め漏水を遮断、断水区域を最小限に限定。
③ 重要施設への緊急配慮 ─── 人工透析病院、救急指定病院への給水車応急給水を最優先！
④ 緊急出動体制と広報 ──── 24時間動員体制、住民広報、事故マニュアルの習熟。
```

1. **現場確認と二次災害防止**:
   * 直ちに現場へ急行し、道路陥没の兆候がないか確認し、コーン等による通行止め・車線規制を実施。歩行者の転倒、感電、沿道家屋・地下街への浸水を防止する。
2. **断水作業（弁閉止）と影響の局所化**:
   * 直近の上流・下流仕切弁を閉止して漏水を遮断し、断水・濁水影響区域を最小限に封じ込める。
   * ※**現場実務の泥水対策**: 道路が冠水して弁筐の鉄蓋が見えない現場では、台帳の「オフセット寸法（境界・電柱からの距離）」をメジャーで測定し、バールや鉄棒で路面を突いて「カツン」という金属音を頼りに弁蓋を探し当てて開栓器で閉止する、高度な現場技術が求められる。
3. **重要施設への配慮と応急給水の最優先手配**:
   * **人工透析を行う医療機関、救急指定病院、高齢者施設など、断水が直接人命危機に直結する施設** の有無を即座に確認し、給水車による応急給水を直ちに手配する。
4. **緊急出動体制の整備と訓練**:
   * 平常時から「夜間休日出動動員計画」「広報連絡体制」「緊急復旧マニュアル」を整備し、定期的なバルブ操作・給水車出動の実動訓練を通じて現場即応力を維持する。

## 7. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：出水不良対策【最頻出】）
* **問題形式**: `choice`
* **問題文**: 配水区域の末端部や高台地域における水圧低下による出水不良対策として、最も適切なものはどれですか？
* **選択肢**:
  1. 管路の途中に増圧ポンプを設置し管本体等の耐圧性能を事前に確認する
  2. 末端部の配水管に大容量の急速空気弁を設置して水圧を自然昇圧させる
  3. 配水池の流出口に設置された緊急遮断弁を中間開度まで常時絞り込む
  4. 給水区域全体の配水支管に減圧弁を一律設置して高水圧を強制的に配分する
* **正解**: 1（インデックス: 0）
* **解説**: 配水区域末端や高台地域の水圧低下に対しては、管路途中に「増圧ポンプ」を設置して水圧を確保します。その際、昇圧によって管体や各家庭の給水用具が破損しないよう、事前に耐圧性能を確認することが必須です。
* **日常のたとえ**: 長いホースの先で水圧が落ちてチョロチョロしか出ないときに、途中に「押し込みブースター」を挟んで勢いを復活させる処置です。ただしホースが古くて破れないか（耐圧性能）を事前に確かめる必要があります。
* **出典**: 講義テキスト 導送配水施設 p.311

### 設問2（4択：水管橋の維持管理・事故教訓）
* **問題形式**: `choice`
* **問題文**: 水管橋の維持管理および2021年の和歌山市六十谷水管橋破損事故に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. アーチから管を支えていた鋼製吊り材の著しい腐食破断が崩落の主因となった
  2. 河川の記録的洪水により流木が管体に直撃したことが落橋の直接原因であった
  3. 水管橋は管内を冷水が流れるため結露が発生せず埋設管より錆びにくい特性を持つ
  4. 水管橋の日常点検は地上からの遠方目視のみで十分であり近接目視は不要である
* **正解**: 1（インデックス: 0）
* **解説**: 和歌山市の六十谷水管橋崩落事故は、アーチリブから管を吊り下げていた鋼製吊り材が長年の腐食により破断したことが原因でした。水管橋は管内の冷水と外気との温度差により激しい結露が生じるため極めて錆びやすく、ドローンや船上調査による近接目視点検が不可欠です。
* **出典**: 講義テキスト 導送配水施設 p.307

### 設問3（4択・否定形：水運用と配水調整）
* **問題形式**: `choice`
* **問題文**: 水道システムにおける水運用および配水調整に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 夜間低需要時の配水調整では水圧上昇を防ぐため仕切弁を極限まで絞り込む
  2. 水運用では可能な限り自然流下の位置エネルギーを活用してポンプ動力を抑える
  3. 配水調整では末端需要者に対し動水圧を0.15MPaから0.74MPaの範囲に維持する
  4. 配水区域のブロック化により水圧の均一化や漏水探知の効率化が図られる
* **正解**: 1（インデックス: 0）
* **解説**: 夜間に仕切弁を極端に絞りすぎると、翌朝のピーク需要時に急激な水圧不足を招いたり、流速急変によって管内の錆コブが剥離して大規模な赤水（濁水）事故を引き起こすリスクがあります。弁操作は翌日のピーク水圧を勘案して慎重に行う必要があります。
* **出典**: 講義テキスト 導送配水施設 p.309〜310

### 設問4（4択：金属管の防食対策）
* **問題形式**: `choice`
* **問題文**: 地中埋設金属管の腐食メカニズムおよび防食対策に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 直流電化鉄道の迷走電流が金属管から土壌へ流出する箇所で電食が発生する
  2. 異種土壌間では酸素の多い砂質土側の管体がアノードとなって急速に腐食する
  3. ステンレス鋼管とダクタイル鋳鉄管を接続する際は両管を直接ボルト接合する
  4. ポリエチレンスリーブ工法は管路の耐震継手の抜け出しを防止する工法である
* **正解**: 1（インデックス: 0）
* **解説**: 直流電化鉄道の迷走電流は、管から土壌へ流出する箇所（アノード）で金属がイオン化して激しい電食（電気腐食）を引き起こします。通気差腐食では酸素の「少ない」粘土層側が腐食し、ステンレスと鋳鉄の接続には「絶縁継手」が必須です。ポリエチレンスリーブは外面土壌腐食防止工法です。
* **日常のたとえ**: 電池から電気が流れ出していくプラス極の金属がどんどん溶けていくのと同じで、管から地面へ電気が飛び出すまさにその出口で金属が削り取られて穴が開きます。
* **出典**: 講義テキスト 導送配水施設 p.311

### 設問5（4択：漏水事故初動対応）
* **問題形式**: `choice`
* **問題文**: 道路下で突発的な管路破裂事故が発生した際の初動対応に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 人工透析医療機関等の断水が生命に直結する施設への給水車手配を最優先する
  2. 泥水で弁筐が見えない場合は水が自然に引くまで仕切弁の操作を待機する
  3. 復旧工事を迅速化するため道路の交通規制は行わずに掘削作業を開始する
  4. 管路破裂事故が発生した際は配水池出口の緊急遮断弁を手動で全開にする
* **正解**: 1（インデックス: 0）
* **解説**: 突発事故発生時は、二次災害防止の交通規制と直近弁の閉止による漏水遮断を行うとともに、人工透析病院や救急病院など生命に直結する重要施設への給水車による応急給水を最優先で手配します。泥水冠水時でも台帳のオフセット寸法等を頼りに弁を探し出して速やかに閉止操作を行います。
* **出典**: 講義テキスト 導送配水施設 p.315
