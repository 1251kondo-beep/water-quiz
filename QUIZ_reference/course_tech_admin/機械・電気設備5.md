## 1. 機械・電気設備の試験・測定体系と目的（テキスト p.556）

水道施設における機械・電気設備は、長期連続稼働に伴う経年劣化が不可避である。設備の信頼性、確実な制御・保護動作、耐力および安全性を保証するため、各種試験・測定が計画的に実施される。

```
【試験・測定の3大分類】
① 完成試験（竣工試験） ── 新設・改造・更新工事の完了時に仕様基準適合を確認
② 臨時試験 ────── 故障・事故発生時、または大規模修繕後に機能復旧を確認
③ 定期試験（保安試験） ── 法令および保安規程に基づき、一定周期で健全性を確認
```

## 2. 機械設備の試験・測定技術（テキスト p.556〜558）

機械設備の健全性を定量的に把握するための代表的な診断・測定技術を整理する。

```
【機械設備の主要測定技術】
① 振動測定 ────── ポンプ・電動機の振動値・周波数スペクトル解析
② 潤滑油・摩耗粉分析 ─ 油の劣化性状、金属摩耗粉による摺動部異常検知
③ 非破壊試験（NDT） ── 配管・タンク・圧力容器の非破壊きず検出（PT/UT）
④ 騒音測定 ────── 騒音規制法に基づく敷地境界での騒音レベル評価
⑤ 心出し測定 ───── ポンプ軸と電動機軸のアライメント（同軸度）調整
```

---

### (1) 振動測定（振動診断）
回転機械（送配水ポンプ、電動機、ブロワ等）の異常兆候を最も敏感に捉える診断技術。
* **簡易測定（振動スクリーニング）**:
  * 携帯型振動計（ポータブルペンスタイラス等）を用い、軸受箱の振動の全体値（オーバーオール値：変位、速度、加速度）を測定。
  * 低周波振動（アンバランス、ミスアライメント）や高周波振動（軸受微小傷）のしきい値超過を監視。
* **精密測定（FFT周波数分析）**:
  * 簡易測定で異常値が検出された場合、FFTアナライザーを用いて振動波形を周波数成分（スペクトル）に分解。
  * **回転一次成分（$1\times$）の増大**: 回転体のアンバランス（羽根車のアンバランス等）。
  * **回転二次成分（$2\times$）の増大**: 軸継手（カップリング）の芯狂い（ミスアライメント）。
  * **高周波特定周波数のピーク**: ベアリング（転がり軸受）の軌道輪や転動体の損傷・フレーキング。

---

### (2) 潤滑油検査および摩耗粉分析（トライボロジー診断）
ポンプや増減速機の軸受・歯車の摺動状態を油から診断する。
* **潤滑油性状検査**:
  * 動粘度、全酸価（酸化劣化の度合い）、水分混入率、スラッジ等の夾雑物を分析し、油の寿命・交換時期を判定。
* **摩耗粉分析（SOAP分析・フェログラフィ分析）**:
  * 潤滑油中に浮遊する微小な金属摩耗粉の「材質、大きさ、形状、発生量」を分析。
  * 軸受合金（ホワイトメタル、銅等）や鋼製歯車の異常摩耗の部位・進行度を、機器を分解することなく早期に特定する。

---

### (3) 非破壊試験（NDT: Non-Destructive Testing）
配管、貯蔵タンク、圧力容器等の母材や溶接部に対し、製品を破壊・損傷させることなく内部および表面の欠陥（きず・割れ・腐食減肉）を検出する。
* **浸透探傷試験（PT: Liquid Penetrant Testing）**:
  * 赤色浸透液と白色現像剤を用い、金属表面に開口した微細なクラック（割れ）を肉眼で視認可能にする（タンク溶接部等）。
* **超音波探傷試験（UT: Ultrasonic Testing）**:
  * 超音波パルスを入射し、内部反射波から内部欠陥や残存板厚（管体の腐食減肉）を高精度に測定。
* **放射線透過試験（RT） / 磁粉探傷試験（MT）**:
  * 溶接内部のブローホールや強磁性体表面直下の欠陥検出。

---

### (4) 騒音測定と心出し調整
* **騒音測定**:
  * 騒音規制法および地方自治体の公害防止条例の適用を受ける事業所において、敷地境界における騒音レベル（$\text{dB}$）を年数回定期測定し、法定基準適合を確認。
* **心出し測定（アライメント調整）**:
  * ポンプ軸と電動機軸を軸継手で直結する際、両軸の芯（中心線）のズレ（面振れ・偏心）をダイヤルゲージを用いて精密測定する。
  * 駆動軸を手動でゆっくり回転させながら、**$0^\circ$、$90^\circ$、$180^\circ$、$270^\circ$ の4位置**で測定値を読み取り、モーター脚部のライナー（シム）厚みを調整して許容公差内に収める。

## 3. 電気設備の試験・測定技術（テキスト p.558〜563）

電気設備の性能・絶縁状態・保護機能を担保するための主要試験を整理する。

```
【電気設備の主要測定技術】
① 絶縁抵抗測定 ────── メガテスターによる電路・機器の日常的絶縁良否判定
② 高圧精密絶縁診断 ──── 直流漏れ電流・誘電正接（tanδ）・部分放電試験
③ 絶縁耐力試験（耐電圧） ─ 規定高電圧印加による絶縁破壊防止確認（完成時等）
④ 絶縁油試験 ────── 油入変圧器の破壊電圧・全酸価・油中ガス分析
⑤ 保護継電器試験 ───── ★テストプラグ使用による継電器単体動作・整定確認
⑥ 接地抵抗測定 ────── A〜D種接地抵抗値の技術基準適合確認
⑦ シーケンス連動試験 ─── 保護・自動制御回路のインターロック連動確認
⑧ 温度上昇測定 ────── 赤外線サーモグラフィによる端子・母線の過熱検知
⑨ 絶縁用保護具定期検査 ── 労働安全衛生規則に基づく6ヶ月に1回の耐圧自主検査
```

---

### (1) 絶縁抵抗測定と精密絶縁診断
* **絶縁抵抗測定（メガ測定）**:
  * 直流高電圧（低圧電路：$500\text{ V}$、高圧電路：$1,000\text{ V}$ または $2,000\text{ V}$）を印加し、漏洩電流から絶縁抵抗値（$\text{M}\Omega$）を測定。
  * **時系列トレンド管理**: 測定結果をグラフ化し、湿度の影響を考慮しつつ経年的な低下傾向（劣化屈曲点）を捉える。
* **高圧精密絶縁診断（ケーブル・高圧回転機）**:
  * **直流漏れ電流試験**: 電圧昇圧に伴う漏れ電流の急増（キック現象）や不平衡度から絶縁劣化を検出。
  * **誘電正接試験（$\tan\delta$ 試験）**: 絶縁体に交流電圧を印加した際の誘電損角を測定し、絶縁体全体の吸湿・熱劣化度を判定。
  * **部分放電試験**: ボイド（微小空隙）内で発生する微弱なコロナ放電パルスを検出し、絶縁破壊の前兆を捕捉。

---

### (2) 絶縁耐力試験（耐電圧試験）
* **目的と実施時期**:
  * 新設・更新工事の完成時、または重要機器の大規模補修後に実施。
  * 電路や機器が、異常電圧（雷サージ、開閉サージ）に対して十分に耐えうる絶縁耐力を持つかを直接保証する試験。
* **試験方法**:
  * 対象電路に、電気設備技術基準で定められた試験電圧（例：最大使用電圧の1.5倍の交流電圧等）を**連続して10分間印加**し、絶縁破壊や異常発熱が生じないことを確認する。

---

### (3) 絶縁油試験（油入変圧器）
油入変圧器の絶縁油の劣化は、内部短絡・爆発事故に直結する。
* **絶縁破壊電圧試験**: 電極間に油を満たし、火花放電が生じる電圧を測定（絶縁耐力の評価）。
* **全酸価試験**: 油の酸化生成物（有機酸）の量を測定（油の劣化・スラッジ生成リスク評価）。
* **★ 油中溶存ガス分析（ガスクロマトグラフィー分析）**:
  * 変圧器内部で局所過熱や微小アーク放電が発生すると、周囲の絶縁油や絶縁紙が熱分解して**特定ガス（アセチレン $\text{C}_2\text{H}_2$、水素 $\text{H}_2$、メタン $\text{CH}_4$、エチレン $\text{C}_2\text{H}_4$、一酸化炭素 $\text{CO}$ 等）**が発生し油中に溶解する。
  * 油中に溶けた微量ガス成分の組成比を分析することで、**変圧器を解体することなく「内部の過熱、部分放電、アーク放電の有無と重大度」を精密診断**できる。

---

### (4) 保護継電器試験（★実務上の最重要留意点）
過電流継電器（OCR）、地絡継電器（GR）、不足電圧継電器（UVR）等の動作電流・動作時間を試験器を用いて測定する。

```
【保護継電器試験における重大事故防止手順】
［実稼働電路］ ── 遮断器（CB）
        │
      ［CT/VT］ ─── 信号線 ─── ［保護継電器］
                                     │
                     ★ テストプラグ挿入による回路切り離し！
                                     │
                               ［試験器接続］（模擬電流・電圧を注入）
```
* **★ テストプラグによる切り離し厳守（全所停電の防止）**:
  * 保護継電器の試験端子（テストブロック）に**テストプラグを挿入し、継電器を主回路（トリップ回路およびCT/VT二次回路）から完全に電気的に切り離した状態**で試験信号を入力しなければならない。
  * 切り離しを行わずに試験電流を流すと、**連動している主遮断器が実際にトリップし、受電が落ちて浄水場全体が全停電（点検誘発事故・波及事故）**となる。
  * 点検作業が重大事故を引き起こさないよう、作業手順の二重確認とインターロック管理を徹底する。

---

### (5) その他の重要電気試験・安全検査
* **漏電遮断器（ELCB）の動作試験**:
  * 低圧回路のELCBについて、**1年に1回以上、本体のテストボタンを押下**してトリップ機構が正常に作動することを確認。
* **シーケンス連動試験**:
  * 事故・停電を想定した模擬信号（UVR動作）を入力し、遮断器開放 ➔ 自家用発電設備自動起動 ➔ 母線連絡遮断器投入といった一連の自動シーケンス制御が正常に完了することを確認。
* **温度上昇測定（赤外線サーモグラフィ）**:
  * 活線運転中の配電盤内において、ボルト締め付け部の緩みによる接触抵抗増大・異常発熱を非接触で熱画像診断。
* **★ 絶縁用保護具の定期自主検査（労働安全衛生規則第351条）**:
  * 高圧活線作業や活線近接作業で使用する**電気用ゴム手袋、ゴム長靴、絶縁衣、絶縁シート**等について、労働安全衛生規則に基づき**「6ヶ月に1回、定期的に自主検査（耐電圧試験）」**を行い、合格したもののみを使用し、記録を3年間保存する。

## 4. 設備の寿命と劣化要因（テキスト p.564〜565）

設備は使用開始と同時に劣化が進行し、やがて機能喪失・寿命に至る。

```
【設備の4大劣化要因体系】
① 物理的劣化 ── 機械的摩耗・疲労、電気的絶縁劣化、化学的腐食、熱劣化、紫外線劣化
② 機能的劣化 ── 性能低下、信頼性低下、操作性悪化、交換部品の入手不能
③ 経済的劣化 ── 維持修繕費・電気代の増大、新規高効率機とのコスト格差拡大
④ 社会的劣化 ── 水質基準改正、脱炭素（省エネ法基準）、新耐震基準への不適合
```

* **複合劣化の現実**:
  * 単一の要因だけでなく、熱と振動が重なって絶縁劣化を早めるなど、複数の要因が複合的に作用して劣化が加速度的に進行する。

## 5. 耐用年数の多面的概念と算定（テキスト p.565〜566）

設備更新の検討において参照される「耐用年数」には、目的の異なる5つの概念が存在する。

| 耐用年数の種類 | 定義と算出根拠 | 特徴と実務上の位置づけ |
| :--- | :--- | :--- |
| **① 法定耐用年数** | 地方公営企業法施行規則・税法に定められた減価償却資産の年数（例：ポンプ15年等）。 | 会計上の減価償却基準。安全側に短めに設定されており、実耐用年数を下回ることが多い。 |
| **② 更新実績耐用年数** | 全国の水道事業体における実際の設備更新実績調査（アンケート統計）に基づく年数。 | 実務的な平均寿命の実態を反映。実務判断の重要な目安。 |
| **③ 寿命要因推定耐用年数** | 設置環境（温湿度・腐食環境）、稼働時間、負荷率などの寿命阻害要因を評価して補正した年数。 | 施設個別の使用過酷度に応じた個別寿命の算定に有用。 |
| **④ 経済的耐用年数** | 設備の**残存簿価（資本費）と累積維持管理費・修繕費の合計の年平均コストが最小**となる年数。 | アセットマネジメントにおいて最も合理的な更新タイミング。 |
| **⑤ 製造者推奨耐用年数** | 機器メーカーが設計・保守基準に基づき保証・推奨する標準使用年数。 | 部品供給保証期間と連動。保守的・安全側に設定される。 |

## 6. 設備更新の必要性判断と判断基準（テキスト p.566〜567）

設備更新を実施すべきか否かの工学的・実務的判断基準は、以下の客観的状況に基づき決定される。

```
【設備更新の必要性を判断する7大基準】
① 故障頻度・停止リスクの増大 ── 突発停止による減水・断水等の供給損失が許容限界を超過
② 交換部品の入手不能 ────── メーカーの製造中止・部品供給期間終了（保全継続不能）
③ 修理の技術的不可能 ────── 機器の抜本的破損・メーカー撤退による修繕技術喪失
④ 性能低下と安全維持不能 ──── 吐出圧・絶縁耐力等の低下により水質・安全の確保が困難
⑤ 維持管理費の異常増大 ───── 修繕費が累積し、新品へ更新した方が経済的に有利
⑥ 需要減少とダウンサイジング ─ 人口減少・水需要減少に伴う設備容量・台数の最適縮小
⑦ 計画容量と実績稼働の大幅乖離 ─ 過大設備の見直しによる電力基本料金・エネルギーロス削減
```

* **★ 交換部品の入手困難リスク（Windows OSのサポート終了と同様）**:
  * 電気計装機器（PLC、プリント基板、保護継電器）等は、電子部品の製造中止に伴いメーカーの部品供給保証（製造中止後7〜10年）が終了する。
  * 故障時に代替部品が入手できず復旧不能となるリスクを避けるため、物理的に動いていても部品供給終了に合わせて計画更新を実施する。

## 7. ライフサイクルコスト（LCC）の最小化と更新計画（テキスト p.567〜570）

### (1) 年平均トータルコスト最小化の理論

```
【設備ライフサイクルコスト（LCC）と最適更新時期】

  年平均コスト (円/年)
    ▲
 高 │                     ＼                ／ 年平均トータルコスト曲線
    │                       ＼            ／   （イニシャル＋ランニング）
    │  年平均イニシャルコスト ＼        ／
    │  （減価償却費・資本費）   ＼    ／★ 最適更新点（最小値）
    │                           ┌──┴──┐
    │  ──────────┐           │  MIN │
    │  年平均ランニングコスト   │      │   ／ 年平均ランニングコスト
 低 │  （修繕費・電気代）       └──┬──┘ ／     （劣化により年々増大）
    └─────────────────────────────┴──────────────────────► 経過年数（年）
                                 最適更新年
```

* **最適更新時期の決定**:
  * **年平均イニシャルコスト**: 経過年数が長くなるほど、建設費が分散されて年平均額は減少する。
  * **年平均ランニングコスト**: 経年劣化に伴い、故障修繕費や効率低下による電気代が増大するため、年々増加する。
  * 両者を合算した**「年平均トータルコスト」が最小となる転換点（極小値）**を捉えて設備を更新することが、長期財政・経済性において最も有利となる。

---

### (2) 単なる同等品更新から「機能改善・最新技術導入」への転換
機械・電気設備の更新にあたっては、以前と同じ型式・仕様の機器に単純更新（同等品更新）する旧来の手法から脱却しなければならない。

* **最新技術の積極導入**:
  * **高効率機器への更新**: トップランナー変圧器、IE3/IE4高効率電動機、最新インバータ制御への置換による劇的な省エネルギー化。
  * **ICT・AI・IoT監視の導入**: 状態監視センサーの搭載により、人手による巡回点検からオンライン遠隔診断へ転換し、業務効率化と省人化を達成。
  * **耐震性・耐浸水性の強化**: 耐震クラスSグレード機器の採用、電気室のかさ上げ。
* **設備容量のダウンサイジング（適正規模化）**:
  * 水需要の減少実績を踏まえ、過大なポンプ口径や変圧器容量を現在の実態に合致した適正容量に縮小し、設備投資額と契約電力基本料金を恒久的に圧縮する。

---

### (3) 施設（土木建築）と設備（機電）の一体更新・整合
* **耐用年数スパン差の同期**:
  * 機械・電気設備（寿命15〜20年）は、土木構造物（寿命50〜100年）よりも圧倒的に寿命が短い。
  * アセットマネジメントにおいて、土木施設の改築・統廃合スケジュールを視野に入れ、**「更新したばかりの機械設備が数年後の浄水場廃止・改築で無駄に破棄される」**といった重大な投資ロスを絶対に起こさないよう、施設全体の長期構想と同期させた年次更新計画を策定する。

---

### (4) PCB廃棄物の適正処理管理
* **法令遵守**:
  * 高圧変圧器、進相コンデンサ、蛍光灯安定器等の絶縁油に含まれるポリ塩化ビフェニル（PCB）は、『PCB特別措置法』に基づき、国が定めた処分期限までに完全無害化処理を行わなければならない。
  * 計画的な調査、保管状況の届出、中間貯蔵・環境安全事業株式会社（JESCO）等への委託処理を確実に履行する。

## 8. まとめ：試験測定・劣化診断・設備更新 重要キーワード・数値基準一覧表

| 項目区分 | 最重要キーワード | 具体的工学的要点・管理数値・法的根拠 |
| :--- | :--- | :--- |
| **試験分類** | 完成試験・臨時試験・定期試験 | 竣工時（完成）、事故修繕後（臨時）、保安規程に基づく周期実施（定期）。 |
| **機械診断** | 振動測定（簡易 vs 精密） | 簡易：全体値スクリーニング。精密：FFT周波数スペクトル解析（アンバランス1X、芯狂い2X、ベアリング傷）。 |
| **機械診断** | 潤滑油・摩耗粉分析 | 動粘度・全酸価。SOAP/フェログラフィ分析により油中金属粉から摺動部異常を非破壊診断。 |
| **機械診断** | 非破壊試験（NDT） | 浸透探傷（PT：開口欠陥）、超音波（UT：残存板厚・内部欠陥）。配管・タンク構造物対象。 |
| **機械据付** | 心出し測定（アライメント） | ポンプ・電動機直結軸。ダイヤルゲージで0°、90°、180°、270°の4位置測定、シム調整。 |
| **電気診断** | 絶縁抵抗測定（メガ） | 電路・機器の絶縁判定。時系列トレンド管理により劣化屈曲点を早期覚知。 |
| **電気診断** | 高圧精密絶縁診断 | ケーブル・高圧機対象。直流漏れ電流、誘電正接（$\tan\delta$）、部分放電コロナパルス測定。 |
| **電気試験** | 絶縁耐力試験（耐電圧） | 新設・重要修繕後。規定試験電圧（最大使用電圧の1.5倍等）を**10分間印加**し破壊防止確認。 |
| **変圧器診断** | 油中溶存ガス分析 | 絶縁油中の可燃性ガス（アセチレン、水素等）組成から内部過熱・アーク放電を解体せず診断。 |
| **継電器試験** | ★テストプラグによる切離し | 保護継電器試験時はテストプラグで主回路から完全切り離し。**未切離しは全所停電事故を誘発**。 |
| **低圧保安** | 漏電遮断器（ELCB）点検 | テストボタンによる動作確認を**1年に1回以上**実施。 |
| **安全保護具** | 絶縁用保護具定期自主検査 | 電気用ゴム手袋・長靴・シート等は**6ヶ月に1回定期自主検査（耐電圧）**、記録3年保存（安衛則）。 |
| **耐用年数** | 5大耐用年数 | 法定（会計上短め）、更新実績（実態平均）、寿命要因（個別補正）、経済的（LCC最小）、推奨（メーカー保証）。 |
| **更新判断** | 部品供給停止・乖離 | メーカー部品供給終了（復旧不能リスク）、需要減少に伴うダウンサイジング、過大容量是正。 |
| **LCC最適化** | 年平均トータルコスト最小化 | 年平均イニシャル（逓減）＋年平均ランニング（逓増）の合計が**最小となる時点で更新**。 |
| **更新方針** | 最新技術導入・機能改善 | 単なる同等品更新を脱却。高効率インバータ、省エネモーター、AI遠隔監視、耐震化を推進。 |
| **環境法規** | PCB廃棄物の適正処理 | 変圧器・コンデンサのPCB含有油。PCB特措法の期限内に計画的無害化処理完了。 |
