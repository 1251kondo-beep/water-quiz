## 1. オゾン処理設備（テキスト p.454〜457）

### (1) オゾンの物理化学的特性と安全性管理
* **特性**:
  * 化学式 $\text{O}_3$。特有の青草臭・刺激臭を持つ淡青色の気体。
  * **極めて強力な酸化力**: 酸化還元電位は 2.07 V であり、次亜塩素酸（1.48 V）や塩素（1.36 V）を遥かに凌駕する。
  * 自家分解性: 水中および空気中で速やかに酸素（$\text{O}_2$）へと自己分解し、残留性がない。
* **生体毒性と環境基準**:
  * **作業環境許容濃度（日本産業衛生学会）**: **0.1 ppm（約 0.2 mg/m³）**
  * 0.1 ppm を超えると鼻・喉・呼吸器への強い刺激、数 ppm で頭痛・疲労感・肺水腫等の重大な中毒症状を引き起こす。
  * 光化学オキシダント環境基準: 1時間値 0.06 ppm 以下。
  * **漏洩検知・安全対策**: オゾン発生器室・接触槽上部には**オゾンガス濃度検知警報装置（連続測定）**および緊急強制換気ファン、携帯用検知器を常備する。

### (2) 施設基準と高度浄水処理における必須要件
水道施設の技術的基準を定める省令に基づき、オゾン処理設備には以下の要件が定められている。

```
【オゾン処理設備の法定施設要件（技術的基準省令）】
① 接触槽の構造 ────── オゾンガスと水が効率的に混和・接触し、偏流や短絡流（ショートパス）
                         を生じない構造であること。
② 接触時間の確保 ──── 所要の水質基準を達成するために必要な接触時間（通常10〜20分）を有すること。
③ 【最重要】後段BAC配置 ─ オゾン処理設備の後段には、必ず「粒状活性炭（生物活性炭BAC）処理設備」
                         を設けなければならない。
                         （理由: オゾンにより生成した生分解性有機物・消毒副生成物を徹底除去するため）
④ 排オゾン処理設備 ─── 接触槽気相部から排出される未反応オゾン（排オゾン）を無害化分解して
                         大気へ放出する排オゾン処理設備を設けること。
⑤ 漏洩防止と保安 ──── オゾンガスの漏洩を検知・遮断・防止する措置を講じること。
```

### (3) 処理効果と副生成物（臭素酸）対策
1. **主要な処理効果**:
   * **かび臭物質の分解**: ジェオスミンおよび 2-MIB を強力に酸化分解（後段BACとの併用でほぼ 100% 除去）。
   * **トリハロメタン（THM）生成能の低減**: 腐植酸（フミン質）を酸化・低分子化し、後段BACで吸着・生物分解することで全体で約 60% 低減。
   * **脱色（色度除去）**: 不飽和二重結合を開裂させ、着色成分を無色化。
   * **病原微生物の不活化**: 塩素耐性のクリプトスポリジウムを不活化可能（ただし低水温時は効率低下）。
2. **副生成物「臭素酸（$\text{BrO}_3^-$）」の生成と抑制対策（★試験頻出）**:
   * **生成メカニズム**: 原水中に**臭化物イオン（$\text{Br}^-$）**が存在する場合、オゾンにより酸化されて発がん性物質である**「臭素酸イオン」**が副生される（水質基準値: **0.01 mg/L 以下**）。
     $$\text{Br}^- \xrightarrow{\text{O}_3} \text{OBr}^- \xrightarrow{\text{O}_3} \text{BrO}_3^-$$
   * **臭素酸の抑制対策**:
     * オゾン注入率の低減、接触時間の短縮。
     * **pHの酸性側への調整**: 前酸（濃硫酸等）の注入によりpHを低下させると、次亜臭素酸イオンへの解離が抑えられ臭素酸生成が激減する。
     * **促進酸化法（AOP：Advanced Oxidation Process）**: **オゾンに過酸化水素（$\text{H}_2\text{O}_2$）を併用注入**し、オゾン単独酸化をバイパスしてヒドロキシラジカル（$\cdot\text{OH}$）を発生させ、臭素酸生成を抑えつつ有機物を超高速分解する。

## 2. 生物接触ろ過・生物処理設備（テキスト p.457〜460）

### (1) 目的と除去対象
原水中のアンモニア態窒素、微量溶解性鉄・マンガン、陰イオン界面活性剤、微量有機物等を、薬品を使わずに**固着微生物（好気性菌・硝化菌等）の生物酸化分解作用**によって除去する前処理・中間処理設備である。

```
【生物処理設備の代表的3大形式】
┌──────────────────┬────────────────────────────────────────────────────┐
│ 形式             │ 構造と特徴                                         │
├──────────────────┼────────────────────────────────────────────────────┤
│ ① 生物接触ろ過池 │ 砂利、アンスラサイト、セラミック等の担体を充填し、 │
│                  │ 上向流または下向流で通水。通水空塔速度 10〜15 m/h。│
│                  │ 目詰まり防止のため定期逆洗が必要。                 │
├──────────────────┼────────────────────────────────────────────────────┤
│ ② 浸漬ろ床装置   │ 水槽内にプラスチック製ハニカム材や接触材を浸漬し、 │
│                  │ 底部から散気管で曝気しながら循環接触。             │
│                  │ 接触時間: **1 〜 3 時間**。                        │
├──────────────────┼────────────────────────────────────────────────────┤
│ ③ 回転円盤装置   │ 水槽内に円盤面積の **約 40 % が水没** するよう多数 │
│                  │ のプラスチック円盤を配置し、低速回転（数rpm）。    │
│                  │ 空気中と水中の出入りにより酸素供給と接触を両立。   │
└──────────────────┴────────────────────────┴──────────────────────────────────────┘
```

### (2) 運転管理の重要留意点
* **水温依存性（★試験頻出）**:
  * 至適水温は **20 〜 30 ℃**。水温低下とともに生物活性が低下し、**水温 5 ℃ 以下になると硝化菌の活性が著しく減退**してアンモニア除去率が急落する。
* **生物膜の立ち上げ期間**:
  * 新設・更新時は生物膜が成熟するまで **高水温期でも 2 〜 3週間程度** のならし通水期間を要する。

## 3. 除鉄・除マンガン設備（テキスト p.461〜463）

### (1) 鉄・マンガンによる給水障害
* **鉄（$\text{Fe}$）**: 水質基準 **0.3 mg/L 以下**。酸化されると不溶性の水酸化第二鉄（赤褐色）となり、**赤水障害**、金属味、洗濯物の赤褐色着色、給水管・メーター閉塞を引き起こす。
* **マンガン（$\text{Mn}$）**: 水質基準 **0.05 mg/L 以下**（色度目標は 0.01 mg/L 以下）。微量でも黒色二酸化マンガン沈殿を生じ、**黒水障害**、配水管内の黒色スケール堆積を引き起こす。

---

## 6. 想定問題集（4択ドリル用プロトタイプ問題）

### 設問1（4択：オゾン処理設備の構造基準と臭素酸対策）
* **問題形式**: `choice`
* **問題文**: 水道におけるオゾン処理設備およびその副生成物に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 原水中に臭化物イオンが存在する場合、オゾン酸化によって発がん性の臭素酸イオンが生成されるため、pH調整や過酸化水素併用（AOP）等の抑制対策を講じる
  2. オゾン処理は強力な酸化・消毒作用を有するため、水道施設の技術的基準において後段に活性炭吸着設備を配置することは禁止されている
  3. オゾンガスの作業環境許容濃度は 10 ppm であり、密閉室内で作業員が高濃度オゾンを吸入しても人体への毒性は全く認められない
  4. オゾン接触槽の深層下向流方式は、敷地面積が広大な郊外型浄水場専用の方式であり、市街地浄水場の省スペース化には適用できない
* **正解**: 1（インデックス: 0）
* **解説**: 原水中の臭化物イオン（$\text{Br}^-$）から発がん性の臭素酸イオン（$\text{BrO}_3^-$）が副生するため、pH低下（前酸注入）や過酸化水素併用による促進酸化処理（AOP）等の抑制対策を講じます（1が正解）。省令基準によりオゾン処理の後段には必ず「粒状活性炭（BAC）処理設備」を設けなければなりません。作業環境許容濃度は「0.1 ppm」です。深層下向流方式は水深を深くして吸収率を高め、敷地面積を縮小できるため市街地浄水場（東村山等）で積極的に採用されます。
* **日常のたとえ**: オゾンは「超強力な漂白剤」ですが、海水成分の臭素が混ざっていると有害な焦げ跡（臭素酸）ができてしまうため、弱火にしたり（pH低下）別の助剤（過酸化水素）を加えて焦げを防ぐ工夫をしています。
* **出典**: 講義テキスト 浄水施設 p.454〜457 / 水道施設の技術的基準を定める省令

### 設問2（4択：生物接触ろ過および回転円盤装置）
* **問題形式**: `choice`
* **問題文**: 水道原水の生物処理設備に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 生物処理設備の至適水温は 20〜30 ℃ であり、水温が 5 ℃ 以下に低下すると硝化菌の活性が著しく減退してアンモニア態窒素の除去率が急落する
  2. 回転円盤装置は、円盤の表面全体（100%）を水面下に完全に水没させた状態で高速回転させて微生物と水を接触させる
  3. 生物処理設備は薬品を使用しないため、充填担体の洗浄作業や逆流洗浄は数年間一切行わずに放置するのが標準管理である
  4. 新設した生物処理設備は、通水を開始した当日から直ちに 100% 完全な硝化・分解性能を発揮するため、ならし運転期間は不要である
* **正解**: 1（インデックス: 0）
* **解説**: 好気性微生物（硝化菌等）の至適水温は「20〜30 ℃」であり、水温「5 ℃ 以下」では活性が著しく減退します（1が正解）。回転円盤装置は円盤面積の「約40%が水没」するように設置し、低速回転させて大気中酸素と水中の交互接触を行います。生物処理担体は目詰まり防止のため定期逆洗が必要です。生物膜形成には高水温期でも「2〜3週間程度」のならし期間を要します。
* **日常のたとえ**: 観葉植物が真冬の寒さ（5℃以下）で成長を止めて冬眠してしまうように、浄水のバクテリアたちも真冬の冷水では活動が極端に鈍くなります。
* **出典**: 講義テキスト 浄水施設 p.457〜460

### 設問3（4択：除鉄・除マンガン設備と接触酸化法）
* **問題形式**: `choice`
* **問題文**: 地下水等の除鉄・除マンガン処理設備に関する記述として、水道施設設計指針および維持管理指針に照らして**最も適切なもの**はどれですか？
* **選択肢**:
  1. マンガン砂を用いた接触酸化法では、二酸化マンガンの触媒酸化機能を維持するため、流入水中に常時「遊離残留塩素」を存在させることが不可欠である
  2. 多量の鉄とマンガンが共存する原水では、1段目でマンガン砂を用いてマンガンを除去し、2段目で鉄を除去する順序が標準的である
  3. 水中の炭酸第一鉄をエアレーションにより酸化沈殿させる場合、pHを強酸性（pH 4以下）に下げて溶存酸素をゼロにするのが最も効果的である
  4. オゾン酸化法によりマンガンを除去する際、オゾンを過剰に注入すればするほど水が無色透明化し、着色障害は完全に防止される
* **正解**: 1（インデックス: 0）
* **解説**: マンガン砂ろ過（接触酸化法）では、二酸化マンガンの自己触媒作用を維持・再生するために常時「遊離残留塩素」の存在が絶対不可欠です。塩素が途絶えると吸着されたマンガンが再溶出します（1が正解）。鉄・マンガン共存時は、鉄がマンガン砂表面を覆って触媒機能を阻害するため「1段目で鉄除去 $\rightarrow$ 2段目でマンガン除去」の順序とします。エアレーション除鉄は高pH（8.5程度以上）で促進されます。オゾン過剰注入は過マンガン酸イオン（$\text{MnO}_4^-$）の生成による赤紫色着色を招きます。
* **日常のたとえ**: マンガン砂は「充電式電池」のようなもので、塩素という電力を常に供給（充電）し続けていないと、マンガンを捕まえるパワーが切れて逆に逃げ出してしまいます。
* **出典**: 講義テキスト 浄水施設 p.461〜463 / 水道施設維持管理指針

### 設問4（4択：マイクロストレーナーの構造と藻類除去）
* **問題形式**: `choice`
* **問題文**: 水道水源における藻類対策およびマイクロストレーナーに関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. マイクロストレーナーは、回転ドラムの外周に張った微細メッシュにより原水中のプランクトンや藻類を物理的に捕捉し、約70%を除去する
  2. マイクロストレーナーは、急速混和池においてポリ塩化アルミニウム（PAC）とフロックを形成させた後の沈殿池出口に設置するのが原則である
  3. 貯水池における防藻対策として用いられる硫酸銅は、散布後数分以内に完全に効力を失うため、毎時連続注入しなければならない
  4. マイクロストレーナーのろ網に捕捉された藻類は、年1回の定期点検時に池水を全量抜いて手作業のワイヤーブラシで削り落とす構造である
* **正解**: 1（インデックス: 0）
* **解説**: マイクロストレーナーは回転ドラムに張った微細金網・合成繊維メッシュ（数十μm）により、原水中の藻類（アナベナ、シネドラ等）を物理捕捉し約70%を除去します（1が正解）。設置場所は混和池や普通沈殿池の前（前塩素注入点より上流）です。硫酸銅は銅イオンの微量作用により持続性が高いのが特徴です。マイクロストレーナーは上部スプレーノズルからろ過水を噴射し、連続的に逆流洗浄・泥樋排出する全自動機構を備えています。
* **日常のたとえ**: プールの水面を泳ぐ虫や落ち葉を、巨大な回転水車型の「自動ゴミすくいネット」でくるくる回りながらシャワーで洗い落とし続ける装置です。
* **出典**: 講義テキスト 浄水施設 p.463〜466

### 設問5（4択：高度浄水処理システムの総合判断）
* **問題形式**: `choice`
* **問題文**: 高度浄水処理施設（オゾン・生物活性炭BAC・接触酸化・防藻対策）に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. オゾン接触槽内の点検作業を行う際は、オゾンガス濃度が作業環境基準である 0.1 ppm 以下であることを確認し、十分な換気を行う
  2. 臭素酸イオンの水質基準値は 0.01 mg/L 以下に定められており、原水中の臭化物イオン濃度が高い水源ではオゾン処理の注入率やpH管理に細心の注意を払う
  3. 地下水から溶存鉄・マンガンを除去する際、水質基準値は鉄が 0.3 mg/L 以下、マンガンが 0.05 mg/L 以下と規定されている
  4. オゾン処理設備から排出される排オゾンガスは、大気汚染防止法上の特定物質ではないため、排オゾン処理設備を介さず全量を大気中へ無処理放流する
* **正解**: 4（インデックス: 4）
* **解説**: 未反応の排オゾンガスは強烈な毒性と酸化力を持つため、活性炭吸着分解、熱分解、触媒分解等の「排オゾン処理設備」により完全に無害化分解（0.1ppm以下）してから大気放出することが法令上義務付けられています（4が誤り）。作業環境基準（0.1ppm以下）、臭素酸基準（0.01mg/L以下）、鉄（0.3mg/L以下）・マンガン（0.05mg/L以下）の基準値の記述はすべて適切です。
* **日常のたとえ**: 工場で有毒ガス（排オゾン）が出たのに「煙突からそのまま外に垂れ流す」のが許されないのと同じで、必ず排ガス浄化フィルター（排オゾン分解塔）を通さなければなりません。
* **出典**: 講義テキスト 浄水施設 p.454〜457 / 水道施設の技術的基準を定める省令
