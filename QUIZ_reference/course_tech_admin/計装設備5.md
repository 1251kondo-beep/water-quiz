## 1. 魚類による水質監視装置（バイオアッセイ装置）（テキスト p.616〜617）

河川水や原水に対する毒物・有害物質の不法投棄・混入を早期に察知するため、生物応答（バイオアッセイ）を利用した連続水質監視装置が浄水場の取水部等に導入されている。

```
【魚類水質監視システムの構成と動作フロー】
［原水連続流入槽（金魚・タモロコ等）］
   ├── ① 活動電位検出方式 ── 魚の呼吸・筋活動に伴う微弱生体電位の検知
   └── ② 映像画像解析方式 ── ITVカメラ画像による遊泳行動・群れパターンの統計解析
            ↓ （異常行動・へい死の検知・警報発報）
［オートサンプラー（自動採水器）起動］
   ・異常検知時の試料水を複数ボトルへ自動分取・密閉保冷保管
            ↓
［緊急手分析・毒物スクリーニング］
   ・職員が採取水を検査室へ直ちに持ち込み、化学分析試薬・機器分析で安全性を確定
```

### (1) 測定原理と検知方式
1. **活動電位検出方式**:
   * 魚類が呼吸（エラ運動）や遊泳を行う際に体表から水中に発生する微弱な生体電気信号（活動電位）を電極で捕捉し、呼吸数や運動量の異常低下・停止を検出する。
2. **映像（画像処理）解析方式**:
   * 水槽上部のカメラから魚の遊泳軌跡・速度・水槽底面への沈降（へい死）を画像処理によりリアルタイムで統計解析し、平常行動パターンからの逸脱を検知する。
3. **微生物呼吸速度（酸素消費量）検出方式**:
   * 活性汚泥や特定の微生物が毒物によって呼吸阻害を受ける際の溶存酸素消費量変化を検出する方式。

### (2) 実務運用と保守上の留意点
* **オートサンプラー（自動採水器）との連動**:
  * 警報発報と同時に自動採水器が作動し、原因究明用の原水を確実に確保する。
* **維持管理の負担**:
  * 生物（魚類）を扱うため、水槽の定期清掃、給餌、水温・溶存酸素管理、魚の定期補充・入替など、機械設備とは異なる特有の手間とコストを要する。

## 2. トリハロメタン計および特殊水質監視装置（テキスト p.617〜619）

### (1) トリハロメタン計（テキスト p.617）
* **生成機構**:
  * 塩素消毒時に、原水中に含まれるフミン質等の溶存有機物質（トリハロメタン前駆物質）と塩素が反応して生成される消毒副生成物（クロロホルム、ブロモジクロロメタン、ジブロモクロロメタン、ブロモホルムの総称）。
* **監視の目的**:
  * 発がん性が指摘される水質基準項目（総トリハロメタン 0.1 mg/L以下）であり、浄水処理工程における前塩素・中間塩素注入率の適正化やオゾン・活性炭処理効果の監視に用いられる。
  * オゾン処理を併用することでトリハロメタン生成は大幅に抑制されるが、臭化物イオンが存在する場合は微量のブロモホルムや臭素酸が生成されるため、適切なプロセス管理が求められる。

### (2) 水質自動監視装置（自動水質計器）（テキスト p.618）
* **給水栓末端における最終品質確認**:
  * 配水管網の要所や末端給水栓（東京都では都有施設等に設置）に配置され、**水道法法定毎日検査3項目（色度、濁度、残留塩素）**に加え、**水温、水圧、電気伝導率**を連続自動測定する。
* **データ公開と震災対策**:
  * 計測データは光回線・LTE等で水運用センターへ伝送され、インターネット（ホームページ）上でリアルタイムに一般公開されている。
  * 管網の圧力・水質データは、平常時の水運用だけでなく、震災・管路事故時における**断水・漏水エリアの迅速特定（減圧ブロックの早期把握）**に威力を発揮する。

### (3) その他のプロセス計器（テキスト p.618〜619）
* **温度計（水温計）**:
  * 熱電対温度計、白金測温抵抗体（Pt100）が主流。
  * **水温低下に伴う影響**: 冬季の水温低下は水の粘性係数を上昇させ、**「ろ過池の損失水頭上昇（ろ過抵抗増大）」**や凝集反応速度の遅延を招くため、プロセス制御の重要な基礎パラメータとなる。
* **オゾン濃度計**:
  * オゾン処理設備において、オゾン発生器出口や排オゾン分解塔入口の気相オゾン濃度（紫外線吸光式）、接触池出口の溶存（液相）オゾン濃度を厳格に測定。
* **塩素ガス漏洩検知器**:
  * 液化塩素を使用する施設における安全防護（漏洩警報発報、緊急遮断弁連動、苛性ソーダ除害装置連動）。※現在の大規模水道局（東京都等）では安全性の観点から次亜塩素酸ナトリウムへの切替が進み、液化塩素使用施設は激減している。

## 3. 監視制御システムの保守管理とセキュリティ（テキスト p.622〜626）

監視制御システム（SCADA / DCS）は、浄水場および広域管網を統括する中枢頭脳である。

```
【監視制御システムの基本構成】
［現場設備］──［PLC / PCS］──［制御LAN］──［情報サーバー］──［監視卓（PC/LCD）］
 (ポンプ・弁)    (論理演算・I/O)  (FL-net等)    (帳票・履歴)      (操作指令・グラフィック)
```

### (1) PLC（プログラマブルロジックコントローラ / PCS）の保全と更新課題
* **停電復電時のリスク**:
  * 商用電源停電からの復電時、サージ電圧や突入電流によりPLCのCPUユニットや電源ユニットが立ち上がらなくなるトラブルが頻発する。
* **★更新時のマルチベンダー非互換性問題（現場の重大課題）**:
  * 既存PLC（A社製）が製造中止（保守終了：EOL）となり更新する際、競争入札によって他社（B社製・C社製）が落札することがある。
  * メーカーごとに内部通信手順が異なるため、既設システムと直接通信できなくなるリスクがある。
  * **【実務対策】**:
    * 業界標準プロトコル（**FL-net**等）の採用。
    * 設計段階であらかじめ**「プロトコル変換器（通信変換装置）」**を計上しておき、他社製PLCが納入された場合でも確実に対向接続できる設計とする。
* **経済安全保障と特定国製機器の排除**:
  * 重要インフラ指定を受けた基幹浄水場の監視制御システムでは、不正アクセスやサイバーテロ、バックドア設置を防止するため、**「信頼性が担保された国内製等の指定適合品」**を採用することが厳格に審査される。

### (2) 保守作業における安全管理原則（★試験頻出）
1. **原則停電作業の徹底**:
   * 制御盤内点検において「活線（通電状態）のまま作業できる」とするのは誤りであり、**感電事故および短絡による全所停電防止のため原則停電作業が鉄則**である。
2. **手動運転への事前切替**:
   * 制御装置の点検・ソフトウェア修正を行う際は、**制御対象機器（ポンプ・電動弁・薬注機）を必ず「現場手動運転」に切り離し**、不意の自動連動による人身事故・誤動作を阻止する。
3. **警報回路の模擬信号試験**:
   * 警報回路の動作確認は、現場端子台からの**模擬入力（テスト信号印加）やテストボタン**を用いて安全に検証する。

### (3) 情報サーバー・冷却ファンの維持管理（テキスト p.624）
* **半導体素子の熱劣化防止**:
  * サーバー室・計装盤室の空調管理を徹底し、温度・湿度ストレスを抑制する。
* **★冷却ファンの時間計画保全（TBM）交換**:
  * サーバーやPLC盤に内蔵される冷却ファンは、数年でベアリング摩耗・固着により突然停止する。ファン停止による盤内温度上昇・CPU熱暴走を防ぐため、**故障を待たずに数年周期で定期交換（TBM）**する。

## 4. 通信機器・遠方監視制御装置の二重化と信頼性（テキスト p.626）

### (1) テレメータ・テレコントロール装置の二重化
* 無人施設（給水所・ポンプ所）と中央監視室を結ぶ通信系統は、CPU、電源、通信回線を**主系・待機系の二重化（デュアル化）**とする。

### (2) 単一障害点（SPOF）の排除
* システムの二重化を図っていても、**「共通部分（スイッチングハブ、回線ルーター、共通電源部等）」が1つ故障しただけでシステム全体がダウンする事態（単一障害点：Single Point of Failure）**を絶対に作らないよう、共通機器を含めた完全冗長化を設計する。

### (3) 無停電電源装置（UPS）による電源保護
* 瞬時電圧低下（瞬低）や短時間停電によって監視制御がリセットされないよう、重要計装盤・通信機器には蓄電池を備えた**UPS（CVCF）給電**を常時介在させる。

## 5. 無人施設の防犯・危険防止対策（テキスト p.628〜630）

給水所・配水場・遠隔ポンプ所など、日常的に職員が常駐しない無人施設では、物理的セキュリティとテロ対策が極めて重要となる。

```
【無人施設の防犯・危険防止対策体系（テキスト p.629・下線箇所）】
┌── 外周防護 ────── 堅牢で高いフェンス、忍び返し、赤外線侵入検知センサー
├── 建物防護 ────── 扉・窓の常時施錠、破壊防止ガラス・防犯ネット・シャッター
├── 換気口防護 ──── 配水池等の換気開口部に「ガラリ（防虫網付ルーバー）」常設（異物投下防止）
└── 監視・通報 ──── 24時間ITV監視カメラ（夜間照明）、警備会社機械警備・警察即時通報
```

* **換気口ガラリの異物投下防止と腐食対策（★重要）**:
  * 地下配水池や受水槽の地上露出換気口は、悪意ある侵入者による毒物・異物の投下を防ぐため、**「強固な防護ガラリ」**を設置する。
  * 塩素ガスや次亜蒸気による腐食を受けやすいため、ステンレス製であっても定期的な発錆点検・更新を行う。

## 6. 計装データ等を活用した高度運転・DX（テキスト p.631〜633）

計装設備は単なる監視ツールではなく、収集されたビッグデータを活用して水道経営・運転効率化（DX）を推進するための基盤である。

### (1) 計測データの傾向管理と予兆保全
* 電動機の運転電流値、受電電圧、力率、消費電力量をトレンドグラフ化し、平常時からの乖離（同一吐出圧での電流値上昇等）から機械的異常を早期発見。

### (2) 契約電力の見直しとエネルギー最適化（テキスト p.632）
* **夜間電力割引契約の活用**:
  * 安価な夜間電力を利用して送配水ポンプをフル稼働させ、配水池を満水近くまで揚水。昼間の電力ピーク時間帯はポンプ稼働を抑制（ピークシフト）。
* **ポンプ最高効率点（BEP）を狙った台数制御**:
  * 流量変動に対し、インバータ変速制御と適切な台数制御を組み合わせ、ポンプの最高効率点付近で運転を維持する。

### (3) 落雷・停電予報時の系統解列運用（テキスト p.633）
* 常用自家発電設備を電力系統と連系（系統連系）して並列運転している場合、外部電力系統で落雷・事故停電が発生すると、発電設備が引きずられて非常停止（開列）するリスクがある。
* **【実務対策】**: 落雷注意報発令時などには、あらかじめ電力会社からの受電遮断器を開放（意図的解列）し、**自家発電設備による単独自立運転へ移行**させてプラントを外部停電から防護する。

## 7. 計装設備の耐用年数とLCC更新計画（テキスト p.633〜635）

### (1) 計装設備の短寿命性と更新の必要性
* コンクリート土木構造物（50〜100年）や大型ポンプ・配電盤（20〜30年）に対し、**計装設備・電子機器の物理的寿命は著しく短い（7〜15年程度）**。
* 15年以上経過した計装システムを放置することは「ロシアンルーレット状態」であり、突然の機能停止を招く。

### (2) 3大耐用年数の概念比較

| 耐用年数の種類 | 定義と水道計装における実務的扱い |
| :--- | :--- |
| **① 法定耐用年数** | 財務省令（減価償却資産の耐用年数省令）で定められた税法・公営企業会計上の年数。計装設備は比較的短期間で減価償却が終了するため、償却後は資産価値が帳簿上ゼロとなり、早期の更新予算要求・起債が行いやすい。 |
| **② 寿命要因耐用年数** | 電解コンデンサの容量抜け、電子基板の劣化、半導体素子の熱疲労など、物理的・機能的限界に基づく寿命。メーカー推奨年数（5年〜7年）などを参考に設定。 |
| **③ 経済的耐用年数** | 経年劣化に伴い急増する「修繕費・部品交換費」と、最新システムへの「更新投資額」を比較し、**ライフサイクルコスト（LCC）の年平均トータルコストが最小となる年数**。 |

### (3) 更新設計における部品調達性（汎用性の確保）
* 設備更新にあたっては、特殊な一品特注品を極力排除し、**「市場で容易・迅速に入手可能な標準汎用機器（短納期品）」**を採用することが、将来の維持管理コスト低減と事故時の即応体制確保につながる。

## 8. 【問題作成用】試験最頻出ポイント総まとめ・論点整理

本講義録（テキスト p.616〜635）から出題される4択問題・正誤判定問題の作成用キーワード対比表：

| 分野・論点 | 正しい記述（正肢のポイント） | 誤りとして出題されやすい引っかけパターン |
| :--- | :--- | :--- |
| **魚類水質監視装置** | 魚類の活動電位や遊泳行動を監視し、**異常検知時はオートサンプラー（自動採水器）で原水を採取保管**する。 | 「魚類水質監視装置は、毒物を検知すると水槽内の魚が自律的に中和剤を分泌して毒物を無害化する」（×：自動採水・警報機能） |
| **自動水質監視装置** | 給水栓等で**毎日検査3項目（色度・濁度・残留塩素）や水圧等を連続測定**し、最終品質を保証する。 | 「給水栓に設置される自動水質監視装置は、水質基準51項目の全項目を毎日自動分析している」（×：毎日3項目＋水温・水圧・導電率等） |
| **水温低下の影響** | 水温が低下すると水の粘性が高まるため、**急速ろ過池の損失水頭（ろ過抵抗）が上昇しやすくなる**。 | 「水温が低下すると水の粘性が下がり、ろ過池の損失水頭はゼロに近づく」（×：粘性増大で損失水頭上昇） |
| **PLCの更新課題** | メーカー非互換性を解決するため、**FL-net等の標準プロトコル採用や通信変換器の事前組み込み**を行う。 | 「PLCは全世界で完全共通化されているため、異なるメーカー間でも特別な変換器なしにそのまま直結通信できる」（×：非互換性対策が必須） |
| **点検作業の安全原則** | 制御盤やPLCの点検整備は、**感電および誤動作による全所停止を防ぐため「原則停電作業」**とする。 | 「計装設備の点検整備は、給水を停止させないためいかなる場合でも活線（通電）のまま実施することが義務付けられている」（×：原則停電作業） |
| **制御対象の手動切替** | 監視制御システムの点検・改修時は、**現場機器を「手動運転」に切り離し、不意の自動連動を防止**する。 | 「制御プログラムの修正中は、誤動作を即座に確認するため全機器を全自動運転モードのままにしておく」（×：手動切替が必須） |
| **サーバー冷却ファン** | サーバーやPLC盤の冷却ファンは、熱暴走によるダウンを防ぐため**時間計画保全（TBM）で定期交換**する。 | 「盤内冷却ファンは停止してサーバーが過熱故障するまで一切交換してはならない」（×：予防保全TBMで定期交換） |
| **通信機器の単一障害点** | システムを二重化する場合でも、**ルーターやハブ等の共通部分が単一障害点（SPOF）にならないよう完全冗長化**する。 | 「CPUさえ二重化しておけば、共通の通信ルーターやハブは1台のみで十分であり冗長化は不要である」（×：共通部分も冗長化） |
| **無人施設の換気口ガラリ** | 配水池等の換気開口部には、**毒物や異物の投下を防止するため堅牢な防護ガラリを設置**する。 | 「配水池の換気口は通気性を最優先するため、金網やガラリ等の遮蔽物は一切設けてはならない」（×：異物投下防止ガラリ必須） |
| **計装設備の耐用年数** | 計装設備は土木構造物（50〜100年）に比べ**物理的寿命が短く（7〜15年）、LCC最小化を考慮した計画更新**が必要。 | 「計装機器は電子機器であるため経年劣化せず、土木構造物と同じく50年以上無更新で使用し続けるのが最も経済的である」（×：短寿命で計画更新必須） |
