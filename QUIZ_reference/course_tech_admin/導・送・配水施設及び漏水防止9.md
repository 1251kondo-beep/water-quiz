## 1. 地下漏水調査の実務（テキスト p.342〜344）

地上に現れない「地下漏水」は、道路陥没や無効水量の増大を招くため、計画的・科学的な調査によって早期に発見・修繕する必要がある。

### (1) 調査区画の設定と作業方式

```
【地下漏水調査の2大作業方式】
① 計量作業方式 ── 区画を孤立化させ、直接法または間接法（夜間最小流量測定）により漏水量を「計量・数値化」して評価する方式。
② 簡易作業方式 ── 事前計量は行わず、音聴棒や路面音聴器・相関式探知器を用いて全路線を直接「探査・発見」していく方式。
```

* **調査区画の規模**:
  * 配水管網の密度や給水栓数（戸数）に応じて設定するが、**一区画あたり管路延長 $1 \sim 3\text{ km}$ 程度を標準** とする（東京都水道局等の過密都市部では実質 $3.5 \sim 4\text{ km}$ 程度で設定される地域もある）。
  * 区画が大きすぎると流量変化が検知しにくくなり、小さすぎると仕切弁の閉止・管理作業が膨大となる。

---

### (2) 間接測定法（夜間最小流量測定）の実務手順

住民の日常給水を止めずに区画全体の漏水量を把握する実務の標準手順である。

```
【夜間最小流量測定の実務ステップ】
ステップ1: 区画の孤立化 ────── 外部からの流入バルブを1箇所を残して全閉し、単一系統化。
ステップ2: 流量計の接続 ────── 流入部の「区画流量測定室」で中間弁を全閉、バイパスホースと可搬式流量計を接続。
ステップ3: 深夜帯の追跡 ────── 水使用が極小となる午前2〜3時頃の流量波形を連続記録。
ステップ4: 無用時間の特定 ──── 使用による跳ね上がりが収まり、最低値（ボトム値）が安定して現れる流量を「漏水量」と判定。
```

1. **区画の孤立化**:
   * 調査対象区画へ流入する配水幹線の仕切弁を、指定の1箇所を除いてすべて全閉し、水が単一のルートからのみ流入する状態をつくる。
2. **流量測定（区画流量測定室）**:
   * 流入基点に整備された「区画流量測定室（2基の消火栓と中間仕切弁で構成）」において、本管の中間仕切弁を全閉し、消火栓間にバイパスホースを繋ぎ、可搬式電磁流量計を介して流入水量を全量計測・記録する。
3. **無用時間の特定と漏水量判定**:
   * 深夜帯（**午前2時〜3時頃**）は住民の大部分が就寝している。誰かがトイレ等を使用すると一時的に波形が跳ね上がるが、使用が終われば再びベースライン（底）へ戻る。
   * この **安定した最低値（ボトム値）が数回現れる時間帯（無用時間）の流量を、その区画に常時存在する「地下漏水量」と判定** する。

## 2. 漏水箇所の探査技術と水質判定（テキスト p.344〜347）

### (1) 地上湧水の水質判定（水道水かどうかの識別）

路上や法面から水が湧出している場合、それが水道管の破断による漏水なのか、天然の湧水・雨水・下水なのかを現場で迅速に識別しなければならない。

```
【湧出水の判定手順】
［第1段階：現場簡易試験］
  ├─ 遊離残留塩素測定（DPD法） ── 残塩検出なら「水道水」と即座に断定。
  │                                 ※ただし、土壌中の有機物等で塩素が還元消費され「不検出」となる場合あり。
  └─ 電気伝導率（導電率）測定 ── 下水・地下水は塩類が多く高導電率。通常値を示す水道水と対比。
        │ （判定困難な場合）
［第2段階：精密集約試験（持ち帰り）］
  └─ トリハロメタン（THM）検査 ── 浄水処理（塩素消毒）の副生成物。微量でも検出されれば「100%水道水」と断定。
```

* **トリハロメタン検査の決定力**:
  * 地層を通過する間に残留塩素が完全に分解・消失してしまった場合でも、原水の有機物と塩素が反応して生成されたトリハロメタンは地中を通っても分解されずに残留する。
  * そのため、水質研究所等に持ち帰ってガスクロマトグラフ質量分析等でトリハロメタンを検出すれば、確実に水道水由来の漏水であると科学的に断定できる。

### (2) 漏水探査機器の種類と構造特性

漏水箇所を路面からピンポイントで特定するため、管種や環境に応じた多様な機器が組み合わせて使用される。

| 機器名称 | 構造・動作原理 | 特徴・長所 | 短所・留意点・伝播特性 |
| :--- | :--- | :--- | :--- |
| **音聴棒**<br>（直読式） | 金属棒先端をメーター・弁棒・消火栓に当て、共鳴板に耳を押し当てて音を聴取。 | 電源不要、軽量、最も基本的で熟練者の一次判断に不可欠。 | **金属管（DIP/SP/LP）は音の伝播良好**。<br>**樹脂管（VP/PE）は減衰が大きく音が伝わらない**。大口径管も伝播不良。生活音・下水音等の誤認に注意。 |
| **電子式漏水発見器**<br>（路面音聴器） | 路面に集音ピックアップを接地し、地下漏水音をアンプで電気的に増幅・フィルタリングして聴取。 | 深小漏水音の増幅が可能。特定周波数の強調フィルターを搭載。 | 車両走行音や風切音、生活騒音の影響を受けやすいため、**静寂な夜間調査で威力を発揮**。 |
| **時間積分式漏水発見器**<br>（リークチェッカー） | メーターボックス内の給水管に十数秒間センサーを当てるだけで、音の定常性を内部解析。 | 専門知識や音聴熟練度が不要。LED等の合否判定で迅速。 | 一次スクリーニングに多用。確定診断には二次探査が必要。 |
| **相関式漏水探知器**<br>（2点相関法） | 疑い区間の両端（仕切弁等）に2基の高感度振動センサーを設置し音波到達の時間差を測定。 | 騒音下でもピンポイントで漏水位置を逆算可能。非掘削特定。 | 管長、管種（音速データ）、口径の正確な入力が必要。樹脂管では長距離伝播が困難。 |
| **多点相関調査法**<br>（ロガー型相関方式） | 数十基の超小型無線ロガーを一斉配置し、深夜帯に同時収録したデータをクラウド自動相関。 | 広域スクリーニングを完全自動化・無人化（NB-IoT通信）。 | 機器導入コスト、通信環境、ロガー設置・回収の手間。 |
| **トレーサーガス式探知器** | 管内にヘリウムガスを注入し、漏水部から地表へ染み出る微量ガスをセンサー検知。 | 音が出ない微小漏水や非金属管、大深度管路でも特定可能。 | **世界的なヘリウムガス不足により調達・運用が制限**。管内排水が必要。 |
| **管路探知器** | 金属管：**電磁誘導法**（微弱電流磁界探知）<br>非金属管：**打撃音波法**（パルス打撃音波伝播） | 図面不備の不明管や位置ズレ管路の埋設位置・深度を地上から特定。 | 誘導電流の回り込み（他管誤認）や、土質・深度による音波減衰に留意。 |

## 3. 漏水調査・修繕の体制と民間委託・契約実務（テキスト p.348）

### (1) 調査・修繕記録の保存とアセットマネジメントへの活用

漏水調査や日々の緊急修繕の結果は、単に工事伝票として処理して終わらせるのではなく、**発生日時、詳細位置（GIS座標・オフセット寸法）、管種、口径、管齢、破損形態（亀裂・腐食・継手抜け）、土質、周辺環境などを詳細に記録・データベース化** する。
これらの蓄積データは、将来の漏水予測シミュレーションや、**管路健全度評価に基づく「更新優先度判定」の最も信憑性の高い根拠** として永久保存・利活用される。

---

### (2) 直営と民間委託の合理的役割分担（東京都水道局モデル）

膨大な給水栓を効率的に点検するため、業務の難易度に応じた官民分担が確立されている。

```
【漏水探査の官民ハイブリッド分担】
［一次スクリーニング（民間委託）］
  ・全戸メーター巡回調査（リークチェッカーによる簡易判定）
  ・多点相関ロガーの現場設置および回収
  └───→ 「漏水の疑いがある箇所（グレー判定）」を大量抽出。
            │
［二次探査・位置特定・修繕指示（直営熟練職員または直営指示）］
  ・音聴棒や電子式路面音聴器、2点相関式探知器を用いたピンポイント特定
  ・掘削箇所の決定、道路管理者・警察協議、年間単価業者への緊急発注
```

---

### (3) 突発修繕における契約実務（年間単価契約と起工前着手）

* **年間単価契約（実績払い）**:
  * 突発漏水に対して都度入札を行うことは不可能なため、あらかじめ土工、配管工、舗装本復旧等の工種別単価を決定した指定工事事業者と **「年間単価契約」** を締結しておく。
  * 現場で職員が修繕指示書を交付して即座に着工させ、工事完了後に出来高の実績検査を行って精算払いを行う。
* **緊急時の起工前着手（事後契約・事後議決）**:
  * 年間単価契約がない小規模自治体で大規模管路破断事故が発生した場合は、道路陥没や市民生活の危機を回避するため、**総務・契約管財部門の事前了解のもと「起工前着手」を行い、復旧工事を先行させた上で事後的に契約手続き・議決を行う** 運用ルールを庁内で確立しておく必要がある。

## 4. 予防的漏水防止対策（テキスト p.348〜350）

漏水が起きてから修理する「対症療法」に対し、最も投資対効果が高く根本的な解決策が「予防的対策（未然防止）」である。

```
【予防的漏水防止対策の体系】
① 管路の改良・更新 ──── 耐震管（NS/GX形）化、波状ステンレス鋼管化、ポリスリーブ防食。
② 給水管の整理統合 ──── 私道内配水小管（φ50〜75mm）の布設と長距離引き込み解消。
③ 道路の両側配水 ────── 重交通幹線道路におけるダブル配管（車道横断給水管の解消）。
④ メーター境界配置 ──── 官民境界から1m以内の道路近傍設置（点検・修繕容易化）。
⑤ 不用給水管の撤去 ──── 解体・休止給水管の本管分岐部からの完全撤去・切離し。
⑥ 他企業工事立会い ──── ガス・下水・電線管掘削時の事前協議と現場立会指導。
```

### (1) 管路の改良・更新と防食

* **配水管**:
  * 離脱防止性能を備えた耐震ダクタイル鋳鉄管（NS形・GX形）への計画的更新。
  * 腐食性土壌（沖積低地や埋立地）における **ポリエチレンスリーブ（厚さ約 $0.2\text{ mm}$）の装着被覆** の徹底。
  * 構造物境界や軟弱地盤境界への可とう伸縮管の配置。
* **給水管**:
  * 漏水原因の大多数を占める老朽鉛管、亜鉛めっき鋼管、硬質塩化ビニル管を全廃し、**耐食性・耐震性・柔軟性に優れる「波状ステンレス鋼管」** へ更新。

### (2) 給水管の整理統合（私道内配管の布設替）

* **課題**:
  * 私道の奥にある複数世帯に対して、公道の配水本管から細い給水管（$\phi 20 \sim 25\text{ mm}$）が何十メートルも並行して長距離埋設されている路線は、継手や管体の腐食・漏水リスクが極めて高い。
* **抜本改善策**:
  * 私道内に公費等を用いて **口径 $50 \sim 75\text{ mm}$ の「配水支管（配水小管）」を中央に1本布設** し、管末に排水栓を設ける。
  * 各戸への給水管をこの配水小管から最短距離で直角に分岐し直す（整理統合する）ことで、総延長と継手数を激減させ、漏水を根絶する。

### (3) 道路の両側配水（ダブル配管）

* 幅員の広い幹線道路において片側歩道下にしか配水管がない場合、反対側の需要家へ給水するために長大な給水管が車道を横断することになる。
* 大型車の激しい交通荷重や道路掘削によって車道横断給水管が頻繁に破断・漏水するため、**道路の両側歩道下にそれぞれ配水管を布設（両側配水）し、車道を横断する給水管を全廃** する。

### (4) 水道メーターの境界付近設置と不用給水管の撤去

* **メーターの境界配置**:
  * 水道メーターが民地奥深く（中庭や建物の裏手等）にあると、道路境界からメーターまでの配管延長が長くなり、地下漏水が長期にわたり放置される原因となる。
  * そのため、**給水条例等に基づき、水道メーターを官民境界から $1\text{ m}$ 以内の点検・修繕が容易な場所へ適正配置** する。
* **不用給水管（休止管）の完全撤去**:
  * 建物の解体や空き家化によって水を使用しなくなった給水管を宅地側で栓止めしたまま残置すると、道路下の老朽管に常時水圧がかかり続け、重大な路上漏水や道路陥没を引き起こす。
  * そのため、**道路内の配水本管からの分岐箇所（サドル分水栓部等）で完全に掘削・撤去し、穿孔部をプラグ止め（縁切り）** する。

### 【第1のポイント】送水管と配水管の機能分離（テキスト p.271）

```
★ 講義指定文（正誤・選択肢頻出）：
「送水管の途中から配水管（または給水管）を分岐して、給水区域内に直接給水することは、やむを得ない場合を除き避けるべきである。」
```

* **理由・解説**:
  * 送水管は浄水場から配水池へ「定量（1日最大給水量基準）」を安定輸送するための管路である。
  * 送水管から直接需要家へ給水（直配）すると、地域の時間的需要変動（時間最大配水量）の影響を直接受けてしまい、水圧低下を防ぐために送水ポンプを過大加圧運転しなければならなくなる。
  * その結果、水圧管理が極めて困難になり、エネルギー効率が著しく低下し、事故時の影響も広範囲化するため、機能分離が鉄則である。（※「積極的に直配すべきである」は誤り）

---

### 【第2のポイント】導水路の流速規定（テキスト p.279）

```
★ 講義指定数値（数値穴埋め・正誤頻出）：
・最大流速： 毎秒 3.0 m 以下 （水路内面の摩耗を防止するため）
・最小流速： 毎秒 0.3 m 以上 （水路内に土砂や浮遊物が沈殿・堆積するのを防止するため）
```

* **覚え方**:
  * **「最大 $3.0\text{ m/s}$、最小 $0.3\text{ m/s}$」**（3と0.3の組合せ）。これ以外の数値（例：最大 $5.0\text{ m/s}$ や最小 $0.05\text{ m/s}$ 等）はすべて誤り。

### 【第3のポイント】消火栓の多面的機能と維持管理（テキスト p.289）

```
★ 講義指定文（正誤頻出）：
「消火栓は消防水利としてはもとより、水圧・水質の測定、洗管排水、管内状況調査など多様な役割を担う設備である。したがって、常時その機能が十分に発揮できるよう適切に維持管理・整備しておく必要がある。」
```

* **理由・解説**:
  * 消火栓は単なる火災時の消防用設備にとどまらず、末端水圧測定、残留塩素測定、新設管の洗管・排水、内視鏡カメラによる管内調査など、水道管網の日常的な維持管理に不可欠な多目的アクセス口である。
  * 「消防専用設備であるため水道事業者が維持管理する必要はない」等の記述は完全な誤り。

### 【第4のポイント】管路更新におけるアセットマネジメント（テキスト p.296）

```
★ 講義指定文（正誤頻出）：
「管路の更新には多額の費用と長期にわたる工事期間が必要となるため、アセットマネジメントによる実践活動が求められる。すなわち、施設の重要度、健全度、耐震性能などを総合的に評価し、財源的な裏付けのある更新計画を策定し、計画的かつ継続的に管路を更新していくことが重要である。」
```

* **理由・解説**:
  * 水道資産の7割以上を占める管路を一度に更新することは財政的・物理的に不可能である。
  * したがって、管路の重要度（基幹管路、病院・避難所供給管路）、健全度（経年、漏水履歴、土壌腐食度）、耐震性能を総合評価し、中長期的な財源収支計画と一体となった更新計画を策定して、計画的・平準的・継続的に更新を進めることがアセットマネジメントの真髄である。

---

### 【第5のポイント】高台・末端部の出水不良と増圧ポンプ（テキスト p.311）

```
★ 講義指定文（穴埋め・用語選択頻出）：
「広範囲に設定した配水区域の末端部や、高台の地域などにおける水圧低下による出水不良に対しては、管路の途中に『増圧ポンプ』を設置する。この場合、配水区域内の管本体や給水装置が昇圧に耐えられるかを事前に確認する。」
```

* **理由・解説**:
  * 高台や末端部の水圧不足を解消するために管路の途中に設ける設備は **「増圧ポンプ（ブースターポンプ）」** である（減圧弁や空気弁、緊急遮断弁に置き換えられたダミー選択肢に注意）。
  * 増圧ポンプの設置に際しては、下流側の管路や各家庭の給水装置（配管・パッキン・給湯器等）が高くなった水圧に耐えられる耐圧性能を有しているかを必ず事前調査・確認しなければならない。

---

### 【第6のポイント】漏水防止対策の3分類（テキスト p.339）

```
★ 講義指定文（穴埋め・分類選択頻出）：
「漏水防止対策は、漏水量などを把握するための『基礎的調査』、地上・地下の漏水に直接対応する『対症療法的対策（漏水防止作業）』、漏水を未然に防止する『予防的対策』の3つに大別される。」
```

* **キーワードの対応表**:
  1. **基礎的調査**: 漏水量の把握、水圧測定、夜間最小流量測定。
  2. **対症療法的対策（漏水防止作業）**: 
     * **機動作業**: 地上漏水の通報対応・即座の修理。
     * **計画作業**: 地下に潜む不可視漏水の音聴探査・計画修理。
  3. **予防的対策**: 耐震管更新、給水管波状ステンレス化、ポリスリーブ装着、他企業工事立会い（漏水の未然防止）。

## 6. 【問題作成のための重要ポイント・キーナンバーまとめ】

クイズ・ドリル問題作成時（出題・選択肢・誤答作成）に直結する必須キーデータ一覧です。

| 項目 | 重要数値・定義・基準 | 試験・ドリル出題ポイント |
| :--- | :--- | :--- |
| **調査区画の規模** | **管路延長 $1 \sim 3\text{ km}$ 程度を標準** | 適正な流量変化把握と弁管理作業のバランス |
| **夜間最小流量測定時刻** | **深夜帯（午前2時〜3時頃）の無用時間** | 水使用ボトム値＝当該区画の漏水量判定 |
| **漏水水質判定（現場）** | **遊離残留塩素（DPD法） ＋ 電気伝導率（導電率）** | 地下水・下水（高導電率）と通常水道水の識別 |
| **漏水水質判定（精密）** | **「トリハロメタン」の有無検査** | 土壌通過で残塩消失時でも確実に水道水と断定 |
| **音聴棒の伝播特性** | **金属管は伝播良好、樹脂管は減衰大で伝播不良** | 管種による音聴難易度（大口径管も伝播不良） |
| **電子式路面音聴器** | **特定周波数の電気的増幅・夜間調査で威力** | 生活騒音や車両騒音の少ない時間帯の活用 |
| **リークチェッカー** | **十数秒の内部解析・一次スクリーニング用** | 熟練不要の給水管漏水判定ツール |
| **相関式漏水探知器** | **2点センサーの音波到達時間差から位置逆算** | 騒音下での非掘削ピンポイント位置特定 |
| **トレーサーガス工法** | **ヘリウムガス注入地表探知（世界的不足で制限）** | 音の出ない微小漏水・非金属管路の特定 |
| **管路探知器の方式** | **金属管：電磁誘導法、非金属管：打撃音波法** | 不明管・位置ズレ埋設管の地上探知技術 |
| **官民業務分担** | **一次スクリーニング委託 $\rightarrow$ 二次特定・修繕直営** | 膨大給水栓の効率的スクリーニング体制 |
| **突発修繕の契約** | **「年間単価契約」（実績精算）と「起工前着手」** | 道路陥没防止のための緊急即時着工ルール |
| **給水管の整理統合** | **私道内に配水小管（$\phi 50 \sim 75\text{ mm}$）を布設替** | 長距離並行給水管の解消と最短直角分岐 |
| **道路の両側配水** | **幹線道路両側歩道下配水（ダブル配管）** | 重交通車道を横断する給水管の全廃 |
| **水道メーター配置** | **官民境界から $1\text{ m}$ 以内の道路近傍** | 点検・修繕容易化と長距離民地配管の排除 |
| **不用給水管の撤去** | **配水本管からの分岐部で完全撤去・プラグ止め** | 解体休止管の残置による潜在的漏水の撲滅 |
| **【最重要1】送水管直配** | **送水管からの直接分岐給水は「原則禁止」** | 一定輸送 vs 変動直配の過大加圧不合理を排除 |
| **【最重要2】導水路流速** | **最大 $3.0\text{ m/s}$ 以下、最小 $0.3\text{ m/s}$ 以上** | 内面摩耗防止（最大）と土砂沈殿防止（最小） |
| **【最重要3】消火栓機能** | **消防水利だけでなく水圧水質・洗管・調査の多目的** | 単なる放水設備ではなく日常維持管理の基幹設備 |
| **【最重要4】管路更新AM** | **重要度・健全度・耐震性の総合評価と財源裏付け** | 一括更新不可に伴う計画的・継続的更新推進 |
| **【最重要5】出水不良対策** | **末端・高台へ「増圧ポンプ」設置＋昇圧耐圧確認** | 減圧弁等との混同防止、管体・給水装置の耐圧確認 |
| **【最重要6】漏水防止体系** | **①基礎的調査、②対症療法的対策、③予防的対策** | 3大区分の定義・具体策（機動・計画・予防） |

## 7. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：漏水水質判定技術）
* **問題形式**: `choice`
* **問題文**: 道路上に湧出した水が水道管からの漏水であるかを判定する試験手法に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 地層浸透で残留塩素が消失した場合はトリハロメタン検査で水道水と断定する
  2. 残留塩素が検出されない水は土壌性状に関わらず100%自然湧水と判定する
  3. 水道水の電気伝導率は下水や一般的な地下水と比較して著しく高い値を示す
  4. 現場でのDPD試薬による遊離残留塩素測定は土壌成分の影響を全く受けない
* **正解**: 1（インデックス: 0）
* **解説**: 水道水が地層を浸透する過程で土壌の還元物質等により残留塩素が消失することがあります。この場合、浄水消毒の副生成物であるトリハロメタンの有無を検査することで、微量でも検出されれば確実に水道水由来であると科学的に断定できます。下水や地下水は塩類が多く電気伝導率が高くなります。
* **日常のたとえ**: 消毒液の塩素の匂いが土に触れて消えてしまっても、水道水にしか含まれない「特有の指紋（副生成物）」を精密検査で見つけ出し、雨水や地下水と見分ける手法です。
* **出典**: 講義テキスト 導送配水施設及び漏水防止 p.344

### 設問2（4択：漏水探査機器の特性）
* **問題形式**: `choice`
* **問題文**: 各種漏水探査機器の原理および音の伝播特性に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 音聴棒による漏水音はダクタイル鋳鉄管に比べ樹脂管の方が減衰が著しく大きい
  2. 音聴棒は配水管の口径が大きくなるほど漏水振動が遠くまで明瞭に伝播する
  3. 電子式漏水発見器は昼間の激しい交通騒音や風切音が存在する環境で最も威力を発揮する
  4. 時間積分式漏水発見器は給水管の漏水確定診断用であり一次スクリーニングには使用しない
* **正解**: 1（インデックス: 0）
* **解説**: 音聴棒による振動伝播は、金属管（ダクタイル鋳鉄管や鋼管等）では良好ですが、硬質塩化ビニル管やポリエチレン管等の樹脂管では管体の弾性により振動減衰が著しく大きく、遠くまで伝わりません。また口径が大きいほど伝播が困難になります。電子式路面音聴器は騒音の少ない夜間に威力を発揮します。
* **出典**: 講義テキスト 導送配水施設及び漏水防止 p.344〜346

### 設問3（4択・否定形：予防的漏水防止対策）
* **問題形式**: `choice`
* **問題文**: 漏水の発生を未然に防止するための「予防的対策」に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 私道内の漏水を防ぐため各戸への細い給水管を本管から並行して長距離配管する
  2. 重交通幹線道路では車道横断給水管を解消するため道路の両側配水を実施する
  3. 水道メーターは漏水の早期発見や修繕のため官民境界から1m以内に配置する
  4. 解体や空き家化に伴う不用給水管は配水本管からの分岐部で完全に撤去する
* **正解**: 1（インデックス: 0）
* **解説**: 私道奥への長距離並行給水管は漏水リスクを著しく高めるため、私道内に口径 $50 \sim 75\text{ mm}$ の配水支管（小管）を布設し、各戸の給水管を最短距離で分岐し直す（整理統合する）のが正しい予防対策です。両側配水、メーター境界1m以内配置、不用給水管の本管分岐部撤去はすべて適切な予防対策です。
* **出典**: 講義テキスト 導送配水施設及び漏水防止 p.348〜350

### 設問4（4択：総復習・導水路流速と水運用基準）
* **問題形式**: `choice`
* **問題文**: 水道施設設計指針等に定める導水路の流速規定および水運用に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 導水路の流速は摩耗防止のため最大3.0m/s以下、沈殿防止のため最小0.3m/s以上とする
  2. 送水管の途中から配水管を直接分岐して給水区域へ給水することは積極的に推奨される
  3. 配水池の有効容量は給水区域の需要変動を吸収するため計画1日最大給水量の1時間分とする
  4. 導水路の流速は建設費を縮減するため最大毎秒10m以上となる急勾配に設計する
* **正解**: 1（インデックス: 0）
* **解説**: 導水路の流速規定は、水路内面の摩耗を防ぐため「最大 $3.0\text{ m/s}$ 以下」、土砂沈殿堆積を防ぐため「最小 $0.3\text{ m/s}$ 以上」と定められています（★最重要ポイント第2）。送水管からの直接分岐は過大加圧を招くため原則禁止であり（★第1）、配水池の有効容量は「12時間分以上」が標準です。
* **出典**: 講義テキスト 導送配水施設及び漏水防止 p.271, 279, 325

### 設問5（4択：総復習・出水不良対策と消火栓機能）
* **問題形式**: `choice`
* **問題文**: 水道維持管理指針等に基づく配水管理および消火栓の機能に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 配水区域末端や高台の出水不良に対しては増圧ポンプを設置し管路耐圧を確認する
  2. 高台地域で水圧が不足して出水不良が生じている管路には減圧弁を設置して昇圧を図る
  3. 消火栓は消防専用施設であるため水道事業者が水圧測定や洗管清掃に用いてはならない
  4. 管路更新は財源に関わらず健全度のみを評価して全配水管を一括して同時更新する
* **正解**: 1（インデックス: 0）
* **解説**: 配水区域末端や高台の出水不良に対しては管路途中に「増圧ポンプ」を設置し、管本体や給水装置の耐圧性能を事前確認します（★最重要ポイント第5）。減圧弁は水圧を下げる設備です。消火栓は水圧・水質測定や洗管等に多目的に活用する維持管理基幹設備であり（★第3）、更新はアセットマネジメントにより計画的・継続的に進めます（★第4）。
* **出典**: 講義テキスト 導送配水施設及び漏水防止 p.289, 296, 311
