## 1. 水道事業者の使命と機械・電気設備の基本的役割（テキスト p.487）

### (1) 水道事業者の使命と三位一体のマネジメント
水道事業者の根幹たる使命は、**「安全で良質な水道水（安全で美味しい水）を、いかなるときも止めることなく常時安定して給水すること（安定供給の確保）」**に尽きる。

この至上命題を実現・継続するためには、以下の3つの要素が三位一体となって効果的かつ継続的に実施されなければならない。
1. **水道経営（経営管理）**: 健全な財政基盤と適正な料金水準の維持
2. **施設維持管理**: 日常の確実な運転操作・点検保全
3. **施設計画・更新**: 将来の需要見通しとアセットマネジメントに基づく計画的投資

```
【水道事業者の至上命題と三位一体のマネジメント】
                ┏━━━━━━━━━━━━━━━━━━━━┓
                ┃  安全で良質な水の安定供給  ┃
                ┃    （止めることなく提供）    ┃
                ┗━━━━━━━━━━━━━━━━━━━━┛
                            ▲
                            │ 支える3大基盤
        ┌───────────────────┼───────────────────┐
        ▼                   ▼                   ▼
   ［水道経営］       ［施設維持管理］      ［施設計画・更新］
   独立採算・財政     機械・電気・水質管理   耐震化・長寿命化
```

---

### (2) 機械・電気設備の位置づけと重要性
現代の水道システムにおいては、取水から貯水、導水、浄水処理、送配水、給水に至るすべてのプロセスにおいて機械化・自動化が高度に進展している。

* **機械設備と電気設備の機能分担**:
  * **機械設備**: 取水、送水、薬注、攪拌、沈殿掻寄せ、ろ過、排水処理などの**物理的・化学的動作を直接担う設備**（ポンプ、バルブ、ブロワ、オゾン発生器、掻寄機等）。
  * **電気設備**: これらの機械設備を安全・確実に稼働させるための**動力エネルギー供給および制御を担う設備**（受変電設備、配電設備、自家発電設備、監視制御設備等）。
* **計装設備との連動**:
  * 計測・制御を担う計装設備（センサー、テレメーター、PLC等）と一体不可分に機能することで、水道システム全体の自動運転・遠隔監視が成立している。
* **事故・故障の影響の甚大さ**:
  * 機械・電気設備は水道運用の「心臓部（中核）」であるため、一箇所の故障や停電・事故が直ちに**広範囲の断水、減水、または水質異常**を引き起こし、市民生活や都市機能に壊滅的な影響を及ぼす。
  * したがって、設備の高い信頼性確保と適切な維持管理が不可欠である。

---

### (3) 「装置産業」としての水道とエネルギー運用
水道施設は典型的な**「装置産業」**であり、膨大な機械・電気設備が24時間365日連続稼働している。

* **電力消費の規模**:
  * 水道施設を稼働させるためには莫大な電気エネルギーを消費する。日本の水道事業における年間消費電力量は、**全国総電力消費量の約0.8%**（2023年実績）に達する。
  * 水質基準の強化や高度浄水処理（オゾン・生物活性炭、粉末活性炭、紫外線等）の導入に伴い、水処理負荷と電力使用量は増加傾向にある。
* **経済的な電力運用の必要性**:
  * 効率的な機器運転、ピークカット（最大電力抑制）、夜間電力シフト、高効率機器の導入など、経済的かつ環境負荷の少ない電力運用計画の策定・実践が強く求められる。

---

### (4) 水道施設の代表的機械・電気設備（東京都水道局等の実例）

```
【水道施設における主要機械・電気設備プロセス】
［水源・取水］ ──→ ［浄水処理（沈殿・高度処理）］ ──→ ［受変電・動力］ ──→ ［送配水］
  ・取水塔              ・高速凝集沈殿池掻寄機          ・特別高圧受変電       ・送水ポンプ
  ・取水ゲート            ・オゾン発生器（ブロワ等）       （154kV→6.6kV）       ・配水ポンプ
```

* **村山・山口貯水池（取水塔・機械設備）**:
  * 貯水池から原水を取り入れる取水ゲート・取水弁等の機械設備。取水された水は導水路を経て浄水場へ送られる。
* **金町浄水場 高速凝集沈殿池（掻寄機・機械設備）**:
  * 凝集剤によって形成されたフロックを短時間で沈降分離させる池。
  * 池底に沈殿した高濃度のスラッジ（泥）を連続的または間欠的に集泥・排出するための**スラッジ掻寄機（スクレーパー）**などの大型機械設備から構成される。
* **金町浄水場 オゾン発生器（高度浄水処理設備・機械/電気複合）**:
  * オゾンの強力な酸化作用により、トリハロメタン前駆物質の低減やカビ臭物質（ジェオスミン、2-MIB）の分解を行う設備。
  * オゾン発生機本体（無声放電管）、原料空気を供給する**空気ブロワ**、水分を除去する**除湿装置（乾燥装置）**、排オゾン分解器等から構成される。
* **金町浄水場 受変電設備（特別高圧電気設備）**:
  * 電力会社から**特別高圧（154,000V＝154kV）**で受電。
  * 所内の変圧器（トランス）により**高圧（6,600V＝6.6kV）**等へ降圧し、場内の各大型ポンプや動力盤・電動機へ安全に配電する。
* **金町浄水場 送配水ポンプ設備**:
  * 浄水池の水を域外の各給水所へ圧送する「送水ポンプ」および、近隣配水区域の管網へ直接圧送する「配水ポンプ」。
  * 大容量電動機（モーター）と渦巻きポンプ・斜流ポンプ等から構成され、水道施設内で最も大量の電力を消費する。

## 2. 維持管理の目的と基本姿勢（テキスト p.488〜489）

### (1) 維持管理の至高目的
機械・電気設備を維持管理する目的は、**「安全で良質な水道水の安定供給を確保すること」**の1点に集約される。

この目的を達成するためには、個々の機器の構造・性能・特性を深く理解するだけでなく、**水道システム全体を俯瞰した総合的な運転管理・保全管理**を展開しなければならない。

---

### (2) システム化と冗長性（バックアップ機能）
近年の水道施設は自動化・広域化が進み、個々の機器が単体・独立して動くのではなく、取水から末端給水栓に至るシステム全体が密接に連動して機能している。

* **単体信頼性からシステム信頼性へ**:
  * 個別の機器信頼性を高めることは当然であるが、それだけでは万一の突発事故や災害を防ぎきれない。
* **冗長性（二重化・バックアップ機能）の確保**:
  * ポンプ、受電系統、計装制御系などの重要機器を**二重化（常用＋予備）**または**多重化**し、片肺運転や瞬時切替が可能なバックアップ機能を構築する。
* **施設能力の余裕度と相互融通**:
  * 施設能力に一定の余裕度を持たせるとともに、他浄水場や隣接事業体との**水系間連絡管（相互融通）**を活用し、機器停止時でも給水停止を招かないシステム構成とする。
* **費用対効果（LCC）の勘案**:
  * 無制限に冗長性を高めることは莫大なコスト増を招くため、設備の重要度・リスクに応じた費用対効果の高い運転管理・保全計画を策定する。

---

## 3. 運転管理と保全管理の基本原則（テキスト p.489〜490）

### (1) 運転管理の目的とデータ活用
水道施設における機械・電気設備の運転管理とは、**「水量・水圧・水質」の3大指標を常に適正範囲に保持し続けること**を目的とする。

```
【運転管理の3大管理目標】
① 水量管理 ──── 需要変動に応じた過不足ない取水・浄水・送配水のコントロール
② 水圧管理 ──── 給水末端で必要水圧（動水圧0.15MPa以上等）を確保し、過大水圧・水撃を防止
③ 水質管理 ──── 混和・沈殿・ろ過・消毒工程を最適制御し、水質基準完全適合を維持
```

* **運転記録データのフィードバック**:
  * 日々の流量、圧力、水質、電力消費量、運転時間のデータを解析し、制御目標値（設定値）を適宜見直す。
* **保全・更新計画への反映**:
  * 点検記録や故障履歴を蓄積・分析し、合理的な運転計画や設備の修繕・更新計画の策定に反映させ、経済性の高い管理を実現する。

---

### (2) 自動化の進展と「人間の役割（現場力）」
近年の水道設備はコンピュータ制御による全自動化・遠隔監視が普及しているが、**「すべてを機械・自動システム任せにしてはならない」**という鉄則がある。

* **異常時・突発事態への対応主体は「人間」**:
  * システムの誤作動、落雷による制御器故障、激甚災害による停電・通信途絶などの異常事態において、最終的に的確な判断を下し、物理的に操作を行うのは**現場の運転員・技術者（人間）**である。
* **手動操作マニュアルの整備と訓練**:
  * 自動制御機能が喪失した場合を想定し、**現場での「手動操作（手動運転）」への切替手順マニュアル**を整備する。
  * 定期的な**異常時対応訓練（実地訓練・机上シミュレーション）**を反復実施し、現場職員の緊急対応能力を維持・向上させる。
* **運転部門と保全部門の連携**:
  * 機器の点検状態、劣化状況、整備スケジュールなどの保全情報を、運転員へ常時フィードバック・共有する体制を確立する。
* **五感による異常兆候の早期発見**:
  * 日常点検において、計器数値（電流値・温度・圧力）の監視のみならず、異音、振動、異臭、油漏れ、発熱などを五感で察知し、異常の初期兆候を見逃さない観察力を養う。

## 4. 保全管理の手法と分類体系（テキスト p.490〜491）

保全管理（メンテナンス）は、実施のタイミングと目的によって大きく**「予防保全」**と**「事後保全」**の2つに大別される。

```
【保全管理の分類体系図】
保全管理
  ├─ 予防保全（故障の未然防止）
  │    ├─ 時間計画保全（TBM: Time-Based Maintenance）
  │    │    ├─ 定期保全（一定周期で点検・分解手入れ）
  │    │    └─ 経時保全（規定稼働時間・年数で部品・機器を定期交換）
  │    │
  │    └─ 状態監視保全（CBM: Condition-Based Maintenance）
  │         └─ 設備診断技術（振動・温度・絶縁抵抗等の計測データに基づく予知保全）
  │
  └─ 事後保全（故障発生後の処置）
       ├─ 緊急保全（給水支障・二次災害防止のため至急復旧）
       └─ 通常事後保全（予備機切替等により、計画的に部品調達・修理契約を実施）
```

---

### (1) 予防保全（Preventive Maintenance: PM）
機器の故障・停止を未然に防止し、設備の初期性能・安全性を維持するために計画的に行う保全活動。

#### ① 時間計画保全（Time-Based Maintenance: TBM）
* **特徴**:
  * 過去の実績、経験則、メーカー推奨基準に基づき、**カレンダー周期（1年、3年等）や積算運転時間（例：10,000時間等）を基準として一律に点検・整備・部品交換を行う方式**。
  * 全国の大半の水道事業体で従来から主流として採用されてきた手法。
* **具体例**:
  * 電気計装部品（リレー、電解コンデンサ、バッテリー等）の3〜5年ごとの定期交換。
  * ポンプ・モーターのグランドパッキンや潤滑油の定周期交換。
* **メリットと課題**:
  * メリット：計画が立てやすく、確実な故障防止が期待できる。
  * 課題：機器ごとの使用環境や負荷の差異を無視して一律交換するため、まだ十分に使える部品を廃棄する**「過剰保全（オーバーメンテナンス）」**に陥りやすく、維持管理コストが増大する。

#### ② 状態監視保全（Condition-Based Maintenance: CBM）
* **特徴**:
  * 設備診断技術や各種センサーを用い、機器の物理的・電気的状態（振動、発熱、絶縁状態、油中摩耗粉等）を**継続的または定期的に測定・監視し、劣化の兆候が現れた段階で最適な補修・部品交換を行う方式（予知保全）**。
* **具体例**:
  * 大型送水ポンプの軸受振動測定（FFTアナライザーによる周波数分析）。
  * 高圧電動機・変圧器の絶縁抵抗・部分放電測定、絶縁油ガス分析。
* **効果**:
  * 部品の寿命限界（安全限界）まで使用できるため、**設備寿命の延伸（延命化）**と**維持管理費（LCC）の大幅な削減**を両立できる。

---

### (2) 事後保全（Corrective Maintenance / Breakdown Maintenance）
機器の機能低下または故障・停止が発生した後に、その修繕・復旧を行う方式。

#### ① 緊急保全（Emergency Maintenance）
* **特徴**:
  * 給水停止、水質汚染、感電・火災などの人身事故や二次災害に直結する突発故障に対し、**昼夜を問わず即時に緊急出動して復旧・修理を行う保全**。
  * 予備機のない単独重要設備や、基幹送配水系統の破断・全停電時などに適用される。

#### ② 通常の事後保全（Planned Corrective Maintenance）
* **特徴**:
  * 故障が発生しても、**直ちに待機予備機（バックアップ）へ自動切替または手動切替できる設備**において実施。
  * 直ちに給水支障や安全上の危険が生じないため、故障原因の究明、部品の調達、修繕工事契約などを計画的かつ合理的に進めて復旧を図る保全。

---

## 5. 設備システム管理と情報共有（テキスト p.491〜492）

### (1) システム管理の全体最適化とPDCAサイクル
水道施設の機械・電気設備管理は、個々の機器の点検にとどまらず、**「計画・設計 $\rightarrow$ 建設・導入 $\rightarrow$ 運転管理 $\rightarrow$ 保全管理 $\rightarrow$ 更新」に至る設備ライフサイクル全体をシステムとして総合評価**しなければならない。

```
【設備システム管理のPDCAサイクル】
［Plan: 計画・基準策定］ ──→ ［Do: 運転・点検実施］
        ▲                              │
        │                              ▼
［Action: 標準化・改善］ ──← ［Check: 評価・原因究明］
  ・保全周期・基準見直し          ・運転/故障記録の解析
  ・設計部門へのフィードバック    ・LCC・信頼性評価
```

* **管理プロセスの標準化**:
  1. **現状把握・問題発見**: 日常監視・定期点検データから異常や劣化兆候を早期覚知。
  2. **原因究明・対策立案**: 故障の根本要因（設計、施工、操作、環境、材質）を究明し再発防止策を立案。
  3. **効果確認・標準化**: 対策の実施効果を検証し、標準作業手順書（SOP）や点検基準書に反映。
  4. **継続的改善（スパイラルアップ）**: システム全体の信頼性と経済性を継続的に向上。

---

### (2) 管理情報の一元化と部門間フィードバック
運転記録、日常点検結果、定期点検記録、故障・補修履歴などの**設備台帳・履歴データを一元的にデータベース化（共有化）**することが不可欠である。

* **現場運用における効果**:
  * 事故・故障発生時の迅速な復旧判断および二次災害の防止。
  * 故障の発生傾向や要因の多角的な統計分析。
* **設計・計画部門へのフィードバック（LCC最小化）**:
  * 保全履歴から「故障頻度の高い構造」や「点検作業性の悪い機器配置」などの課題を洗い出し、将来の施設更新や新設時の**設計仕様・計画部門へフィードバック**する。
  * これにより、初期建設費（イニシャルコスト）と長期維持管理費（ランニングコスト）を合算した**ライフサイクルコスト（LCC）の最小化**と施設信頼性の向上が実現する。

## 6. システム機能診断と設備診断技術（テキスト p.492〜493）

### (1) 定量的データに基づく機能診断
設備の劣化や寿命は、運転時間、負荷、温湿度、塵埃、起動停止頻度などの使用環境によって大きく左右される。しかし、時間経過とともに確実に老朽化が進行し、最終的には機能限界（寿命）に達する。

* **定量的計測データの活用**:
  * 従来の「勘や経験」に頼る点検から脱却し、**電気的特性（絶縁抵抗値、漏洩電流、部分放電等）や機械的特性（振動値、温度、摩耗量等）を計測機器によって数値化・定量的に追跡・トレンド解析**する。
* **管理限界での高精度保全**:
  * 機器が安全に稼働できる管理限界値（しきい値）を見極めることで、機能喪失直前の最適なタイミングで部品交換や補修を実施でき、極めて高い精度の保全が可能となる。
* **保全効果の評価指標**:
  * 年間修繕費の推移、機器故障率、稼働率、平均故障間隔（MTBF）、平均復旧時間（MTTR）などの統一的指標を確立し、保全の妥当性を客観的に評価する。

---

### (2) 設備診断技術の定義と3大要素技術
設備診断技術とは、**設備にかかるストレス、劣化度、強度、性能を定量的に把握し、将来の信頼性を予測・評価して、最適な保全措置を決定する技術体系**である。

```
【設備診断技術の3大要素】
① 状態把握のための「測定技術」 ── 各種センサー・計器による物理量・電気量の高精度計測
② 異常識別・将来予測の「解析・評価技術」 ─ 測定データのトレンド解析、異常要因の特定
③ 最適保全を決定する「保全判断技術」 ── 補修・交換・運転継続の時期と工法の決定
```

* **診断レベルの区分**:
  * **簡易診断技術**: 日常点検員が携帯型計測器等を用いて定期的に測定し、異常の有無を簡易スクリーニングする技術（振動計、表面温度計、聴診器等）。
  * **精密診断技術**: 簡易診断で異常が疑われた機器に対し、専門技術者が高度な測定器を用いて異常の原因、部位、危険度、残存寿命を詳細に究明する技術（FFT周波数分析、超音波探傷、油中金属分析等）。

---

### (3) バスタブ曲線（バスタブカーブ / 故障率曲線）
設備の運用時間経過に伴う故障発生率の推移を示す信頼性工学の基本モデルであり、その形状が西洋風呂（バスタブ）に似ていることから**バスタブ曲線（バスタブカーブ）**と呼ばれる。

```
【バスタブ曲線（故障率曲線）の3大領域】

  故障発生率 λ(t)
    ▲
 高 │ ＼                                                      ／ 破壊に至る
    │   ＼  初期不良期            偶発故障期             劣化・摩耗期
    │     ＼（初期故障領域）     （安定運用領域）        （摩耗故障領域）
    │       ＼                ┌───────────────┐     ／
    │         ＼              │               │   ／
 低 │           └─────────────┴───────────────┴─／
    └─────────────────────────────────────────────────────────► 時間 t
         ［運転開始直後］      ［平常運用期間］      ［耐用年数経過後］
```

* **① 初期故障領域（初期不良期）**:
  * 設備導入・試運転の直後。設計不良、製作上の欠陥、据付・組立不良、初期調整不足などにより、**運転開始直後に故障率が最も高い**。
  * 調整や不良部品の排除が進むにつれて故障率は急激に低下する。
* **② 偶発故障領域（安定運用領域）**:
  * 初期不良が解消した後の安定した稼働期間。故障発生率は**時間に関係なく低く一定（偶発故障）**となる。
  * 予期せぬ外部ストレスや突発的な要因によってのみ故障が発生する。
* **③ 摩耗故障領域（劣化・老朽化領域 / 注意・危険領域）**:
  * 長期間の運転により、部品の摩耗、金属疲労、絶縁劣化、腐食などの経年劣化が顕在化する期間。
  * **時間経過とともに故障発生率が急激に跳ね上がり**、放置すれば最終的に致命的な設備破壊に至る。
* **★ 設備診断技術の真髄**:
  * 設備が「安定運用領域」から「摩耗故障領域」へと移行する転換点を、**設備診断技術によって定量的に検知・把握し、破壊に至る前の適切なタイミングで保全・更新を実施すること**が維持管理の核心である。

## 7. 維持管理の最適化とVFM・ICT/AI活用（テキスト p.493〜494）

### (1) 維持管理の最適化とVFM（Value for Money）
* **予防保全重視の体制構築**:
  * 平常時の安定稼働だけでなく、地震・台風・突発事故などの異常時においても迅速かつ的確に対応できる体制を整備する。
* **施設全体のバランス評価**:
  * 機械・電気設備は、土木構造物（池・管路）や計装・通信設備と一体となって稼働する。個別機器の性能だけでなく、システム全体の整合性とバランスを正しく評価して維持管理計画を策定する。
* **VFM（Value for Money）の概念**:
  * **「支払うコスト（投資金額・維持管理費）に対して、最大の価値（機能・信頼性・効用）を獲得する」**というコスト意識。
  * 維持管理の投資対効果（成果・低減リスク）を可能な限り数値化・指標化し、事業評価を行う。

---

### (2) ICTおよびAIを活用した維持管理の展望と留意点
情報通信技術（ICT）の急速な発展に伴い、設備管理は従来の「ハードウェア単体の監視」から「高度な情報管理・ソフトウェア中心の統合運用」へと移行している。

* **ICT活用のメリット**:
  * クラウド、IoTセンサー、ビッグデータ解析による設備情報の一元化・体系化。
  * 巡回点検の自動化・効率化、遠隔監視による省力化。
  * 異常時の迅速な情報集約と的確な緊急対応支援。
* **★ AI活用の本質と水道技術者の責任主体性（重要論点）**:
  * 近年、機械学習やAIによる劣化予測・運転支援が導入されつつあるが、**「AIの判断や出力が常に正しいとは限らない」**。
  * AIは過去データのパターン認識に基づく確率的提示を行っているに過ぎず、未知の複合災害や異常水質において誤判断・見逃しを起こすリスクを常に内包している。
  * したがって、AIはあくまで強力な**「意思決定支援（サポートツール）」**として位置づけ、**最終的な運転判断、操作決定、およびその結果に対する責任を負う主体は、どこまでも「我々人間（水道技術者）」である**ことを強く自覚しなければならない。

## 8. 環境対策と省エネルギー運用（テキスト p.494）

### (1) 水道事業における環境問題の重要性
地球温暖化対策、温室効果ガス排出削減（脱炭素化）、廃棄物減量化、健全な水循環の維持は、現代の水道事業に課せられた重責である。

* **電力消費と環境負荷**:
  * 水道事業の電力消費量は全国総電力の約0.8%を占めるため、水道事業における省エネルギー対策は地域・国家レベルの脱炭素化に直結する。

---

### (2) 電力運用の最適化（ピークカット・夜間シフト）
水道事業における電気料金体系の多くは、デマンド電力（最大需要電力）に基づく基本料金と、使用電力量に応じた従量料金で構成される。

```
【電力運用の最適化手法】
① ピークカット（最大電力抑制） ── デマンド監視により契約電力（基本料金）を大幅削減
② 夜間シフト（負荷平準化） ──── 電力単価の安い夜間帯に配水池へ揚水・貯留
```

* **ピークカット（最大需要電力の抑制）**:
  * 1日の電力需要がピークに達する時間帯に、一部の大型ポンプの運転を停止・抑制し、配水池の貯留水を活用して自然流下給水を行う。
  * これにより最大電力を抑制し、**契約電力（電気基本料金）の大幅な削減**を実現する。
* **夜間シフト（電力需要の平準化）**:
  * 電力需要が少なく単価の安い夜間時間帯に送水ポンプを集中的に稼働させ、地域の配水池を満水にしておく。
  * 1日の電力負荷を平準化させるとともに、電力会社側の発電・送電設備の効率的運用にも寄与する。

---

### (3) ポンプ設備の省エネルギー制御方式
水道施設において最も大量のエネルギーを消費するのは**送配水ポンプ設備**である。したがって、ポンプの運転制御を適正化することが最大の省エネ効果を生み出す。

```
【ポンプ制御方式の比較】
① 回転速度制御（インバータ制御） ── ポンプ回転数を連続制御。流量変化に伴う動力ロスが最小（極めて省エネ）
② 台数制御 ──────────── 複数台のポンプを需要流量に応じて起動・停止制御
③ 弁制御（吐出弁絞り） ────── 吐出仕切弁を絞って流量調節。弁で圧力を捨てるためエネルギー損失大
```

* **回転速度制御（インバータ制御）の優位性**:
  * ポンプの軸動力は**回転速度の3乗に比例**する（相似則）。
  * 吐出弁を絞って流量を落とす「弁制御」は配管抵抗を人為的に増大させてエネルギーを熱として捨てるのに対し、「回転速度制御」は回転数そのものを下げるため、劇的な電力削減効果を発揮する。
* **最適な制御方式の選択**:
  * 配水系統の流量変動特性、高低差（実揚程）、台数構成を総合的に勘案し、最も経済的で安定した制御方式を採用する。

## 9. 設備更新とアセットマネジメント（テキスト p.494〜495, p.151）

### (1) コンクリート構造物と機械・電気設備の耐用年数スパン差
水道施設を構成する資産は、土木建築構造物と機械・電気設備でその物理的・経済的寿命が決定的に異なる。

* **コンクリート構造物の寿命**:
  * ダム、浄水池、沈殿池、配水池などのコンクリート構造物は、**50年〜60年、適切に維持管理すれば100年以上**の寿命を有する。
* **機械・電気設備の寿命**:
  * ポンプ、電動機、弁類、受変電設備、計装機器などの機械・電気設備は、連続稼働による摩耗や電気的絶縁劣化により、**おおむね15年〜20年前後**で寿命・更新時期を迎える。

---

### (2) 施設更新（土木建築）と設備更新（機電）の計画的整合（リンク）
アセットマネジメントにおいて最も重要な視点は、**「コンクリート構造物の更新時期と、内部の機械・電気設備の更新時期を計画的に同期・整合させること」**である。

```
【更新時期不整合による重大な経済的損失の回避】
［不整合の失敗例］
2025年: 大型機械設備を莫大な費用を投じて新品に更新
2028年: 施設本体（コンクリート構造物）が老朽化のため全体更新・解体撤去
  ➔ 更新したばかりの機械設備（残存耐用年数10年以上）を廃棄する重大な無駄が発生！

［あるべき計画的整合］
構造物の全体更新・改築時期を見据え、機械・電気設備の更新周期を前倒し・延命（保全強化）等で調整し、
施設全体の改築と同時に一括更新する計画を策定する。
```

* **情報の統合管理**:
  * 設置年度、仕様諸元、運転時間、点検結果、修繕履歴などの情報をデータベースで一元管理し、ライフサイクル全体で最も効率的かつ経済的な更新マネジメントを行う。

## 10. リスク管理と業務委託（テキスト p.495〜496）

### (1) 機械・電気設備におけるリスク要因の2大分類
水道施設の安定稼働を脅かすリスクは、「内的要因」と「外的要因」に分類される。

```
【リスク要因の2大分類】
① 内的要因 ── 施設内部で発生する事象
                ・機器の突発的故障・破損、電気系統の地絡・短絡
                ・運転員の誤操作、設定ミス、点検整備の不備
② 外的要因 ── 施設外部から襲来する事象
                ・地震、台風、集中豪雨・洪水、落雷などの自然災害
                ・電力会社からの商用電力の供給停止（広域停電）
                ・原水の油流出・水質異常、外部サイバー攻撃
```

* **リスクへの備え**:
  * 設備のハード対策（自家発電設備、2系統受電、耐震化、浸水防止かさ上げ、防液堤）。
  * ソフト対策（手動運転マニュアル、緊急連絡体制、定期的な実動防災訓練、人材育成・技術継承）。

---

### (2) 業務委託と第三者委託制度（水道法第24条の3）

#### ① 専門点検の個別業務委託
* 水道施設で使用される高圧・特別高圧受変電設備、大型自家発電設備、大型ポンプ・電動機、クレーン、ボイラー、消防設備などは、高度に専門的な計測技術や法定資格を要するため、多くの水道事業者が専門の検査機関や民間事業者に点検整備を**業務委託**している。

#### ② 第三者への包括的委託制度（2002年水道法改正）
2002年（平成14年）の水道法改正により、浄水場等の運転管理業務、保全管理業務、水質検査業務などを民間の第三者に包括的に委託できる**「第三者委託制度（水道法第24条の3）」**が創設された。

* **包括的委託（第三者委託）の契約上の明確化事項**:
  * 委託の目的、適用範囲
  * 受託者の技術的適格性、法令遵守義務
  * **責任とリスクの分担（事故発生時の損害賠償・復旧責任の範囲）**
  * 業務手順、定期報告および緊急時連絡体制
* **第三者委託のメリットとデメリット**:
  * **メリット**: 民間事業者が保有する高度な専門技術、最新ノウハウ、スケールメリット（コスト削減）を存分に活用できる。
  * **デメリット（深刻な課題）**: 運転管理を民間に全面依存することにより、**水道事業者側のプロパー職員に技術・ノウハウが蓄積・継承されず、将来的に技術力が空洞化・喪失するリスク**がある。
* **履行確認と成果のマネジメント**:
  * 包括的委託においては、単に「無事故で施設を回す」ことだけを求めるのではなく、**省エネルギーの推進、維持管理経費の節減、予防保全の適切な実施**といった目標責任を課す。
  * 業務指標（PI: Performance Indicator）を設定し、目標達成度や業務品質を客観的・定量的に評価・確認（モニタリング）することが重要である。

---

## 11. 水道技術管理者の責務（機械・電気設備分野）（テキスト p.496）

水道技術管理者は、水道法第19条第2項に基づき、水道の全施設における技術的業務を一手に統括・監督する最高技術責任者（CTO）である。機械・電気設備に関しても以下の重責を負う。

```
【水道技術管理者の機械・電気設備における主要職務】
① 平常時の運用把握 ────── 全施設の稼働状況・電力使用・保全状況を常時把握
② 緊急時の的確な指揮命令 ── 故障・事故・災害発生時、迅速に状況を判断し復旧を統制
③ 運転・保全の指導助言 ──── 運転員に対する技術的指導、点検整備基準の遵守徹底
④ 職員の教育・訓練推進 ──── 異常時手動操作訓練の計画・実施、技術継承の推進
⑤ 資格取得の奨励 ────── 電気主任技術者等の専門法定資格の取得支援・育成
⑥ 関係法令の完全遵守 ──── 電気事業法、高圧ガス保安法、消防法等の遵守体制統括
```

* **安全管理の徹底**:
  * 機械・電気設備は、高電圧、高圧流体、回転体、重量物などを取り扱うため、常に**感電、巻き込まれ、墜落、火災などの重大な危険**を伴う。
  * 労働安全衛生法に基づく安全教育や作業環境の維持、保護具の着用徹底を統括する。

## 12. 水道施設における機械・電気設備の関連法規（テキスト p.496〜498）

機械・電気設備の維持管理においては、水道法のみならず多岐にわたる国の法規・基準を厳格に遵守しなければならない。

```
【機械・電気設備に関連する4大法令体系】
① 電気事業法 ─────── 自家用電気工作物の保安、電気主任技術者の選任、事故報告
② 高圧ガス保安法 ───── 液化塩素取扱施設、製造許可・届出、危害予防規程
③ 消防法 ────────── 自家発電設備の燃料タンク（危険物）、火災予防条例
④ 省エネ法 ──────── エネルギー管理指定工場（1,500kL/年）、中長期計画・定期報告
```

---

### (1) 電気事業法（最重要法令）
電気設備に関する基本法であり、電気の供給および使用による災害の防止と安全確保を目的とする。

#### ① 電気工作物の分類と水道施設の位置づけ
電気事業法において、電気工作物は以下のように分類される。

```
【電気工作物の分類体系】
電気工作物
  ├─ 一般用電気工作物（低圧［600V以下］受電の一般住宅、小規模商店等）
  │
  └─ 事業用電気工作物
       ├─ 電気事業用電気工作物（電力会社等の発電・変電・送配電設備）
       │
       └─ 自家用電気工作物（★水道施設はこれに該当！）
            └─ 高圧（600V超〜7,000V以下）または特別高圧（7,000V超）で受電する需要設備、
               および一定規模以上の発電設備（太陽光、水力、自家発等）
```

* **水道施設は「自家用電気工作物」**:
  * 浄水場や送配水ポンプ所は、通常6,600Vの高圧または22,000V〜154,000Vの特別高圧で商用電力を受電するため、電気事業法上の**「自家用電気工作物」**に位置づけられる。
* **自主保安の原則**:
  * 自家用電気工作物の設置者（水道事業者）は、自らの責任において保安を確保しなければならない（自主保安体制）。
* **国の直接関与**:
  * 受電電圧が**10,000V（10kV）以上の特別高圧需要設備**の新設・改造工事を行う場合は、経済産業大臣（産業保安監督部長）への**工事計画の認可または届出**が必要となる。

#### ② 設置者（水道事業者）に義務づけられる3大要件
自家用電気工作物の設置者には、法令上以下の3つの義務が課せられる。

1. **技術基準適合維持義務**:
   * 電気工作物を、経済産業省令で定める「電気設備に関する技術基準」に適合するように維持しなければならない。
2. **電気主任技術者の選任義務**:
   * 工事・維持および運用の保安の監督を行わせるため、免状交付を受けている**電気主任技術者**を選任しなければならない。
   * 免状の区分（第1種：すべて、第2種：17万V未満、第3種：5万V未満）に応じた選任が必要。
   * 設置者は、電気主任技術者の保安に関する意見を**尊重しなければならない**。
3. **保安規程の制定・届出・遵守義務**:
   * 工事・維持・運用に関する保安を確保するため、**「保安規程」**を制定し、使用開始前に所轄の産業保安監督部長へ届け出なければならない。
   * 設置者およびその従業者は、保安規程を遵守しなければならない。

#### ③ 電気事故の報告義務（重要数値基準）
自家用電気工作物において、感電死傷事故、電気火災、主要電気設備の破損、他者へ停電を波及させた事故（波及事故）等が発生した場合は、所轄の産業保安監督部長へ報告しなければならない。

```
【電気事故報告の法定期限】
① 速報 ──── 事故の発生を知った時から「24時間以内」（電話・FAX・電磁的方法等）
② 詳報 ──── 事故の発生を知った日から「30日以内」（詳細報告書の提出）
```
> **★ 試験対策の急所**: 「速報＝24時間以内」「詳報＝30日以内」の数値と報告先（産業保安監督部長）は頻出重要事項である。

---

### (2) 高圧ガス保安法
高圧ガスによる災害を防止し、公共の安全を確保するための法律。

* **水道施設における適用対象**:
  * 浄水場等で消毒剤として**「液化塩素」**を使用・貯蔵している施設。
  * （※近年は安全性の観点から「次亜塩素酸ナトリウム」への切替が進んでいるが、液化塩素を取り扱う施設では本法が厳格に適用される）。
* **製造者の区分**:
  * **第1種製造者**: 1日の処理容積が**$100\text{ m}^3$（約300kg相当）以上**の事業所（都道府県知事の許可が必要）。
  * **第2種製造者**: 1日の処理容積が**$100\text{ m}^3$未満**の事業所（都道府県知事への届出が必要）。
* **保安体制の義務**:
  * 高圧ガス製造保安責任者の選任、危害予防規程の制定・届出、定期自主検査の実施。

---

### (3) 消防法
火災の予防・警戒・鎮火により、生命・身体・財産を保護するための法律。

* **水道施設における適用対象**:
  * 非常用自家発電設備や動力ポンプを駆動するための**燃料貯蔵施設（重油、軽油タンク等）**。
  * 蓄電池設備、変電設備、発電設備などの火気使用・電気設備。
* **危険物規制と火災予防条例**:
  * 燃料（軽油・重油）の貯蔵量が「指定数量」以上の場合は消防法に基づく**危険物製造所・貯蔵所・取扱所の許可**が必要。
  * 指定数量未満であっても、各市町村（消防本部）が定める**「火災予防条例」**に基づく届出・構造基準の遵守が必要となる。
  * 発電設備・蓄電池設備等を新設・改修する際は、必ず管轄の消防署と事前協議・届出を行う。

---

### (4) 省エネ法（エネルギーの使用の合理化及び非化石エネルギーへの転換等に関する法律）
内外のエネルギー情勢を踏まえ、事業者に対してエネルギー使用の合理化および非化石エネルギーへの転換を求める法律（1979年制定、2023年改正施行）。

* **トップランナー制度**:
  * ポンプ、変圧器、電動機、照明器具、建築材料等について、省エネ性能の優れた機器の選択・導入が求められる。
* **事業者の指定区分と義務**:
  * 事業者全体（企業単位）での年間エネルギー使用量によって特定事業者等に指定される。
* **第一種エネルギー管理指定工場等（事業所単位の基準）**:
  * 1つの浄水場等の事業所において、年間のエネルギー使用量（燃料・熱・電気）の合計が**原油換算で $1,500\text{ kL/年}$ 以上**である大規模施設。
  * **義務事項**:
    1. **エネルギー管理者（またはエネルギー管理員）**の選任
    2. **中長期計画書**の作成・提出（毎年度）
    3. **定期報告書**の提出（毎年度）

## 13. まとめ：機械・電気設備分野の重要キーワード一覧

水道技術管理者試験および実務において最重要となる概念・数値を一覧で整理する。

| 分野・区分 | 最重要キーワード | 具体的要点・数値基準・法的根拠 |
| :--- | :--- | :--- |
| **事業者の使命** | 安全で美味しい水の安定供給 | 経営、維持管理、計画の効果的・継続的実施が3本柱。 |
| **水道の特性** | 装置産業 | 全国総電力消費量の約0.8%を水道事業が消費。電力最適化が必須。 |
| **受変電設備** | 特別高圧受電 | 大規模浄水場（例：金町）では154kV受電 $\rightarrow$ 6.6kV降圧配電。 |
| **保全手法** | 予防保全（TBM vs CBM） | TBM＝時間計画（過剰保全の懸念）、CBM＝状態監視（設備診断、延命化・LCC削減）。 |
| **保全手法** | 事後保全 | 緊急保全（至急対応） vs 通常事後保全（予備機切替により計画対応）。 |
| **信頼性工学** | バスタブ曲線 | 初期故障期（低下） $\rightarrow$ 偶発故障期（安定・低水準） $\rightarrow$ 摩耗故障期（急上昇）。 |
| **投資評価** | VFM（Value for Money） | 支払うコストに対して最大の価値・効用を得る。維持管理成果の数値化。 |
| **ICT・AI** | 人間の責任主体性 | AIは支援ツール。判断の誤りがあり得るため最終責任・判断は人間が担う。 |
| **省エネルギー** | ピークカット・夜間シフト | 最大電力を抑制して契約電力を低減、夜間揚水で負荷平準化。 |
| **ポンプ制御** | 回転速度制御（インバータ） | 軸動力は回転数の3乗に比例。弁絞り制御に比べ圧倒的省エネ。 |
| **アセットマネジメント** | 寿命スパン差の整合 | コンクリート（50〜100年）と機電設備（15〜20年）の更新時期を計画的にリンク。 |
| **官民連携** | 第三者委託（水道法第24条の3） | 2002年法改正。包括的委託。技術継承の断絶が課題。PIによる履行確認。 |
| **電気事業法** | 自家用電気工作物 | 水道施設が該当。設置者の自主保安。10kV以上は国（経産省）への認可/届出。 |
| **電気事業法** | 設置者の3大義務 | ①技術基準適合維持、②電気主任技術者の選任、③保安規程の制定・届出・遵守。 |
| **電気事業法** | 電気事故報告期限 | **速報：24時間以内**、**詳報：30日以内**（産業保安監督部長宛て）。 |
| **高圧ガス保安法** | 液化塩素施設 | 処理容積 $100\text{ m}^3/\text{日}$ 以上＝第1種製造者（許可）、未満＝第2種（届出）。 |
| **消防法** | 自家発電・燃料タンク | 軽油・重油タンクは危険物規制。指定数量未満は火災予防条例に基づく届出。 |
| **省エネ法** | 第1種エネルギー管理指定工場 | 事業所単位で原油換算 **$1,500\text{ kL/年}$ 以上**。管理者選任、年1回報告。 |
