## 1. 事故処理基準と危機管理体制（テキスト p.315）

突発的な管路破損や大規模漏水事故が発生した際、被害を最小限に食い止め、二次災害を未然に防止するためには、明確な指揮命令系統と平時からの即応体制が不可欠である。

### (1) 指揮命令系統の徹底と初動の心構え

事故は夜間や休日、あるいは管理職が不在の時間帯に突然発生する。現場や事務所に最初に参集した職員がいかに迅速・的確に動けるかが初動の成否を分ける。

```
【非常時における指揮命令と行動原則】
① 現場責任者（指揮権）の代行順位の事前策定 ── 管理職不在時のお見合い・指示待ちを完全排除。
② 主体的な行動姿勢 ──────────── 指示を待つだけでなく、各自ができる役割を自ら見つけて即動。
③ システム・資機材の日常習熟 ────── 平常時に触っていないシステムは有事の極限状態では絶対に使えない。
```

* **現場責任者（指揮権）の代行順位の明確化**:
  * 所長や課長が不在の場合、「誰が現場の最高判断を下すのか」の代行序列（職務代理順位）をマニュアルで明確に定めておく。
  * これにより、行政組織特有の「誰が責任を持つのか」という遠慮やお見合いによる致命的なタイムロスを排除する。
* **マッピングシステム（管路情報GIS）の日常習熟**:
  * 事故直後、直ちに現場周辺の配水系統、管種、口径、バルブ位置を割り出す必要がある。
  * 普段設計や工務を担当していない職員であっても、緊急時に即座にマッピングシステムを操作して管路図面を検索・出力できるよう、定期的な操作研修・訓練を徹底する。

### (2) 応急復旧業者の確保と契約手続きの事前整理

* **修繕業者の常時確保（年間単価契約）**:
  * 東京都水道局をはじめとする主要事業体では、不断水穿孔や管路修繕に精通した指定工事事業者と **「年間単価契約（緊急復旧工事単価契約）」** を締結している。
  * 夜間・休日の緊急出動に対応できるよう、事業者を **「待機輪番制（当番制）」** で配置し、24時間365日、要請から数十〜1時間程度で重機・作業員が現場急行できる体制を担保している。
* **小規模事業体における体制づくり**:
  * 専任の待機業者を置くことが財政的に難しい中小事業体であっても、「緊急時にどの事業者に連絡し、どのような手順で招集するか」の応援協定や連絡網を整備しておく。
* **例外的な契約手続きの事前ルール化（着工前着手）**:
  * 漏水事故は一刻を争うため、正規の見積・入札・契約締結を待ってから発注することはできない。
  * **「着工前着手（緊急施工後の事後契約・事後精算手続き）」** が適法・円滑に行えるよう、総務・契約等の事務部門とあらかじめ運用基準を取り決めておく。

### (3) 損害賠償・補償対応を見据えた現場記録の徹底

漏水により道路冠水、民家・店舗の床上・床下浸水、商品や家財の水損、車両の水没が発生した場合、最終的な損害賠償や損失補償の示談交渉は事務部門（総務・補償担当）が担う。
しかし、**事故発生直後の泥水に浸かったリアルな被災実態を直接確認できるのは、初動対応にあたる技術系職員（現場部隊）だけ** である。

```
【現場技術職員に求められる保全記録】
・浸水深（壁や柱に残った泥水の喫水線、メジャーを当てて測定）
・浸水範囲（敷地内、室内、床下、道路冠水エリアの境界）
・被災物件（商品、什器、家具、家電、自動車の損害状況）
・時系列記録（通水停止時刻、水が引いた時刻の写真・動画）
```

* **記録不足がもたらすリスク**:
  * 復旧作業に追われて写真・動画記録を怠ると、後日、被災者側から事故と無関係な老朽家屋の修繕費や過大・架空な商品補償を請求された際、行政側で適正な査定や反論ができず、公金の不適正支出や泥沼の紛争を招く。
  * 現場部隊は、修繕作業と並行して **必ず1名を記録担当に指定し、スマートフォンやカメラで克明な証拠保全を行う** ことが実務上の鉄則である。

## 2. 情報収集と初動体制の確立（テキスト p.315）

### (1) 第1報の鉄則（速報性とスピード重視）

事故発生直後の情報収集において、最もやってはならないのは「すべての情報（被害規模・原因・復旧見込み）が揃うまで報告を留保すること」である。

> **★第1報の鉄則（クライシスマネジメントの基本原則）**
> **「現時点で判明している事実のみを直ちに上層部・関係機関へ報告する。」**
> ※未確認・調査中の項目は、そのまま「現在調査中」と明記して速報性を最優先する。

* **情報のアップデート**:
  * 第1報（発生場所・出水状況・出動事実） ➔ 第2報（管種・口径・推定影響戸数） ➔ 第3報（バルブ閉止・断水完了・復旧見込み）と、時系列で矢継ぎ早に情報を更新していく。

---

### (2) 警察・消防機関との現場合流と実態

大規模な路上漏水・出水事故では、道路管理者、所轄警察署（交通管理者）、消防署との速やかな連携が不可欠である。

* **現場実態（警察・消防の先行到着）**:
  * 一般市民は水道局の電話番号を知らないことが多く、異常出水を目撃すると真っ先に **「110番」または「119番」へ通報** する。
  * したがって、水道局の現場部隊が到着した時点では、**すでに警察や消防が先行到着し、赤色灯をつけて交通規制を行っていたり、イエローテープ（規制線）を張っているケースがほとんど** である。
* **現着直後のアクション**:
  * 到着後、直ちに警察・消防の現地指揮官と合流し、身分を明かした上で「出水している管路の概要」「これからどのバルブを閉めて何分程度で水を止めるか」の対応方針を伝え、合同の安全確保体制を確立する。

### (4) 初動出動時の準備資機材（段階的携行）

出動部隊は、初動のスピードを損なわないよう「第1陣」と「第2陣以降」で資機材を分けて出動する。

```
【初動出動のステップ】
・第1陣（先行調査班） ── 時間をかけず「配管図面」を最優先で掴んで現場へ猛ダッシュ！
・第2陣・第3陣（復旧班） ─ 現場からの情報に基づき、必要な重機・資機材・安全器具を積載して急行！
```

* **第1陣（最優先）**:
  * **配管図面（紙図面またはオフライン対応タブレット端末）**。これがないとバルブの位置が一切特定できない。
  * バルブ開栓器（T字レンチ）、バール、懐中電灯。
* **第2陣・第3陣（バックアップ機材）**:
  * **安全測定器**: 複合ガス検知器（酸素・可燃性ガス・硫化水素）、可搬式送風機（換気ファン）。
  * **排水・照明機材**: 水中ポンプ、排水ホース、可搬式発電機、投光器（LEDバルーンライト）。
  * **応急補修資材**: 漏水補修クランプ、仕切弁、直管、不断水バルブ・穿孔機。

## 3. 断水作業の実務（計画断水と突発断水）（テキスト p.319）

水道管路の維持管理において、断水は需要者の市民生活や都市活動に極めて重大な影響を与える。断水は「計画断水」と「突発断水」に大別される。

### (1) 計画断水の手順と留意事項（テキスト p.319）

老朽管の更新工事、新設管の連絡工事、基幹バルブの交換などに伴い、事前に日時を定めて実施する断水である。

```
【計画断水の実務フロー】
① 系統・弁の事前調査 ── 閉止弁の選定、濁水（赤水）影響区域のシミュレーション。
② 排水先の確保と中和 ── 消火栓・泥吐弁の選定、チオ硫酸ナトリウムによる脱塩素。
③ 最適な時間帯の設定 ── 原則「夜間作業（22時〜翌朝5時等）」で実施。
④ 事前広報と周知徹底 ── チラシ全戸配布、掲示板、HP、受水槽施設への個別連絡。
```

1. **系統と弁の事前調査**:
   * どの仕切弁を閉めれば断水区域を最小化できるかを机上解析する。
   * バルブを操作すると管内の流向・流速が激変するため、**影響を受ける「濁水（赤水）発生予想区域」を厳密にシミュレーション** する。
2. **排水先の確保と脱塩素（中和）処理**:
   * 管路切断前に管内の水を抜くための消火栓や排水弁を特定する。
   * **河川放流時の鉄則**: 魚類への毒性を排除するため、**必ずチオ硫酸ナトリウム等の還元中和剤を準備し、残留塩素を完全に中和して放流** する。
3. **時間帯の設定（夜間作業の原則）**:
   * 配水本管や商業地域、交通量の多い道路では、給水需要が極小となり道路規制が可能な **「深夜帯（夜22時〜翌朝5時頃）」の夜間作業** を原則とする。
4. **事前広報の徹底**:
   * 断水日時、濁水発生時の注意（朝一番の流し始め、給湯器や受水槽への流入防止）、応急給水所の場所を記載したチラシを対象全戸へ事前ポスティングする。

### (2) 仕切弁の「締め切り確認」とバルブ洗浄（フラッシング）

断水バルブを全閉操作した後、**「本当に水が完全に止まっているか」** を確認せずに道路を開削・管切断すると、高圧水が噴出して大事故となる。

```
【仕切弁の締め切り確認とフラッシングのメカニズム】
[仕切弁全閉操作] ──→ [管内の消火栓・空気弁を開放]
                             │
                             ▼ 管内の残水が出尽くした後…
                ┌────────────┴────────────┐
                ▼                                 ▼
         【完全に止水】                     【チョロチョロ水が出続ける】
         ➔ 安心して掘削・切断へ！          ➔ 弁座底部に錆や砂が噛み込んでいる！
                                                  │
                                                  ▼
                                      【バルブ洗浄（フラッシング）】
                                      弁を少し開けて高圧通水し異物を吹き飛ばす！
                                      数回繰り返して再度全閉 ➔ 確実止水！
```

* **仕切弁の異物噛み込みとフラッシング**:
  * 古いJIS規格仕切弁（メタルシート弁）は、弁座の底部に溝があるため、錆コブや砂利が噛み込んで全閉しないケースが極めて多い。
  * この際、無理に巨大なパイプレンチ等でスピンドルを締め付けると弁棒がねじ切れて破損する。
  * **フラッシング（バルブ洗浄）の手順**:
    1. 弁を $2 \sim 3$ 回転開け、管内の水圧で弁座の隙間から勢いよく水を噴出させて噛み込んだ土砂・異物を下流へ吹き飛ばす。
    2. これを $2 \sim 3$ 回繰り返した後、再び締め込む。
    3. これにより、ゴムライニングのないメタル弁であっても劇的に止水性が向上する。

### (3) 突発断水（緊急断水）の3大判断基準

路上漏水や他企業工事事故が発生した際、事前広報を行う時間的猶予がない場合、現場責任者は直ちに「緊急断水」を決断しなければならない。

```
【緊急断水を即座に決断すべき3大基準】
① 噴出水量が道路雨水桝の排水能力を超過し、道路が広範囲に冠水している。
② 沿道の家屋、店舗、地下街、電気室等への浸水被害が発生・切迫している。
③ 水道水の噴出流により路盤の土砂が吸い出され、大規模な道路陥没の危険がある。
```

> **【実務教訓事例：他企業工事による管路抜け出しと泥水冠水現場での弁探索】**
> 近年、当局管内において、隣接掘削を行っていたガス工事現場の土圧解放により、水道管（口径 $\phi 300\,\text{mm}$）が突如継手から抜け出し、大量の水が道路上に噴出・冠水する事故が発生した。
> 道路一帯が深い泥水で完全に水没すると、路面上から仕切弁の弁筐（鉄蓋）を目視で確認することは不可能となる。
> このような極限状況では、**配管図面をもとに沿道建築物や電柱からのオフセット寸法（離隔距離）をメジャーで実測** し、開栓器（T字レンチ）やバールで泥水の底を突き刺しながら、**「コンコン」という金属音の違いを手がかりに手探りで鉄蓋を探し当て、泥水の中に手を突っ込んでバルブを遮断** する。
> 泥水を被りながらの迅速なバルブ閉止には、日頃の図面読解力と現場実務経験が不可欠である。

## 5. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：危機管理・初動体制）
* **問題形式**: `choice`
* **問題文**: 水道管路の突発事故発生時における初動体制および指揮命令系統に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 管理職不在時に備えて現場責任者の代行順位をあらかじめ定めておく
  2. 被害規模や復旧見込みなどの全情報が判明するまで第1報は留保する
  3. 漏水現場での写真や動画による被害記録の撮影は事後補償と無関係である
  4. 現場到着後は警察や消防の規制線が解除されるまで待機を継続する
* **正解**: 1（インデックス: 0）
* **解説**: 管理職不在時のお見合いや指示待ちによるタイムロスを防ぐため、現場責任者の代行順位を事前に明確化しておくことが重要です。第1報は判明事実のみを直ちに速報し、示談補償交渉のために現場写真等の証拠保全を行い、現場到着後は先行している警察・消防と直ちに合流・連携します。
* **日常のたとえ**: 救急救命や消防と同じで、隊長が不在でも副隊長、先任隊員へと瞬時に現場指揮権が移行するルールを決めておかないと、緊急事態で全員が立ちすくんでしまうのを防ぐ仕組みです。
* **出典**: 講義テキスト 導送配水施設 p.315

### 設問2（4択：事故対策本部・広報実務）
* **問題形式**: `choice`
* **問題文**: 大規模断水事故に伴う事故対策本部の運営および広報活動に関する記述として、最も適切なものはどれですか？
* **選択肢**:
  1. 広報車のアナウンスは聞き取りやすさを高めるため車両を一時停止させて行う
  2. 対策本部の時系列記録は混乱を防ぐため収束後に一括して作成する
  3. 応急給水班は一般家庭への給水車配備を災害拠点病院より優先する
  4. 断水区域や給水拠点の情報は電話問い合わせがあった需要家のみに伝える
* **正解**: 1（インデックス: 0）
* **解説**: 広報車を走行させながらアナウンスすると反響やドップラー効果で聞き取れないため、交差点や広場等で一時停止させて明瞭に繰り返すのが正しい実務です。時系列記録（クロノロジー）はリアルタイムに可視化し、応急給水は人工透析等の病院を最優先とし、情報はHPやSNS等で広く発信します。
* **出典**: 講義テキスト 導送配水施設 p.315〜316

### 設問3（4択・否定形：計画断水実務）
* **問題形式**: `choice`
* **問題文**: 配水管路の計画断水工事を実施する際の手順および留意事項として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 管路切断作業を迅速化するため消火栓等による締め切り確認は省略する
  2. 幹線道路や商業地域の計画断水は給水需要の少ない夜間作業を原則とする
  3. 配水管内の残水を河川へ排出する際は中和剤を用いて残留塩素を脱塩素する
  4. 仕切弁操作に伴う水流の変化を考慮して濁水の発生予想区域を事前調査する
* **正解**: 1（インデックス: 0）
* **解説**: 断水バルブ閉止後、消火栓や空気弁を開放して管内残水が出尽くし完全に水が止まっているか（締め切り確認）を行わずに管路を切断・掘削すると、高圧水噴出による大事故につながるため絶対に省略してはなりません。
* **出典**: 講義テキスト 導送配水施設 p.319

### 設問4（4択：バルブ維持管理・フラッシング）
* **問題形式**: `choice`
* **問題文**: メタルシート仕切弁を全閉操作した際に水が完全に止まりきらない場合の実務対応として、最も適切なものはどれですか？
* **選択肢**:
  1. 弁を数回転開けて高圧通水し弁座に噛み込んだ異物を下流へ洗い流す
  2. スピンドル弁棒が破断するまで大型レンチを用いて過大トルクで締め込む
  3. 止水不良の仕切弁の直前に泥土を投入して弁座の隙間を目地埋めする
  4. バルブの全閉を諦めて通水状態のまま既設管路の急速ガス切断を開始する
* **正解**: 1（インデックス: 0）
* **解説**: メタルシート仕切弁は弁座底部に錆や砂が噛み込んで全閉しないことが多いため、弁を少し開けて高圧水で異物を吹き飛ばす「バルブ洗浄（フラッシング）」を数回繰り返すことで確実に止水できます。無理な過大トルクでの締め付けは弁棒の破断を招きます。
* **日常のたとえ**: 窓のサッシレールに小石が挟まって鍵が閉まらないときに、無理やり鍵をねじ回して壊すのではなく、一度窓を少し開けてゴミを息やブラシで吹き飛ばしてから閉め直すのと同じ作業です。
* **出典**: 講義テキスト 導送配水施設 p.319

### 設問5（4択：突発断水の判断基準）
* **問題形式**: `choice`
* **問題文**: 路上漏水事故の発生に伴い、事前広報を行わずに直ちに「緊急断水」を決断すべき基準として、最も適切なものはどれですか？
* **選択肢**:
  1. 噴出する水量が道路雨水桝の能力を超過し家屋浸水や道路陥没の危険がある場合
  2. 漏水量が極めて微少であり道路側溝内を静かに流下している場合
  3. 周辺住民から濁水に関する電話問い合わせが数件寄せられた場合
  4. 漏水調査の音聴棒により地下配管から微弱な漏水音が感知された場合
* **正解**: 1（インデックス: 0）
* **解説**: 突発断水（緊急断水）は、噴出水量が道路排水桝の許容量を超えて冠水している場合、家屋・店舗・地下街への浸水被害が切迫している場合、または路盤土砂が流出して大規模な道路陥没を引き起こす危険がある場合に直ちに決断・実施します。
* **出典**: 講義テキスト 導送配水施設 p.319
