# 浄水施設12：浄水発生土の乾燥設備・物性管理・有効利用と法的処分（廃掃法・管理型処分場）

---

## 1. 講義の全体位置づけと概要

本資料は、テキスト第9章「浄水施設」の最終単元（テキスト p.480〜485）である**「浄水発生土（脱水ケーキ）の処理・乾燥・有効利用および最終処分」**に関する講義内容を、水道技術管理者試験および水道技術実務に即して体系的に再構築したリファレンスである。

浄水処理工程（凝集沈殿・ろ過）から分離・濃縮・脱水された泥状物質は、一般に**「浄水発生土（脱水ケーキ）」**と呼ばれる。最終処分場の残余容量の逼迫や環境負荷低減の観点から、単なる埋立処分から「乾燥・造粒等による高付加価値化と有効利用（リサイクル）」への転換が強く推進されている。本単元は、脱水ケーキの物性調整、乾燥設備の工学、廃棄物処理法（廃掃法）における法的区分、および資源化技術に関する頻出論点を網羅する。

```
【浄水発生土の処理・資源化フロー】
沈殿池排泥・逆洗排水
       │
       ▼
 濃縮槽（シックナー） ──［上澄水］──> 着水井等へ返送（クローズド化）
       │
       ▼［濃縮スラッジ（含水率 95〜98%）］
 機械脱水機（加圧ろ過・遠心・真空）
       │
       ▼［脱水ケーキ（含水率 約60%・塊状 2〜20cm）］
┌──────┴────────────────────────┐
│ 解砕機・破砕機（均一化・細粒化）        │
└──────┬────────────────────────┘
       ▼
 汚泥乾燥機（直接加熱法 / 間接加熱法）
   ├── 集塵設備（バグフィルター等：粉塵捕集）
   └── 脱臭設備（燃焼法・活性炭吸着法：悪臭防止）
       │
       ▼［乾燥ケーキ（含水率 30〜36%・粒径 0.5〜5mm）］
┌──────┴────────────────────────┐
│ 【法的区分と出口管理（廃掃法）】        │
├────────────────────────────────┤
│ ① 有価物（有償取引）                   │ ──> 園芸用土（培土・赤玉土代替）、グラウンド土
│ ② 有効利用（無償・逆有償）             │ ──> セメント原料（粘土代替）、盛土材・路盤材
│ ③ 埋立処分（産業廃棄物・無機性汚泥）   │ ──> 【管理型最終処分場】（安定型・遮断型ではない）
└────────────────────────────────┘
```

## 2. 脱水ケーキの物性と解砕・破砕設備

### (1) 脱水ケーキの物理的性状
機械脱水機（特に主流である加圧ろ過機＝フィルタープレス）から排出される脱水ケーキは、厚さ数センチメートル、一辺が数十センチメートルに及ぶ板状・塊状の硬い固形物である。
* **脱水直後の含水率**: 約 $60\%$（加圧脱水の場合。遠心脱水では約 $70 \sim 75\%$）。
* **形状・サイズ**: 厚さ $2 \sim 5\,\text{cm}$、長さ $10 \sim 20\,\text{cm}$ 程度の不規則な板状・ブロック状。
* **課題**: 塊状のままでは内部の水分が蒸発しにくく、次工程の乾燥機内での伝熱効率が著しく低下する。また、園芸用土や土工資材として利用する際にも均一なハンドリングが困難となる。

### (2) 解砕機・破砕機の設置目的と機能
脱水ケーキを乾燥機に投入する前、あるいは利用目的に適合した形状に加工するため、脱水機出口のホッパーや搬送コンベヤ部に**解砕機（破砕機・チョッパー）**を設置することが望ましい。
* **水分・密度の均一化**: 巨大な塊を細かく破砕することで、ケーキ内部に閉じ込められた水分の偏りを解消し、均質な物性にする。
* **比表面積の増大**: ケーキを小径化して表面積を飛躍的に拡大させ、乾燥設備における熱効率（熱風や伝熱面との接触効率）を高め、乾燥時間を短縮する。
* **搬送性の向上**: スクリューコンベヤやベルトコンベヤでの閉塞（ブリッジ現象）を防止し、安定供給を可能にする。

## 3. 汚泥乾燥設備の原理・方式と付帯設備

脱水ケーキの含水率をさらに低減させ、製品としての品質（取扱性、輸送効率、形状の均一性）を高めるため、熱源を用いた乾燥設備が導入される。

### (1) 加熱乾燥方式の分類と特徴

| 方式 | 原理・熱媒体 | メリット（長所） | デメリット（留意点） | 代表例・構造 |
| :--- | :--- | :--- | :--- | :--- |
| **直接加熱乾燥法** | 重油・ガスバーナー等で発生させた**高温熱風を汚泥ケーキに直接接触**させて乾燥。 | * 熱伝達速度が速く、短時間で大量処理が可能。<br>* 装置構成が比較的単純。 | * 熱風量が膨大となるため、排ガス処理（集塵・脱臭）設備の規模が大きくなる。<br>* 粉塵爆発防止対策や熱効率の管理が必要。 | 回転熱風乾燥機（ロータリーキルン型）、気流乾燥機 |
| **間接加熱乾燥法** | ボイラー蒸気や熱媒油を用い、**伝熱面（ドラム・ロール・ディスク・中空翼）を介して熱伝導**により汚泥を加熱乾燥。 | * 汚泥と熱媒体が直接触れないため、**排ガス量が極めて少なく**、集塵・脱臭設備の負荷が小さい。<br>* 自家発電（コージェネ）の排熱蒸気等を有効活用可能。<br>* 熱効率が高い。 | * 伝熱面への汚泥付着（スケーリング）による熱伝導率低下の防止（自掃翼等の機構）が必要。<br>* 構造がやや複雑でイニシャルコスト大。 | **中空多軸パドル式乾燥機**、回転ロール式ドラム乾燥機（兵庫県営・阪神水道企業団 新尼崎浄水場等で採用） |

### (2) 必須となる環境保全付帯設備
乾燥工程では高温の排ガス、微細な粉塵、および熱分解や濃縮に伴う臭気ガスが発生するため、以下の環境対策設備を一体的に整備することが義務付けられる。

1. **集塵設備（バグフィルター・サイクロン）**
   * **機能**: 乾燥機から排出される排ガスに同伴する微粒子・乾燥粉塵（ダスト）を高度に遠心分離またはろ布ろ過して捕集する。
   * **目的**: 大気汚染防止、作業環境の粉塵対策、および捕集した粉末ケーキの製品回収。
2. **脱臭設備（燃焼法・活性炭吸着法）**
   * **機能**: 汚泥の加熱に伴い揮発・発生する特有の臭気成分（微量有機物、アンモニア様成分等）を徹底除去する。
   * **方式**:
     * **燃焼脱臭法（直接燃焼・触媒燃焼）**: 高温（$700 \sim 800^\circ\text{C}$ または触媒下 $300 \sim 400^\circ\text{C}$）で酸化分解。大風量・高濃度臭気に最適。
     * **活性炭吸着脱臭法**: 充填塔内の粒状活性炭に吸着させて除去。低濃度臭気の仕上げや排ガス精製に好適。
   * **目的**: 周辺住宅地・近隣環境への悪臭放散防止（悪臭防止法・環境確保条例の遵守）。

## 4. 脱水ケーキと乾燥ケーキの物性対比

乾燥処理を経ることにより、発生土の物理的性状、容積、ハンドリング性能は劇的に改善される。

```
【脱水ケーキ（乾燥前）】                 【乾燥ケーキ（乾燥後）】
  含水率：約 60%                           含水率：30〜36%（またはそれ以下）
  形状  ：塊状（厚さ 2〜5cm、長さ 20cm）    形状  ：細粒状・ペレット状（粒径 0.5〜5mm）
  性状  ：粘着性あり・重量大・腐敗発酵懸念   性状  ：流動性良好・サラサラ・軽量・長期保存可
```

| 項目 | 脱水ケーキ（機械脱水直後） | 乾燥ケーキ（熱乾燥・造粒後） | 設計・利用上の意味 |
| :--- | :--- | :--- | :--- |
| **含水率** | **約 $60\%$**（加圧脱水の場合） | **約 $30 \sim 36\%$**（用途によりさらに低下） | 水分量が半減以下となり、輸送重量・運搬コストが大幅に縮減する。 |
| **形状・寸法** | 不定形塊状（長径 **$2 \sim 20\,\text{cm}$**、板状） | 均質細粒状・造粒品（粒径 **$0.5 \sim 5\,\text{mm}$**） | 土壌改良材や園芸培土、配合原料として混合・散布が極めて容易。 |
| **容積・密度** | 隙間が多くかさばり、粘着性が残る | 緊密な細粒または流動性に富む顆粒状 | 貯蔵ホッパー内でのブリッジを起こさず、フレコンバッグ等への袋詰めが容易。 |
| **市場価値** | 産業廃棄物としての逆有償処分が多い | 園芸資材・グラウンド用材として**「有価物（売却）」取引が可能** | 処分費用の支出から、売却益・リサイクル化へと経営・環境面で転換。 |

## 5. 浄水発生土の法的区分と廃棄物処理法（廃掃法）

水道技術管理者が最も厳格に把握・遵守しなければならないのが、「廃棄物の処理及び清掃に関する法律（廃棄物処理法／廃掃法）」に基づく法的責務である。

```
                    ┌── 産業廃棄物から除外（製品・原料として流通、マニフェスト不要）
                    │
┌─ 有価物（有償取引）
│
└─ 廃棄物（無償・逆有償）
   └─ 【産業廃棄物】（事業活動に伴って生じたもの）
       ├─ 法定20種類のうち ──> 『無機性汚泥』（浄水汚泥）
       │
       └─ 埋立処分を行う場合の施設 ──> 【管理型最終処分場】
            （※安定型は不可、遮断型は不要）
```

### (1) 産業廃棄物（汚泥）としての位置づけと「有価物除外」
1. **原則（産業廃棄物）**:
   * 水道事業という事業活動に伴って生じる浄水発生土は、廃棄物処理法第2条第4項に定める**「産業廃棄物（汚泥）」**（具体的には凝集沈殿スラッジに由来する**無機性汚泥**）に該当する。
   * 排出事業者（水道事業者）は、自らの責任において適正に処理（自己処理または許可業者への委託）しなければならず、委託時には産業廃棄物管理票（マニフェスト）の交付・管理、帳簿記載、最終処分の確認が義務付けられる。
2. **例外（有価物としての除外）**:
   * 園芸業者や土木業者、農家等に対し、**「有償（金銭の対価を得て）」で売却・取引される浄水発生土は、客観的価値を有する「有価物」とみなされ、廃棄物処理法の規制（産業廃棄物の定義）から除外**される。
   * 乾燥・造粒によって高品質化を図る最大の目的の一つは、この「有価物化」を達成し、法的な廃棄物規制から脱却して安定的な資源循環ルートを確立することにある。

### (2) 最終処分場の3分類と浄水発生土の埋立区分（★超頻出）
有効利用されずに埋立処分される浄水発生土について、持ち込むべき最終処分場の種別は法律で厳格に区分されている。

| 処分場の種別 | 対象廃棄物の性質 | 主な対象品目 | 構造・設備の特徴 | 浄水発生土の該否 |
| :--- | :--- | :--- | :--- | :---: |
| **安定型<br>最終処分場** | 雨水等にさらされても**性状が変化せず、浸出液によって生活環境保全上の支障を生じない**安定した廃棄物。 | **限定5品目**：<br>廃プラスチック類、ゴムくず、金属くず、ガラス・コンクリート・陶磁器くず、がれき類 | 浸出液処理施設や遮水工（シート）の設置は義務付けられていない。 | **× 不可**<br>（汚泥の埋立は禁止） |
| **管理型<br>最終処分場** | 分解・溶出等により、**汚濁成分を含む浸出液を発生させる恐れがある**一般的な産業廃棄物。 | **汚泥（浄水発生土）**、動植物性残渣、紙くず、木くず、繊維くず、燃え殻、ばいじん 等 | 底面・法面に**遮水工（二重遮水シート等）**を敷設し、集水管、浸出液処理施設（pH調整・凝集沈殿・生物処理等）を備える。 | **◎ 該当**<br>（★浄水発生土はここに埋立処分） |
| **遮断型<br>最終処分場** | 重金属や有害物質を基準値を超えて含み、環境中に絶対に漏出させてはならない有害廃棄物。 | 特別管理産業廃棄物（基準値超の有害汚泥、水銀・カドミウム・鉛含有物等） | 雨水・地下水を完全に遮断する**鉄筋コンクリート製水密構造ピット**、屋根・覆蓋設備。 | **× 不要**<br>（通常基準内の浄水発生土には過剰） |

> **試験対策の急所**:
> 「浄水発生土は腐敗しない土状物質であるため、安定型最終処分場に埋立処分できる」という誤った選択肢が頻出する。浄水発生土は「無機性汚泥」であり、微量な有機物や薬剤成分を含み浸出液を生じる恐れがあるため、**必ず「管理型最終処分場」**で処分しなければならない。

## 6. 浄水発生土の有効利用と排出者責任

### (1) 多様な有効利用（リサイクル）先
埋立処分場の延命化および循環型社会の形成に向け、浄水発生土の特性（粘土分を多く含み、病原菌が死滅・不活化されており、重金属等の有害物質を含まない清浄な土）を活かした有効利用が進められている。

1. **園芸用土・農業用土**:
   * **用途**: 花卉・野菜の育苗用土、家庭園芸用培土、赤玉土・鹿沼土の代替配合材、農地土壌改良材。
   * **要求品質**: 雑草種子や病原菌の混入がないこと、均一な粒径（$1 \sim 5\,\text{mm}$ 程度）、適度な保水性と透水性、適切なpH。乾燥・造粒品が極めて高く評価される。
2. **セメント原料（粘土代替原料）**:
   * **用途**: ポルトランドセメントの焼成原料（シリカ・アルミナ源）として粘土の代替利用。
   * **特徴**: 大量受入が可能であり、セメントキルン（約 $1,450^\circ\text{C}$）で超高温焼成されるため完全に無害化・マテリアルリサイクルされる。
3. **土工資材・盛土材・埋戻し材**:
   * **用途**: 道路路盤材の下層、構造物の埋戻し土、河川築堤・宅地造成の盛土材。
   * **留意点**: 生石灰やセメント系固化材等を添加・混合（改良土化）して所定のコーン指数（トラフィカビリティ＝締固め強度）を確保する。
4. **グラウンド用土（クレイ舗装）**:
   * 学校や運動場のグラウンド用クレイ（適度な粘性と弾力性を有する表土材）。

### (2) 水道事業者（技術管理者）の排出者責任と自主的適合評価
* **原水・薬品による性状の差異**:
  原水の水質特性（河川水、ダム湖水、地下水）や使用薬品（PAC、硫酸バンド、鉄系凝集剤、高分子凝集剤の有無）によって、発生土のpH、アルミニウム含有量、粒度分布、保水性は事業体ごとに大きく異なる。
* **自主的な利用先開拓と品質管理**:
  水道事業者は自ら発生土の物理的・化学的性質（土壌環境基準適合試験、有害物質溶出試験）を正確に把握し、自団体の発生土に最も適した有効利用先（園芸用、セメント用、土工用など）を主体的に見出す努力が求められる。

## 7. 重要論点対比表（キーワード＆正誤判定ポイント）

| 重要論点 | 正しい記述（○のポイント） | 誤りとして出題されるパターン（×の罠） |
| :--- | :--- | :--- |
| **解砕・破砕機の役割** | 脱水ケーキの巨大な塊を破砕して**水分の均一化と比表面積の増大**を図り、乾燥機の熱伝導効率向上と搬送閉塞防止を図る。 | 「脱水ケーキは十分に乾燥しているため、解砕機を通さずそのまま製品出荷するのが標準である」とする記述は誤り。 |
| **乾燥方式の比較** | **間接加熱乾燥法**は熱媒（蒸気等）を伝熱面越しに作用させるため、直接加熱法に比べて**排ガス量が極めて少なく、集塵・脱臭設備の負荷が小さい**。 | 「間接加熱法は熱風を直接汚泥に当てるため、直接加熱法よりも膨大な排ガスが発生する」とする記述は逆で誤り。 |
| **付帯環境設備** | 乾燥工程で発生する粉塵対策として**集塵設備（バグフィルター等）**、悪臭対策として**脱臭設備（燃焼法・活性炭吸着法）**を併設する。 | 「浄水発生土は水道水由来で清浄であるため、乾燥排ガスに対する集塵や脱臭などの環境保全設備は一切不要である」とする記述は誤り。 |
| **乾燥前後の物性変化** | 加圧脱水直後のケーキ含水率は**約 $60\%$**、乾燥ケーキは**約 $30 \sim 36\%$**まで低下し、粒径も数cmの塊状から**$0.5 \sim 5\,\text{mm}$ の細粒状**に変化する。 | 「乾燥処理を行うと含水率は約60%から約80%へと上昇する」「乾燥後も20cm四方の板状ブロックのまま維持される」とする記述は数値・物理的に誤り。 |
| **有価物と廃棄物** | 浄水発生土であっても、**有償で売却・取引されるものは廃棄物処理法上の産業廃棄物から除外**され、有価物として扱われる。 | 「水道事業から排出される発生土は、いかなる場合も例外なく産業廃棄物としてマニフェスト管理を行わなければならない」とする記述は誤り。 |
| **最終処分場の種別** | 浄水発生土を埋立処分する場合、無機性汚泥に該当するため**「管理型最終処分場」**に埋立処分しなければならない。 | **「安定型最終処分場に埋立処分できる」「遮断型最終処分場でなければ埋立できない」**とする記述は頻出の誤り。 |
| **排出事業者責任** | 凝集剤等の使用薬品や原水水質により発生土の性状が異なるため、**水道事業者自らが性状を把握し、適合する有効利用先を見出す**必要がある。 | 「浄水発生土の有効利用先は国が一律に指定するため、水道事業者が自ら性状を評価・選定する必要はない」とする記述は誤り。 |

## 8. 水道技術管理者試験 想定問題集（5問）

### 【問1】脱水ケーキの破砕・乾燥設備に関する記述（基礎）
浄水処理工程における脱水ケーキの破砕および乾燥設備に関する次の記述のうち、**最も不適切なもの**はどれか。

1. 機械脱水機から排出された脱水ケーキは、内部の水分を均一化し乾燥効率を向上させるため、乾燥機の前段等に解砕機や破砕機を設置して細粒化することが望ましい。
2. 直接加熱乾燥法は、高温の熱風を汚泥ケーキに直接接触させて乾燥させる方式であり、伝熱速度が速く大量処理に適している反面、排ガス量が大きくなる。
3. 間接加熱乾燥法は、水蒸気等の熱媒体を伝熱面を介して汚泥に伝える方式であり、排ガス量が少ないため集塵設備や脱臭設備の負荷を軽減できる。
4. 加圧ろ過機で脱水された直後の脱水ケーキは、一般に含水率が約 $30 \sim 36\%$ 程度まで低下しており、そのまま園芸用土として粒状で流通できる。

**【正解】4**  
**【解説】**
* 1, 2, 3：記述の通り正しい。
* 4：誤り。加圧ろ過機（フィルタープレス）から排出された直後の脱水ケーキの含水率は**約 $60\%$** であり、形状も厚さ $2 \sim 5\,\text{cm}$、長さ十数センチメートル以上の塊状・板状である。熱乾燥設備等を経ることで含水率が **約 $30 \sim 36\%$** まで低下し、粒径 $0.5 \sim 5\,\text{mm}$ 程度の均一な細粒状となって園芸用土等に利用される。
* **日常のたとえ**: 絞ったばかりの濡れ雑巾（含水率60%・塊）をそのまま植木鉢に入れることはできず、細かくちぎってアイロンや乾燥機でパラパラ（含水率30%・顆粒）にして初めて土として使えるのと同じである。
* **出典**: テキスト第9章 p.480〜482「排水処理施設 乾燥設備及びケーキ性状」

### 【問2】汚泥乾燥設備の環境保全設備に関する記述（構造・維持管理）
浄水場の汚泥乾燥設備に付帯する環境保全設備に関する次の記述のうち、**最も適切なもの**はどれか。

1. 乾燥機から排出される排ガス中には微細な乾燥粉塵が含まれるため、大気汚染防止および製品回収を目的としてバグフィルター等の集塵設備を設ける。
2. 浄水発生土は河川やダム湖の土砂由来であるため加熱しても臭気成分は一切発生せず、脱臭設備を設置することは法令上禁止されている。
3. 間接加熱乾燥法を採用した場合であっても、汚泥から発生する可燃性ガスにより排ガス量が直接加熱法の10倍以上に達するため、集塵装置は直接加熱法より大型化する。
4. 悪臭防止のための脱臭方式としては生物脱臭法のみが認められており、燃焼脱臭法や活性炭吸着脱臭法を用いることはできない。

**【正解】1**  
**【解説】**
* 1：記述の通り適切。乾燥排ガス中の粉塵（ダスト）を高度に捕集するため、バグフィルターやサイクロン等の集塵設備が設けられる。
* 2：不適切。加熱乾燥の過程で汚泥中に含まれる微量有機物や薬剤成分の熱分解等により特有の臭気が発生するため、周辺環境保全のために脱臭設備（燃焼法・活性炭吸着法等）の設置が強く求められる。
* 3：不適切。間接加熱法は熱風を直接吹き込まないため、直接加熱法に比べて**排ガス量が極めて少なく**、集塵設備や脱臭設備の規模を小型化できるのが大きな利点である。
* 4：不適切。脱臭設備としては、高温で熱分解する燃焼法（直接燃焼・触媒燃焼）や、比表面積の大きい活性炭による吸着脱臭法が広く用いられている。
* **日常のたとえ**: 魚焼きグリル（乾燥機）から出る煙（粉塵）を換気扇フィルター（集塵機）でキャッチし、気になるニオイを脱臭触媒（脱臭機）で分解してから外に逃がす家庭のレンジフードと同じ仕組みである。
* **出典**: テキスト第9章 p.481「集塵設備及び脱臭設備」

### 【問3】浄水発生土の法的区分と廃棄物処理法（法規・基準）
浄水発生土の法的取扱いに関する次の記述のうち、廃棄物の処理及び清掃に関する法律（廃掃法）に照らして**最も適切なもの**はどれか。

1. 浄水処理工程から排出される浄水発生土は、事業活動に伴って生じるものであるため、有償で園芸業者に売却される場合であっても産業廃棄物としてマニフェストを発行しなければならない。
2. 浄水発生土は、廃棄物処理法上において産業廃棄物の20種類のうち「無機性汚泥」として位置づけられる。
3. 浄水発生土を最終処分（埋立処分）する場合、有害物質を含まない清浄な土砂と同等であるため、「安定型最終処分場」に埋立処分することができる。
4. 浄水発生土の埋立処分を行う際は、いかなる場合であっても放射性物質等と同等のピット構造を持つ「遮断型最終処分場」へ搬入することが義務付けられている。

**【正解】2**  
**【解説】**
* 1：不適切。客観的に金銭の対価を得て有償で取引（売却）される浄水発生土は**「有価物」**とみなされ、廃棄物処理法上の産業廃棄物の定義から除外される（マニフェスト発行不要）。
* 2：記述の通り適切。浄水発生土は産業廃棄物の「汚泥」（有機性汚泥と対比して主に鉱物質・粘土分から成る**無機性汚泥**）に分類される。
* 3：不適切。安定型最終処分場に埋立できるのは安定5品目（廃プラスチック類、ゴムくず、金属くず、ガラス・陶磁器くず、がれき類）に限定されており、汚泥である浄水発生土は埋立できない。浸出液処理施設を備えた**「管理型最終処分場」**で処分しなければならない。
* 4：不適切。遮断型最終処分場は、基準値を超える有害物質を含有する特別管理産業廃棄物等をコンクリート構造で完全に環境遮断して埋立する施設であり、一般的な浄水発生土に要求されるものではない。
* **日常のたとえ**: 古本や古着をブックオフに売れば「商品（有価物）」だが、ゴミ収集に出せば「廃棄物」になるのと同じである。また、生ごみや泥は雨水で成分が溶け出すため、プラスチックや金属だけを埋める場所（安定型）には捨てられず、排水処理プラント付きの専用処分場（管理型）に埋める必要がある。
* **出典**: テキスト第9章 p.483〜484「浄水発生土の有効利用と処分（廃掃法）」

### 【問4】脱水ケーキと乾燥ケーキの物性比較（数値基準）
機械脱水直後の脱水ケーキと、熱乾燥処理後の乾燥ケーキの性状・物性の変化に関する次の記述のうち、**最も適切なもの**はどれか。

1. 加圧脱水直後の脱水ケーキは含水率が約 $90\%$ であり、乾燥処理を行うことによって含水率は約 $60\%$ まで低下する。
2. 熱乾燥処理を行うことにより、脱水ケーキの含水率は約 $60\%$ から約 $30 \sim 36\%$ 程度まで低減され、長径 $2 \sim 20\,\text{cm}$ の塊状から粒径 $0.5 \sim 5\,\text{mm}$ の細粒状へと性状が変化する。
3. 乾燥ケーキは脱水ケーキに比べて水分が抜けるため、同一重量あたりの輸送体積（かさ容積）が約5倍に膨張し、運搬効率が著しく悪化する。
4. 脱水ケーキを乾燥処理しても、その外観形状や粒径分布には一切変化が生じず、単に重量のみが比例して減少する。

**【正解】2**  
**【解説】**
* 1：不適切。加圧脱水直後の脱水ケーキの含水率は約 $60\%$ であり（濃縮汚泥スラッジが約 $95 \sim 98\%$）、乾燥処理によって約 $30 \sim 36\%$（またはそれ以下）まで低下する。
* 2：記述の通り適切。含水率が約60%から約30〜36%に低下し、サイズも $2 \sim 20\,\text{cm}$ の板状・塊状から $0.5 \sim 5\,\text{mm}$ の扱いやすい細粒状（ペレット状）に改質される。
* 3：不適切。水分が蒸発し細粒化されることで空隙が減少し、総重量・総体積ともに大幅に縮減するため、輸送効率は飛躍的に向上する。
* 4：不適切。破砕・乾燥・造粒の各工程により、不規則な巨大ブロック状から均質な球状・顆粒状の細粒へと劇的に形状が変化する。
* **日常のたとえ**: 濡れた重い粘土の塊（脱水ケーキ）を、パン粉やグラニュー糖のようなサラサラの粒（乾燥ケーキ）に加工することで、袋詰めしやすく持ち運びも軽くなる。
* **出典**: テキスト第9章 p.482〜483「乾燥ケーキの性状」

### 【問5】浄水発生土の有効利用と排出者責任（総合実務）
浄水発生土の資源有効利用および水道事業者の責務に関する次の記述のうち、**最も不適切なもの**はどれか。

1. 浄水発生土は、病原菌や有害重金属の混入懸念が極めて少ない清浄な無機性土壌であるため、適切に乾燥・造粒されたものは園芸用土やグラウンド用土として高い需要がある。
2. 浄水発生土はセメント工場において、粘土の代替原料（シリカ・アルミナ源）として高温キルンで焼成利用されるマテリアルリサイクルルートが確立されている。
3. 浄水発生土を道路の盛土材や埋戻し材として利用する場合、所定の強度（コーン指数）を確保するため、必要に応じて生石灰やセメント系固化材等を添加・混合して改良土とする。
4. 浄水処理工程で使用する凝集剤の種類や注入率に関わらず、発生する浄水発生土の化学的・物理的性状は全国一律であるため、水道技術管理者が自ら性状試験を行って適応先を検討する必要はない。

**【正解】4**  
**【解説】**
* 1, 2, 3：記述の通り正しい。園芸用土、セメント原料、改良盛土材等へのリサイクルは代表的な有効利用事例である。
* 4：不適切。原水の水質特性や、使用する薬品（ポリ塩化アルミニウム、硫酸アルミニウム、鉄系凝集剤、高分子凝集剤等）の違いによって、発生土のpH、アルミニウム残留濃度、保水性、粒度構成等は事業体ごとに大きく異なる。水道事業者は排出者として自ら発生土の性状を把握し、それに適合した有効利用先を見出す責務がある。
* **日常のたとえ**: 料理で出る「出汁ガラ」が、かつお節か昆布か煮干しかによってふりかけや肥料への向き不向きが違うように、使った凝集剤や取水河川によって土の性質が異なるため、自分の浄水場の土に合ったリサイクル先を技術者が自ら見極めなければならない。
* **出典**: テキスト第9章 p.483〜485「浄水発生土の有効利用と排出者責任」
