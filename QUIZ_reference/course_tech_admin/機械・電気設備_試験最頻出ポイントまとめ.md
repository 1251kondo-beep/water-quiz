  * **2) 設備診断技術（ハイライト）**
    > 「(3) 設備診断技術とは、一般的に『**設備の状態、すなわち設備にかかるストレス、故障や劣化、強度、性能等を定量的に把握して信頼性や性能を診断予測し、異常があれば、その原因、位置、危険度等を識別評価し、その修正方法を決定する技術**』と解されている。」

* **試験対策・出題のツボ**:
  * **TBMからCBMへの転換**: 従来の定期的な時間計画保全（TBM）だけでなく、計測データに基づく状態監視・機能診断（CBM）を組み合わせることが合理的管理の基本。
  * **定量的追跡データの例**:
    * 電気的特性 $\rightarrow$ **絶縁抵抗（メガオーム）**、漏れ電流、誘電正接（tanδ）
    * 機械的特性 $\rightarrow$ **摩耗量（油中摩耗粉、クリアランス）**、**振動幅（変位・速度・加速度）**
  * **管理限界（クライテリア）**: 機器が破損する前に、あらかじめ設定した「管理限界（閾値）」に近い段階で計画的に部品交換・補修を行うことで、機器の延命化とLCC（ライフサイクルコスト）最小化を図る。

```
【テキスト該当箇所: p.501 / 2.3.2 浄水施設の機械設備 / 3) 保全の留意点】
```

* **青チェック（✓）および蛍光ペンハイライト・下線箇所**:
  * **3) 保全の留意点（✓）**

  * **送・配水ポンプの役割と総合的水運用（ハイライト）**
    > 「送・配水ポンプの役割は、必要な水量及び水圧を確保し、需要者へ安全かつ安定的で効率的に給水することである。しかし、そのためにはポンプのみでなく、**系統の複数化・ループ化や水撃作用（ウォータハンマ）対策、配水池容量を活用した水運用等、送・配水系として総合的に対応する必要がある。**」

* **試験対策・出題のツボ**:
  * **膨大な機器と重点保全**: 浄水施設には多種多様な機械が存在するため、一律の管理ではなく、**プラントの主体をなす重要機器（送配水ポンプ、主電動機等）を重点対象**とする。
  * **予知保全（Predictive Maintenance）**: 故障の兆候を事前に察知し、重大故障に至る前に対処する。
  * **管路・施設の一体対応**: ポンプ単体の性能だけでなく、配水池の容量、管路のループ化、水撃防止設備を含めた**系全体としての総合的水運用**が問われる。

### ③ ポンプ運転時の異常現象と防止策（IMG_7314 / p.506-507）

```
【テキスト該当箇所: p.506〜507 / 3.2.5 運転管理 / 2) 運転時の異常現象】
```

写真では、ポンプの運転異常現象の項目に**青チェック（✓）と蛍光ペン**が集中している。試験の最頻出分野である。

* **青チェック（✓）およびハイライト箇所**:

  1. **(1) キャビテーション（✓＋ハイライト）**:
     > 「ポンプのキャビテーションは、**羽根車の入口において圧力が低下し、そのときの水温における飽和蒸気圧に近づくと、水中の空気が遊離し空洞（キャビティ）ができる現象**をいう。空洞が羽根車内の圧力分布の高いところにおいて急激に押しつぶされて消滅し、**衝撃圧力**が発生する。これが継続すると**金属表面が壊食（エロージョン）**により肉減りや穴開き等を生じ、ポンプ能力を著しく低下させ羽根車を破壊する。」

  2. **(2) 水撃作用（ウォータハンマ）（✓）**:
     > 「水撃作用は、**停電や設備故障等によりポンプが急停止すると、管内を充満して流れる水流が急激に変動し、管内に異常に大きい圧力変動が発生する**。この場合、**負圧や衝撃圧力により配管やポンプ用バルブ等に、変形・破損等の被害**を与えることがある。」

  3. **(3) サージング（✓＋ハイライト）**:
     > 「サージングとは、**ポンプ揚程―流量特性の右上がりになる流量範囲において、圧力及び吐出し量が周期的に不安定になり、振動、騒音を発生する現象**をいう。」

  4. **(5) ポンプ吸込側の異常（✓＋ハイライト）**:
     > 「ポンプは、**異物の吸込み、吸込水位の異常低下、吸込管路及び軸封部からの空気の混入等により、異常振動・騒音を発生**することがある。」

  5. **(7) 効率低下（✓＋ハイライト＋下線）**:
     > 「ポンプは、**仕様点からかけ離れた領域で運転すると、著しい効率の低下を招く**。このような場合は、**回転速度制御などの運転方式を採用するか、給水区域の変更により適正なポンプ吐出し量となるようにする。**」

* **試験対策・出題のツボ（ひっかけパターン）**:
  * **キャビテーションの発生場所**: 「羽根車の出口」とする誤り肢 $\rightarrow$ 正しくは**「羽根車の入口（吸込側負圧部）」**。
  * **キャビテーションの物理要因**: 水温における**「飽和蒸気圧」**以下になること。
  * **サージングのQ-H特性**: 「右下がり特性」とする誤り肢 $\rightarrow$ 正しくは**「右上がり特性（不安定領域）」**。
  * **締切運転（過小流量運転）の危険性**: 吐出弁を閉じたまま運転すると、内部水が攪拌熱で急激に温度上昇・蒸気化し、焼付き事故を起こす（バイパス弁で逃がす）。
  * **効率改善手法**: 流量を減らすために吐出弁を絞る（バルブ絞り運転）のはエネルギー損失が大きい。**インバータ等による回転速度制御**、または**給水ブロック（給水区域）の再編**により適正吐出し量とする。

### ④ 凝集用薬品注入設備の構成と注入方式（IMG_7315 / p.514）

```
【テキスト該当箇所: p.514 / 5.2.1 凝集用薬品及び注入設備の種類 / 2) 薬品注入設備】
```

* **青チェック（✓）および蛍光ペンハイライト箇所**:
  * **2) 薬品注入設備（✓）**

* **試験対策・出題のツボ**:
  * **構成機器3要素**: **「貯蔵槽」**、**「注入ポンプ」**、**「注入機」**。

    1. **定量ポンプ式**: ダイヤフラム式・プランジャー式ポンプのストローク調整により注入量を高精度に決定。

    * 滅菌設備（塩素注入・次亜注入）、計装・通信制御電源、**緊急遮断弁**、取水・送水ポンプ。

### ⑥ 機電設備のリスク対策・停電対策と実地訓練（IMG_7317 / p.570-571）

```
【テキスト該当箇所: p.570〜571 / 13.3 機械・電気設備におけるリスク対策 / 13.3.1 停電対策】
```

* **青チェック（✓）および蛍光ペンハイライト・下線箇所**:
  * **13.3.1 停電対策（✓＋ハイライト＋下線）**
    > 「**停電発生に対して、安全性を確保しながら施設の停止を極力低減するとともに速やかな復旧が行えるよう、マニュアルの作成と定期的な停電対応の訓練を実施することが重要である。**」
  * **1) マニュアルの作成（ハイライト）**:
    > 「各種の事故を想定し、**停電時の施設の運用方法や停電事故時の連絡系統、復電時の復旧方法、事故原因の究明手順リスト等のマニュアルを作成**することが重要である。」
  * **3) 停電事故時の対応（ハイライト）**:
    > 「事故原因や施設の状況を詳細に把握することに努め、これらの情報を正確に**電気主任技術者に報告しその指示に従う**。」
  * **13.3.2 地震対策（ハイライト）**:
    > 「冷却水などの給水ラインについては、破損のおそれの有無などを調査し、**燃料供給槽や小出し槽と発電機本体との連結配管の要所への可とう管の挿入等、配管が地震時に破損しないよう改善**する。始動用の蓄電池の電槽などについても点検し、電槽間や架台との間に緩衝材を入れて揺れによる電槽の破損防止を行い架台にしっかり固定する。」
  * **配電盤・継電器の耐震化（p.571）**:
    > 「配電盤は**アンカーボルトで固定**。盤に設置する保護継電器は、**振動に強いデジタル型、静止型を使用することが望ましい**（誘導形は誤動作しやすい）。」
  * **雷害対策・瞬低対策（p.571）**:
    > 「**接地設備、SPD（サージ防護装置）**の整備。ポンプ回転速度制御装置（VVVF・インバータ）は雷等の瞬時電圧低下で停止しやすいため、**運転継続に必要な制御電源や冷却ファン電源に対し、無停電電源装置（UPS）から供給するなどの瞬時電圧低下対策**を行う。」

* **試験対策・出題のツボ**:
  * **マニュアル＋実地訓練の必須性**: マニュアルを整備するだけでなく、日常業務で経験できない事故対応を迅速に行うため、**「定期的な停電対応訓練の実施」**が必須条件。
  * **電気主任技術者の指揮**: 停電事故発生時は、独断で操作せず**電気主任技術者へ正確に報告し、その指示に従って**受電操作を行う。
  * **配管の可とう管（フレキシブルジョイント）**: 地震による不同沈下・相対変位から**燃料配管・冷却水配管の破断を防ぐ**ため、要所に可とう管を挿入。
  * **静止形・デジタル形継電器**: 機械的可動接点を持つ誘導形継電器は地震の揺れで誤トリップしやすいため、**静止形・デジタル形**を採用。
  * **インバータの瞬低保護**: 落雷による瞬時電圧低下（数十ミリ秒）でインバータが停止しないよう、**制御電源・冷却ファン電源をUPS（無停電電源装置）でバックアップ**。
