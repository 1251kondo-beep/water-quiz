## 1. 取水管理の基本方針と法的義務（テキスト p.248〜249）

### (1) 取水管理の目的
* 常に所要量の良質な原水を安定して確保し、後段の導水・浄水・配水工程へ安全に供給すること。

### (2) 給水開始前の検査（水道法に基づく義務）
* **検査の対象**: 新設、増設、または改造した取水施設を用いて給水を開始しようとするとき。
* **検査内容**: **水質検査** および **施設検査**。
* **水道技術管理者の職責（重要事項）**:
  * 水道法第13条および第19条に基づき、これらの検査は **水道技術管理者が自ら従事するか、または従事する職員を直接監督して実施しなければならない**。

### (3) 取水管理の実務基準
* **常時監視・制御**: 取水量、河川水位・井戸水位、水圧、原水水質（濁度・pH・水温・電気伝導率・油膜等）を24時間連続監視する。
* **非常時・水質事故時の迅速遮断体制**:
  * 油流出事故や有害物質流入時には、取水ゲートや仕切弁を迅速に遠隔・手動操作して **直ちに取水を遮断・停止できる体制** を確立しておく。
* **地表水と地下水の管理区分**:
  * **地表水**: 河川水位の急激な変動や洪水時の濁水流入に対し、ゲート開度調節や取水塔の選択取水により的確に対応する。
  * **地下水**: 揚水試験で定めた適正揚水量を遵守し、過剰揚水による井戸枯渇、砂の吸い込み、地盤沈下を防止する。
* **法令遵守**: 河川区域内の取水施設は河川法の適用を受けるため、河川管理者と合意した「取水操作規程」を厳格に遵守する。

## 2. 貯水施設（ダム・貯水池）の要件と形式（テキスト p.250〜256）

### (1) 貯水施設に求められる3大基本要件
1. **安全性・経済性**: 構造物自重、静水圧・動水圧、堆砂圧、地震力、間隙水圧に対して構造力学的に安全であり、経済性や周辺環境保全に配慮されていること。
2. **水量の安定確保**: 河川の自然流量が減少する渇水時においても、必要量の原水を安定供給できる十分な有効貯水容量を有すること。
3. **水質保全**: 貯留水の長期滞留に伴う富栄養化（アオコ・異臭味発生）や貧酸素化を防止するため、**曝気循環設備（エアレーション装置）** や選択取水設備を具備すること。

### (2) ダムの定義と分類
* **河川法上のダムの定義**:
  * 基礎地盤から堤頂（天端）までの高さ（堤高）が **$15\,\text{m}$ 以上のもの** を「ダム」と定義する（堤高15m未満のものは「堰（せき）」として扱われる）。
* **多目的ダムと専用ダム**:
  * **多目的ダム**: 水道用水、洪水調節（治水）、流水の正常な機能の維持、かんがい用水、工業用水、水力発電など、2つ以上の用途を併せ持つダム（国土交通省や独立行政法人水資源機構が築造・管理）。
  * **専用ダム**: 水道専用ダムなど、単一の目的のために水道事業体が築造・管理するダム。
  * ※日本の水道取水量（年間約150億トン）の **約半数はダムによる開発・補給水** に依存している。

### (3) ダムの主な構造形式の比較

```
              【貯水施設（ダム）の主要形式】
  ┌────────────────┬────────────────┬────────────────┐
  │ ① 重力式      │ ② アーチ式     │ ③ ロックフィル │
  │ (コンクリート自重│ (水圧を両岸岩盤 │ (岩石盛立・    │
  │  で水圧に対抗)  │  へ伝達・薄堤体)│  中央遮水心壁) │
  └────────────────┴────────────────┴────────────────┘
                   │ ④ アース式     │ ⑤ 中空重力式   │
                   │ (土質材料締固め│ (内部空洞・    │
                   │  溜池・小規模) │  コンクリート節減)│
                   └────────────────┴────────────────┘
```

| ダム形式 | 構造機構・特徴 | 代表例・留意事項 |
| :--- | :--- | :--- |
| **コンクリート重力式ダム**<br>（Gravity Dam） | コンクリートの巨大な自重によって水圧を支える形式。日本で最も実績が多く信頼性が高い。 | 宮ヶ瀬ダム（神奈川県）、小河内ダム（東京都・奥多摩湖） |

## 3. 有効貯水容量と利水安全度（テキスト p.257）【最重要】

### (1) 新規開発水量と利水安全度の定義
* **新規開発水量の決定基準（最重要ポイント）**:
  * 貯水施設（ダム）における新規開発水量は、**「10年に1回程度」の発生確率を基準とする渇水年（基準渇水年）** においても、ダムからの補給によって計画取水量を安定して確保・供給できる容量として設計する。
* **利水安全度 $1/10$**:
  * 過去数十年の降雨・河川流況データに基づき、確率規模 1/10（10年に1回）の大渇水を想定しても計画水量を補給しきれる規模として有効貯水容量を算定する。
  * 1/20や1/50を想定するとダム規模・事業費が過大となり不経済となるため、日本の利水計画では「10年に1回」が標準採用されている。

### (2) 河川の正常流量とダム補給放流のメカニズム
* **正常流量（維持流量）**:
  * 河川生態系の保全、景観維持、漁業、舟運、下流の既得水利（農業用水等）、塩水遡上防止などのために、河川に常時流れていなければならない最低限の流量。
* **ダム補給の仕組み**:
  * 渇水期に河川の自然流量が「正常流量 ＋ 各利水者の取水量」を下回った場合、利水者は河川から無条件に水を取ることはできない。
  * そこで、**豊水期にダムに貯留した水を河川へ放流（補給放流）** し、河川流量を底上げすることで、下流での安定した水道取水を可能にしている。

## 4. 水利権の3大分類体系（テキスト p.266）【最重要】

河川の流水を排他的・継続的に使用（取水）する権利（水利権）は、以下の3つの観点から体系的に分類される。

```
                    【水利権の3大分類】
  ┌───────────────────┬───────────────────┬───────────────────┐
  │ ① 成立の由来     │ ② 使用目的       │ ③ 権利の安定性   │
  │ ・許可水利権      │ ・水道用水        │ ・安定水利権      │
  │   (河川法第23条)  │ ・かんがい(農業)  │   (通年・常時安定)│
  │ ・慣行水利権      │ ・工業用水        │ ・豊水水利権      │
  │   (明治29年以前)  │ ・発電用水        │   (出水期限定)    │
  │                   │                   │ ・暫定水利権      │
  └───────────────────┴───────────────────┴───────────────────┘
```

### (1) 成立の由来による分類
* **許可水利権**:
  * **河川法第23条** に基づき、河川管理者（国土交通大臣または都道府県知事）から正規の審査・許可を受けて成立した権利。
  * 近代以降のダム開発水や水道取水の大部分がこれに該当する。通常10年等の有効期間が設定され、更新許可が必要。
* **慣行水利権**:
  * 旧河川法が制定された **明治29年（1896年）以前** から、農業用水等として慣行的に利用されてきた歴史的権利。
  * 法の施行に伴い、河川法第23条の許可を受けたものと法的にみなされている（みなし水利権）。

### (2) 使用目的による分類
* 水道用水、かんがい（農業）用水、工業用水、発電用水、養殖用水など、取水した水の利用目的ごとの区分。

### (3) 権利の安定性による分類
* **安定水利権**:
  * 年間を通じて、基準渇水時であっても **常時安定して取水することが法的に認められている最も強固な権利**。水道用水の基本水利権はこれに該当する。
* **豊水水利権（特定水利権）**:
  * 出水期や農閑期など、河川流量が豊富にある特定の季節・時期に限定して取水が認められる権利。
* **暫定水利権**:
  * ダム本体工事の遅延等により、ダムが完全竣工するまでの間、暫定的な条件付きで取水を認める一時的な水利権。

### (4) 【参考】多目的ダムのコストアロケーション（費用配分）
* 多目的ダムの建設には巨額の公金と利水者負担金を要するため、国土交通省の基本計画に基づき、治水（洪水調節）および各利水者（水道・工水・農水・発電）が受ける **有効貯水容量の割合や推定便益の比率に応じて建設費・維持管理費を公平に分担** する。これを「コストアロケーション」と呼ぶ。

## 5. 貯水施設の維持管理と河川法上の義務（テキスト p.258〜265）

### (1) 法令に基づく管理者の義務
* **技術基準の遵守**: ダム堤体、洪水吐き、放流設備は「河川管理施設等構造令」の構造技術基準に適合しなければならない。
* **ダム管理主任技術者の選任義務（河川法第50条）**:
  * ダムの維持・操作・安全管理を統括させるため、所定の資格・実務経験を有する **「ダム管理主任技術者」の選任が法的に義務付けられている**。
* **ダム操作規程の厳守**:
  * 洪水時・渇水時のゲート開閉手順、放流連絡体制を定めた「ダム操作規程」を策定し、河川管理者の認可を受けて厳格に運用する。

### (2) 堤体の保全と貯水池の維持管理実務
* **堤体の安全点検**:
  * 堤体内や基礎岩盤の **揚圧力（浮力・間隙水圧）**、堤体積算 **漏水量**、堤頂の変位（たわみ）、地震時の地震動加速度などを計器で常時測定し、転倒・滑動に対する安全性を照査する。
* **貯水池の堆砂（たいさ）対策**:
  * 上流から流入する土砂が貯水池に堆積すると有効貯水容量が減少する。
  * **対策工法**:
    * 水源林の保全・上流砂防堰堤の整備
    * **土砂バイパストンネル**: 洪水時の高濃度土砂流をダム湖に流入させず、トンネルで直接ダム下流へ迂回・バイパスさせる。
    * **排砂・フラッシング放流**: 堤体底部の排砂門から堆積土砂を下流へ洗い流す（下流河川への濁水影響に十分配慮）。
* **貯水池の水質保全対策**:
  * **曝気循環設備（エアレーション装置）**: 深層に圧縮空気を送り込み、底層水と表層水を循環混合させて水温成層を破壊し、アオコ増殖や底泥の貧酸素化（マンガン・鉄・硫黄溶出）を防止する。
  * **選択取水設備**: 水深方向の水質を観測し、最も良質な水深のゲートから取水する。
  * **流木止めフェンス（オイルフェンス）**: 洪水時に流入する流木やゴミ、表層アオコを貯水池上流端で捕捉する。

## 6. 【総括】全講義の最重要9大ポイント総まとめ

講義全体を通じて、水道技術管理者試験および実務において最重要となるポイント（スライド黄字箇所）の総括一覧。

```
              【水道水源・取水・貯水 9大重要ポイント総括】
  ┌─────────────────────────────────────────────────────────────┐
  │ ① 水源の特性: 表流水は渇水・洪水の影響大、浅井戸は地表汚染影響大  │
  │ ② 水源の選定: 将来水量の安定確保、自然流下の活用配置        │
  │ ③ 水質監視体制: 24時間監視と水系内水道事業者間の情報連絡共有│
  │ ④ 取水塔の機能: 多段ゲートによる水位・水質変動への「選択取水」  │
  │ ⑤ 沈砂池の構造: 粗砂の重力沈降、清掃時取水継続のため原則2池以上 │
  │ ⑥ 井戸揚水試験: 段階揚水・連続揚水(24h)・水位回復試験の3種    │
  │ ⑦ 有効貯水容量: 「10年に1回程度」の基準渇水年に対応する新規開発 │
  │ ⑧ ダム関係法令: 河川法・構造令、ダム管理主任技術者選任義務   │
  │ ⑨ 水利権の3分類: 成立の由来(許可/慣行)、目的、安定性(安定/豊水) │
  └─────────────────────────────────────────────────────────────┘
```

1. **水道水源の特性（テキスト p.234）**:
   * 表流水：渇水時に水量減少・水質悪化の影響を強く受ける。洪水時に高濁度となる。
   * 浅井戸：地表面からの生活排水・農薬・油・PFAS等の汚染を受けやすい。水量が降雨に左右される。
2. **水道水源の選定と取水口の位置（テキスト p.235）**:
   * 将来にわたり必要水量・水質が安定して確保できる地点を選定する。
   * 送配水網との位置関係を考慮し、可能な限り自然流下を活用できる省エネ配置とする。
3. **水源の水質管理と情報共有体制（テキスト p.237）**:
   * 原水水質を常時監視し、水質異常（油流出等）検知時は同一水系の関係水道事業者に速やかに連絡し、連携して取水停止等の措置を講じる。
4. **取水塔の構造と機能（テキスト p.240〜241）**:
   * 水中に独立設置され、外壁の多段ゲートから取水する。
   * 水位変動や水質変化（表層アオコ・底層濁水）に応じて最適な層を選んで取水する「選択取水」が可能。
5. **沈砂池の機能と構造（テキスト p.241）**:
   * 粗い砂を重力沈降させ、ポンプや管路の摩耗を防ぐ。
   * 点検・清掃時にも取水を停止させないため、**原則として「2池（2系列）以上」を設置** する。
6. **井戸の揚水試験（テキスト p.245）**:
   * **段階揚水試験**（限界揚水量把握）、**連続揚水試験**（24時間以上連続揚水・平衡水位確認）、**水位回復試験**（ポンプ停止後の水位復帰推移）の3試験を実施する。
7. **貯水施設の有効貯水容量（テキスト p.257）**:
   * ダムの新規開発水量は、**「10年に1回程度」の発生確率を基準とする渇水年（基準渇水年）** においても計画取水量を確保できる容量として設計する。
8. **ダムに関係する法令（テキスト p.258）**:
   * 堤高15m以上のダムは「河川法」および「河川管理施設等構造令」の適用を受ける。
   * 河川法第50条に基づき「ダム管理主任技術者」の選任が義務付けられている。
9. **水利権の3大分類（テキスト p.266）**:
   * 成立の由来（許可水利権、慣行水利権）
   * 使用目的（水道用水、かんがい用水、工業用水、発電用水等）
   * 権利の安定性（安定水利権、豊水水利権、暫定水利権）
