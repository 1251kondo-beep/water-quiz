## 1. 水道事業カルテと経営・耐震化の現状（テキスト 47ページ）

国土交通省は耐震化推進には経営改善が不可欠であるとの観点から、料金見直しや耐震化の取り組みを加速させるため、各事業体の状況をまとめた**「水道事業カルテ」**を公表しています。

水道事業カルテでは、**「料金回収率」**と**「耐震化に関する3指標」**を組み合わせて評価を行っています。
1. 基幹管路の耐震適合率
2. 浄水施設の耐震化率
3. 配水池の耐震化率

### 主な分析グループと課題
* **グループ分けの定義**:
  * **グループⅠ**: 料金回収率が100％未満の水道事業者等
  * **グループⅡ**: 料金回収率が100％以上の水道事業者等
  * **ハイフン後の数字**: 耐震3指標（管路・浄水施設・配水池）のうち、全国平均以下の項目数（0〜3）
* **グループ1-3（グループⅠ-3：料金回収率100%未満 かつ 耐震3指標すべてが全国平均以下）**:
  * 全国の事業者の**約18%（248事業者）**を占める。
  * このグループの**約73%が給水人口3万人未満**の小規模事業者であり、収支が赤字な上に耐震化も進まないという極めて厳しい経営状況にある。
* **グループ2-3（グループⅡ-3：料金回収率100%以上 だが 耐震3指標すべてが全国平均以下）**:
  * 全国の**約11%（146事業者）**が該当し、このうち約65%が給水人口3万人未満。
  * 料金回収率は黒字であっても耐震投資に十分回せていない実態が浮き彫りとなっている。
* **国の対応**: 耐震3指標がすべて全国平均以下の事業体に対しては、経営状況や資産管理状況を確認するためのチェックシートの提出を求め、課題の詳細な把握に努めています。

## 2. 震災対策と相互応援体制（テキスト 47〜48ページ）

大地震においては、平時の施設予防計画（耐震化）を進めていても被害をゼロにすることは難しいため、応急給水・応急復旧といった「応急対策」の手順確立と日頃の訓練が極めて重要です。

### (1) 相互応援体制と手引きの改定
日本水道協会（日水協）は「地震等緊急時対応の手引き」を策定し、全国7支部・46都道府県支部等のネットワークによる迅速な応援体制を整備しています。

* **能登半島地震（令和6年1月）を受けた手引きの改定（令和7年3月）**:
  * **先遣隊の迅速派遣**: 支援要請を待たずに先遣隊を派遣する枠組みの構築。
  * **デジタル技術の活用**: 情報共有の迅速化・一元化。
* **緊急時の情報伝達ルール（重要）**:
  * 発災時、被災事業体は被害状況および応援要請の有無を速やかに県支部長へ連絡する。
  * **「被害がない場合」や「応援要請がない場合」であっても、状況確認のため必ず一報を入れることが徹底ルール**となっています（初動は電話やメールでも可）。
  * 原則として**震度6強以上**の地震が発生した場合、県支部長は速やかに先遣調査隊を派遣します（県内対応が困難な場合は地方支部へ要請）。

### (2) 近年の地震災害における対応事例
* **令和8年 熊本県を震源とする地震（7月28日発生・M7.1・最大震度7）**:
  * 九州3県14事業体で最大10万8,000戸の断水が発生。
  * 激甚な被害を受けた八代市、宇城市、宇土市、氷川町等に対し、応援部隊（給水班・復旧班）をブロックごとに配置。
  * 能登半島地震での教訓を活かした全国からの応援により、給水車延べ4,331台が稼働し、発災から約1か月で全域の断水が解消。
  * **復旧の具体例**: 八代生活環境事務組合の浄水場では、着水井への流入管（導水管）破損に伴い、仮配管（地上配管）を迅速に布設して早期再稼働を実現。また、入浴支援のために「可搬式浄水装置（日量50m³規模）」が配備・活用されました。

## 3. 広域連携と官民連携（ウォーターPPP）（テキスト 49〜51ページ、98〜102ページ）

### (1) 改正水道法に基づく広域連携
小規模事業体における技術力不足やノウハウ継承の課題を解決するため、国が基本方針を策定し、都道府県が「広域化推進計画」を策定して推進しています。

* **連携の類型（ピラミッド構造）**:
  1. **施設の共同化**: 施設共同設置、緊急時連絡管の整備、資機材の共同備蓄など。
  2. **管理の一体化**: 水質検査の共同実施、維持管理や総務事務の共同委託など。
  3. **経営の一体化**: 経営主体を同一にしつつ、認可は個別に保持する形態。
  4. **事業統合**: 経営も事業認可も1つに統合する形態（水平統合・垂直統合）。

### (2) 官民連携手法の整理
* **第三者委託（法第34条の2）**: 技術的業務を水道法上の管理責任とともに外部委託する方式。
* **DBO方式（Design-Build-Operate）**: 設計・建設・運転管理を一括発注（資金調達は自治体）。
* **コンセッション方式（PFI法に基づく運営権設定型）**: 自治体が施設所有権を保持したまま、民間事業者に運営権を設定し利用料金を徴収させる方式（例：宮城県の上工下水一体官民連携事業「みやぎ型管理方式」）。

### (3) ウォーターPPPの推進（レベル3.5の導入）
国はコンセッション（レベル4.0）への移行段階として、**「管理・更新一体マネジメント方式（レベル3.5）」**を位置付け、重点的に推進しています。

* **レベル3.5の4要件**:
  1. 原則10年以上の長期契約
  2. 性能発注の導入
  3. 維持管理と更新の一体マネジメント（※施設運営権は設定しない）
  4. 利益の適正な配分を行うプロフィットシェアリング等の仕組み

## 4. 水質管理と水質基準（テキスト 51〜55ページ）

### (1) 水質基準の体系
水道法第4条に基づき「水質基準に関する省令」で規定されています。

* **水質基準項目（51項目）**: 遵守が義務付けられている基準。
  * **人の健康に関する項目（31項目）**
  * **性状・生活利用上の支障に関する項目（20項目）**
  * ※PFOSおよびPFOAについては水質管理上の重要な物質として位置付けられています。
* **水質管理目標設定項目（26項目）**: 将来的な基準化の検討や管理上留意すべき項目。
* **要検討項目（49項目）**: 今後のデータ収集・評価が必要な項目。

### (2) 耐塩素性病原微生物（クリプトスポリジウム等）対策
クリプトスポリジウムは塩素消毒に対する耐性が極めて強い原虫です（平成8年 埼玉県越生町での集団下痢症事例）。
* 対策として**「ろ過池出口の濁度0.1度以下」**の保持が定められています。
* 不活化技術として**「紫外線処理設備」**が導入されており、当初は地下水・伏流水等に限定されていたものが、ろ過設備との併用を前提に表流水系でも適用が拡大されています。

### (3) 水質検査体制と「水道GLP」
* 水質検査の信頼性確保のため、外部委託検査機関は指定制から**「3年ごとの更新登録制」**に改められています。
* **水道GLP（優良試験所規範制度）**: 日本水道協会が定めた水質検査の品質保証システム（ISO 9001の品質管理システムとISO/IEC 17025の技術的要件をベースに構成）。全国の多くの主要検査機関が認定を取得しています。

### (4) 水質異常時の給水継続判断（極めて重要）
水質基準を超過した場合の対応について、水道技術管理者は社会的影響を考慮した高度な判断が求められます。

#### 【水質基準超過時の給水停止の原則】
* **原則**: 基準値を形式的に超えたからといって直ちに給水を全停止するのではなく、代替水源の有無や消火・医療等の社会的影響を勘案し、**飲用制限（飲用以外の生活用水として供給）をかけた上で給水を継続する判断**を取り得る。
* **例外（直ちに給水停止しなければならない4項目）**:
  人の健康に直接かつ甚大な危害を及ぼす以下の項目が検出された場合は、**直ちに給水を全停止**しなければならない。
  1. **一般細菌**
  2. **大腸菌**
  3. **シアン化合物**
  4. **水銀 及び その化合物**
* **実例（熊本の地震時）**: 地震の影響で一時的に「濁度」の基準値を超過した際、直ちに給水を止めるのではなく、飲用制限の広報・周知を行った上で生活用水としての給水を継続し、市民生活への破滅的な影響を回避した事例があります。
