## 1. 薬品注入設備の目的と法定基準（テキスト p.376）

### (1) 薬品注入処理の目的と不可欠性
* **急速ろ過方式における必然性**:
  * 水道原水中に含まれる微細な懸濁物質やコロイド粒子、病原微生物（クリプトスポリジウム等）は、微小かつ負（マイナス）の電荷を帯びて反発し合っているため、**砂層を通過させる「ろ過」だけでは物理的に捕捉・除去することができない**。
  * したがって、前処理として薬品を注入し、粒子同士を結合・凝集させて巨大なフロック（塊）を形成させ、沈殿池で分離除去することが不可欠である。
* **緩速ろ過方式における位置づけ**:
  * 緩速ろ過は薬品を用いないのが原則であるが、洪水時等に原水濁度が **30度（または20〜30度）以上** に達すると、普通沈殿池を経ても濁質が沈降しきれず、砂層表面を急激に閉塞（目詰まり）させてしまう。そのため、高濁度時に限定して凝集処理や前処理設備を適用する場合がある。

```
【浄水薬品の3大分類】
┌──────────────────┬──────────────────┬──────────────────┐
│ ① 凝集剤（主剤） │ ② pH調整剤       │ ③ 凝集補助剤     │
│ (Coagulants)     │ (pH Conditioners)│ (Coagulant Aids) │
├──────────────────┼──────────────────┼──────────────────┤
│ ・PAC            │ ・アルカリ剤     │ ・活性ケイ酸     │
│ ・硫酸アルミニウム│   (苛性ソーダ等)  │ ・ポリアクリルアミド│
│ ・鉄系凝集剤     │ ・酸（濃硫酸等） │   (高分子凝集剤)  │
└──────────────────┴──────────────────┴──────────────────┘
```

### (2) 施設基準における薬品注入設備の4大要件（水道法・技術的基準省令）
水道法第5条に基づく「水道施設の技術的基準を定める省令」において、薬品注入設備は以下の厳格な構造・性能要件を満たさなければならない。

```
【薬品注入設備の4大構造・技術基準】
① 注入能力と耐薬品性 ── 原水の水質変動に応じた所要量を正確に注入でき、薬品の腐食性に耐える材質であること。
② 予備設備の義務付け ── 注入機には原則として「予備機（100%バックアップ）」を常備すること（停止時給水支障防止）。
③ 薬品・資材の安全性 ── 水に添加・接触する薬品および設備材質は、浸出性能基準に適合し、水質汚染の恐れがないこと。
④ 機械的耐久性       ── 状況に応じた強度、耐久性、耐摩耗性、耐食性、水密性を有すること。
```

* **最大注入量から最小注入量までの制御精度**:
  * 豪雨時の最大注入能力はもちろん重要であるが、実務上は**渇水期や清澄原水時における「最小注入量」を高精度に微量制御できること**が極めて重要である（注入ポンプの選定・インバータ制御・多段レンジ切替）。

## 2. 凝集の根本メカニズムと攪拌の2段階（テキスト p.376〜378）

### (1) コロイド粒子の荷電中和とフロック形成原理
自然界の河川水中に存在する粘土微粒子、細菌、ウイルス、着色有機物などの微小粒子（コロイド粒子：$1\,\text{nm} \sim 1\,\mu\text{m}$）は、水中で**「負（マイナス）の静電気（ゼータ電位）」**を帯びている。

```
【コロイド粒子の分散と凝集のメカニズム】
［自然状態］
   ( - ) ← 斥力（静電反発） → ( - )   自然界では同種電荷が反発し、永久に沈殿せず浮遊分散
                ▼
［凝集剤注入：荷電中和］
   ( - ) ＋ [ Al³⁺ / PAC ] ──→ [ ( ±0 ) ]  多価金属の正電荷が負電荷を中和（電気的二重層圧縮）
                ▼
［フロック成長］
   [ ±0 ] ── ファンデルワールス力 ──→ [ 巨大フロック ]  分子間引力で衝突・合体し重力沈降
```

---

### (2) 攪拌の2段階：急速攪拌 vs 緩速攪拌（★試験超頻出）
良好なフロックを形成し沈殿除去するためには、混和池とフロック形成池において攪拌強度を明確に分ける必要がある。

```
【急速攪拌（混和池） vs 緩速攪拌（フロック形成池）の対比】
┌───────────────────────────────┬───────────────────────────────┐
│ ① 急速攪拌（Rapid Mixing）    │ ② 緩速攪拌（Flocculation）    │
├───────────────────────────────┼───────────────────────────────┤
│ 【場所】薬品混和池（混和池）  │ 【場所】フロック形成池（凝集池）│
├───────────────────────────────┼───────────────────────────────┤
│ 【目的】                      │ 【目的】                      │
│ 注入した凝集剤を瞬時に水全体へ│ 電荷中和された微小粒子同士を穏│
│ 均等拡散させ、原水粒子と激しく│ やかに衝突・接触させ、沈降しや│
│ 衝突させて「荷電中和」を完了。│ すい「巨大フロック」へ成長。  │
├───────────────────────────────┼───────────────────────────────┤
│ 【攪拌強度】                  │ 【攪拌強度】                  │
│ **極めて強力（G値 大）**      │ **穏やか・緩速（G値 小）**    │
│ （フラッシュミキサー・水流段差）│ （フロキュレーター・パドル型）│
├───────────────────────────────┼───────────────────────────────┤
│ 【時間】                      │ 【時間】                      │
│ **数秒 〜 1分程度（極短時間）**│ **20分 〜 40分程度（長時間）**│
└───────────────────────────────┴───────────────────────────────┘
```

* **攪拌強度が不適正な場合の重大障害（★最頻出引っかけ）**:
  * **緩速攪拌が強すぎる場合**:
    * 水流の**「せん断力（破砕力）」**により、せっかく成長したフロックがズタズタに破壊され、再分散して沈殿しなくなる。
  * **緩速攪拌が弱すぎる場合**:
    * 粒子同士の衝突頻度が不足し、フロックが大きく成長せず、微小なまま沈殿池上澄水へ流出してしまう。

### 【PAC（ポリ塩化アルミニウム）の取り扱い注意点】
1. **希釈禁止の原則**:
   * PACを水で希釈して貯蔵すると、加水分解反応が進行して**白濁・ゲル化（凝固）**し、注入ポンプや配管を完全に閉塞させる。原則として「納入原液のまま」注入する。
2. **硫酸バンドとの混合厳禁**:
   * PACと硫酸アルミニウム（硫酸バンド）を同一タンクや同一配管で混合すると、化学反応により不溶性の沈殿・ゲル化を生じ、配管を閉塞させる。薬品を切り替える際は、**設備全体の入念な水洗浄（フラッシング）**が不可欠である。

## 4. ジャーテスト（Jar Test）の意義と手順（テキスト p.379）

### (1) ジャーテストの定義と目的
凝集剤および凝集補助剤の最適注入率、最適凝集pH、攪拌条件を決定するための、最も基本的かつ確実な室内実験である。

```
【ジャーテストの標準手順】
［原水採取］ ──→ ［複数ビーカーに分注］ ──→ ［薬品注入率を段階変化］ ──→ ［急速攪拌（1分）］ ──→ ［緩速攪拌（10〜15分）］ ──→ ［静置沈殿（10〜15分）］
                                                                                                                │
                                                                   ［評価：フロック形成・沈降速度・上澄水濁度・pH］ ◄─┘
```

### (2) 判定・評価項目
* **フロック形成の速さと大きさ**: フロックが速やかに発生し、粗大（直径数ミリ）に成長するか。
* **フロックの沈降速度**: 静置後、数分以内に底面へ急速沈降するか。
* **上澄水の清澄度（濁度・色度）**: 沈殿後の上澄水濁度が最も低く澄んでいるか。
* **pH・残留アルカリ度**: 凝集処理後のpHが適正範囲（pH 6.5〜7.5等）に収まり、アルカリ度が $20\,\text{mg/L}$ 以上残存しているか。

## 5. 凝集に影響を与える水質要因（pH・アルカリ度・水温）（テキスト p.379〜381）

### (1) pH（水素イオン濃度指数）
* アルミニウム系凝集剤（PAC・硫酸バンド）は、水中で加水分解して不溶性の水酸化アルミニウム $\text{Al(OH)}_3$ の沈殿（フロック）を形成することで濁質を巻き込む。
* pHが酸性側に外れるとアルミニウムイオン $\text{Al}^{3+}$ として水中に溶解し、逆に高アルカリ側に外れるとアルミン酸イオン $\text{Al(OH)}_4^-$ として再溶解する。
* 適正凝集pHを外れると、**フロックが形成されないばかりか、処理水中に溶存アルミニウムが残留（水質基準 $0.2\,\text{mg/L}$ 超過リスク）**する。

---

### (2) アルカリ度（Alkalinity）（★最重要数値基準）
* **凝集剤によるアルカリ度消費**:
  * アルミニウム塩が加水分解して酸（塩酸や硫酸）を放出するため、原水中のアルカリ度成分（$\text{HCO}_3^-$ 等）が中和・消費される。
* **残留アルカリ度の基準値**:
  * 良好な凝集反応を完結させ、処理水pHの過度の低下を防ぐため、**凝集剤注入後の水中に「アルカリ度 $20\,\text{mg/L}$ 以上」が残留していることが望ましい**（テキスト p.380）。
  * 原水のアルカリ度が低い場合（雪解け水、出水時など）は、**アルカリ剤（苛性ソーダ・消石灰）を併用注入してアルカリ度を補給**しなければならない。

---

### (3) 水温（Water Temperature）
* 水温が低下すると水の動粘性係数が上昇し、粒子のブラウン運動が低下するとともに凝集剤の化学反応が遅延する。
* **水温 $5^\circ\text{C}$ 以下の厳寒期**:
  * 硫酸アルミニウムでは著しいフロック形成不良が生じる。
  * 対策として、PACへの切り替え、アルカリ剤の添加、凝集補助剤（活性ケイ酸）の併用、または沈殿を省く直接ろ過法を採用する。

## 6. 酸・アルカリ剤の種類と注入実務（テキスト p.380〜381）

### (1) 酸処理（前酸処理）
* **適用ケース**:
  * 夏期のダム・湖沼等で植物プランクトン（藻類）の光合成により、二酸化炭素が消費されて**原水pHが異常高値（pH 8.5〜9.0以上）に跳ね上がった場合**。
* **使用薬品**:
  * **濃硫酸（$\text{H}_2\text{SO}_4$）**: 強酸。少容量でpHを強力に引き下げられる。耐酸性ポンプ・配管必須。
  * **炭酸ガス（二酸化炭素 $\text{CO}_2$）**: 取扱いは安全であるが、高圧ガス設備・大型気化貯蔵設備が必要。

---

### (2) アルカリ処理（前アルカリ処理 vs 後アルカリ処理）

```
【前アルカリ処理 vs 後アルカリ処理の目的比較】
┌───────────────────────────────┬───────────────────────────────┐
│ ① 前アルカリ処理 (Pre-Alkali) │ ② 後アルカリ処理 (Post-Alkali)│
├───────────────────────────────┼───────────────────────────────┤
│ 【注入点】着水井または混和池  │ 【注入点】ろ過池出口〜浄水池  │
├───────────────────────────────┼───────────────────────────────┤
│ 【目的】                      │ 【目的】                      │
│ 凝集剤注入に伴うpH低下を防ぎ、│ 給水栓水のpHを水道水質基準    │
│ 凝集に必要なアルカリ度（20mg/L│ （5.8〜8.6）に適合させるととも │
│ 以上）を補給してフロック形成。│ に、ランゲリア指数を改善する。│
└───────────────────────────────┴───────────────────────────────┘
```

* **ランゲリア指数（Langelier Saturation Index: LI）の改善**:
  * 水の炭酸カルシウムに対する溶解・析出傾向を示す指数。
  * $\text{LI} < 0$（負の値）では、水が配水管・給水管の金属を腐食・溶解（赤水発生）させる。
  * 消石灰や苛性ソーダを注入して $\text{LI}$ を $0$ 付近（ややプラス側）に調整することで、**管内面に炭酸カルシウムの緻密な保護被膜を形成させ、配水管路の腐食（赤水）を防止**する。

---

### (3) 代表的アルカリ剤の特性比較（苛性ソーダ vs 消石灰）

```
【苛性ソーダ vs 消石灰の特性対比】
┌──────────────┬────────────────────────────────┬────────────────────────────────┐
│ 項目         │ 水酸化ナトリウム（苛性ソーダ） │ 水酸化カルシウム（消石灰）     │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 化学式       │ $\text{NaOH}$                  │ $\text{Ca(OH)}_2$              │
│ 形態         │ 液体（通常48%または45%原液）   │ 白色微粉末                     │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 溶解性       │ 水に極めて易溶（液体注入容易） │ **水に極めて難溶**（スラリー化要）│
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ 防食効果     │ pH・アルカリ度上昇のみ         │ **管内面に保護被膜形成（大）** │
├──────────────┼────────────────────────────────┼────────────────────────────────┤
│ **取扱注意点**│ **① 低温（約10〜15℃）で結晶化・固化**│ **① ポンプ・配管内にスケール付着**│
│              │ **② 水で希釈する際に激しい発熱**│ **② 注入ノズルの閉塞頻発**     │
│              │ **③ 空気中のCO₂を吸収して劣化**│ ③ 湿気で炭酸塩化して硬化       │
└──────────────┴────────────────────────────────┴────────────────────────────────┘
```

* **苛性ソーダ希釈時の重大安全ルール（★最重要）**:
  * 苛性ソーダ原液を水で希釈する際は、膨大な「溶解熱（発熱）」が発生し、急激に沸騰・突沸して強アルカリ液が飛散する危険がある。
  * **「必ず大量の水の中に、苛性ソーダを攪拌しながら少しずつ注ぐ」**（絶対に苛性ソーダの中に水を注いではならない）。
  * 原液（48%）は冬期に結晶化（固化）しやすいため、受入後に **20〜25% 程度に希釈**して貯蔵するか、タンク・配管に加温保温設備を設ける。

## 7. 凝集補助剤（テキスト p.381〜382）

* **目的**: フロックの結合力（粘結性）を高めて比重を大きくし、低水温期や高濁度時におけるフロックの粗大化・急速沈降を促す。
* **活性ケイ酸（Activated Silica）**:
  * 水ガラス（ケイ酸ナトリウム）を硫酸等で部分中和して重合させたもの。
  * 二酸化ケイ酸（$\text{SiO}_2$）として $1 \sim 3\,\text{mg/L}$ 程度注入する。適正時期を過ぎると自己ゲル化するため、調製後速やかに使用する。
* **高分子凝集剤（有機高分子ポリアクリルアミド等）**:
  * 巨大な分子鎖による「架橋作用」で強固なフロックを形成する。
  * 日本の水道水処理（飲用水）においては、モノマーの毒性懸念等から使用基準が厳しく制限されており、主として**排水処理（排泥濃縮槽・汚泥脱水機）**で使用される。

## 8. 薬品の受入・検収および貯蔵設備（テキスト p.383〜384）

### (2) 注入設備の維持管理留意事項
1. **予備機（100%予備）の常時確保**:
   * 注入機や注入ポンプは、故障時にも直ちに切り替えて給水を継続できるよう、**「常用1台＋予備1台（または常用2台＋予備1台）」**などの予備設備を必ず備える。
2. **薬品切り替え時のフラッシング**:
   * PACから硫酸バンド、またはその逆への切り替え時は、配管内での沈殿ゲル化を防ぐため、**清水による十分なフラッシング（洗浄）**を行う。
3. **配管の色分けと誤接続防止**:
   * 異種薬品（特に酸とアルカリ、塩素と有機物等）の混入・誤注入は、有毒ガス発生（塩素ガス等）や急激な発熱事故を招くため、**薬品ごとに配管塗色を明確に識別し、接続口の形状を変える（フールプルーフ）**。

## 11. 【想定問題集（ドリル実装用プロトタイプ問題）】

### 設問1（4択：凝集のメカニズムと攪拌条件）
* **問題形式**: `choice`
* **問題文**: 浄水処理における凝集の原理および攪拌条件に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 薬品混和池では、注入した凝集剤を瞬時に均等拡散させて荷電中和を行うため、短時間の「急速攪拌」を行う
  2. 水道原水中の微小なコロイド粒子は正（プラス）の電荷を帯びているため、負（マイナス）の凝集剤で中和する
  3. フロック形成池（凝集池）では、フロックを強固にするため可能な限り強力な攪拌力（せん断力）を加え続ける
  4. 急速ろ過方式においては、原水濁質を砂層のみで完全に除去できるため薬品凝集による前処理は省略できる
* **正解**: 1（インデックス: 0）
* **解説**: 混和池における急速攪拌（数秒〜1分程度）は、注入された凝集剤を瞬時に水全体へ拡散させ、負（マイナス）の電荷を帯びた原水粒子と衝突させて電気的二重層を圧縮・荷電中和させる目的で行われます。フロック形成池では穏やかな「緩速攪拌」を行い、過大なせん断力によるフロックの破壊を防ぎます。急速ろ過では前処理（薬品凝集）が不可欠です。
* **日常のたとえ**: ドレッシングを作るとき、最初に油と酢を一気に激しく振って乳化させるのが急速攪拌、その後具材を潰さないよう優しく和えるのが緩速攪拌です。
* **出典**: 講義テキスト 浄水施設 p.376〜378

---

### 設問2（4択：代表的凝集剤の特性）
* **問題形式**: `choice`
* **問題文**: 浄水処理に使用される各種凝集剤の特性に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. ポリ塩化アルミニウム（PAC）は、硫酸アルミニウムに比べて適正凝集pH範囲が広く、低水温時にも比較的良好な凝集性を示す
  2. PACは原液のまま貯蔵すると配管を閉塞させるため、受入後直ちに水道水で10倍以上に希釈して貯蔵しなければならない
  3. 硫酸アルミニウム（硫酸バンド）は、アルカリ度を全く消費しないため低アルカリ度原水に最も適している
  4. 鉄系凝集剤は腐食性が極めて低いため、特別な耐酸・防食材料を用いずに普通鋼管のまま注入できる
* **正解**: 1（インデックス: 0）
* **解説**: PACは適正凝集pH範囲が pH 6.5〜9.0 と広く、冬期の低水温時でも硫酸バンドより優れた凝集・沈降性能を発揮します。PACを水で希釈すると加水分解が進んでゲル化・白濁するため原液のまま使用します。硫酸バンドは加水分解時に多くのアルカリ度を消費します。鉄系凝集剤は強酸性で腐食性が非常に高く、耐食材質が必須です。
* **出典**: 講義テキスト 浄水施設 p.377〜378

---

### 設問3（4択：pH・アルカリ度と水質管理）
* **問題形式**: `choice`
* **問題文**: 凝集処理におけるpHおよびアルカリ度の管理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 良好な凝集フロックを形成させるため、凝集剤注入後の水中にアルカリ度「20 mg/L 以上」が残留していることが望ましい
  2. 原水のpHが過度に低下した場合は、濃硫酸等の酸性薬品を注入してpHをさらに引き下げる
  3. 凝集処理においてアルカリ度が不足しても、フロック形成や処理水中の溶存アルミニウム濃度には何の影響も生じない
  4. 給水栓におけるランゲリア指数を改善して配水管の腐食（赤水）を防ぐ処理を「前酸処理」と呼ぶ
* **正解**: 1（インデックス: 0）
* **解説**: アルミニウム系凝集剤の注入によって原水アルカリ度が消費されるため、凝集後の水中にアルカリ度が 20 mg/L 以上残留していないとpHが低下してフロック形成不良やアルミニウムの残留を招きます。アルカリ度不足時にはアルカリ剤（苛性ソーダ等）を補給します。配水管防食のための処理は「後アルカリ処理」です。
* **出典**: 講義テキスト 浄水施設 p.379〜381

---

### 設問4（4択：アルカリ剤の特性と取扱い）
* **問題形式**: `choice`
* **問題文**: 浄水場で使用されるアルカリ剤（水酸化ナトリウムおよび水酸化カルシウム）の特性に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 水酸化ナトリウム（苛性ソーダ）原液は低温で結晶化しやすく、水で希釈する際には激しい発熱を伴う
  2. 水酸化カルシウム（消石灰）は水に極めて溶けやすいため、高濃度溶液としても配管内にスケールが付着することはない
  3. 苛性ソーダを水で希釈する際は、突沸を防ぐため苛性ソーダ原液の中に少量の水を激しく注ぎ込むのが正しい手順である
  4. 苛性ソーダは空気中の二酸化炭素を一切吸収しないため、大気開放型の容器で長期間安定して貯蔵できる
* **正解**: 1（インデックス: 0）
* **解説**: 苛性ソーダ原液（48%）は約10〜15℃で結晶化（固化）するため保温または希釈が必要であり、水で希釈する際は膨大な溶解熱が発生します。希釈時は「大量の水の中に苛性ソーダを少しずつ注ぐ」のが絶対ルールです。消石灰は難溶性で配管内にスケール（炭酸カルシウム）が付着しやすい欠点があります。苛性ソーダは空気中のCO₂を吸収して劣化するため密閉貯蔵します。
* **出典**: 講義テキスト 浄水施設 p.380〜381

---

### 設問5（4択：薬品貯蔵・注入設備の構造と維持管理）
* **問題形式**: `choice`
* **問題文**: 浄水場の薬品貯蔵および注入設備に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. 乾式注入装置において、ホッパー内で粉体がアーチ状に架橋して落下が停止する現象を「フラッシング」と呼ぶ
  2. 液体薬品貯蔵タンクの周囲には、万一の破損時に薬液が場外へ流出するのを防ぐため「防液堤」を設ける
  3. 薬品注入機には、故障時にも給水に支障が生じないよう、原則として予備機（予備設備）を設置しなければならない
  4. 凝集剤やアルカリ剤の貯蔵容量は、『水道施設設計指針』において計画一日最大浄水量に対し原則「10日分以上」と規定されている
* **正解**: 1（インデックス: 0）
* **解説**: ホッパー内で粉体がアーチ状に架橋して落下が止まる空洞化現象は「ブリッジ現象（Arching）」です。「フラッシング（Flushing）」は粉体が急激に流動化して隙間から一気に噴き出してしまう現象を指します。防液堤の設置、予備機の設置義務、貯蔵日数原則10日分以上の記述はすべて正しい内容です。
* **出典**: 講義テキスト 浄水施設 p.383〜385
