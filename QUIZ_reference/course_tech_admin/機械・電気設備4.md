## 1. 高圧受電設備と受電方式（テキスト p.539〜541）

### (1) 水道電力設備の重要性とリスク
近代水道システムにおいて、機械設備の大型化と全自動化に伴い、電気設備への依存度は極めて高い。
* **高リスク性**:
  * 停電や電力設備の故障は、直ちに全浄水場・送配水ポンプの停止（広域断水）に直結する。
  * 電気設備の経年劣化は、**感電事故、電気火災、波及事故（電力会社配電線への影響拡大）**を引き起こす危険性を内包する。

---

### (2) 高圧受電設備の定義と構造形式
受電電圧は「低圧（600V以下）」「高圧（600V超〜7,000V以下）」「特別高圧（7,000V超）」に大別される。中規模水道施設では主に**6,600V（6.6kV）の高圧受電**が採用される。

* **高圧受電需要家の定義**:
  * 一般的に電力会社において、契約電力が**「$50\text{ kW}$ 以上 $2,000\text{ kW}$ 未満」**の施設を高圧受電需要家と定める（$2,000\text{ kW}$ 以上は特別高圧受電）。
* **構造形式の分類**:
  * **屋内式スイッチギア（閉鎖配電盤）**: 金属製キャビネット内に遮断器、断路器、母線、継電器を収納。
  * **キュービクル式高圧受電設備**: 受電用開閉器、変圧器、配電設備を一括して金属製外箱にコンパクトに収納したパッケージ設備。耐候構造により**屋外設置が可能**であり、省スペース・工期短縮の利点から水道施設で広く普及している。

---

### (3) 受電方式の分類（引き込み回線数と遮断器構成）

```
【受電方式の比較】
［1回線受電］               ［2回線受電（常用・予備1遮断器）］     ［2回線受電（常用・予備2遮断器）］
   電力線                     常用線      予備線                    常用線      予備線
     │                          │          │                         │          │
   ［DS］                       ［DS］    ［DS］                     ［DS］    ［DS］
     │                          └──┬─────┘                         │          │
   ［CB］                            │                             ［CB］    ［CB］
     │                             ［CB］                            │          │
   変圧器                            │                             └──┬─────┘
                                   変圧器                              │
                                                                     変圧器
```

* **① 1回線受電**:
  * 最も安価で構成が単純であるが、電力会社の送電線事故や引込線の保守点検時に施設全体が全停電となる。
* **② 2回線受電（常用線＋予備線受電）**:
  * **常用・予備 1遮断器受電**: 断路器（DS）で回線を切り替える方式。遮断器は1台で済むが、切替操作時に一時的な停電を伴う。
  * **常用・予備 2遮断器受電**: 常用線・予備線の双方に遮断器（CB）を独立配置する方式。**信頼性が最も高く、事故時や法定点検時にも瞬時に予備線へ切り替えて停電時間を最小化**できる。重要浄水場や基幹送水ポンプ所で採用される。

---

### (4) 構内配電方式
受電した電力を所内の各変圧器や電気室へ分配する方式。
* **樹枝状配電方式（ラジアル方式）**:
  * 主母線から各負荷（配電盤）へ木の枝のように放射状に配線する方式。
  * **特徴**: 構成が最も単純で運用・保護協調が容易、かつ経済的であるため、水道施設の高圧構内配電において最も一般的に採用される。
* **ループ配電方式（環状方式）**:
  * 配電線を環状にループさせ、任意の箇所で切り離せる方式。一部系統の事故・点検時にも反対側から送電継続が可能（重要施設向け）。

---

## 2. 配電機器・開閉機器の機能と工学的役割（テキスト p.542〜544）

受変電設備を構成する主要機器には、明確な機能分担と厳格な操作ルールが存在する。

```
【受変電主要機器の機能一覧】
① 引込開閉器（PAS/UGS） ── 責任分界点に設置。地絡事故時の上位波及遮断
② 断路器（DS） ─────── 機器の無電圧隔離（★負荷電流の遮断は絶対に不可！）
③ 遮断器（CB） ─────── 負荷電流の開閉、および短絡・地絡事故電流の高速度遮断
④ 変圧器（Tr） ─────── 高圧（6.6kV）から低圧（400V/200V/100V）への降圧
⑤ 計器用変成器（VT/CT） ─ 高電圧・大電流を計器・継電器用信号へ安全に変換
```

---

### (1) 引込開閉器（責任分界点）
* 電力会社と水道事業者との財産・保安上の境界（責任分界点）に設置される区分開閉器。
* 架空引込では電柱最頂部に**地絡継電装置付高圧交流負荷開閉器（GR付PAS）**、地中線引込では**UGS**を設置する。
* 構内での地絡事故を瞬時に検知して切り離し、電力会社の配電系統全体を巻き込む波及事故を水際で防止する。

---

### (2) 断路器（DS: Disconnecting Switch）（★超重要・出題急所）
* **目的**:
  * 機器の点検・修理時に、電路から対象機器を**「目視で完全に切り離す（無電圧状態にする）」**ための開閉器。
* **★ 絶対的禁止事項（アーク放電事故の防止）**:
  * 断路器には**消弧能力が一切ない**ため、**「負荷電流が流れている状態での開閉は絶対に不可（禁止）」**である。
  * 通電中に誤って断路器を開路すると、接点間に猛烈な**アーク放電（火花・プラズマ）**が持続発生し、相間短絡事故、機器の爆発炎上、作業者の重度熱傷・感電死という破滅的大事故を引き起こす。
  * **インターロックの原則**: 必ず上位または下位の遮断器（CB）を開放（OFF）し、電流が完全にゼロであることを確認した後にのみ断路器を操作する。

---

### (3) 遮断器（CB: Circuit Breaker）
* **目的**:
  * 平常時の負荷電流を安全に開閉するだけでなく、電路に短絡（ショート）や地絡事故が発生した際、保護継電器の指令を受けて**数万アンペアに達する巨大な短絡事故電流を瞬時（数サイクル以内）に遮断**する。
* **形式分類**:
  * **真空遮断器（VCB: Vacuum Circuit Breaker）**: 高真空中の高い絶縁耐力と消弧力を利用。高圧受変電設備の主力（長寿命・小型・保守容易）。
  * **ガス遮断器（GCB: Gas Circuit Breaker）**: 優れた消弧性を持つ $\text{SF}_6$（六フッ化硫黄）ガス中での消弧。特別高圧向け。
  * **配線用遮断器（MCCB）**: 低圧電路の開閉・過電流保護用。

---

### (4) 変圧器（トランス: Transformer）
高圧受電した $6,600\text{ V}$ の電圧を、場内動力用（$400\text{ V}$ または $200\text{ V}$）や照明・制御用（$100\text{ V}$）に降圧する。
* **モールド変圧器（近年主流）**:
  * コイルを難燃性エポキシ樹脂で高圧真空注型した変圧器。
  * 従来の油入変圧器に比べ、**火災の危険性が極めて低く（自己消火性）、絶縁油の管理・漏油リスクがなく、小型軽量で保守性に優れる**ため、水道施設内のキュービクルで急速に普及している。

---

### (5) 計器用変成器（VT・CT・VCT）
高電圧・大電流を直接計器や保護継電器に入力することは危険であるため、安全な標準値（$110\text{ V}$、$5\text{ A}$）に変換する機器。
* **計器用変圧器（VT / PT）**: 高電圧を $110\text{ V}$ に降圧。
* **変流器（CT）**: 大電流を $5\text{ A}$ に降流。
* **電力需給用計器用変成器（VCT）**: VTとCTを一体化した装置。電力会社が電力使用量（電気料金）を計量するための財産境界機器。

## 3. 動力設備と保護協調（テキスト p.544〜547）

### (1) 動力制御設備
* **高圧コンビネーションスタータ**: 高圧ポンプ電動機の始動用。高圧真空接触器（VMC）と限流形電力ヒューズ（PF）を組み合わせ、過負荷と短絡を保護。
* **低圧コントロールセンター（MCC）**: 多数のポンプ・弁・ブロワ等の低圧電動機を集中制御するため、配線用遮断器（MCCB）と電磁開閉器（MS）をユニット化して収納した盤。

---

### (2) 保護協調（Protection Coordination）（★極めて重要）
保護協調とは、電気回路のどこかで事故が発生した際、**「事故点の直近下位にある保護装置（遮断器・ヒューズ）のみが最優先で高速動作し、上位の遮断器をトリップさせないように保護継電器の動作時間と電流値を段階的に整定（設定）すること」**である。

```
【保護協調の概念図】
受電用遮断器（主CB） ──────────── 動作遅め（事故が波及しない限り切らない）
        │
        ├─ 配電遮断器（フィーダーCB） ── 中間動作
        │        │
        │        └─ ポンプ用遮断器 ───── 最速動作！（ポンプ事故時はここだけ遮断）
        │
        └─ 他の健全系統 ───────────── 送電継続！（浄水処理は止まらない）
```

* **目的**:
  * 事故区間を最小限に限定・隔離し、健全な他の設備への電力供給を継続して全所停電を回避する。
* **主要な保護継電器**:
  * **過電流継電器（OCR: Overcurrent Relay）**: 過負荷電流や短絡電流を検出。限時特性（電流が大きいほど早く動作）を持つ。
  * **地絡継電器（GR: Ground Relay） / 地絡方向継電器（DGR）**: 配線や機器の絶縁劣化による大地への漏洩電流（地絡）を検出。
  * **不足電圧継電器（UVR: Undervoltage Relay）**: 停電や電源電圧の急激な低下を検知し、自家用発電設備の起動指令や重要負荷の自動切替を行う。
  * **避雷器（LA: Lightning Arrester）**: 落雷による雷サージ電圧を瞬時に大地へ放流し、後段の変圧器や配電機器の絶縁破壊を防止する。

## 4. 接地工事（アース）と等電位ボンディング（テキスト p.547〜549）

### (1) 接地工事の種別と基準（電気設備技術基準）
接地工事は、地絡事故時の対地電圧上昇を抑え、人身への感電防止、火災防止、および保護継電器の確実な動作を目的として施工される。

| 接地工事の種別 | 主な適用箇所 | 接地抵抗値の規定 | 備考 |
| :--- | :--- | :--- | :--- |
| **A種接地工事** | 高圧・特別高圧機器の金属製外箱、避雷器（LA） | **$10\,\Omega$ 以下** | 高圧機器の地絡時の感電・火災防止 |
| **B種接地工事** | 高圧/特高から低圧へ変電する変圧器の低圧側中性点 | **$150/I_g\,\Omega$ 以下**<br>（$I_g$：高圧側1線地絡電流） | 高低圧混触時の低圧側電位上昇抑制 |
| **C種接地工事** | $300\text{ V}$ を超える低圧機器の金属製外箱（$400\text{ V}$ 級電動機等） | **$10\,\Omega$ 以下**<br>（地絡遮断装置設置時は $500\,\Omega$） | 感電防止 |
| **D種接地工事** | $300\text{ V}$ 以下の低圧機器の金属製外箱（$200\text{ V}/100\text{ V}$ 機器） | **$100\,\Omega$ 以下**<br>（地絡遮断装置設置時は $500\,\Omega$） | 最も一般的な低圧機器の接地 |

---

### (2) 等電位ボンディング（Equipotential Bonding）
* **原理と目的**:
  * 建築物内のすべての電気機器接地線、鉄骨構造物、金属製配管（水道管・ガス管等）、ケーブルトレイを相互に金属線で連接（ボンディング）し、**施設全体を共通の「等電位面」とする工法**。
* **効果**:
  * 落雷サージが侵入した際、建物内部のあらゆる金属体間の「電位差」の発生を抑制し、**火花放電（逆フラッシオーバ）による電子機器（PLC・計装サーバー等）の破壊および人体への感電を防止**する。

## 5. 力率改善設備（テキスト p.549〜550）

### (1) 力率（Power Factor）の基礎
交流回路において、電源から送り出される電力（皮相電力 $\text{kVA}$）のうち、実際に機械的動力や熱として消費される電力（有効電力 $\text{kW}$）の比率を**力率（$\cos\theta$）**と呼ぶ。

* **遅れ力率の発生**:
  * 水道施設に多数設置されている誘導電動機（ポンプ用モーター）は、磁界を形成するために多くの「遅れ無効電力」を消費するため、力率が低下（80%前後）しやすい。
* **力率低下の弊害**:
  * 配電線の電流が増大し、ケーブルの発熱・電力損失が増大する。
  * 電圧降下が大きくなる。
  * **電気基本料金の割引率低下（割増しペナルティ）**: 電力会社の料金制度では力率85%を基準とし、1%上回るごとに基本料金が1%割引され、下回ると割増しされる。

---

### (2) 進相コンデンサ（SC: Static Capacitor）の設置
* **改善原理**:
  * 誘導電動機の負荷と並列に**進相コンデンサ（進相無効電力を供給する機器）**を接続することで、モーターが要求する遅れ無効電力を局所で相殺する。
* **効果**:
  * 受電端での力率を95%〜100%近くまで高め、**電気料金の大幅削減**および構内変圧器・配電設備の容量有効利用を図る。
* **直列リアクトル（SR）の併設**:
  * コンデンサ投入時の突入電流抑制、およびインバータ機器等から発生する**第5調波等の高調波によるコンデンサの過熱・焼損を防止**するため、進相コンデンサには必ず直列リアクトルを直列接続する。

## 6. 直流電源装置と無停電電源装置（UPS）（テキスト p.550〜551）

水道施設の制御・計装システムは、商用電源の瞬時停電（瞬低）や全停電時にも一切停止してはならない。

```
【補助電源設備の比較】
① 直流電源装置 ───────── 蓄電池＋整流器（DC100V出力） ── 遮断器操作・リレー電源・自家発始動
② 無停電電源装置（UPS/CVCF） ── 蓄電池＋整流器＋インバータ（AC100V） ── 計装・監視サーバー（瞬断0秒）
```

* **直流電源装置**:
  * 遮断器の投入・引外しコイル電源、保護継電器の制御電源、非常用発電機の始動セルモーター用。
  * 蓄電池には信頼性の高い**制御弁式据置鉛蓄電池（MSE等）**やアルカリ蓄電池が広く用いられる。
* **無停電電源装置（UPS: Uninterruptible Power Supply / CVCF）**:
  * 商用電源から交流を受電して整流器で直流に変換し、蓄電池を常時浮動充電しながら、**インバータによって極めて安定した交流電力を無瞬断（切替時間0ミリ秒）で供給**し続ける。
  * 水質計器、プログラマブルコントローラ（PLC）、中央監視コンピュータ、通信機器に不可欠。

## 7. 電力設備の保全管理と電気事故対応（テキスト p.551〜553）

### (1) 保安体制と点検管理
* **電気主任技術者の統括**:
  * 水道施設の自家用電気工作物は、電気事業法に基づき電気主任技術者を選任し、保安規程を策定・遵守しなければならない。
* **日常巡視点検と年次定期点検**:
  * 日常巡視：異音、異臭、温度（サーモグラフィによる端子部過熱点検）、計器指示値の確認。
  * **年次定期点検（精密点検）**: 全所停電を伴う作業。遮断器の開閉特性試験、保護継電器の動作連動試験、変圧器・高圧ケーブルの絶縁抵抗測定および絶縁油耐圧試験。感電防止の安全対策（検電、短絡接地器具の装着）の徹底。

---

### (2) 電気事故発生時の初動と報告義務（★出題急所）
* **初動対応**:
  1. 直ちに電気主任技術者に報告し、その技術的指示を受ける。
  2. 動作した保護継電器（OCR、GR等）の表示（ターゲット）を確認し、事故種別と事故区間を同定する。
  3. 不良箇所を電路から切り離して隔離し、健全系統へ速やかに受電復旧する。
* **★ 電気事業法に基づく事故報告義務（重要基準）**:
  * 自家用電気工作物における感電死傷事故、電気火災、主要設備の破損、波及事故が発生した場合：
    * **速報**: 事故発生を知った時から**「24時間以内」**（所轄産業保安監督部へ電話・FAX等）
    * **詳報（詳細報告）**: 事故発生を知った日から**「30日以内」**（詳細報告書の提出）

---

## 8. 建築付帯設備・消防・電食防止設備（テキスト p.553〜555）

### (1) 建築付帯設備（電気室の換気・空調）
* 電気室や計装室は、機器の密閉性・信頼性を保つため、屋内に設置される。
* **塩素ガス・腐食性ガスの侵入防止**: 水道施設特有の腐食環境（塩素ガス、硫化水素）から電子基板や銅母線を保護するため、**空調による陽圧化（室外からのガス流入防止）や化学吸着フィルター**を設置する。
* **放熱対策**: 変圧器やインバータからの発熱を強制換気またはパッケージエアコンで冷却する。

---

### (2) 消防用設備（消防法の適用）
* 水道施設（浄水場等）は、消防法別表第一において**「防火対象物（15項：その他の事業場）」**に該当する。
* 消火設備（消火器、屋内消火栓）、警報設備（自動火災報知設備）、避難設備等を法令に基づき設置・点検する。
* **★ 無人化施設における留意点**:
  * 近年推進されている送配水ポンプ所等の「無人化（遠隔無人監視）」に際しては、有人時と異なる消防用設備の追加（火災信号の遠隔移報設備等）が求められる場合があるため、事前に所轄消防署と協議を行う。

---

### (3) 電食防止設備（電気防食）（★水道特有の最重要項目）
* **電食（Electrolytic Corrosion）の発生機構**:
  * 直流電気鉄道（電車）のレールから大地へ漏れ出た**迷走電流（Stray Current）**が、地中に埋設された金属製水道本管に侵入し、管路を伝わって再び大地・変電所へ流出する箇所（アノード部）において、**金属がイオン化して溶出し、短期間で管体に穿孔（孔あき漏水）を生じさせる現象**。
* **電食防止の3大工法**:
  1. **選択排流法**: 埋設管と鉄道レールを変電所付近で排流器（逆流防止ダイオード付き）を介して金属線で接続し、管内の迷走電流をレールへ安全に逃す方式。
  2. **流電陽極法（犠牲陽極法）**: 鉄管よりもイオン化傾向の大きい金属（マグネシウムや亜鉛塊）を管に接続して地中に埋設し、マグネシウムを身代わりに腐食させて鉄管を防食する方式。
  3. **外部電源法**: 直流電源装置を用い、地中に埋めた不溶性電極から管体に向けて常に防食電流を強制的に流し込む方式。
* **維持管理**:
  * 防食効果を監視するため、**「管対地電位（管と大地との電位差）」**を照合電極（飽和硫酸銅電極等）を用いて**年1〜2回定期測定**し、所定の防食電位基準（$-850\text{ mV}$ 以下等）が保持されているかを評価する。

---

## 9. 自家用発電設備（ディーゼル・ガスタービン）（テキスト p.555〜558）

商用電源の停電時にも水道の機能を維持するため、自家用発電機が設置される。

```
【自家用発電機の用途と機関比較】
［用途区分］
  ・非常用発電設備 ── 停電時の重要負荷バックアップ（照明・計装・塩素除害・重要弁）
  ・常用発電設備 ──── ピークカット・負荷平準化・コージェネレーション（熱電併給）

［原動機形式の比較］
  ・ディーゼル発電機 ── 燃費良好・即時始動性に優れる（中・小容量の主流）
  ・ガスタービン発電機 ─ 小型軽量・低振動（防振不要）・寒冷地始動性良好 vs 燃費悪・排気大
```

---

### (1) 非常用と常用の区分およびコージェネレーション
* **非常用発電設備**:
  * 停電直後に自動始動（UVR信号等）し、保安用照明、計装監視設備、緊急遮断弁、塩素除害設備等の保安重要負荷へ電力を供給する。
* **常用発電設備とコージェネレーション（熱電併給）**:
  * 平常時も連続稼働させ、電力会社からの受電電力を抑える（ピークカット・負荷平準化）。
  * 発電時の排熱（エンジン冷却水・排ガス）を熱交換器で回収し、**排水処理施設における脱水ケーキの加温脱水や汚泥乾燥の熱源として有効利用（コージェネレーション）**する。

---

### (2) ディーゼルエンジン vs ガスタービンの工学的比較

| 項目 | ディーゼル発電設備 | ガスタービン発電設備 |
| :--- | :--- | :--- |
| **熱効率（燃費）** | **高い（35〜40%）**、燃料消費が少ない | 低い（25〜30%）、燃料消費が多い（燃費が悪い） |
| **始動時間** | 良好（10〜15秒程度で全負荷投入可能） | 良好（40秒〜数分程度） |
| **寒冷地始動性** | 軽油凍結・水温低下時に予熱が必要 | **極めて良好（低温下でも確実に瞬時始動）** |
| **振動と騒音** | 往復動ピストンのため**振動大（防振架台・防振継手必須）** | 回転運動のみのため**低振動（特殊な防振基礎不要）** |
| **重量・設置面積** | 重く大きい | **小型軽量**（屋上や狭小スペースにも好適） |
| **排気ダクト** | 比較的小さい | **大容量の給排気ダクト・大形サイレンサーが必要** |

---

### (3) 法規制と維持管理の実務
* **消防法の危険物規制**:
  * 燃料（A重油または軽油）の貯蔵タンクは、消防法に基づく「危険物施設（指定数量以上の危険物取扱所・貯蔵所）」に該当し、**防油堤の設置、危険物取扱者の選任、定期点検**が義務づけられる。
* **公害防止法規（騒音規制・排ガス規制）**:
  * 発電機運転時の騒音は極めて大きいため、**敷地境界における騒音レベル規制基準値（条例基準値 $\text{dB}$）**を遵守できるよう、高性能消音器（サイレンサー）や防音吸音ルーバーを施工する。
* **月次定期試運転の徹底**:
  * いざという本番の停電時に始動不能となる事故を防ぐため、**月1回以上の定期的な試運転（無負荷運転または実負荷運転）**を実施し、始動性、バッテリー液量、潤滑油量、冷却水ヒーターを点検する。

---

## 10. 再生可能エネルギー設備（小水力・太陽光）（テキスト p.558〜560）

環境負荷低減（脱炭素・カーボンニュートラル）および買電量削減を目的として、水道インフラのポテンシャルを活かした再エネ設備の導入が進んでいる。

### (1) 小水力発電設備（テキスト p.558〜559）
* **原理と適用**:
  * ダムからの導水管、浄水場からの自然流下送水管、配水池への流入管など、水道管路内の**高低差（位置エネルギー）や余剰水圧**を利用して水車（フランシス水車、水撃ポンプ水車、クロスフロー水車等）と発電機を回す。
  * 出力 $1,000\text{ kW}$（$1\text{ MW}$）以下の設備が「小水力発電」として多用される。
* **★ 安定給水を阻害しないバイパス管の整備（最重要設計）**:
  * 水道管路内の水は本来「上水供給用」であるため、水車発電機の故障や点検停止時に水流が止まることは許されない。
  * したがって、水車の前後に必ず自動調節弁を備えた**「バイパス配管ライン」**を併設し、水車停止時でも瞬時にバイパス管へ通水を切り替えて送配水流量・水圧を維持する。
* **保安管理**: 一定規模以上（$20\text{ kW}$ 以上等）の水力発電設備は電気事業法上の自家用電気工作物となり、電気主任技術者の選任・保安規程策定が必要。

---

### (2) 太陽光発電設備（PV: Photovoltaic）（テキスト p.559〜560）
* **設置形態**:
  * 薬品沈殿池、急速ろ過池、浄水池、配水池などの**上部空間（覆蓋・上部スラブ）**を活用して太陽光パネルを設置する事例が多い（水面への直射日光遮断による藻類繁殖抑制効果も兼ねる）。
* **系統連系と運転管理**:
  * 天候や夜間により発電量が変動するため、商用電力系統と連系（パワーコンディショナー：PCS使用）して運用する。
  * パネル受光面の汚れ・黄砂の清掃、台風・落雷後の架台ボルト緩み点検、PCSの絶縁抵抗・変換効率測定。
  * 契約電力 **$50\text{ kW}$ 以上の設備は自家用電気工作物**に該当する。

---

## 11. まとめ：電気・自家発・再エネ設備 重要キーワード・数値基準一覧表

| 設備・法規 | 最重要キーワード | 具体的工学的要点・管理数値・法的根拠 |
| :--- | :--- | :--- |
| **高圧受電** | 契約電力範囲 | **$50\text{ kW}$ 以上 $2,000\text{ kW}$ 未満**（高圧受電＝主に6.6kV）。キュービクル式。 |
| **受電方式** | 2回線受電（2遮断器） | 常用線＋予備線に各遮断器配置。点検・事故時も予備線切替で停電時間を最小化。 |
| **構内配電** | 樹枝状（ラジアル）方式 | 構成簡単・経済的・保護協調容易。水道高圧配電の主流。 |
| **引込開閉器** | GR付PAS（区分開閉器） | 責任分界点柱上に設置。地絡事故時の上位系統への波及事故防止。 |
| **断路器（DS）** | 負荷電流遮断不可 | 消弧能力なし。**通電中の開閉はアーク爆発事故を招き厳禁**。無電圧で操作。 |
| **遮断器（CB）** | 真空遮断器（VCB） | 高圧の主流。消弧性能大・長寿命。短絡・地絡の巨大事故電流を高速度遮断。 |
| **変圧器** | モールド変圧器 | エポキシ樹脂注型。難燃性・防災性大、油なし・漏油ゼロ・小型軽量（現代主流）。 |
| **保護協調** | 事故区間の限定隔離 | 事故点直近の遮断器のみを最速遮断し、上位受電遮断器のトリップ（全所停電）を防止。 |
| **接地工事** | A種・B種・C種・D種 | **A種：$10\,\Omega$ 以下**（高圧機器外箱）、**C種：$10\,\Omega$ 以下**（300V超低圧）、**D種：$100\,\Omega$ 以下**（300V以下）。 |
| **等電位接地** | 等電位ボンディング | 建物内全接地・鉄骨・配管を連接。雷サージ時の電位差ゼロ化・電子機器保護。 |
| **力率改善** | 進相コンデンサ（SC） | モーターの遅れ無効電力を相殺し力率向上。基本料金割引、直列リアクトルSR併設。 |
| **無停電電源** | UPS（CVCF） | 整流器＋蓄電池＋インバータ。計装・監視サーバーへ**瞬断ゼロ（0秒）**で交流継続供給。 |
| **電気事故報告** | 24時間速報・30日詳報 | 自家用電気工作物の重大事故時、産業保安監督部長へ**速報24時間以内・詳報30日以内**。 |
| **建築付帯** | 電気室陽圧空調 | 塩素ガス・腐食性ガスの侵入防止（陽圧化）、変圧器・インバータ放熱冷却。 |
| **消防法** | 防火対象物15項 | 無人化施設への移行時は遠隔移報設備等の要件について所轄消防署と事前協議。 |
| **電食防止** | 迷走電流と管対地電位 | 直流鉄道レールからの迷走電流腐食。選択排流法、外部電源法、流電陽極法。年1〜2回電位測定。 |
| **自家発比較** | ディーゼル vs ガスタービン | ディーゼル：燃費良・即時始動・振動大。ガスタービン：小型軽量・低振動・寒冷地始動良・燃費悪。 |
| **自家発法規** | 危険物規制と騒音規制 | 燃料タンクは消防法危険物規制。敷地境界での騒音基準値（dB）遵守。月1回試運転。 |
| **小水力発電** | バイパス管の設置 | 導送水管落差・余剰圧力利用。発電機故障停止時も送水を止めないバイパスライン必須。 |
| **太陽光発電** | 池覆蓋利用と自家用工作物 | 沈殿池・ろ過池上部空間の有効活用。$50\text{ kW}$ 以上で自家用電気工作物（主任技術者選任）。 |
