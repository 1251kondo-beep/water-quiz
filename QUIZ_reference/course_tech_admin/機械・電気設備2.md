## 1. 水道施設別 機械・電気設備の役割と維持管理（テキスト p.500〜503）

水道システムは、水源から需要者の蛇口に至る連続した水処理・水輸送プロセスであり、各施設に配置された機械・電気設備が相互に連携して機能している。

```
【水道施設における主要機械・電気設備の役割連携】
［取水・導水・貯水］ ──→ ［浄水施設］ ──→ ［送配水施設］ ──→ ［給水装置（需要者）］
  ・取水ゲート・弁          ・沈殿池掻寄機      ・送水ポンプ          （安定水圧・清浄水）
  ・取水・導水ポンプ        ・急速ろ過洗浄      ・配水ポンプ
  ・貯水池放流弁            ・薬品注入設備      ・各種制御弁
        ▲                        ▲                  ▲
        └────────────────────────┼───────────────────┘
                                 │ 動力・制御
                        ［受変電・配電・自家発］
                        （2系統受電・瞬低保護）
```

---

### (1) 取水・導水・貯水施設の機械設備
* **基本的役割**:
  * 渇水期や洪水期（高濁度時）を含め、**年間を通じて計画水量を確実に取水・導水すること**。
  * 設備の故障や停電、事故時においても安定した取水を継続できるよう、適切な予備力や代替機能を確保する。
* **主要設備構成**:
  * **取水施設**: 取水堰ゲート、取水塔ゲート、取水門、スクリーン（除塵機）、深井戸水中モーターポンプ。
  * **導水施設**: 導水管、導水渠ゲート、導水ポンプ。
  * **貯水施設**: ダム・貯水池の各種取水ゲート、放流ゲート、高圧スルース弁、ホロージェット弁等。
* **保全管理の留意点**:
  * **操作規程の制定と厳格な遵守**: ゲートやバルブの誤操作は河川環境や取水機能に直結するため、操作手順を標準化する。
  * **水中・水没設備の計画的保全**: 水中に常時没しているゲート、スクリーン、弁体、戸溝（水密ゴム含む）などは日常点検が困難であるため、定期的な水抜き点検や潜水点検を計画的に実施する。

---

### (2) 浄水施設の機械設備
* **基本的役割**:
  * 混和、凝集、沈殿、ろ過、消毒等の各プロセスを的確に運用・制御し、水質基準に完全適合した浄水を連続生産すること。
  * 機械設備の機能低下は、直ちに**処理能力の低下（造水能力不足）や処理水質悪化**に直結する。
* **主要設備構成**:
  * 高速凝集沈殿池スラッジ掻寄機、フロック形成池フロキュレーター（攪拌機）、急速ろ過池逆洗ポンプ・ブロワ、緩速ろ過池洗砂設備・削開機、オゾン発生設備、薬品注入ポンプ。
* **保全管理の留意点**:
  * 設備の種類と設置台数が極めて膨大であるため、計画的かつ合理的な保全計画を策定する。
  * 大型ポンプや電動機に対しては、後述する**設備診断技術（振動測定、絶縁診断等）**を活用した状態監視保全（CBM）を推進し、延命化とLCC低減を図る。

---

### (3) 送・配水施設の機械設備
* **基本的役割**:
  * 浄水場から給水所へ水を送る「送水」、および配水池から各需要家へ適正な圧力で水を届ける「配水」を担い、**給水区域全体の「水量」と「水圧」を適正に維持すること**。
* **主要設備構成**:
  * 送水ポンプ、配水ポンプ、加圧ポンプ、各種流量・圧力制御弁。
* **保全管理の留意点**:
  * **予備機の常時確保**: ポンプの点検・補修時や突発故障時でも送配水能力を低下させないよう、必ず待機予備機を整備・管理する。
  * **環境対策**: ポンプ室内外の塵埃（じんあい）・粉じん対策、ならびに電動機の放熱を考慮した換気・温湿度管理を徹底する。
  * **弁類の動作把握**: 常時開・常時閉のバルブ状態を台帳で一元管理し、緊急時に操作すべき弁の位置・操作性を定期的な開閉作動点検で確認しておく。

---

### (4) 電気設備（各施設共通）の役割と保護
* **基本的役割**:
  * 電力会社の送電系統から受電した電気エネルギーを変電・降圧し、所内の全機械設備および計装制御盤へ安全・確実に供給する動脈の役割。
* **高信頼度化対策**:
  * **受電系統の2系統受電**: 商用電源の送電線トラブルに備え、常用・予備の2回線受電を構築。
  * **非常用自家発電設備**: 全停電時でも主要なポンプや計装監視設備、塩素注入設備を稼働できるよう設置。
* **保全・運用の留意点**:
  * **瞬時電圧低下（瞬低）・停電対策**: 落雷等に伴う瞬時電圧低下は、コンピュータ制御機器の停止やポンプのトリップを引き起こすため、無停電電源装置（UPS）や瞬低保護リレーを設置する。
  * **絶縁抵抗の傾向管理**: 機器や高圧ケーブルの絶縁抵抗測定を定期的に実施し、経年劣化のトレンド（低下傾向）を監視して絶縁破壊を予知防止する。
  * **波及事故の防止**: 所内末端の電気事故（地絡・短絡）が上位系統に波及して電力会社の送電系統を停止させたり、浄水場全体が全停電に至ったりしないよう、保護協調（遮断器・リレーの動作協調）を厳格に管理する。

## 2. ポンプ設備の工学分類と構造（テキスト p.504〜505）

ポンプは機械的エネルギーを流体の圧力および速度エネルギーに変換する流体機械であり、水道施設で最も重要な基幹設備である。

```
【ポンプの作動原理による3大分類体系】
ポンプ
  ├─ ① ターボ型ポンプ（羽根車の回転力：水道の主流・大容量移送）
  │    ├─ 遠心ポンプ（渦巻きポンプ、ディフューザーポンプ、多段ポンプ）
  │    ├─ 斜流ポンプ（斜流羽根車：取水ポンプ等）
  │    └─ 軸流ポンプ（プロペラ羽根車：低揚程・大流量）
  │
  ├─ ② 容積型ポンプ（容積の変化：高圧・定量注入・粘性汚泥移送）
  │    ├─ 往復動ポンプ（ピストンポンプ、プランジャーポンプ、ダイヤフラムポンプ）
  │    └─ 回転ポンプ（ネジポンプ、ギヤポンプ、モーノポンプ）
  │
  └─ ③ 特殊型ポンプ（気泡や噴流の利用）
       └─ エアーリフトポンプ（圧縮空気混入による比重差揚水）、ジェットポンプ
```

---

### (1) ターボ型ポンプ（水道施設の主力）
ケーシング内で羽根車（インペラ）を高速回転させ、遠心力や揚力によって水にエネルギーを与える方式。

* **遠心ポンプ（Centrifugal Pump）**:
  * 羽根車から半径方向（外周方向）へ水が流出する構造。水道施設で最も広範に採用される。
* **斜流ポンプ（Mixed Flow Pump）**:
  * 遠心力と羽根の揚力の両方を活用し、流れが主軸に対して斜め方向に流出する。取水ポンプ等に好適。
* **軸流ポンプ（Axial Flow Pump）**:
  * プロペラ状の羽根車により、主軸と平行な軸方向に水を押出す。全揚程が極めて低く大流量の排水処理等に使用される。

---

### (2) 水道施設で用いられる代表的ターボ型ポンプの構造

```
【遠心ポンプのケーシング構造比較】
［渦巻型（ボリュート型）］           ［案内羽根型（ディフューザー型）］
      ┌────────┐                           ┌────────┐
      │ 渦巻室 │                           │ 案内羽根│
      │ ケーシング                         │（ディフューザー）
      └────────┘                           └────────┘
羽根車の吐出流を直接                羽根車外周に固定案内羽根を設け、
渦巻状流路で減速・昇圧               速度エネルギーを高効率に圧力変換
（構造簡単・安価）                  （大型・高圧・多段ポンプに適用）
```

* **横軸両吸込渦巻きポンプ**:
  * 羽根車の表裏両側から均等に水を吸い込む構造。
  * **長所**: 左右から吸い込むため**スラスト荷重（軸方向の力）が理論上完全に相殺**され、軸受の負担が極めて小さい。大流量を安定して送水・配水できるため、水道の基幹ポンプの代表格である。
* **多段渦巻きポンプ**:
  * 1本の主軸に複数の羽根車を直列に配置した構造（2段、3段、多段）。
  * **長所**: 1台のポンプで段階的に圧力を高められるため、**極めて高い全揚程**を確保できる。深井戸揚水、高台への送水、消防用、水質サンプリング測定用に用いられる。
* **立軸斜流ポンプ**:
  * 縦向きに設置され、下方の吸込口から水を汲み上げて上方に吐出する。河川や湖沼からの取水設備、沈殿池上澄水移送等に多用される。

---

### (3) 容積型ポンプと特殊型ポンプ
* **容積型ポンプ（Positive Displacement Pump）**:
  * シリンダー内の往復運動または回転体の噛み合いによって生じる容積変化により液体を吸込・圧送する。
  * **特徴**: 吐出圧力に関わらず回転数やストローク数に比例した**正確な定量性**を持つ。
  * **用途**: 薬品注入設備（ダイヤフラムポンプ、プランジャーポンプ）、浄水汚泥や高粘度液体の移送（ネジポンプ、モーノポンプ）。
* **エアーリフトポンプ（特殊型）**:
  * 水中深くに配管を沈め、その下部に圧縮空気を圧入する。
  * 水と無数の気泡が混ざり合うことで管内の**見かけ比重（体積重量）が水単体より軽くなり、管内外の比重差（浮力）によって気液混合流が地上へ自噴・揚水**される原理。炭酸飲料が瓶から吹き出す現象と同様である。

## 3. ポンプの性能曲線と最高効率点（BEP）（テキスト p.504〜505）

ポンプの運転管理・選定においては、メーカーが作成する**ポンプ性能曲線（特性曲線）**を正しく読解・活用することが極めて重要である。

```
【ポンプ性能曲線の基本構成】

  全揚程 H(m)
  軸動力 P(kW)
  効率 η(%)
    ▲
 高 │ ＼  全揚程曲線（Q-H曲線: 右下がり特性）
    │   ＼
    │     ＼       最高効率点（BEP: 運転の最適ポイント）
    │       ＼       ┌─────────┐
    │  ───┐   ＼     │  ★ η max│
    │  軸 │     ＼   └─────────┘
    │  動 │       ＼      ／￣￣＼
    │  力 │         ＼  ／ ポンプ ＼ 効率曲線 η
 低 │  P  │           ＼          ＼
    └─────┴────────────┴───────────────────────► 吐出量 Q (m³/min)
          小                 適正（設計点）           大
```

* **ポンプ性能曲線の3大要素**:
  1. **全揚程曲線（Q-H曲線）**: 吐出量 $Q$ が増加すると、ポンプが出せる全揚程 $H$ は減少する（右下がり特性）。
  2. **効率曲線（$\eta$ 曲線）**: 吐出量の増加に伴い効率は上昇し、ある特定の吐出量で最大値に達した後、急激に低下する山形を描く。
  3. **軸動力曲線（$P$ 曲線）**: 遠心ポンプの場合、吐出量 $Q$ が増えるほど必要な軸動力 $P$（モーター負荷）は増大する（締切付近で最小）。
* **★ 最高効率点（BEP: Best Efficiency Point）での運転**:
  * 効率が最大となる点（$\eta_{\max}$）を「最高効率点（設計仕様点）」と呼ぶ。
  * この点付近で運転することが、**最も電力消費（エネルギーロス）が少なく、かつ水流の乱れ・振動・騒音・キャビテーションリスクが最小となる理想的な状態**である。
  * 実際の運転点がBEPから大きく外れている場合は、回転速度制御（インバータ）の導入やポンプ口径の見直しを行う。

## 4. 電動機（モーター）の特性比較（テキスト p.505〜506）

水道施設で使用されるポンプの駆動源としては、信頼性と保守性に優れた**三相誘導電動機（Induction Motor）**が圧倒的多数を占める。三相誘導電動機には「かご形」と「巻線形」がある。

| 項目 | 三相かご形誘導電動機 | 三相巻線形誘導電動機 |
| :--- | :--- | :--- |
| **回転子構造** | 導体バーを両端の短絡環で結合した**かご形構造** | 固定子と同様にスロットに巻線を施した**巻線構造** |
| **構造の複雑さ** | 極めて単純で堅牢 | スリップリング、ブラシ、外部抵抗器があり複雑 |
| **価格** | 安価 | 比較的高価 |
| **保守管理** | **保守が極めて容易**（摩耗部品が軸受のみ） | **保守が極めて煩雑**（ブラシ・リング摩耗粉清掃、交換） |
| **始動特性** | 始動電流が極めて大きい（定格の5〜7倍）<br>始動トルクは比較的小さい | 外部抵抗調整により、**始動電流を抑えつつ大きな始動トルクを発生可能** |
| **速度制御** | インバータ（VVVF）装置による制御 | 二次抵抗制御、静止セルビウス制御 |
| **近年の動向** | **現代の水道施設において圧倒的主流** | インバータの普及・低価格化に伴い**新規採用は激減** |

* **巻線形の維持管理上の弱点**:
  * スリップリングとカーボンブラシが常時接触・摺動するため、カーボン粉（黒色粉じん）が機内に飛散・堆積する。
  * 放置すると絶縁破壊を招くため、定期的に機内を開放して真っ黒になりながら清掃・研磨を行う必要があり、維持管理現場の大きな負担となっていた。

## 5. 電動機の回転速度制御方式の比較（テキスト p.506〜507）

ポンプの流量・水圧を調整するにあたり、吐出弁を絞る方式は大きな圧力損失（エネルギーの浪費）を招く。そのため、電動機の回転速度そのものを変化させる**回転速度制御**が広く普及している。

```
【回転速度制御の3大方式比較】
① インバータ制御（一次周波数制御 / VVVF） ── 最新主流。全速度域で高効率・大幅省エネ
② 二次抵抗制御（巻線形電動機） ──────── 抵抗器で熱消費するため低速時の効率極小
③ 静止セルビウス制御（二次励磁制御） ────── 二次電力を電源回生。落雷サージに弱く高価
```

---

### (1) インバータ制御（VVVF: Variable Voltage Variable Frequency 制御）
* **原理**:
  * 商用交流電源を一度直流に整流・平滑化した後、インバータ回路（IGBT等の半導体スイッチング素子）により任意の周波数（$f$）と電圧（$V$）を持つ交流に変換して電動機へ供給する。
* **圧倒的な省エネルギー性**:
  * ポンプの軸動力は**回転速度の3乗に比例**するため、回転数を落とすことで劇的に電力を削減できる。
  * 必要な出力に応じた電力のみを電源から受け取るため、全速度域にわたって総合効率が極めて高い。
* **維持管理上の留意点（高調波対策）**:
  * 高速スイッチングに伴い**高調波電流（波形の歪み）**が発生する。
  * これが進相コンデンサの過熱・破損、変圧器の過熱、計装機器への電磁ノイズ混入、電動機の振動・電食を引き起こす恐れがあるため、**交流リアクトル（ACL）や高調波抑制フィルター**の設置が必須である。

---

### (2) 二次抵抗制御および静止セルビウス制御
* **二次抵抗制御**:
  * 巻線形電動機の二次回路に接続した外部抵抗器の抵抗値を変化させて「すべり」を増大させ、回転数を制御する。
  * 設備費は安いが、低速運転時には電動機二次側の電力の多くが抵抗器で**ジュール熱として無駄に大気へ放出（消費）されるため、エネルギー効率が極めて悪い**。
* **静止セルビウス制御**:
  * 巻線形電動機の二次電力を静止変換器によって電源側へ回収（回生）する方式。運転効率は良いが、設備が複雑・高価であり、落雷による電圧変動の影響を受けやすいため、現在はほとんどインバータ制御へ更新されている。

---

## 6. ポンプ運転時の異常現象と防止対策（★超重要・テキスト p.507〜509）

水道用ポンプの運転・維持管理において、重大な設備破損や事故を引き起こす代表的な異常現象を整理する。

```
【ポンプの4大異常現象】
① キャビテーション ── 羽根車入口の局所低圧・気泡崩壊による壊食（孔食）・能力激減
② 水撃作用（ウォーターハンマー） ─ ポンプ急停止時の急激な圧力波による管路・機器破壊
③ サージング ───── Q-H曲線の右上がり部における周期的な圧力・流量の脈動現象
④ 締切過小流量運転 ─ 吐出弁全閉時の内部攪拌熱による水温沸騰・羽根車焼き付き
```

---

### (1) キャビテーション（Cavitation: 空洞現象）
* **発生機構**:
  * ポンプの吸込口や羽根車入口付近で局所的に水圧が低下し、その水温における**「飽和蒸気圧」**以下になると、水が沸騰して無数の微細な蒸気泡（キャビティ）が発生する。
  * これらの気泡が高圧部（羽根車外周側）へ送られると、周囲の高圧によって**瞬時に圧壊・消滅**する。
  * 気泡消滅時に発生する極めて強力な局所的衝撃圧（数千気圧）が金属表面を繰り返し直撃する。
* **被害**:
  * 羽根車やケーシング金属表面の**壊食（エロージョン・海綿状の孔食・ピッティング）**、振動・異常音、全揚程および吐出量の急減、最終的な部品損壊。
* **防止対策**:
  * **有効吸込水頭（NPSHa）を必要吸込水頭（NPSHr）より十分大きく確保する（安全余裕の確保）**。
  * 吸込揚程を小さくする（ポンプ据付位置を下げる、吸水井水位を適正保持）。
  * 吸込配管の損失水頭を小さくする（管径を太くする、管路を短くする、曲がりや弁の数を減らす）。

---

### (2) 水撃作用（Water Hammer: ウォーターハンマー）
* **発生機構**:
  * 落雷や事故による突然の全停電で送水ポンプが急停止した際、管路内を流れていた水の運動エネルギーが急激に遮断され、管路内に巨大な**衝撃正圧（異常昇圧）および負圧（圧力降下）**の圧力波が音速で往復する現象。
* **被害**:
  * 衝撃正圧による配管破裂、ポンプ・弁類の破損。
  * 負圧による配管の座屈（押し潰れ）、管継手からの土砂・汚水吸い込み。
  * 水柱分離後の再結合による壊滅的衝撃。
* **防止対策**:
  * **サージタンク（調圧水槽）やエアチャンバー（空気槽）**の設置による圧力吸収。
  * **フライホイール**の設置（電動機軸に重量円盤を取り付け、慣性力でポンプの急停止を緩やかにする）。
  * 急閉逆止弁、緩閉逆止弁、または安全弁（逃し弁）の設置。

---

### (3) サージング（Surging）
* **発生機構**:
  * ポンプのQ-H特性曲線が「山形（右上がり特性）」を描く領域において、管路の抵抗特性と合致した際に、**圧力と吐出量が周期的に激しく変動（自己励起振動・脈動）**する現象。
* **被害**:
  * 配管全体の激しい振動・騒音、圧力計の針の激しい振れ、運転不能。
* **防止対策**:
  * Q-H曲線が常に右下がり特性（安定特性）を持つポンプを採用する。
  * 吐出弁の開度を調整し、山形領域（危険流量域）を外して運転する。

---

### (4) 締切過小流量運転（過熱現象）
* **発生機構**:
  * 吐出弁を完全に閉じたまま（締切運転）、あるいは極めて少ない流量のままでポンプを長時間運転し続けること。
* **被害**:
  * ポンプに投入された軸動力の全エネルギーが内部の水との摩擦・撹拌熱に変換され、ケーシング内の**水温が急激に上昇して沸騰**する。
  * 羽根車やライナーリングが熱膨張し、**金属同士が接触して焼き付き（固着）・破損**に至る。
* **防止対策**:
  * 締切運転を極力避ける。
  * 締切時でも最小限の流量を逃す**バイパス配管（過熱防止配管・最小流量弁）**を設置する。

---

## 7. ポンプ・電動機の保全管理（テキスト p.509〜510）

### (1) 水中モーターポンプの保全留意点
* **過酷な使用環境**:
  * 深井戸や取水井など、**ポンプおよび電動機本体が常時水没した状態**で稼働するため、陸上ポンプのように日常的に五感（目視・触手）で確認することが困難である。
* **保全実務**:
  * 運転時の吐出圧力、流量、運転電流値、振動・異音の監視。
  * **毎月の定期的な絶縁抵抗測定**: 水中ケーブルおよびモーター巻線の絶縁状態をメガテスターで測定し、絶縁低下の兆候を早期覚知して水没事故を未然に防止する。

---

### (2) 電動機の絶縁抵抗トレンド管理
* **絶縁抵抗の経年低下**:
  * 電動機巻線の絶縁物は、熱、振動、湿気、塵埃、サージ電圧などのストレスを受け、年数の経過とともに確実に劣化（絶縁抵抗値の低下）が進行する。
* **トレンド管理の重要性**:
  * 単発の測定値だけで判断するのではなく、**測定データを時系列グラフ（トレンド）として蓄積・比較**する。
  * 降雨や湿度の影響を補正した上で、抵抗値が急激に低下し始める「屈曲点」を捉え、絶縁破壊（ショート・地絡）に至る前の段階でコイルの巻き替えやモーター更新を実施する。

---

## 8. バルブ（弁類）の機能分類と維持管理（テキスト p.510〜513）

バルブは、水流の遮断、流量・圧力の調整、管路の保護など多面的な役割を担う機器である。

```
【バルブの機能別分類】
① 遮断用 ──── 仕切弁、ボール弁（全開または全閉で使用。流路の完全遮断）
② 制御用 ──── バタフライ弁、コーン弁、調節弁（開度を調整し流量・圧力を制御）
③ 逆流防止用 ── 逆止弁（スイング逆止弁、ウェハー逆止弁。ポンプ停止時の逆流防止）
④ 減圧用 ──── 減圧弁（管網の下流側圧力を一定値に低減・保持）
⑤ 管路保護用 ── 急速空気弁（管路頂部の空気排出・負圧時吸気）、逃し弁（安全弁）
⑥ 薬品・排泥用 ─ ダイヤフラム弁（弁体が膜状。腐食性薬液や固形物混入液に適用）
```

---

### (1) バタフライ弁と仕切弁の構造・保全比較

```
【主要バルブ2種の構造比較】
［バタフライ弁］                    ［仕切弁（ゲート弁）］
    ┌──────┐                           ┌──────┐
    │ 弁箱 │                           │ 弁体 │（上下動）
    │（円盤弁体が回転）                 │ 弁座 │
    └──────┘                           └──────┘
  ・薄型・小スペース・軽量            ・全開時、流路に障害物がなく
  ・大口径の配水本管に好適             圧力損失が最小
  ・中開度での流量制御が可能          ・全開または全閉で使用（制御不可）
```

* **バタフライ弁の維持管理上の留意点**:
  * **ゴム弁座の劣化**: 弁体外周または弁箱内面のゴムシートの摩耗・剥離による止水不良。
  * **開度計の指示ズレ**: 弁軸のガタつきによる外部開度計と実際の弁開度の食い違い。
  * **★ ポリピグ管内洗浄の禁止**: バタフライ弁は全開時でも弁体が流路中央に残るため、管内洗浄用ピグ（ポリピグ）を通過させると**ピグが引っ掛かり弁体が大破**する。
* **仕切弁（ゲート弁）の維持管理上の留意点**:
  * **グランドパッキンの調整**: ステム（弁棒）からの漏水防止。締め付け過ぎるとハンドルが重くなり操作不能となり、片締めすると弁棒を損傷する。
  * **全閉時の食い込み防止**: 砂やスラッジなどの異物が底部弁座に噛み込んだ状態で無理に締め込むと、弁座が破損・食い込みを起こして開かなくなる。

---

### (2) バルブ操作の共通鉄則
* **急開・急閉の厳禁**:
  * バルブを急激に開閉すると、急激な流速変化により管路内に激しい**水撃圧（ウォーターハンマー）**が発生し、配管や機器を破壊する。必ず緩速操作を行う。
* **全開・全閉位置での無理な締め込み禁止**:
  * リミットに達した弁をバール等で無理に過大トルクで回すと、弁棒の変形・ネジ山の破損を招く。
* **止水状態の確実な確認**:
  * 全閉操作後は、下流側圧力計、排水弁からの出水状況、聴音により完全に止水されているかを確認する。
* **電動弁の安全インターロック**:
  * 手動ハンドル操作時に電動モーターが誤起動して作業者が負傷しないよう、**手動切替時の電気的インターロック（電源遮断回路）**が確実に機能していることを確認する。

---

## 9. 浄水処理機械設備（薬品注入設備）（テキスト p.514〜518）

浄水処理で用いられる各種薬品は、強酸、強アルカリ、強酸化剤などの強い腐食性・危険性を持つため、薬品の性状に応じた専用設備と厳格な管理が求められる。

```
【薬品注入設備の系統構成】
［液体薬品］ 貯蔵槽 ──→ 注入ポンプ（定量・ダイヤフラム等） ──→ 流量計・注入点
［粉体薬品］ サイロ・ホッパー ──→ フィーダー（供給機） ──→ 溶解槽 ──→ 注入ポンプ
［液化ガス］ 貯蔵槽（ボンベ） ──→ 気化器（エバポレーター） ──→ 質量流量計・注入機
```

---

### (1) 凝集用薬品注入設備（PAC・硫酸バンド）
* **凝集剤の特性**:
  * **ポリ塩化アルミニウム（PAC）**: 液体で供給される。凝集適正pH範囲が広く低温低濁度にも強いが、配管内で結晶化・固着しやすい。
  * **硫酸アルミニウム（硫酸バンド）**: 液体または固形（粉体）。アルカリ度消費が大きい。
* **保全管理の実務**:
  * **PACの固着防止と水洗浄（フラッシング）**: PACは空気に触れたり滞留したりすると容易に固化・スケール化し、注入ノズルや細径配管を閉塞させる。定期的に管内を水洗いする。
  * **注入停止時の全系統洗浄**: 設備を停止する際は、配管内に薬品を残さず、**貯液系統から注入点に至る全ラインを清水で完全にフラッシング**する。
  * **粉体設備のブリッジ防止**: 粉体サイロ・ホッパー内では、湿気等により粉体がアーチ状に固まって落下しなくなる「ブリッジ現象」が起きやすいため、ノッカーやバイブレーター（ブリッジ破壊装置）の動作を点検する。
  * **バグフィルターの管理**: 粉体受入時の集塵機バグフィルター（ろ布）の目詰まり点検と定期交換。

---

### (2) pH（ペーハー）調整用薬品注入設備
* **目的**:
  * 原水の凝集適正pH範囲（通常6.5〜8.0程度）への調整、および給水栓末端における法定水質基準（pH 5.8〜8.6）の適合・配水管防食（ランゲリア指数の改善）。
* **使用薬品**:
  * **酸剤**: 濃硫酸、塩酸（液体）、炭酸ガス（液化ガス：気化器・差圧式流量制御）。
  * **アルカリ剤**: 水酸化ナトリウム（苛性ソーダ＝液体）、水酸化カルシウム（消石灰＝粉体）。
* **★ 苛性ソーダ（液体）の冬期結晶化対策**:
  * 工業用苛性ソーダ（濃度48%等）は、**外気温が10℃〜15℃程度に低下すると容易に凍結・結晶化（凝固）**する性質を持つ。
  * 冬期に配管やタンク内で凝固すると一切の注入が不可能となるため、屋外露出配管やタンクへの**保温材施工、ヒータートレース（電気ヒーター帯）の敷設**が必須である。

---

## 10. 次亜塩素酸ナトリウム注入設備の運転保全（★超重要・テキスト p.519〜520）

水道法第22条に基づき、給水栓末端での遊離残留塩素濃度（平常時0.1mg/L以上、病原生物汚染懸念時0.2mg/L以上）を保持するための最重要設備である。

```
【次亜塩素酸ナトリウムの3大特性と管理課題】
① 自然分解特性 ── 有効塩素濃度の低下、副生成物「塩素酸」の急増
② ガスロック現象 ─ 自然分解で生じる酸素気泡による注入ポンプの「無注入（空引き）」
③ スケール付着 ── 強アルカリと水中のカルシウム反応による注入ノズル閉塞
```

---

### (1) 自然分解と塩素酸の生成
* **自然分解のメカニズム**:
  * 次亜塩素酸ナトリウム（有効塩素濃度5〜12%の淡黄褐色液体）は、**保管温度の上昇、直射日光（紫外線）、長期保管、金属イオン（鉄・銅）の混入**により著しく自然分解が促進される。
* **分解による2大弊害**:
  1. **有効塩素濃度の低下**: 消毒効力が失われ、設定通りの量を注入しても残留塩素が上がらなくなる。
  2. **塩素酸（Chlorate）の増加**: 自然分解の副反応により、水道水質基準項目である「塩素酸（基準値：$0.6\text{ mg/L}$以下）」が急増し、水質基準超過リスクが生じる。
* **適正な貯蔵計画**:
  * 水道施設設計指針では、塩素剤の貯蔵容量を**「1日平均注入量の10日分以上」**と定めている。
  * しかし、過剰な長期保管は自然分解と塩素酸増加を招くため、使用量を精緻に予測し、過大な滞留を生じさせない計画的受入・消費管理を行う。

---

### (2) ガスロック現象（無注入事故）と防止対策
* **発生機構**:
  * 次亜塩素酸ナトリウムの自然分解に伴い、**微細な酸素ガス（気泡）**が連続的に発生する。
  * ダイヤフラム式定量ポンプや吸込配管内にこの気泡が滞留すると、ポンプの圧縮室が気体で満たされ、ダイヤフラムが往復動しても気体が伸縮するだけで液体を吸い上げなくなる**「ガスロック（エア噛み）」**が発生する。
* **重大なリスク**:
  * ポンプが正常にモーター回転・往復動しているにもかかわらず、**薬品が全く注入されない「無注入状態（消毒停止）」**に陥る。
* **防止対策**:
  * 自動エア抜き弁（脱泡機能付きポンプヘッド）の採用。
  * ポンプ吸込側を「押し込み配管（タンク液面よりポンプを低く配置）」とし、負圧による気泡発生を防止。
  * 定期的な手動脱泡（エア抜き）操作の実施。

---

### (3) スケール閉塞と酸洗浄手順（テキスト p.519）
* **スケール発生の理由**:
  * 次亜塩素酸ナトリウムは強アルカリ性（pH 11〜13）であるため、水（希釈水や主配管の水）と接触する注入点ノズル付近において、水中に溶存しているカルシウムイオンやマグネシウムイオンと反応し、**炭酸カルシウム等の白色結晶（スケール）**を析出・沈着させる。
* **配管閉塞の防止と酸洗浄手順**:
  * 放置すると注入ノズルが完全に閉塞するため、定期的な酸洗浄を実施する。
  * **酸洗浄の手順**:
    1. 注入ラインを隔離し、残留次亜を水で十分にフラッシングする。
    2. **濃度1〜5%程度に希釈した塩酸（希塩酸）**を注入管内に充填・注入する。
    3. **約30分間静置**し、炭酸カルシウムスケールを化学反応（溶解）させる。
    4. スケール溶解後、**清水で徹底的にフラッシング（水洗浄）**を行い、塩酸を完全に排出する。

---

### (4) 安全管理と配管の二重化
* **有毒塩素ガスの発生防止（混触厳禁）**:
  * 次亜塩素酸ナトリウム溶液に**酸性薬品（硫酸、塩酸、PAC等）が混入・接触すると、猛毒の塩素ガスが爆発的に発生**する。
  * 薬品受入口の誤接続防止（異径継手・色分け）、防液堤の完全分離を徹底する。
* **配管ライン・設備の二重化**:
  * 消毒設備の停止は、水道法上直ちに「給水停止」に直結する。
  * したがって、次亜注入ポンプだけでなく、**注入配管ラインそのものを2系統（常用・予備）化**し、閉塞や漏洩時でも瞬時に切り替えて消毒を継続できるシステム構成とする。
* **作業者の安全保護具**:
  * 強アルカリ腐食性と眼球への重大な危険性から、点検・補修作業時は**保護メガネ（ゴーグル）、耐薬品手袋、保護前掛け**を必ず着用する。

## 11. まとめ：機械・電気設備（各論編）重要キーワード・数値基準一覧表

| 設備・項目 | 最重要キーワード | 具体的要点・工学的仕様・管理数値 |
| :--- | :--- | :--- |
| **取水・貯水設備** | 水中設備の計画保全 | 水没ゲート・スクリーン・戸溝水密ゴム等の定期水抜き点検。 |
| **電気設備** | 瞬低・波及事故防止 | 2系統受電、自家発電、UPS瞬低保護、上位波及事故防止の保護協調。 |
| **ポンプ分類** | 横軸両吸込渦巻きポンプ | 左右両側吸込によりスラスト力を完全相殺。水道基幹送配水用。 |
| **ポンプ分類** | 多段渦巻きポンプ | 複数の羽根車を直列配置し高揚程を確保。深井戸・高台送水用。 |
| **特殊ポンプ** | エアーリフトポンプ | 水中に圧縮空気を送り込み、気泡混入による比重差（浮力）で自噴揚水。 |
| **性能曲線** | 最高効率点（BEP） | 効率 $\eta$ が最大となる点。省エネ、低騒音・低振動、長寿命運転の基本。 |
| **誘導電動機** | かご形 vs 巻線形 | かご形：構造簡単・保守極めて容易（現代主流）。巻線形：ブラシ摩耗粉保守煩雑。 |
| **速度制御** | インバータ（VVVF） | 軸動力は回転数の3乗に比例（省エネ絶大）。高調波抑制対策が必須。 |
| **異常現象** | キャビテーション | 局所低圧が飽和蒸気圧以下となり気泡発生・圧壊。壊食（孔食）。対策：NPSH確保。 |
| **異常現象** | 水撃作用（ウォーターハンマー） | 停電急停止時の圧力波。配管破裂・負圧座屈。対策：サージタンク、フライホイール。 |
| **異常現象** | 締切過小流量運転 | 吐出弁全閉時の内部摩擦熱による沸騰・焼き付き。バイパス過熱防止弁。 |
| **バルブ工学** | バタフライ弁 | 円盤弁体回転。小スペース。ゴム弁座点検。**ポリピグ通過厳禁**。 |
| **バルブ工学** | 仕切弁（ゲート弁） | 流路を直角遮断。全開時圧力損失最小。グランドパッキン調整、片締め防止。 |
| **バルブ操作** | 急開急閉の厳禁 | 急な弁開閉による水撃圧発生防止。手動切替時の電気インターロック。 |
| **凝集剤注入** | PAC固着・フラッシング | 結晶化によるノズル閉塞防止のため定期水洗浄。停止時は全系統水洗。 |
| **pH調整剤** | 苛性ソーダ冬期結晶化 | 10〜15℃以下で凝固。屋外配管ヒータートレース・保温必須。 |
| **次亜注入** | 自然分解と塩素酸 | 温度・光で分解。有効塩素低下、塩素酸増加、酸素気泡によるガスロック。 |
| **次亜貯蔵** | 貯蔵容量基準 | **1日平均注入量の10日分以上**（ただし長期過剰保管は避ける）。 |
| **次亜スケール** | 希塩酸による酸洗浄 | 炭酸カルシウムスケールに対し**1〜5%希塩酸を30分静置**後水洗。 |
| **次亜安全** | 配管二重化・混触防止 | 消毒停止即断水防止のため配管ライン二重化。酸との混触で有毒塩素ガス発生。 |
