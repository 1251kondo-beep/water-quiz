## 1. 保全管理の目的と基本概念（テキスト p.580）

水道計装設備における保全管理は、プラントの健全性を担保し、突発的な運転停止や水質事故を未然に防ぐための根幹業務である。

```
【計装設備保全管理の目的（★最重要・下線指定箇所）】
「計装設備の保全の目的は、点検などによって機能の劣化等を見出し、
 設備を常に正しい状態に復元・維持することである。」
```

* **保全業務の構成要素**:
  * 日常点検、定期点検、整備、修繕、更新などが含まれる。
  * 各機器の始動後・稼働中に、正常な状態で運転されているかを**「指示計（計測値）」**および**「五感（異音、振動、異臭、発熱）」**で確認する。
* **PDCA / CAPDによる作業の質の向上**:
  * 機能・運転状態に異常を発見した場合は直ちに処置し、機能低下や故障を未然に防止する。
  * 保全管理業務で蓄積された**故障記録・修繕記録を分析・「評価」**し、点検整備の作業計画や点検周期を見直して作業の質を向上させる。
* **★試験・実務の着眼キーワード**:
  * **「劣化」**: 経年的な機能劣化を潜在段階で見出す。
  * **「指示計」**: 定量的な計測データで確認する。
  * **「五感」**: 現場巡視において聴覚・触覚・嗅覚・視覚を総動員して予兆を察知する。
  * **「評価」**: データを蓄積するだけでなく、統計的・技術的に評価して保全周期に反映する。

## 2. 保全管理の業務分類体系（テキスト p.580）

保全方式は、故障発生前に対処する**「予防保全」**と、故障発生後に対処する**「事後保全」**に大別される。

```
【計装保全の体系】
┌── 予防保全（Preventive Maintenance）
│     ├── 時間計画保全（定周期保全 / TBM: Time Based Maintenance）
│     │     ├── 日常点検（状態監視・定点観測）
│     │     └── 定期点検（法定点検・停止分解点検・水質計器点検）
│     └── 予知保全（状態監視保全 / CBM: Condition Based Maintenance）
│           └── 設備診断技術（振動・加速度・自己診断機能）
└── 事後保全（Breakdown Maintenance / 故障後修理・緊急保全）
```

### (1) 予防保全の分類と特徴

#### ① 時間計画保全（定周期保全 / TBM）
* **概念**: 機器の稼働時間や経過期間（例：1年、3年、5年）に基づき、劣化の有無にかかわらず一律に点検・整備・部品交換を行う方式。
* **メリット**: 突発故障を大幅に抑制でき、計画的な予算計上・工事発注が可能。
* **デメリットと課題**: まだ十分に使える（劣化していない）健全な部品も廃棄・交換することになり、余分なコストが発生する。
* **実務的判断**: 設備の故障重要度、代替機能（予備機）の有無、万一故障した際の社会的影響度を総合的に勘案し、効率的・経済的な周期を設定する（例：メーカー推奨5年に対し、稼働率や環境を考慮して7年で更新するなど）。

#### ② 日常点検（状態監視保全）
* 計装機器は高度に電子化されており、機械的駆動部が少ない。多くは監視制御システム（SCADA）によってリアルタイムにデータ把握が可能である。
* **定点観測の重要性**: 運転電流値、圧力、温度、流量などの平常時データをマーキング・トレンド管理し、「同一条件なのに電流値が異常に高い」「水圧変動パターンが平常と異なる」といった**異常の初期兆候（予兆）を早期発見**する。

#### ③ 定期点検
* 一定期間ごとに機器を停止・校正・詳細測定する点検。保全費用全体に占める割合が大きいため、点検周期と内容の適正化が重要。
* **水質計器の定期点検**:
  * 水回り設備のため電極汚れ・消耗・ドリフトが著しく激しい。
  * 大規模浄水場（東京都の朝霞・金町・東村山等）では、水質計器室に専門の保守点検員が常駐し、日次・週次で洗浄・校正を実施している（中小規模施設では定期巡回委託）。
* **受変電・電気設備**: 電気事業法に基づく「保安規程」に定められた周期（月次点検、年次停電点検等）を確実に遵守。

#### ④ 予知保全（CBM: 状態監視保全）
* **概念**: 設備診断技術によって劣化の進行状態を定量的に推定し、限界値に達する直前の最適なタイミングで補修・更新を行う手法。
* **計装設備の自己診断機能**: 最新の伝送器やPLCは、CPU異常、メモリ異常、ループ断線、センサ素子劣化等を自動検知する自己診断（インテリジェント）機能を備える。
* **機械設備の劣化診断（実例）**:
  * ポンプ電動機の**「振動測定・振動加速度解析」**。新設時のベースライン値と現在値を比較し、軸受（ベアリング）の摩耗や芯狂い（ミスアライメント）を判定して工場オーバーホール時期を決定する。

### (2) 事後保全の概念と実務上のリスク管理
* **概念**: 故障が発生した時点で修理・交換を行う方式。給水への影響が軽微な付帯設備や、完全二重化された予備機がある設備に適用される。
* **事後保全の至上命題**: **「故障によるシステムの停止時間（ダウンタイム）をいかに極小化するか」**。
* **必要な体制**: 即応修繕体制、補修技術の確保、および**「適切な予備品管理（ストック）」**。

## 3. サプライチェーン問題と予備品管理の実務（テキスト p.580〜581）

### (1) 予備品管理の4大原則（テキスト p.580）
1. **品目・数量の決定**: 故障頻度と納期を考慮した適正ストック設定。
2. **在庫量の定期点検**: 劣化・員数不足の定期確認。
3. **予備品の整理**: 即座に取り出せる5S管理。
4. **予備品の保管環境**: 温湿度管理、静電気防止、防塵。

### (2) 現代における納期長期化（受注生産化）とストックの重要性
* **メーカーの在庫圧縮傾向**:
  * 近年、ベンダー・メーカーはコスト削減のため中間在庫を保有せず、発注を受けてから製造する「受注生産」が主流となっている。
  * 重要機器・電子基板であっても、**「発注から納品まで3ヶ月〜半年（場合によっては1年以上）かかる」**事態が常態化している。
* **現場における事前購入・在庫確保の必要性**:
  * 故障してから手配したのでは浄水場・給水所が数ヶ月間機能停止に陥るため、**「致命的な機器・専用部品はあらかじめ事業団・水道局側で予算を確保して買い置き（ストック）しておく」**ことが不可欠である。

```
【予備品ストック必須の代表的クリティカル機器】
① 薬品注入ポンプおよび消耗部品（ダイヤフラム、逆止弁、三方弁等）
② 遠隔監視テレメータ装置の通信カード・入出力（I/O）基板
③ 受変電設備・動力回路の配線用遮断器（MCCB）・漏電遮断器（ELB）
④ pH調整用硫酸・苛性ソーダ注入系統の耐食耐酸バルブ・パッキン
```

### (3) 実務事故・トラブル教訓から学ぶ予備品・更新の重要性

#### 【実例1：応急給水施設における漏電遮断器（ELB）故障事故】
* **状況**: 震災時用応急給水施設（1,500m³地下貯水槽）において、設置後30年を経過した大型漏電遮断器（ELB）が突如トリップし、再投入不能（投入コイル・機構破損）となった。
* **危機**: 貯水槽の循環ポンプが停止。放置すれば水が滞留・腐敗し、1,500m³の飲料水を全量廃棄せざるを得ない緊急事態が発生。
* **教訓**: 大型ELBは特注品で正規納期に数ヶ月を要したため、急遽業者が保有していた中古品を探索・転用して辛うじて復旧した。ブレーカー・遮断器であっても「30年経過品は突発故障前に計画更新する」「重要設備は予備品を常備する」ことの重要性を示した。

#### 【実例2：重要病院・警察署における受電用遮断器の投入不能事故】
* 高圧遮断器（VCB等）が点検後に投入不能となり全所停電。非常用自家発電設備が起動したものの、燃料保有量は48時間分しかなく、燃料枯渇までに遮断器を復旧できなければ医療崩壊・治安麻痺に至る極限状態を招いた。

#### 【実例3：導水ポンプ所のテレメータ基板故障と「目くら状態」】
* 浄水場から1km以上離れた遠隔導水ポンプ所のテレメータ通信基板が破損し、監視制御卓からデータが消失（目くら状態）。
* 基板の手配に半年かかるため、復旧まで運転員が遠隔施設に常時張り付く事態となった。テレメータ系統の二重化や共通予備基板の確保が不可欠。

## 4. 保全計画の体系と作成手順（テキスト p.581）

水道施設の保全計画は、階層構造を持つ以下の3つの計画から構成される。

```
【保全計画の3階層体系】
┌── 長期保全計画 ──── 新設から廃止・全面更新まで（20〜30年スパン、ライフサイクルコスト最小化）
├── 年間保全計画 ──── 法安規程・定期点検周期に基づく年度ごとの実施計画（予算執行）
└── 個別保全計画 ──── 特定の重要設備・ユニットごとの詳細整備・点検仕様計画
```

### (1) 長期保全計画の策定と財政調整
* プラントの耐用年数（コンクリート構造物50〜100年、受変電設備25〜30年、計装設備10〜15年、消耗機器数年）を見据えた中長期修繕・更新計画。
* 財政・予算担当部署と事前に綿密な調整を行い、毎年の更新投資額を平準化させるとともに、必要な予算枠を確実に確保する。
* **【実例：粉末活性炭注入設備の摩耗対策】**:
  * 多摩川等の水源水質悪化（カビ臭原因物質ジェオスミン・2-MIB等）に伴い、小作浄水場等で粉末活性炭を高頻度注入。
  * 活性炭スラリーは研磨性が極めて高く、配管が1〜2ヶ月で摩耗貫通（ピンホール漏洩）する。このような高摩耗設備は、長期・年間保全計画に短周期更新をあらかじめ組み込んで運用する。

### (2) 各種台帳・設計図書の整備と保管（テキスト p.582）
* **設計図書の散逸防止**:
  * 一般建築物等では担当者の異動や維持管理不足により設計図書・完成図面が散逸し、地下埋設管の位置すら不明となるトラブルが頻発している。
* **水道における完成図書・マッピングシステム**:
  * 水道施設・管路網では、最新の変更履歴を反映した**施設台帳・設計図書・管網マッピングシステム（GIS）**を常に最新状態に更新・保管・バックアップすることが保安の前提条件である。

## 5. 運転・保全データの管理と活用（テキスト p.582〜583）

### (1) データ管理の目的
運転日報、月報、年報、故障履歴、警報ログを単にファイリングするだけでなく、統計分析を行って以下の業務へフィードバックする。
1. **運転操作の最適化**: 季節変動・時間変動に応じた薬注率や水圧目標の見直し。
2. **保全周期・更新時期の客観的判断**: 故障頻度や稼働時間の積算に基づくオーバーホール判定。
3. **異常予兆の早期察知**:
   * **過トルク（トルクリミット）履歴**: 電動弁の過トルク警報頻度を分析。冬季の凍結負荷や弁座へのスケール付着・機械的固着を早期察知し、バルブ全開全閉不能になる前に修繕を行う。

### (2) 設備更新の着眼点：省エネルギーと高効率化
* 経年劣化した設備の更新時は、単なる同等品交換（原形復旧）にとどまらず、**「エネルギー消費削減・脱炭素化」**の観点を取り入れる。
  * 例：昭和40〜50年代の**油入変圧器**を、最新の高効率**モールド変圧器（トップランナー変圧器）**へ更新し、無負荷損（鉄損）・負荷損（銅損）を激減させて年間電気料金を大幅に縮減する。

## 6. 計装設備の精度管理（テキスト p.584〜585）

計装システムが計測するデータが不正確であれば、適切なプロセス制御や水運用は不可能となる。計器の精度維持は計装保全の最重要テーマである。

### (1) 精度管理の基本手法
* **許容誤差の管理**: 計器のフルスケール（最大目盛）に対する許容誤差（例：$\pm 0.5\% \sim \pm 1.0\%$以内）を設定し、定期的に確認。
* **現場圧力計の管理**: 圧力計は振動や脈動で指示が狂いやすいため、元コックを閉止して点検し、狂いが生じたものは安価であるため躊躇なく新品へ交換する。

### (2) 総合誤差の計算（二乗和平方根）
計測システム全体の総合誤差 $E_0$ は、センサ部、変換器、伝送器等の個別誤差 $E_1, E_2, \dots$ を用いて二乗和平方根で合成される。

$$E_0 = \sqrt{E_1^2 + E_2^2 + \dots + E_n^2}$$

* **アナログ伝送 vs デジタル伝送**:
  * センサから受信部までをアナログ信号（4-20mA DCや1-5V DC）で伝送する場合、伝送路ノイズや変換器ごとに誤差が累積する。
  * 早期にAD変換（アナログ $\rightarrow$ デジタル）してデジタル通信化（フィールドバス・Ethernet）すれば、伝送途中の精度劣化を完全に排除できる。

### (3) 水質計器の校正（キャリブレーション）
* **日次・週次校正の必須性**: 水質計器（濁度計、残留塩素計、pH計等）はセンサ部が水流・薬品に常時接触するため、汚れや電極劣化による測定値のズレ（ドリフト）が不可避である。
* **クリプトスポリジウム対策における高感度濁度計**:
  * ろ過池出口水濁度「0.1度以下」を監視する精密濁度計は、ポリスチレンラテックス標準液等を用いて極めて厳格に定期校正を実施する。

### (4) 流量計の経年ドリフトと更新困難性（現場の重大課題）
* **大口径電磁流量計の実態**:
  * 送水本管や浄水場流出口の電磁流量計は、配管直管長（上流5D・下流2D等）の制約や、断水不能・バイパス管欠如・地下ピット狭小などの理由から、**新設以来数十年間にわたり更新できないケースが存在する**。
  * 長期使用に伴い測定値が徐々にドリフトし、浄水場側の「送水流量」と受水側給水所の「受水流量」との間に大きな乖離が生じる問題がある。超音波流量計の後付け設置等も検討されるが、直管長不足等で対応に苦慮する現場が多い。

### (5) 計器のトレーサビリティ（国家標準への連鎖）
* **国家計量標準への連鎖**: 計測器の校正に使用する標準器が、国家計量標準（産総研等）まで途切れることなくトレースされていることの体系的保証。
* **計量法に基づく検定**:
  * 薬品受入用**トラックスケール（台貫）**等は、計量法に基づく法定検定・定期検査に合格した計器を使用しなければならない。

## 7. 設備管理の広域化と無人施設の保安管理（テキスト p.585〜586）

### (1) 広域集中監視体制の進展
* 人口減少や技術者不足、効率化要請に伴い、水道施設の管理は広域化が進展している。
* **水運用センターによる統合管理**:
  * 例：東京都水道局では、水運用センター（文京区本郷・旧給水所等）や多摩水道改革推進本部（立川市）において、管内の複数浄水場、給水所、配水場、ポンプ所を統合的に集中監視・遠隔制御している。
* **現場操作機能の維持**:
  * 集中監視化された無人施設（給水所・ポンプ所）であっても、通信途絶時や現地作業時に備え、各施設に現場監視端末・手動操作盤を設置し、必要に応じて操作権を現地に移管できるバックアップ構成をとる。

### (2) 監視業務と現場保全のローテーション（五感の育成）
* **監視室固定化の弊害**:
  * 集中監視室でモニター画面だけを見続ける勤務形態が固定化すると、現場の構造や実機器の挙動、運転員としての「五感（音・振動・熱・匂い）」が完全に失われてしまう。
* **ローテーション配置の必須性**:
  * 運転員と保全班（点検・修繕・設計）の間で計画的な人事・勤務ローテーションを行い、**「現場を知る運転員」「運転実務を理解する保全・設計技術者」**を組織的に育成することが不可欠である。

### (3) 物理的セキュリティ・テロ対策
* 水道施設は国民の生命線を握る重要インフラであり、警察・自衛隊等の警備対象重要施設に指定されている。
* **重要施設における防護措置**:
  * 侵入検知赤外線センサー、防犯カメラ、赤外線フェンス、正門の24時間警備員常駐、車両突入防止ゲートの整備。
* **毒物混入テロ・サイバーテロの脅威**:
  * テロの目的は単に水量を止めることだけでなく、「市民に不安を植え付け社会を大混乱に陥れること」にある。
  * 警察本部との定期的な合同テロ対策訓練、原水取水口の連続魚類バイオアッセイ・水質異常検知器の監視を徹底する。

## 8. 経済安全保障とサイバーセキュリティ（テキスト p.586）

### (1) 経済安全保障推進法と特定重要物資・重要インフラ指定
* 大規模浄水場（基幹施設）などの監視制御システムは、国の経済安全保障上の審査対象・指定施設となる。
* **特定国製ハードウェア・ソフトウェアの排除基準**:
  * バックドア（不正侵入路）設置や機能停止リスクを回避するため、基幹監視制御システム、PLC、通信機器、サーバーOS等について、信頼性が担保された国内製または指定適合品を採用することが厳格に求められる。
  * 通信ネットワークの中核を担うスイッチングハブ等の汎用機器であっても、信頼性の確認された機器を選定する。

### (2) マルウェア・ウイルス感染防止の実務管理
* **外部メディア（USBメモリ等）の持込統制**:
  * プラント系制御ネットワークは原則として外部インターネットから物理的・論理的に完全遮断（エアギャップ）されている。
  * 最大の感染ルートは**「保守ベンダーが持ち込む作業用PCやUSBメモリ」**である。
* **持込手順の厳格化**:
  * 施設立入者の事前身元確認（氏名・国籍・所属の提出）。
  * 外部メディアの専用ウイルススキャン端末による事前検査、許可なきUSBメモリの接続完全禁止。

### (3) 信頼性設計（二重化とフェイルセーフ）
* **システムの二重化（デュアル化）**:
  * 主系（Active）と待機系（Standby）の二重化構成（CPU、電源、通信伝送路、PLC）。主系故障時は無瞬断または極短時間で待機系へ自動切替。
* **フェイルセーフ（Fail-Safe）設計**:
  * 万一システムや計器が故障した場合、**「必ず安全側（給水・水質事故を回避する側）へ作動して停止する」**論理回路を構築する（例：制御不能時は薬品注入弁を急閉せず現状維持または安全量へ移行、ポンプは過圧防止のため停止側へ移行等）。

## 9. 計装設備とICT・DXの活用（テキスト p.586）

* **タブレット・モバイル端末による点検効率化**:
  * 従来の紙の点検野帳から、現場タブレット端末を用いた数値入力、QRコード読み取り、写真撮影付き点検記録の電子化（誤記防止・作業効率化）。
* **保全データのクラウド管理**:
  * 設備台帳や保全履歴をセキュアな閉域網クラウドで一元管理し、複数事業所・広域間でのデータ共有を迅速化。
* **ICT導入時の留意事項**:
  * 導入範囲と費用対効果（ROI）の客観的検証。
  * システム障害時でも現場手動運転へスムーズに切り替えられる「アナログ的手順書・現場判断力」を並行して維持すること。

## 10. 【問題作成用】試験最頻出ポイント総まとめ・論点整理

本講義録（テキスト p.580〜586）から出題される4択問題・正誤判定問題の作成用キーワード対比表：

| 分野・論点 | 正しい記述（正肢のポイント） | 誤りとして出題されやすい引っかけパターン |
| :--- | :--- | :--- |
| **保全管理の目的** | 点検等により機能の**劣化を見出し、設備を常に正しい状態に復元・維持**すること。 | 「故障が発生するまで機器を運転し続け、壊れた時点で新品に交換すること」（×：事後保全のみを目的としない） |
| **保全の確認手法** | 指示計の数値確認に加え、**運転員の五感（音・振動・熱・匂い）による確認**が不可欠。 | 「電子化された計装機器の点検は指示計の数値のみで完結し、五感による確認は不要である」（×：五感点検が必須） |
| **時間計画保全（TBM）** | 一定期間で点検・整備するため突発故障を防げるが、**劣化していない部品も交換しコストがかかる**。 | 「時間計画保全は、機器の劣化限界まで部品を使用し続けるため最も経済的である」（×：過剰保全・コスト高の側面がある） |
| **予知保全（CBM）** | 振動測定や自己診断機能等の**設備診断技術により劣化進行を推定**し、最適な時期に補修する。 | 「予知保全とは、過去の故障データのみに基づいて一律の年数で部品交換を行う手法である」（×：それはTBM） |
| **事後保全の目標** | 故障による**「システムの停止時間（ダウンタイム）をいかに短縮するか」**が最大の目標。 | 「事後保全の目標は、故障が発生した機器の修理費用をゼロにすることである」（×：迅速復旧が主目的） |
| **予備品管理の現代的課題** | メーカーの受注生産化・在庫削減に伴い、**重要部品は数ヶ月〜半年以上の納期を要するため事前ストックが必須**。 | 「現代の計装部品は標準化されており、故障発生後に発注しても数日で即座に入手可能である」（×：長納期化が重大課題） |
| **保全計画の体系** | ライフサイクル全体を見据えた**「長期保全計画」**を策定し、予算担当部署と事前に調整する。 | 「保全計画は単年度の点検計画（年間保全計画）のみを策定すれば足り、長期計画は不要である」（×：長期計画が不可欠） |
| **水質計器の保全** | 水回り設備で汚れ・ドリフトが激しいため、**日次・週次等の極めて頻繁な洗浄・校正（キャリブレーション）が必須**。 | 「水質自動測定計器は自動校正機能があるため、人間の手による試薬補充や定期校正は数年間不要である」（×：頻繁な校正必須） |
| **計装の総合誤差** | センサ・変換器・伝送器等の個別誤差を**二乗和平方根**（$\sqrt{E_1^2 + E_2^2 + \dots}$）で合成する。 | 「総合誤差は各機器の誤差を単純に足し算（算術加算）して求める」（×：二乗和平方根で合成） |
| **広域化と組織管理** | 集中監視室での画面監視だけに固定せず、**現場点検・保全班とのローテーションを実施**して技術を維持する。 | 「集中監視化された事業体では、監視員は監視室に恒久固定配置し、現場巡視業務は一切行わせない」（×：技術劣化を防ぐため不可） |
| **サイバーセキュリティ** | 制御系ネットワークのウイルス感染を防ぐため、**保守業者が持ち込む作業PCや外部USBメモリの管理を厳格化**する。 | 「プラント系ネットワークはインターネットに接続されていないため、外部USBメモリの持込検査は不要である」（×：最大感染源） |
| **フェイルセーフ設計** | 機器やシステムが故障した際、**「必ず安全側（事故回避側）へ動作して停止・維持する」**論理を組み込む。 | 「故障発生時には、いかなる場合でも給水を継続するために全ポンプを最大回転数で強制運転する」（×：過圧・破断の危険） |
