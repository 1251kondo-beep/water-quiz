## 1. 概説：地球と日本の水資源（テキスト p.233〜234）

### (1) 地球上の水資源の賦存状況
* **地球全体の水総量**: 約 **14億 $\text{km}^3$**。
  * **海水**: 約 **97.5%**
  * **淡水**: 約 **2.5%**（大部分は極地の氷河・氷床や深層地下水）
* **日常的に利用可能な淡水**:
  * 人類が容易に利用できる河川水や湖沼水は、地球全水分量の **わずか約 0.01%（約 3,500万 $\text{m}^3$）** にすぎない。
  * 琵琶湖の約5,090個分、カスピ海の約1.8倍に相当するが、地球規模で見ると極めて貴重な限定的資源である。

### (2) 日本の水資源の4大特徴

#### ① 降水量と1人当たりの水資源量
* **年間平均降水量**:
  * **日本**: 約 **$1{,}700\,\text{mm}$**（世界平均の約2倍で降雨に恵まれている）。
  * **世界平均**: 約 **$800\,\text{mm}$**。
* **国民1人当たりの水資源量**:
  * **日本**: 約 **$4{,}000\,\text{m}^3/\text{年}$**。
  * **世界平均**: 約 **$14{,}000\,\text{m}^3/\text{年}$**。
  * 日本は狭い国土に人口が密集しているため、**雨は世界の2倍降るが、1人当たりが使える水量は世界の3分の1程度しかない**（水資源に決して余裕があるわけではない）。

#### ② 日本の河川勾配と流出特性
* 大陸の大河川（ナイル川、メコン川等）に比べ、日本の河川は **流路延長が短く、勾配が極めて急** である。
* 高い山地から海へ一気に流れ落ちるため、降った雨が短期間で海へ流出する。
  * 例：関東の利根川（流路延長約 $300\,\text{km}$）では、上流に降った雨が **約4日間** で海まで流下する（平均流速：時速約 $4\,\text{km}$、人の歩行速度並み）。
  * ダム等の貯水施設で一時貯留・補給を行わないと、水資源を有効に利用できない。

#### ③ 日本の水利用の内訳
* 日本の年間総降水量（約6,600億 $\text{m}^3$）のうち、蒸発散等を除く理論上の水資源賦存量は約4,300億 $\text{m}^3$。実際の年間水利用量は **約770億 $\text{m}^3$**。
* **用途別内訳**:
  * **農業用水（かんがい用水）** が圧倒的大部分（約3分の2）を占める。
  * 次いで **生活用水（都市用水）**、**工業用水** の順となる。
* **水源別内訳**:
  * **地表水（河川・ダム等）**: 約 **3分の2**
  * **地下水**: 約 **3分の1**

#### ④ 水資源賦存量の年変動と近年の傾向
* **渇水年の賦存量**: 平年に対して降水量が著しく少ない「渇水年」には、水資源賦存量が **平年値の約 7割程度** まで減少する。
* **近年の極端化傾向**: 年降水量のばらつき（年変動幅）が激しくなり、春先の渇水による給水制限の懸念と、梅雨・台風期の線状降水帯による豪雨災害が表裏一体で発生している。

## 2. 水道水源の種類と特徴（テキスト p.234〜236）

水道水源は大きく「地表水」と「地下水」に大別される。

| 水源分類 | 主な種類 | 特徴・長所 | 課題・短所（出題最頻出） |
| :--- | :--- | :--- | :--- |
| **地表水** | **河川水（表流水）**<br>湖沼水<br>ダム開発水 | ・水量が比較的豊富である。<br>・大規模都市・広域水道の基幹水源となる。 | ・**渇水時には水量・水質ともに大きな影響を受けやすい**。<br>・**洪水時には高濁度水の流入等、水質が急激に悪化する**。 |
| **地下水** | **浅井戸**<br>深井戸<br>伏流水<br>湧水 | ・自然の地層ろ過作用により、**水質が一般に極めて良好**。<br>・年間を通じて水温・水質が安定。 | ・**取水可能な水量に限界がある**。<br>・過剰揚水による井戸枯渇や地盤沈下のリスク。<br>・**浅井戸は地表面からの汚染（生活排水・農薬・油等）を受けやすい**。 |

* **自流水とダム水**:
  * **自流水**: 自然の河川流況から直接取水する水。
  * **ダム水（開発水）**: ダムに貯留し、河川流量低下時に補給放流を受けて取水する水。日本の水道取水量の約半数はダム水に依存している。
* **全水源が地下水の代表例**:
  * **熊本市**: 人口約74万人規模の政令指定都市でありながら、水道水源の **100%を天然地下水** で賄っている世界的にも希有な都市。

## 3. 水源の選定・管理と水源林の保全（テキスト p.235〜237）

### (1) 水道水源の選定要件
1. **水量の安定確保**: 将来の計画給水量を長期にわたり安定して取水できること（基準渇水時でも確保可能であること）。
2. **良好な水質**: 水道水質基準を満たす浄水処理が確実に行える原水であること。
3. **施設計画上の留意点**:
   * 送配水網との位置関係を考慮し、可能な限り **自然流下を活用できる標高・位置** を選定して省エネルギー化を図る。
   * 原水水質に応じた浄水処理方式（緩速ろ過、急速ろ過、膜ろ過、高度浄水処理）を選定する。

### (2) 水源の水質事故実例
* **平成24年 利根川水系ホルムアルデヒド前駆物質流出事故**:
  * 上流の産業廃棄物処理工場からヘキサメチレンテトラミン（ホルムアルデヒド前駆物質）を含む廃液が河川へ放流され、浄水場での塩素消毒処理により基準値を超えるホルムアルデヒドが生成。
  * **オゾン・活性炭等の高度浄水処理施設** を有していた東京都の浄水場等では浄水処理を継続できたが、高度処理施設を持たない千葉県等の浄水場では **取水停止・大規模断水** を余儀なくされた。
  * この事故を契機に、水系ごとの関係水道事業者・河川管理者間の迅速な情報共有連絡体制の構築が義務付けられた。

### (3) 【参考】水源林（森林）の多面的公益機能（緑のダム）
* **水源かん養機能**: 豊かな森林土壌（団粒構造）が雨水をスポンジのように蓄えて地中へ浸透させ、河川への流出量を平準化する（裸地に比べて土壌浸透能は **約3倍**）。
* **土砂流出防止機能**: 樹木の根系が土壌を緊縛し、土砂崩れやダム・河川への土砂堆積を防止する（適切な間伐林では荒廃林に比べ土砂流出量を **約10分の1** に抑制）。
* **水質浄化機能**: 土壌による自然ろ過および樹木による富栄養化物質（窒素・リン）の吸収。
* **地球温暖化防止**: $\text{CO}_2$ の吸収・固定。

## 4. 地表水取水施設の種類と構造（テキスト p.239〜241）

河川や湖沼から所要の原水を安全に取り入れるため、現地の流況・河床変動に応じた形式を採用する。

```
              【地表水取水施設の5大形式】
  ┌───────────────┬────────────────┬────────────────┬───────────────┐
  │ ① 取水堰     │ ② 取水塔       │ ③ 取水門       │ ④ 取水管渠   │
  │ (水位堰上げ)  │ (多段選択取水) │ (堤防部ゲート) │ (堤防下横断)  │
  └───────────────┴────────────────┴────────────────┴───────────────┘
                                   │ ⑤ 取水枠       │
                                   │ (河床・湖底沈設)│
                                   └────────────────┘
```

### (1) 取水堰（しゅすいぜき）
* **構造**: 河川を横断して堰を築造し、河川水位を堰き上げて安定した水深を確保し、側方の取水口から取水する。
* **特徴**: 大河川に多く、大容量の原水を極めて安定して取水可能。
* **附帯設備**: 可動堰ゲート、魚道（アユ・サケ等の遡上用）、土砂吐きゲート、沈砂池。多目的堰（水道・農水・工水・浄化用水等の共同堰）が多い。
* **実例**:
  * **利根大堰**（水資源機構管理、利根川）：堰長約 **$700\,\text{m}$**、最大取水量約 **$134\,\text{m}^3/\text{s}$**（首都圏の水道・農業・都市用水の命脈）。
  * **相模大堰**（神奈川県内広域水道企業団管理、相模川）：堰長約 **$500\,\text{m}$**。

### (2) 取水塔（しゅすいとう）【最重要・出題頻出】
* **構造**: 河川内や貯水池（ダム湖・湖沼）の水中に、円形または小判形の鉄筋コンクリート造の塔状構造物を自立設置する。
* **構造的特徴**: 外壁の **異なる水深（高さ）に多段の取水ゲート（取水孔）** が設けられている。
* **機能的利点（最重要ポイント）**:
  1. 水位変動の激しい貯水池等において、**水位の変化に応じて最適な高さのゲートを選択して取水** できる。
  2. 表層でアオコ（藻類）が発生した際や、底層で貧酸素水・高濁度泥水が滞留した際、**水質が最も良好な中間層を選択して取水（選択取水）** できる。
* **実例**: 村山・山口貯水池取水塔（東京都）、金町浄水場・江戸川取水塔（とんがり屋根のシンボル的意匠）。

### (3) 取水門（しゅすいもん）
* **構造**: 河川の堤防または護岸の一部を切り欠き、流入用ゲート（樋門・水門）を設けて取水する。
* **特徴**: 河川を横断して堰き止めないため構造は比較的簡素。河床や水深が安定した中小河川に適用。流入部にスクリーンを配置して流木やゴミを除去。

### (4) 取水管渠（しゅすいかんきょ）
* **構造**: 河川敷（高水敷）が広い大河川等で、流路水筋に取水頭を設け、堤防下を横断する管渠（RC管・鋼管等）により堤内地へ自然流下で導水する。
* **留意点**:
  * 河床の洗掘により管渠が露出・損壊しない安定河床区間に設置する。
  * 堤防構造の弱点とならないよう堅牢に築造し、点検・補修時にも取水を停止させないため **原則として2系列以上** 布設する。

### (5) 取水枠（しゅすいわく）
* **構造**: 乱流や洗掘の少ない河床または湖底に鉄筋コンクリート製・鋼製の枠体を沈設し、水面下に設けた採水孔から取水する。
* **特徴**: 小規模取水に適し、水面上に構造物が露出しない。スクリーンの目詰まりを防ぐため、**逆洗用の圧縮空気送気管や加圧水逆洗設備** を併設する。

## 5. 沈砂池の構造と設計基準（テキスト p.241）【最重要】

### (1) 設置目的
* 取水した原水に含まれる **粗い砂、砂礫、小石などを重力沈降によって分離・除去** し、後段の導水管、導水ポンプのインペラ（羽根車）、弁類の摩耗や損傷・堆積を防ぐ。

### (2) 構造基準と設計仕様（重要事項）
* **池数**: **原則として 2池（系列）以上を設置する**。
  * 理由：堆積した土砂の排出、定期清掃、点検、補修の際にも、**取水を全面的に停止させず、残りの池で取水を継続できるようにするため**。
* **平面形状**: 細長い長方形（矩形）の鉄筋コンクリート構造。
* **流速制御**: 流入部・流出部を絞り、池中央の断面積を広げることで、池内平均流速を **約 $0.1 \sim 0.2\,\text{m/s}$ の緩流** に減速させ、砂を確実に沈降させる。
* **池底勾配**: 堆積した土砂を排砂弁やサンドポンプの集砂ピットへ集約・排出しやすいよう、底部に一定の勾配を設ける。
* **粉末活性炭注入設備等の併設**:
  * 沈砂池は比重の大きい粗砂の重力沈降を目的としており、微細な有機物や溶解性物質は除去できない。
  * そのため、原水の油臭・カビ臭（異臭味）や有害化学物質の混入時に備え、**沈砂池に粉末活性炭の注入設備を併設** する場合がある。

## 6. 河川法に基づく許認可手続き（テキスト p.241）

河川から水を取水し、河川区域内に取水施設を設置する場合、河川法に基づく厳格な許可が必要となる。

| 河川法の条文 | 許可の名称 | 水道事業における具体的内容 |
| :--- | :--- | :--- |
| **河川法第23条** | **流水の占用の許可（水利権）** | 河川の流水を排他的・継続的に一定量取水する権利の取得。 |
| **河川法第24条** | **土地の占用の許可** | 河川区域内の河川敷等に取水施設や沈砂池の敷地を確保する許可。 |
| **河川法第26条** | **工作物の新築等の許可** | 取水堰、取水口、取水塔、樋門、沈砂池などの構造物を築造する許可（技術基準適合審査）。 |
| **河川法第27条** | **土地の掘削等の許可** | 施設築造に伴い、河床や堤防を掘削・改変する工事の許可。 |
| **関係水利権者の同意** | **水利調整・意見聴取** | 下流・近隣の既存水利使用者（農業用水、発電用水、他水道事業体等）に悪影響を及ぼさないための事前協議と同意。 |
