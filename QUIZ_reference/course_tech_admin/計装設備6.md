## 1. 計装設備の更新計画と工事留意点（テキスト p.635〜637）

計装設備は、土木構造物や機械・受変電設備とは異なり、プラントが24時間連続通水している「稼働中」にシステム全体を切り替えなければならないという極めて高い難易度を持つ。

### (1) 機能向上と更新性・長寿命化のトレードオフ
* **更新の目的**: 経年劣化したハードウェアの更新にとどまらず、最新の省エネ制御、自動化、DX（データ連携）を取り入れてプラント全体の性能を向上させる。
* **過度な複雑化の抑制**: 機能向上を追求しすぎるとシステムが複雑化・ブラックボックス化し、将来の更新性や保守性が悪化する。現場で長く安定して使用できる「汎用性・標準性」を担保することが重要。

### (2) ソフトウェアの継承における困難性
* **機種依存部と移植の限界**:
  * PLC（プログラマブルロジックコントローラ）のラダーシーケンスやSCADAの監視画面ソフトウェアは、メーカーやCPUの世代ごとに命令体系・コンパイラ・I/Oアドレス割り付けが異なる。
  * 既存のソフトウェアをそのまま新システムに流用（コピー＆ペースト）することは不可能であり、**新コントローラー向けに論理の再構築やチューニングが不可欠**となる。
* **改変リスクの極小化**:
  * 安定稼働しているロジックに不用意に手を加えると、新たなバグや予期せぬインターロック誤動作を招く。
  * 基本的な制御アルゴリズム・骨格は変更せず、ハードウェアに依存する下位レイヤー（I/Oドライバ、通信インターフェース）の変更にとどめることが安全運用の鉄則である。

### (3) ★工事計画・施工上の最重要留意事項（テキスト赤線箇所）

```
【稼働中更新における4大工事留意事項】
① 稼働中更新の原則（★最重要）：
   ・水道プラントを全停止して計装更新を実施できる施設は皆無である。
   ・計装設備の更新工事は「プラント稼働中に無断水で実施する」ことを前提に計画する。
② 新旧システムの並行運用と操作責任の明確化：
   ・切替過渡期においては、新旧システムが同時に並行稼働する期間が生じる。
   ・「どのプロセスが旧システムで、どこからが新システムか」の操作範囲・責任分界を明確にする。
   ・中央監視室と現場盤の間で操作権の錯綜を防ぐため、十分な監視・操作要員（マンパワー）を配置する。
③ 仮設設備の適切な活用：
   ・切替時のリスクを低減するため、一時的な仮設PLC、仮設伝送ライン、仮設計器を適切に構築する。
④ 新規設備の試運転・検証と初期故障対応：
   ・稼働中プラントでは全所停電試験や極端な過負荷試験を実地で行うことが制限されるため、
     工場出荷前試験（FAT）や模擬入出力による事前検証を徹底する。
   ・更新直後は「バスタブ曲線の初期故障期」にあたり突発トラブルが発生しやすいため、
     ベンダー（施工業者）の現地待機・即応体制を契約上義務付けておく。
```

## 2. 計装設備のリスク管理体系（テキスト p.637）

水道施設における計装設備のリスク要因は、**「内的要因」**と**「外的要因」**に明確に分類される。

```
【計装設備のリスク要因分類体系（★最重要・下線指定箇所）】
┌── 内的要因 ── ① 点検整備不良
│                 ② 機器・部品の経年劣化（電解コンデンサ、センサ、リレー接点等）
│                 ③ 操作ミス・設定ミス（ヒューマンエラー）
└── 外的要因 ── ④ 自然災害（地震、風水害・浸水、落雷・雷サージ）
                  ⑤ 電気事故・電源異常（商用停電、瞬時電圧低下［瞬低］、高調波）
                  ⑥ ノイズ障害（強電誘導、電磁障害、インバータノイズ）
                  ⑦ サイバー攻撃（不正侵入、マルウェア・ランサムウェア感染）
```

* **微弱信号の脆弱性**:
  * 計装設備は $4 \sim 20\,\mathrm{mA}\,\mathrm{DC}$ や $1 \sim 5\,\mathrm{V}\,\mathrm{DC}$ といった**極めて微弱な電流・電圧信号**を取り扱うため、落雷サージやノイズなどの外的要因によって容易に誤作動・機器破壊を引き起こす。
  * 避雷器（SPD/アレスター）の設置およびノイズ防護対策が不可欠である。

## 3. ノイズ対策と接地の2大目的（テキスト p.637〜638）

### (1) ノイズの侵入経路と影響（★下線指定箇所）
* **微弱信号への影響**: 伝送路や変換器にノイズが重畳すると、計装指示のハンチング、ゼロ点ドリフト、PLCの誤トリップ、通信途絶を引き起こす。
* **代表的ノイズ発生源**:
  1. **インバータ（VVVF）等のパワーエレクトロニクス**: 高速スイッチング素子（IGBT）による高周波コモンモードノイズ。共通接地線を介して計装系へ回り込む。
  2. **誘導性負荷の開閉**: ポンプ電動機、電動弁、電磁弁、大型電磁開閉器（コンダクター）の開閉サージ。
  3. **配線ラックでの誘導**: 動力ケーブル（強電）と計装信号ケーブル（弱電）を同一ラック・ダクトに近接敷設したことによる電磁誘導・静電誘導。

### (2) 実務的ノイズ防止対策
* **ケーブルの物理的離隔**: 動力線と計装信号線は別ルートとし、交差する場合は直角交差させる。
* **ツイストペア・シールド線の採用**: 計装信号にはシールド付きツイストペア線を使用し、シールドの片端を接地する。

### (3) ★計装設備における「接地の2大目的」（★最重要・下線指定箇所）

```
【接地の2大目的】
① 人身保護・保安上の安全対策（感電防止）：
   ・絶縁破壊や漏電時に、機器筐体に触れた作業員が感電死傷するのを防止する（A種・C種・D種接地）。
② システム保護・ノイズ対策（シールド接地・電位安定化）：
   ・信号伝送路のシールド層からノイズ電流を大地へ逃がし、回路の基準電位を安定させる。
```

* **デジタル計装システム特有の高周波インピーダンス問題（下線指定）**:
  * 「近年のデジタル計装システムは**使用周波数が極めて高い**ため、接地回路のインピーダンスが高くなり、微弱なノイズ電流であっても接地線に大きな**電位上昇（ノイズ電圧）**を生じさせる。」
  * したがって、システムの誤作動を防ぎ安定動作させるため、低インピーダンスの**「計装専用接地」**を直接施工することが不可欠である。

## 4. サイバーセキュリティ対策と情報インフラ防護（テキスト p.637〜639）

水道施設は国民の生命と都市機能を支える最重要インフラであり、世界的に水道システムを標的としたサイバー攻撃（不正アクセス・ランサムウェア）の脅威が現実化している。

### (1) セキュリティ安全管理の法的・行政的枠組み
* 国土交通省（旧厚生労働省）策定『水道分野における情報セキュリティ確保に関する安全管理ガイドライン』（令和7年3月改定等）。
* 水道事業者は「情報セキュリティ基本方針」および具体的な「安全管理基準」を策定し、組織全体で防護措置を講じなければならない。

### (2) ★ネットワーク分離の大原則（テキスト p.638・下線指定箇所）

```
【サイバー防護の絶対原則】
「プラントの監視制御を行う『制御系ネットワーク』と、
 インターネットに接続される一般事務・外部通信の『情報系ネットワーク』は、
 物理的または論理的に完全遮断（完全分離・エアギャップ）することを原則とする。」
```

* **安易なインターネット接続の危険性（講義者警告事項）**:
  * 地方・中小事業体において、コスト削減を理由に**「汎用のインターネット回線を経由して遠隔監視・操作を行うシステム」を構築することは極めて危険であり厳禁**である。
  * IPアドレスは外部から容易に特定・走査され、遠隔操作権限を不正に乗っ取られた場合、浄水停止や薬品注入の異常操作による壊滅的水質事故につながる。
  * 水道基幹システムの通信には、通信事業者の**「閉域専用回線（IP-VPN / 専用線）」**を使用しなければならない。

### (3) ★実践的な情報セキュリティ訓練の実施（テキスト p.639・下線指定箇所）
* 制御系システムがインターネットから切り離されていても、**保守業者が持ち込む作業PCや外部USBメモリを介したマルウェア感染**のリスクは排除できない。
* **実務対策**:
  * マニュアルを整備するだけでなく、**「マルウェア感染やサイバー攻撃によるシステム障害の発生を想定した『実践的な訓練』」**を定期的に実施し、即座に現場手動運転へ切り離す手順を習熟する。

## 5. 業務委託（委託管理）の形態と技術継承（テキスト p.639〜640）

### (1) 委託管理の進展と形態
* **一部業務委託**: 水質計器の定期点検・校正業務、漏水調査業務など、特定の専門業務を個別に委託。
* **包括的民間委託**: 複数の施設運転管理・保守点検をパッケージ化して民間事業者に一括委託。
* **第三者委託（水道法第24条の3）**: 水道技術管理者を民間事業者に選任させ、管理業務全般を委託する制度。官民連携（ウォーターPPP）の基盤。

### (2) 委託化に伴うメリットと実務上の重大課題

| 区分 | メリット | デメリット・直面する課題 |
| :--- | :--- | :--- |
| **事業運営面** | * 民間ノウハウの活用による効率化。<br>* 専門技術者・多様な人材の柔軟な確保。<br>* 施設ごとの個別契約事務の集約。 | * 直営職員と委託事業者との**「責任分界点が曖昧化」**するリスク。<br>* 契約仕様外の突発緊急事態における初動の遅れ。 |
| **技術・保安面** | * 専門メーカー・特化業者による高度な精密点検・リモート監視（膜ろ過等）。 | * **直営職員の計装・保守技術の喪失（技術継承の断絶）**。<br>* 異常発生時に職員自身が原因を究明・判断できなくなる「ブラックボックス化」。 |

## 6. 現場実務の生々しい課題と経済安全保障

講義者が実務経験（東京都水道局の大規模・中規模浄水場等）から語った生々しい実態：

1. **ソフトウェア改造費用の高騰とベンダーロックイン**:
   * 監視制御システムに数点の計測タグ（点数）を追加・改造するだけで数百万円の費用を請求される実態。
   * プログラムがメーカー固有の仕様となっているため他社に発注できず、**「ベンダーの独壇場（ベンダーロックイン）」**に陥りやすい。
2. **海外製機器の導入リスク**:
   * 価格が安くても、故障時の国内サポート体制の欠如、補修部品の輸入遅延により、維持管理で甚大な苦労を強いられる。
3. **重要インフラ指定と経済安全保障**:
   * 水道は電力・金融・交通と並ぶ「重要インフラ」に指定されている。
   * 基幹監視制御システムの更新時は、国（国交省・経産省）への事前審査・協議が必要であり、**特定国製機器・ソフトウェアを排除したサプライチェーンの安全性確認**が義務付けられている。
4. **AI技術の進化と暴走リスク**:
   * AI（機械学習）を活用した需要予測・薬注制御が進展する一方、AIが未知の条件下で誤認・暴走を起こすリスクを常に想定し、人間の運転員が介入・オーバーライドできる安全設計を維持しなければならない。

## 7. 【全講義総復習】テキスト第8章「計装設備」赤線・下線・最頻出全集約

本講義において講義者が「試験に必ず出る・実務で最も重要」として赤線・下線・丸付けを指定した**全ポイントの完全集約リスト**：

```
【第8章 計装設備：試験最重要ポイント総点検チェックリスト】

□ 1. 計装設備の定義（p.575）：
   「水道施設を円滑（遠隔）に管理するためのもので、施設の運転や管理に必要な情報を迅速かつ的確に把握し、
    操作に反映させるための設備である。」

□ 2. 計装設備導入の目的（p.575）：
   「各施設の計測設備の自動化及び集中管理化を行うことによって、運転操作の容易性、確実性、安全性等を
    確保するとともに、適切な情報管理を通じて水道施設全体の運転管理や設備管理を効率化することである。」

□ 3. 自動化の不可欠性（p.575）：
   「複雑化する水道施設を運用し、さらに自動化を可能にする手段として不可欠なものとなっている。」

□ 4. 運転管理の基本（p.576）：
   「機器・装置の組み合わせや自動化のためのソフトウェアのレベルによりその機能に大きな差が生じ、
    運転管理の効率化・省力化を左右する。」（※ただし監視員ミニマム2名基準は必須）

□ 5. ハードウェアの寿命（p.576）：
   「電力設備やポンプ設備などに比べて、物理的寿命が短い。」（7〜10年程度、コンデンサ容量抜け）

□ 6. 保全管理の目的（p.580）：
   「点検などによって機能の劣化等を見出し、設備を常に正しい状態に復元・維持することである。」
   ★重要4大キーワード：『劣化』『維持』『五感』『評価』

□ 7. 差圧式流量計の空気混入（p.600）：
   「共通する問題として空気の混入があり、必要により空気抜きを実施する。」（ゼロ点ズレ防止）

□ 8. 差圧式流量計の直管部（p.600）：
   「空気の影響を受けやすいので、絞りの上流・下流にかなりの直管部を要する。」

□ 9. 電磁式流量計のバイパス管（p.601）：
   「流量計の校正・取り替え時には管路の流れを止める必要があるため、給水に影響を与える管路では
    バイパス管を設ける。」

□ 10. 超音波式流量計の気泡影響（p.602）：
   「流体中に超音波を散乱する粒子や気泡が多いと測定が困難となる。」

□ 11. 超音波式流量計の直管長（p.602）：
   「流速分布の乱れ（乱流）や気泡の混入が測定精度に大きく影響するため、
    検出器取り付け部の上流側・下流側に所定の直管長が必要である。」

□ 12. 残留塩素計サンプリング配管の塩素消費（p.611）：
   「試料水はサンプリング配管で送られるため、配管途中に塩素を消費する物質が付着していると
    測定値が低くなる。定期的に採水点と測定点で測定し、低い場合は配管を洗浄する。」

□ 13. 油検知器（油分検知法）の保守（p.616）：
   「採水方式であるため、サンプリング配管類に油が付着しないよう注意する。
    またセンサ取り扱い時は事前の手洗いなど作業環境に注意する。」

□ 14. リスク要因の分類（p.637）：
   「点検整備不良、劣化、誤操作等の『内的要因』と、自然災害（地震・雷）、ノイズ障害、
    電気事故、サイバー攻撃等の『外的要因』に大別される。」

□ 15. ノイズの受けやすさ（p.637）：
   「計装設備は微弱信号を取り扱う設備であるため、ノイズによる影響を受けやすい。」

□ 16. 接地の2大目的（p.637）：
   「計装システムの接地には、人身保護上の安全対策面からの接地と、
    システム保護・ノイズ対策のための接地がある。」

□ 17. デジタル計装の高周波電位上昇と接地（p.637）：
   「デジタル計装システムは使用周波数が高いため接地回路のインピーダンスが高くなり、
    ノイズ電流による電位の上昇も多くなる。したがって、システムを安定に動作させるための接地が必要である。」

□ 18. 重要インフラのセキュリティ対策（p.637）：
   「水道をはじめとする重要インフラ事業者の監視制御設備等は、サイバー攻撃を受ける可能性が
    否定できず、情報セキュリティ対策を必要とする。」

□ 19. 制御系と情報系ネットワークの完全分離（p.638）：
   「監視制御を行う制御系ネットワークと、インターネットにつながる情報系ネットワークは
```

## 8. 【問題作成用】試験最頻出ポイント総まとめ・論点整理

| :--- | :--- | :--- |
