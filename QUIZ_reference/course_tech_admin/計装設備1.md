## 1. 計装設備の基本概念と定義（テキスト p.575）

水道施設における計装設備は、取水・導水・浄水・送水・配水に至る広大な水道システムを安全かつ安定的に稼働させるための中枢神経系である。

```
【水道施設における計装設備の定義（★最重要・赤線箇所）】
「水道施設の計装設備は、水道施設を円滑（遠隔）に管理するためのもので、
 施設の運転や管理に必要な情報を迅速かつ的確に把握し、操作に反映させるための設備である。」
```

* **広義の「計装」の概念**:
  * 計装は単に物理量（流量・圧力・水質・水位等）を「計測」する設備にとどまらない。
  * 施設の「監視（モニタリング）」と「制御（コントロール）」を行うための設備であると同時に、得られた**情報を有効に活用するための技術全般を含んだ広い概念**を持つ。
* **遠隔監視制御の不可欠性**:
  * 取水場、浄水場、給水所、配水池、減圧弁室、管網末端に至る施設群をリアルタイムに統括管理するためには、計装設備（遠隔監視制御システム）が不可欠である。
  * 人員が常時各施設に張り付いて電話等で連絡を取り合う運用は現実的ではなく、計装設備なしに現代の水道施設の維持管理は成立しない。

## 2. 計装設備の目的と期待される効果（テキスト p.575）

### (1) 計装設備導入の目的（★赤線箇所）
> 「取水、導水、浄水、送水及び配水等の各施設の計測設備の自動化及び集中管理化を行うことによって、運転操作の容易性、確実性、安全性等を確保するとともに、適切な情報管理を通じて水道施設全体の運転管理や設備管理を効率化することである。」

### (2) 適切に配置・運用することにより期待される6大効果（★試験頻出）

| 番号 | 期待される効果 | 具体的内容・実務上の着眼点 |
| :---: | :--- | :--- |
| **①** | **水質、水量及び水圧等の品質管理の向上** | 水道水の「品質」とは**水質（残留塩素・濁度・pH等）**と**水圧（適正動水圧0.15〜0.74MPa）**である。プロセス全体を連続監視・自動制御することで品質の均一性と安定性を担保する。 |
| **②** | **運転の安定性及び安全性の確保** | 各施設の稼働状況をリアルタイムで把握し、合理的な自動制御（水位連動・圧力制御等）を行うことで、過負荷や機器トラブルを防止し、安定送配水を維持する。 |
| **③** | **薬品・動力等の適正使用による経済性の向上** | 原水水質（濁度・水温等）に応じた凝集剤（PAC）や次亜塩素酸ナトリウムの適正注入率制御、インバータ（VVVF）速度制御等による電力消費・薬品コストの削減（省エネルギー）。 |
| **④** | **水道施設全体の運転管理・設備管理機能の向上** | 計測データ・警報・稼働履歴を蓄積・一元管理し、処理プロセスの最適化、機器の劣化予兆把握、計画的修繕・更新判断に活用する。 |
| **⑤** | **異常時における迅速かつ適切な対応** | 原水水質急変（油流出・濁水流入）、管路破断、停電、機器故障等の異常発生時に、即座に警報を発報し、取水遮断弁閉止や予備機起動等の緊急処置を迅速に行う。 |
| **⑥** | **労働条件の向上（省力化・安全衛生）** | 現場での手動バルブ操作や夜間巡回監視業務を軽減し、遠隔集中監視化により運転員の身体的・精神的負荷を軽減し、作業安全性を向上させる。 |

## 3. 計装設備の構成と機能・高度化技術（テキスト p.575〜576）

### (1) 計装設備の構成4要素
計装設備は、以下の4つの機器群から構成される。
1. **計測機器（センサ・発信器・検出部）**: 流量計、圧力計、水位計、残留塩素計、濁度計、pH計、水温計、漏液センサ等。
2. **制御機器（調節部・演算部・操作部）**: プログラマブルロジックコントローラ（PLC）、調節計、電動弁・空気式アクチュエータ、インバータ等。
3. **通信機器（伝送路・ネットワーク）**: テレメータ装置、光伝送装置、メタル回線/専用回線モデム、産業用イーサネットスイッチ、無線装置等。
4. **情報処理装置（監視制御卓・サーバー）**: 監視制御PC/SCADA、中央処理装置（CPU）、ヒストリアンサーバー、大画面グラフィック表示盤、帳票プリンタ等。

```
【計装情報の流れ】
［検出］計測機器（流量・圧力・水質・設備状態）
  ↓ （4-20mA DC / パルス / フィールドバス通信）
［伝達］通信機器・テレメータ伝送
  ↓
［処理］情報処理装置・PLC（演算・トレンド・警報生成）
  ↓
［反映］操作端へ制御指令（バルブ開度調整・ポンプ変速・薬注量変更）
```

### (2) 制御技術の高度化（知識工学・AI）と人間の責任・役割
* **複合化・高度化の進展**:
  * 従来の単一ループPID制御から、計算機能力の向上に伴い、モデル予測制御、知識工学を応用した制御（エキスパートシステム）、AI（機械学習・深層学習）による運転支援へと技術が発展した。
  * 過去の水質変動データや天候予測に基づく「凝集剤注入率の自動予測」「次亜塩素酸ナトリウム注入予測」「配水量需要予測」などが実用化されている。
* **★実務上の最重要留意点（自動化の落とし穴と人間の主体性）**:
  * **AIや高度制御は「運転員の判断を支援するツール」に過ぎない。**
  * AIやエキスパートシステムは前例のない突発事象において誤認・誤判断を起こすリスクがある。水道水質事故や断水は市民の生命・健康に直結するため、**全ての判断をシステム任せにすることは極めて危険**である。
  * 運転員自身が水処理プロセスと計装システムの動作論理を熟知し、最終的な確認・判断・責任を人間が担保しなければならない。

### (3) 運転・保全におけるPDCA/CAPDサイクルの実践
* 監視制御システムから得られる運転状況データ、警報履歴、故障記録、修繕履歴を定期的に抽出し、統計分析を行う。
* 分析結果に基づき、**「機器の警報設定値・制御パラメータの見直し」「点検周期・作業計画の修正」「運転モードの改善」**を図るPDCA活動（または現状把握から入るCAPD活動）を継続することが不可欠である。
* **水運用センター等による広域管理**:
  * 大規模事業体（東京都水道局の水運用センター等）では、複数の浄水場、給水所、配水池の流量・圧力・水質データを一括集約し、水系間の相互融通や広域配水調整を行っている。

## 4. 運転管理の基本と留意事項（テキスト p.576, 578）

### (1) 運転管理の基本概念（★赤線箇所）
* **「計装設備を使用して対象施設を運転する」**:
  * 計装設備の運転とは、計装機器単体を動かすことではなく、**計装設備を操作手段として取水・浄水・送配水施設全体を運転すること**である。
  * 機器やソフトウェアの自動化レベルにより、運転管理の効率化・省力化に大きな差が生じる。
* **運転対象の特性理解**:
  * 運転員は計装設備の画面操作だけでなく、制御対象であるポンプの水力特性、薬品注入の反応時間、配水池の滞留時間、管路の圧力波伝播などの物理的・化学的特性を理解していなければならない。

### (2) 省力化（自動化）の限界と保安要員のミニマム基準
* 計装化・自動化の推進により、従来10名体制だった監視業務を8名・6名へと段階的に省力化することは可能である。
* しかし、**「24時間連続交代勤務の保安要員」としては、緊急時の対応やフェイルセーフの観点から最低2名（ミニマム要員）の配置が不可欠**であり、ゼロサム的に無制限に人員を減らすことはできない。

## 5. 保全管理の基本：ハードウェアとソフトウェアの特徴（テキスト p.576〜577）

計装設備は、一般の機械設備や電力設備（強電）とは全く異なる固有の特徴を持つ。保全管理にあたっては、ハードウェアとソフトウェアの特性を明確に峻別して理解する必要がある。

### (1) ハードウェアの特徴と保全上の課題（★試験最頻出）

| 特徴 | 具体的内容・劣化原因・実務対策 |
| :--- | :--- |
| **① 物理的寿命が短い** | * **強電設備（変圧器・遮断器等：20〜30年以上）に比べ、計装設備の寿命は著しく短い（7〜10年程度）。**<br>* 計装盤内の信号変換器、アイソレータ、電源ユニット、電子基板等に含まれる**電解コンデンサの容量抜け（液枯れ）**、半導体素子の経年劣化が主因。<br>* 検出器（水質センサ電極・隔膜）はさらに短寿命であり、1〜3年周期での部品・ユニット交換が必須。 |
| **② 技術の陳腐化が早い** | * マイコン、通信プロトコル、OS（Windows系等）、電子部品の世代交代サイクルが極めて早く、数年〜10年でメーカーの補修部品供給が停止（保守終了：EOL）する。<br>* プラント自体の寿命（30〜50年）に対し、計装システムは複数回の更新が必要となる。 |
| **③ 環境条件に極めて影響されやすい** | * **温度、湿度、粉塵、腐食性ガス（塩素ガス・硫化水素ガス等）**の影響を直に受ける。<br>* **【実務対策：スペースヒータ（盤内電熱器）】**: 屋外盤や温度差の激しい電気室・計装盤内では、外気温低下に伴う結露（水滴付着による基板短絡・絶縁不良）を防止するため、盤内を常時加温するスペースヒータを設置し運用する。 |
| **④ 比較的短い周期の保守・更新が必要** | * 故障してから直す事後保全では取水・送水の全面停止を招くため、予防保全（定期的な点検・基板交換）と、計画的なLCC（ライフサイクルコスト）に基づく更新が不可欠。 |
| **⑤ 委託化に伴う職員の技術力低下とブラックボックス化の防止** | * 点検・修繕の民間委託が進むと、職員の計装技術・トラブル対応力が低下しやすい。<br>* **【最重要】計装システムをメーカー・ベンダー任せの「ブラックボックス」にしてはならない。** 職員自身がシステム構成・信号ループ・論理回路を理解し、設計妥当性の評価や緊急時判断を行える技術力を維持・継承しなければならない。 |

### (2) ソフトウェアの特徴と保全上の課題（★試験最頻出）

| 特徴 | 具体的内容・トラブル実例・実務対策 |
| :--- | :--- |
| **① 変更・追加の頻度が多い** | * ハードウェアの改造を伴わずにプログラム変更だけで機能修正が容易にできる反面、安易な改変が頻繁に行われやすい。 |
| **② 潜在的バグ（障害）の長期内在** | * 稼働開始直後には顕在化せず、特定の稀な複合条件が偶発的に重なった際に突如バグが発現する。<br>* **【講義実例：配水池ポンプ制御フリーズ事件】**: 2箇所の配水池へ送水するポンプ制御において、極めて稀な同一コンマ数秒のタイミングで双方の水位が上限異常（HH）に達した際、ソフトウェアが競合して制御不能（フリーズ）に陥った。手動運転に即座に切り替えて断水を回避した。 |
| **③ わずかな設定ミスによる全所機能不全** | * パラメータ（ゲイン、時定数、上限リミット値）の数値1つの入力ミス、1ビットのフラグ設定漏れによって、システム全体が誤作動・停止することがある。PLC（ラダー図）の安易な現場改変はメーカー保証失効のリスクもある。 |
| **④ 担当者の専門化・特定化（属人化）** | * ソフトウェアに精通した特定職員・技術者に業務が集中し、システムの「ブラックボックス化」や「生き字引化」が生じやすい。手順書・仕様書のドキュメント化が必須。 |
| **⑤【最重要】システム更新時の旧ソフト・バックアップ保持義務** | * 監視制御ソフトやOSを新バージョンへ更新する際、**「旧バージョンのソフトウェアおよびバックアップデータ」を必ず確実に保管**しておくこと。<br>* 新ソフトに致命的な不具合が発生した際、即座に旧ソフトを再インストールして元通りの稼働状態に復元（ロールバック）できるようにしておかなければ、浄水場全体の運転停止に直結する。 |
| **⑥ 複雑化による完全把握の困難性** | * 大規模SCADAや分散制御システム（DCS）はコードが膨大であり、細部まで完全に把握することは困難。全体の制御思想、インターロック系統、主要機能を体系的に把握することが求められる。 |

## 6. 省エネルギーと水運用（テキスト p.577）

### (1) 水道事業における電力消費構造
* 水道事業は大量の電力を消費する典型的な**装置産業**である。
  * 例：東京都水道局の年間電力消費量は、**東京都全体の電力使用量の約1%**を占める巨大な電力需要家である。
* 消費電力の大半は**「水の輸送に伴うポンプ動力」**（取水ポンプ、導水ポンプ、送水ポンプ、配水圧送ポンプ）である。

### (2) 計装設備を活用した省エネ手法
1. **インバータ（VVVF）制御による回転速度可変運転**:
   * 配水圧・配水流量の需要変動に応じ、バルブ絞り制御からインバータによるポンプ回転速度制御へ移行することで、管路抵抗損失を激減させ大幅な省エネを実現する。
2. **需要予測に基づく配水池・ポンプ運用**:
   * 過去データと気象予測から時間ごとの需要量を予測し、ポンプの過剰揚程・過剰送水を防止。
3. **電力料金体系（夜間電力）を活用した水運用**:
   * 夜間の安価な電力時間帯に送配水ポンプを稼働させて配水池の水位を高水位まで揚水し、昼間の電力ピーク時間帯は自然流下給水やポンプ台数を抑制する（ピークカット・ピークシフト）。
4. **管網水圧・水運用の最適化**:
   * 同一配水ブロックに対して複数給水所から圧送する場合、各ルートの圧力損失を計装データから比較し、最もエネルギー効率の高い給水所から優先送水する。
5. **ポンプの最高効率点（BEP）を狙った台数制御**:
   * 1台の大容量ポンプを低効率領域で運転するよりも、適正容量の2台運転に切り替えるなど、Q-H特性上の最高効率点付近で稼働するよう台数制御を行う。

## 7. 情報提供と情報公開（テキスト p.577）

* **水質データ・水源状況のリアルタイム公開**:
  * 計装設備で計測された「給水栓水質（残留塩素、色度、濁度等）」「水源・ダム貯水状況」は、インターネット等を通じて需要家（市民）へ積極的に情報提供されている。
* **管網自動水質監視装置の配置**:
  * 東京都水道局等の実例では、都内各所の給水栓・配水管末端に**自動水質計器（自動水質監視装置）**を密に配置し、残留塩素（0.1mg/L以上確保の監視）、水圧、濁度、pH等を常時遠隔監視している。
* **定期水質検査結果の公開**:
  * 月1回以上の定期精密検査データ（51項目）の公表とあわせ、計装によるリアルタイム連続データが水道水の安全性・透明性の担保に寄与している。

## 8. 水道技術管理者の責務と留意事項（テキスト p.577〜578）

水道技術管理者は、計装設備の適切な管理・運用に関して以下の職務・責任を負う。

```
【水道技術管理者の責務体系】
┌── 責任：適切な状況判断に基づく明確な指揮命令、迅速な報告・連絡体制の確立
├── 役割：施設処理・運用状況を把握するためのデータ収集・分析・評価（水質・水圧の確保）
└── 性能確保：計装設備の機能を維持・向上させるための運転・保守の指導助言、職員教育
```

* **運転・保全データのフィードバック**:
  * 日々の運転ログ、故障警報の頻度、機器の修理履歴を分析し、「そろそろ予備部品の手配が必要か」「設備更新（リプレイス）の時期か」を客観的・計画的に判断する。
* **技術継承と職員の資質向上**:
  * 外部委託化が進む中でも、計装設備の構造・原理を職員が理解できるよう、教育訓練を計画的に実施する。

## 9. 実務的リスク管理と緊急時対応（テキスト p.578）

### (1) 運転管理部門と保全管理部門の緊密な連携
* 運転員（24時間交代勤務の監視員）と、保全管理部門（日勤の維持管理・修繕・設計担当）との情報共有が極めて重要。
* 「警報が頻発している」「ポンプの運転電流が同一吐出圧なのに以前より数アンペア高い」「微小な振動・異音がある」といった**初期の異常兆候を運転員が発見し、保全管理部門へ即座にフィードバックして事前措置を講じる体制**を構築する。
* **交代勤務員の現場点検（五感点検）への関与**:
  * 運転員が監視室の画面だけを見ている運用は不適切である。日勤時間帯等を利用して運転員も積極的に現場巡回・日常点検を行い、**「音、振動、熱、臭気」などの五感で設備の正常状態と異常の兆候を体感的に把握しておくこと**が不可欠である。

### (2) 運転マニュアルの整備と定期的な「図上訓練（机上演習）」
* **緊急時運転マニュアルの策定**:
  * 全所停電、受電系統故障、毒物・油流出、落雷によるテレメータ不通などの緊急時における運転手順書（マニュアル）を整備する。
* **停電時復電シーケンス（実務例）**:
  * 商用電源停電 $\rightarrow$ 非常用自家発電設備の自動起動 $\rightarrow$ 重要負荷への電源供給。
  * 薬品注入設備では、**「① 凝集剤（PAC）注入ポンプの優先立ち上げ」 $\rightarrow$ 「② 次亜塩素酸ナトリウム（消毒剤）注入ポンプの立ち上げ」 $\rightarrow$ ポンプの順次起動** といった明確な優先順位・復電シーケンスが定められていなければならない。
* **図上訓練の反復実施**:
  * マニュアルは策定して棚に保管しているだけでは「宝の持ち腐れ」となる。
  * 実際に全所停電や水質異常を頻繁に実地試験することは困難であるため、**定期的にシナリオを想定した「図上訓練（机上演習）」を行い、全員で手順を確認・検証すること**が事故防止の決定打となる。

### (3) 運転データの定量分析と予防保全
* ポンプ運転を例とすると、**「流量（Q）」「揚程・水圧（H）」「電動機電流」「電圧」「力率」**の相関関係を平時から把握しておく。
* 「同一水圧条件下で電流値が定常時より上昇している」場合、羽根車への異物噛み込み、軸受ベアリングの摩耗、芯狂い（ミスアライメント）などの機械的異常が発生している可能性を早期に特定できる。

## 10. 【問題作成用】試験最頻出ポイント総まとめ・論点整理

計装設備分野における4択問題・正誤判定問題作成のための重要キーワードと論点対比表：

| 分野・論点 | 正しい記述（正肢のポイント） | 誤りとして出題されやすい引っかけパターン |
| :--- | :--- | :--- |
| **計装設備の定義** | 水道施設を円滑・遠隔に管理し、運転管理に必要な情報を迅速・的確に把握して**操作に反映させる**ための設備。 | 「単に流量や水圧を計測・記録するだけの設備である」（×：監視・制御・情報活用を含む） |
| **自動化と人間の役割** | AIやエキスパートシステムは**運転員の判断を支援するツール**であり、最終確認・判断・責任は人間が負う。 | 「高度なAIを導入すれば、運転員の介入や知識習得は一切不要となり全自動化できる」（×：過信は禁物） |
| **運転監視要員** | 計装化により省力化は進むが、交代要員を含め**最低2名（ミニマム）の保安要員が必要**である。 | 「完全自動化された浄水場では監視員を0名（完全無人）にできる」（×：保安・緊急時のミニマム基準が存在） |
| **ハードウェア寿命** | 強電（電力）設備の20〜30年に比べ、**計装設備は物理的寿命が短く（7〜10年程度）、陳腐化も早い**。 | 「計装機器は可動部が少ないため、受変電設備やポンプよりも物理的寿命が長い」（×：電子部品・コンデンサ等で短い） |
| **盤内環境対策** | 温度差による結露を防止するため、盤内を加温する**スペースヒータ**を設置・運用する。 | 「盤内の電子機器を冷却するため、冬季でも強力な換気ファンで外気を取り入れ冷やし続ける」（×：結露の原因となる） |
| **システムの管理責任** | 委託化が進んでも**ブラックボックス化を防ぎ**、職員自らシステム構成・論理を把握しておく必要がある。 | 「システムの保守・更新は専門ベンダーに全て一任し、職員は詳細を理解する必要はない」（×：ベンダー依存の弊害） |
| **ソフトウェア更新** | 新バージョン導入時は、障害発生時に備えて**「旧バージョンのソフト・バックアップ」を必ず保持**する。 | 「新ソフトを導入した際は、容量削減のため旧バージョンのプログラムは即座に完全消去する」（×：元に戻せなくなる） |
| **省エネルギー対策** | 水道事業の消費電力の大半は**「水輸送（ポンプ動力）」**であり、インバータ変速や夜間電力シフトが有効。 | 「水道事業の電力消費の大半は管理棟の照明や計装機器自体であり、ポンプ動力は一部に過ぎない」（×：大半がポンプ） |
| **緊急時マニュアル** | マニュアル作成にとどまらず、定期的な**図上訓練（机上演習）**を実施して手順を習熟することが不可欠。 | 「マニュアルさえ詳細に策定しておけば、定期的な訓練や検証は省略してよい」（×：宝の持ち腐れとなる） |
| **現場点検（五感点検）** | 運転員は監視室の画面監視だけでなく、日勤時等に現場を巡視し**五感（音・振動・熱・臭気）による点検**を行う。 | 「計装設備が完備されていれば、監視室から出ることなく現場点検は全て不要である」（×：五感による予兆把握が必須） |
