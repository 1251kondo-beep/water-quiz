## 1. 継手の構造と耐震化（テキスト p.285）

水道管路における最大の弱点は「管と管のつなぎ目（継手：ジョイント）」にある。地震時の地盤変位や地盤沈下に耐えうる継手構造の進化が、水道システムの強靭化を支えている。

### (1) メカニカル継手（K形）の構造と課題

耐震継手が登場する前の高度経済成長期から広く普及したのが、メカニカル継手の代表格である「K形継手」である。

```
【K形継手の構造（非耐震継手）】
         受口 (Socket)
      ┌─────────────┐
      │  ┌───────┐  │
 ─────┘  │ゴム輪 │  └─── 挿し口 (Spigot)
    ─────┤(圧縮) ├───────
         │       │
      ┌──┴───────┴──┐
      │ 押輪 (Gland) │ ◄── ボルト・ナットで締め付け
      └─────────────┘
  ※管の固定は「ゴム輪の摩擦・圧着力のみ」に依存！
  ➔ 地震の強い引張力（引き抜け方向の力）が作用すると容易にすっぽ抜ける（離脱）。
```

* **構造と止水機構**:
  * 管の受口に挿し口を挿入し、その隙間にゴム輪（ガスケット）を配置。外側から「押輪（おしわ）」を当ててボルト・ナットで均等に締め付ける。
  * ボルトの締付力でゴム輪が強く押し潰され、その弾性反発力で水密性（止水）を保持する。
* **致命的課題（引き抜けに対する脆弱性）**:
  * 管同士の緊結はボルトとゴム輪の「摩擦力」のみに頼っているため、**地震時の引張力（引き抜け方向の力）に対して機械的な抵抗力を持たない**。
  * 地盤の永久変位や液状化、側方流動が起きると、継手部が容易に抜け出して大漏水・断水を招く。
* **現在の更新実務**:
  * 現在、東京都水道局をはじめ全国の水道事業体で進められている管路更新の多くは、管材自体は頑丈なダクタイル鋳鉄管であっても、**継手が非耐震のK形である管路を最新の「耐震継手管」へと入れ替える作業** が中心となっている。

### (2) 耐震継手（NS形・GX形）の構造と特長

地震による地盤変動（引張り・圧縮・曲げ）を吸収し、絶対に抜け出さない構造として開発されたのが「耐震継手」である。

```
【耐震継手（NS形・GX形）の離脱防止メカニズム】
           受口 (Socket)
        ┌───────┬─────┐
        │       │ロック│
        │ゴム輪 │リング│ ◄── 内周部にリング内蔵
   ─────┘(止水) └──┬──┘
      ─────────────┼───┐
                   │突部│ 挿し口 (Spigot)
                   │(ビード)
   ────────────────┴───┘
   ※地震で管が引き抜かれそうになると、挿し口外周の「突部」が
     受口内の「ロックリング」にガチッと噛み合い、それ以上の抜け出しを完全阻止！
```

#### ① 離脱防止のメカニズム（ロックリング機構）
* 受口の内周溝に「ロックリング」が組み込まれており、挿し口の外周部には「突部（ビード）」が設けられている。
* 通常時は伸縮余裕を保っているが、地震時に管が引き抜かれそうになると、**挿し口の突部が受口内のロックリングにガチッと機械的に噛み合う** ため、管の抜け出し（離脱）を物理的に阻止する。

#### ② 伸縮性と可とう性（3大耐震性能）
単に抜けないだけでなく、地盤の動きに追従して伸び縮み・屈曲する性能を備えている。

| 耐震性能項目 | 性能基準値 | 実務上の意味・効果 |
| :--- | :--- | :--- |
| **伸縮量（S）** | 管長の **概ね $\pm 1\%$**<br>（$4\,\text{m}$管で **$\pm 4\,\text{cm}$**、$6\,\text{m}$管で **$\pm 6\,\text{cm}$** 程度） | 地盤の引張り・圧縮変位を継手部で伸縮して吸収。 |
| **屈曲角（可とう角：$\theta$）** | **$3^\circ \sim 4^\circ$ 程度** | 不等沈下や曲げ変形に対して継手部が柔軟に屈曲。 |
| **離脱防止力（P）** | **$3D\,\text{kN}$**（$D$ は呼び径 $\text{mm}$） | 口径 $100\,\text{mm}$ で **$300\,\text{kN}$**（乗用車約30台をぶら下げても抜けない強度）。 |

#### ③ 施工性の飛躍的進化（NS形からGX形へ）
* **NS形**:
  * 現場でゴム輪を装着し、押輪をセットして外側からボルトを全周締め付ける必要があった。
* **GX形（現在の主流：呼び径 $\phi 75 \sim \phi 450\,\text{mm}$）**:
  * 工場出荷時にロックリングやゴム輪ホルダーがあらかじめ受口内に組み込まれた（内蔵された）**「プッシュオン（押し込み）タイプ」**。
  * 現場ではボルト締め作業が不要となり、管を所定位置までジャッキ等で押し込むだけで接合が完了するため、**施工速度が大幅に向上し、狭小な掘削溝内での作業安全性も飛躍的に改善** された。外面には高耐食性塗装＋亜鉛合金溶射が施されている。

### (3) 他管種の耐震接合方式

* **鋼管（SP）**:
  * 開先（かいさき）をとって管同士を現場溶接（内面または外面溶接）し、**完全一体化管路** を形成する。引張強度・靭性が極めて高く、大口径幹線や水管橋で無類の耐震性を発揮する。
* **水道用配水ポリエチレン管（PE管）**:
  * 電熱線を内蔵した「EF（エレクトロフュージョン）継手」を用い、電気を通して母材樹脂を熱融着させる。**材料同士が分子レベルで完全一体化** するため、継手の抜け出しの概念がなく、管全体の高い柔軟性と相まって抜群の耐震性を誇る。

## 2. 管路の耐震設計基準と地震被害の実績

### (1) 耐震性能の要求水準（レベル1・レベル2地震動）

水道施設の耐震設計指針に基づき、管路の重要度に応じて想定地震動に対する要求性能が区分されている。

```
【耐震設計における2段階の地震動と要求性能】
・レベル1地震動 ── 供用期間中に発生確率が高い地震動（震度5弱〜5強程度）
                   ➔ 幹線・支管ともに「機能を損なわず、軽微な被害にとどめる」
・レベル2地震動 ── 想定し得る最大規模の極めて強い地震動（震度6強〜7程度）
                   ➔ 基幹管路：致命的被害を回避し、速やかに機能回復
                   ➔ 配水支管：二次災害を防止し、早期復旧が可能な構造
```

| 地震動区分 | 想定規模と発生確率 | 基幹管路（導水・送水・配水本管）の要求水準 | 配水支管の要求水準 |
| :--- | :--- | :--- | :--- |
| **レベル1地震動** | 施設の供用期間中に発生する確率が高い（震度5弱〜5強程度）。 | **機能を損なわない**（被害は軽微にとどまる）。 | **機能を損なわない**（通水機能を常時維持）。 |
| **レベル2地震動** | 発生確率は低いが、想定し得る最大規模の地震動（震度6強〜震度7程度）。 | **致命的な影響を及ぼさず、速やかに機能回復できる構造**（被害を最小限に抑制）。 | 一定の被害は許容しつつも、**二次災害を防止し、早期復旧が可能な構造**。 |

---

### (2) 「耐震適合性」の定義と分類

水道統計や耐震適合率の算定において、「耐震管」または「耐震適合性あり」とみなされる管種は以下の通り整理される。

1. **本来の耐震管（耐震継手管等）**:
   * 耐震継手を有するダクタイル鋳鉄管（NS形、GX形、S形、SⅡ形等）。
   * 溶接接合鋼管。
   * 熱融着接合（EF接合）ポリエチレン管。
2. **条件付きで「耐震適合性あり」とされる管**:
   * 地盤が極めて良好（硬質地盤・岩盤等）な場所に布設されたメカニカル継手管（K形・T形ダクタイル鋳鉄管）。
   * 受口の差し込み長が十分に長い「ロング受口（RR受口）」構造の硬質塩化ビニル管など。

### (3) 近年の大規模震災における被害実績（耐震管の圧倒的有効性）

#### ① 東日本大震災（2011年）の実績
* 非耐震のK形継手管や経年老朽管では、地盤沈下や液状化により継手の抜け出しや管体折損が多発し、広範囲で断水が発生した。
* 一方、**NS形耐震継手管は、津波で周囲の土砂が流失して管路が完全に宙吊り・露出した現場や道路崩壊現場でも、管同士が鎖（チェーン）のように強固に繋がり、抜け出し・漏水被害は実質ゼロ（被害率 0件/km）** であった。

#### ② 令和6年能登半島地震（2024年）の実績
* 震度7を記録した奥能登（輪島市・珠洲市）では、道路・斜面崩壊により管路被害率が **$1.5 \sim 1.6\,\text{箇所/km}$** という極めて甚大な被害を記録した。
  * （※参考：東日本大震災の東北太平洋沿岸部 $0.2 \sim 0.3\,\text{箇所/km}$、阪神・淡路大震災の芦屋市周辺 約 $1.96\,\text{箇所/km}$）。
* **被害が集中した管種・設備**:
  1. 旧式の普通鋳鉄管（CIP）および非耐震ダクタイル鋳鉄管（K形等）。
  2. 接着接合の旧規格硬質ポリ塩化ビニル管（VP管）。
  3. **給水管引込部の鉛管（LP）**: 加工性が良いため過去に広く使われたが、地震時の引張りに耐えられず破断被害が突出。微量鉛溶出リスクも含め早期根絶が必須。
* **耐震継手管の被害実績**:
  * 激甚な地盤変動の中でも、**耐震継手管の被害率はわずか「$0.009\,\text{箇所/km}$」** にとどまり、非耐震管と比較して圧倒的な耐震安全性が現場で実証された。

## 3. 管径・動水圧・流速の設計（テキスト p.285〜286）

### (1) 管径決定と水理計算（ヘーゼン・ウィリアムスの式）

管径は、計画時間最大配水量を通水した際に、給水区域のすべての末端で必要な動水圧を確保できるように水理計算を行って決定する。

* **自然流下の場合**:
  * 起点と終点の「有効落差（利用可能な動水勾配）」と最大計画水量から、所要の内径（断面積）を算定する。
* **ポンプ圧送の場合（経済的管径の選定）**:
  * **管径を太くした場合**: 摩擦損失水頭が小さくなり、ポンプ動力費（電気代ランニングコスト）は低減するが、初期建設費（管材費・掘削費）が高騰する。
  * **管径を細くした場合**: 初期建設費は安く抑えられるが、管内流速と摩擦損失が増大し、毎月のポンプ電気代が跳ね上がる。
  * したがって、**建設費（減価償却費）と維持管理費（動力費）のライフサイクルコスト合計が最小となる「経済的管径（経済流速 $1.0 \sim 1.5\,\text{m/s}$ 程度）」** を選定する。

#### 【重要】ヘーゼン・ウィリアムス式における流速係数（$C$値）の実務運用
* 圧力管の水理計算には、ヘーゼン・ウィリアムス（Hazen-Williams）公式が標準的に用いられる。
* 公式内の **流速係数（$C$値）** は、管内面の滑らかさ（流れやすさ）を示す値である。
  * 新設の直線管路では理論上 $C = 130$、屈曲部が多い路線では $C = 110$ 等が用いられる。
* **設計実務（東京都水道局等）の標準ルール**:
  * 将来の経年劣化（管内面の微少な付着物等）や、路線のベンド（曲がり管）・弁類の形状損失を安全側に見込み、**路線全体を一律「$C = 110$」として水理計算を実施する** のが実務上の確固たる標準である。

### (2) 配水管の動水圧基準（水道施設の技術的基準省令）

水道水が蛇口から勢いよく出るためには、配水管網内に適切な圧力が維持されていなければならない。

```
【配水管の動水圧基準まとめ】
・最低動水圧 ────── 0.15 MPa 以上（技術基準省令：2階直結可能）
・東京都実務目標 ── 0.20 MPa 程度（3階建て直結給水を安定確保）
・火災時最低動水圧 ── 0.10 MPa 以上（消火栓大量放水時の管内負圧防止）
・最大動水圧 ────── 0.74 MPa 以下（器具破損・漏水増大・水撃圧防止）
```

| 動水圧区分 | 規定圧力値 | 技術的根拠・目的 |
| :--- | :--- | :--- |
| **最低動水圧** | **$0.15\,\text{MPa}$ 以上**（$150\,\text{kPa}$） | ・水道施設の技術的基準省令に定められた絶対下限基準。<br>・直結直圧式で **一般的な2階建て住宅まで安定給水可能** な水圧（水頭換算で約 $15\,\text{m}$）。 |
| **東京都実務目標** | **概ね $0.20\,\text{MPa}$ 程度**（$200\,\text{kPa}$） | ・近年の都市住宅事情（3階建て戸建て住宅の普及）に対応し、**3階建てまで直結直圧給水** を可能とするための独自運用基準。 |
| **火災時最低動水圧** | **$0.10\,\text{MPa}$ 以上**（$100\,\text{kPa}$） | ・消防ポンプ車が消火栓から大流量を急激に吸水した際にも、**管内が負圧（大気圧未満）になるのを防止** する。<br>・管内が負圧になると管継手の隙間から外部の汚水や泥水を吸い込む（逆汚染）危険があるため。 |
| **最大動水圧** | **$0.74\,\text{MPa}$ 以下**（$740\,\text{kPa}$） | ・過大な水圧による給水用具（給湯器・バルブ等）の破損防止。<br>・管路の漏水量増大の抑制およびウォーターハンマー（水撃圧）による管体破断防止。 |

### (3) 給水方式の分類と近年の動向

```
【主な給水方式の比較】
① 直結直圧式 ──── 配水管水圧のみで直結（2〜3階まで）
② 直結増圧式 ──── 増圧ブースターポンプで直結（中高層10〜15階まで急拡大）
③ 受水槽方式 ──── 地下受水槽に貯水後、ポンプアップ（適正清掃・点検が必須）
```

1. **直結直圧式**: 配水管の残留動水圧のみを利用して直接蛇口まで給水する。通常の2〜3階建てに適用。
2. **直結増圧式（近年の主流）**:
   * 給水引き込み管に逆流防止機能付きの「増圧ポンプ（ブースターポンプ）」を直列に設置し、中高層階（概ね10〜15階程度、高さ約 $40 \sim 50\,\text{m}$）まで直送給水する方式。
   * **メリット**: 受水槽が不要なため、**「水質が常に新鮮で衛生的」「受水槽設置スペースが不要」「毎年の水槽清掃・点検コストが不要」**。現在、都市部のマンション・ビルで急速に受水槽方式からの切り替えが進んでいる。
3. **受水槽方式（高置水槽方式・加圧給水方式）**:
   * 一度受水槽に水を貯めてから給水する。大規模病院や工場など、万一の断水時にも水確保が必須な施設に適用。水槽の衛生管理（水道法に基づく簡易専用水道等の定期検査）が受水槽設置者に義務付けられている。

## 4. 管路の布設条件とスラスト力対策（テキスト p.286）

### (1) 埋設深さ（土被り）

道路法および道路占用基準に基づき、道路交通荷重（大型トラックの輪荷重等）から管路を保護するため、路面から管頂までの深さ（土被り：どかぶり）が厳格に規定されている。

* **標準土被り**: **$1.2\,\text{m}$（$120\,\text{cm}$）以上**
  * 幹線道路・一般道路を問わず、大型車両の衝撃荷重から管を守るための基本基準。
* **浅層埋設の緩和基準**: **最低 $0.6\,\text{m}$（$60\,\text{cm}$）まで緩和可能**
  * 道路下に下水道管、ガス管、電力線、通信管などの他企業埋設物が極度に輻輳しており、標準の $1.2\,\text{m}$ が確保できない場合、道路管理者との協議により浅層埋設が認められる。
  * **メリット**: 掘削土量および残土処分費の低減、工期の大幅短縮、工事費の縮減。

#### 【重要】他企業地下埋設物との離隔
* 他企業管（ガス管、下水道管、高圧電力ケーブル、通信ケーブル等）と交差または平行して布設する場合、保安および将来の修繕作業スペースを確保するため、**原則として「最低 $30 \sim 50\,\text{cm}$ 程度」の離隔** を確保しなければならない。

### (2) 曲管部・分岐部のスラスト力（不平均力）対策

有圧管路内を流れる水には内圧が作用しているため、直線部では対向する面同士で圧力が相殺されるが、**「方向が変わる箇所」や「流れが遮断される箇所」では、外側へ向かう巨大な不平衡力（スラスト力）** が発生する。

```
【スラスト力（不平均力）の発生メカニズムと防護】
                水流 ──→
           ┌───────────┐
           │           │
           │     ┌─────┘
           │     │
  スラスト力│     │   曲管部（ベンド管）において、水圧と
     (F)   │     │   流動の運動量変化により、管を外側へ
     ⇦ ⇦  │     │   押し出そうとする巨大な力が発生！
  ┌────────┴─────┴────────┐
  │ コンクリートスラストブロック │ ◄── 背後の硬質地盤で力を支持
  └────────────────────────┘
```

#### ① スラスト力が発生する3大箇所
1. **曲管部（ベンド管）**: 水流の方向が曲げられる箇所。
2. **分岐部（T字管・三方管）**: 水流が直角に分岐する箇所。
3. **管末部・仕切弁閉止部**: 盲フランジやバルブを閉め切って水流を受け止める箇所。

#### ② スラスト対策（離脱・抜け出し事故の防止）
* メカニカル継手管などの非耐震管では、スラスト力によって継手部が外れて管が抜け出し、大規模な噴水事故・陥没事故を引き起こす。
* **対策1（スラストブロック）**:
  * 曲管やT字管の外側に **「コンクリート防護ブロック（スラストブロック）」** を打設し、背後の安定した地盤の受働土圧によってスラスト力を支える。
* **対策2（耐震継手の採用）**:
  * ロックリングを有する耐震継手（GX形・NS形）を採用すれば、継手自体の離脱防止力（$3D\,\text{kN}$）によってスラスト力に抵抗できるため、スラストブロックの小型化または省略が可能となる。
* **露出掘削時の仮防護（実務上の盲点）**:
  * 既設管の周囲を工事で露出掘削すると、これまで管を支えていた周囲の土圧（拘束力）が失われる。その状態で管内に水圧がかかるとスラスト力で継手が抜け出す危険があるため、**必ずH鋼やサポート材で管を固定・仮防護** しなければならない。

## 5. バルブ類の機能と構造（テキスト p.287〜288）

配水管網における弁類（バルブ）は、水の流れを止めるだけでなく、圧力の調整、空気の排出、災害時の飲料水確保など多面的な役割を担う。

### (1) 主な弁類の種類と特徴

```
【配水管路の3大バルブ】
① 仕切弁（ゲート弁） ── 流路を昇降。全開時圧損小。ソフトシール弁が現代の主流。
② バタフライ弁 ───── 弁体が90度回転。面間短くコンパクト。大口径管の主流。
③ 空気弁 ───────── 管頂部に配置。排気および負圧時の外気吸入（座屈防止）。
```

| 弁種名称 | 構造メカニズム | 長所・特徴 | 留意点・課題 |
| :--- | :--- | :--- | :--- |
| **仕切弁**<br>（ゲート弁） | 円板状の弁体が流路に対して直角に昇降して開閉する。 | ・全開時に管路断面を妨げず、**圧力損失が極めて小さい**。 | ・中間開度での流量調整には適さない（弁体の振動・摩耗）。 |
| └ **JIS弁**<br>（メタルシート） | 弁座部が金属同士で接触して止水する。 | （過去の標準仕様） | ・**下部の溝に砂や小石、錆が噛み込むと全閉しない**。<br>・操作トルクが重く、開閉時に濁水が出やすい。 |
| └ **ソフトシール弁**<br>（ゴムシート） | **弁体全体がゴムでライニング** されており、下部に溝がない **フラット底面構造**。 | ・異物を噛み込んでもゴムの弾性で **確実に完全止水**。<br>・溝がないため濁水が発生しにくく、**操作トルクが非常に軽い（現在の主流）**。 | ・高温水や特殊溶剤への耐性には選定注意。 |
| **バタフライ弁** | 円盤状の弁体が管路内で **90度回転** して開閉する（蝶の羽の動作）。 | ・面間寸法（バルブの長さ）が極めて短く、**軽量・コンパクト**。<br>・**大口径管（$\phi 400\,\text{mm}$以上）の遮断弁および流量制御弁** として多用。 | ・全開時でも弁体が流路中央に残るため、仕切弁に比べわずかに圧損がある。 |
| **コーン弁** | 円錐状の弁体が回転する構造。 | ・**高圧・大流量の流量制御および減圧調整** に優れる。 | ・構造が複雑で高価。 |

---

### (2) 緊急遮断弁（震災時の配水池水源保護システム）

配水池の流出口（配水管の最上流部）に設置される、水道システムで最も重要な安全装置である。

```
【緊急遮断弁の作動フロー】
[配水池] (満水：貴重な飲料水)
   │
   ▼
[緊急遮断弁] ◄── ① 感震器（震度5強以上）または
   │               ② 下流管路破断による「異常大流量」を検知！
   │               ➔ 自動で急速全閉！！
   ▼
[市街地配水管網]（地震で水道管が破断・噴水していても…）
   ➔ 配水池内の水は一滴も流出せず、満水状態で確実にプールされる！
   ➔ 避難所や地域住民への「応急給水用水」として100%確保される。
```

* **設置目的**:
  * 大地震発生時、下流の市街地で配水管や給水管が多数破断すると、配水池から水が一気に噴出し、数時間で配水池が空（枯渇）になってしまう。
  * これを防ぐため、**地震発生直後に自動で弁を閉鎖し、配水池内の飲料水を確実に温存・確保** する。
* **能登半島地震の教訓**:
  * 緊急遮断弁が正常に作動した配水池では、管路が壊滅した市街地にあっても配水池内に十分な水が残り、直後からの給水車による応急給水活動を迅速に支えることができた。

### (3) 弁室と弁筐の構造と使い分け

口径の大きさや重要度に応じて、設置方式が異なる。

```
【弁室（大型管）と弁筐（中小型管）の対比】
・弁室（バルブ室）：φ400mm以上の配水本管 ➔ RC製の地下室（人が入れる）
・弁筐（バルブボックス）：φ350mm以下の配水支管 ➔ 道路上の小型鉄蓋（地表から開栓器で操作）
```

#### ① 弁室（バルブ室）
* **適用対象**: 一般に **口径 $\phi 400\,\text{mm}$ 以上の配水本管・送水管**。
* **構造**: 作業員が内部に入って点検・補修・パッキン交換ができる鉄筋コンクリート（RC）構造の地下室。
* **副管（バイパス管）の併設**:
  * 口径 $400\,\text{mm}$ 以上の大口径弁は水圧差が大きく、人力や小型電動機では弁体を動かせない（トルクが重すぎる）。
  * そのため、本弁の脇に **口径 $\phi 100 \sim 150\,\text{mm}$ 程度の仕切弁を備えた「副管（バイパス管）」** を併設する。
  * **副管の機能**: ① 副管を先に開けて下流側に水を送り、本弁前後の水圧差を均等にして本弁開閉を軽くする、② 新設管充水時の微量通水・圧力調整。
* **水抜き設備**: 弁室底版には湧水や雨水を抜く水抜き管を設置する（※外水位が高い場合は逆流防止弁を設けるか設置しない）。

#### ② 弁筐（バルブボックス）
* **適用対象**: **口径 $\phi 350\,\text{mm}$ 以下の配水支管**。
* **構造**: 道路表面に小型の鉄蓋（円形または角形）を設けるのみ。作業員は入れないため、地上から **「開栓器（T字レンチ）」** を弁棒の先端（キャップ）に差し込み、手動で回転させて開閉操作を行う。

---

### (4) 配水管網における弁の配置基準

事故や工事に伴う断水・濁水被害を最小限に抑えるため、以下の基準で弁を配置する。

1. **配水本管からの取出し部**: 配水本管から配水支管が分岐する箇所には、必ず仕切弁（取出し弁）を配置する。
2. **交差部・分岐部**: 管網の交差点や分岐部の各枝線に配置し、任意のブロックを単独で遮断できるようにする。
3. **重要横断部の前後**: **河川横断（水管橋）、鉄道横断、幹線道路横断** の前後には必ず弁を配置し、横断部での漏水事故時に即座に両側を閉塞できるようにする。
4. **幹線管路の配置間隔**: 導水管・送水管・配水本管などの基幹管路では、事故時の復旧区間を限定するため、**概ね $1 \sim 3\,\text{km}$ 程度の間隔** で仕切弁を配置する。

---

### (5) 空気弁の機能と配置基準（テキスト p.288）

管路内の円滑な通水と管体の安全を守るため、空気弁の適正配置が不可欠である。

* **作動メカニズム（急速空気弁・複合空気弁）**:
  * 内部に中空の「フロート（浮子）」が内蔵されている。
  * **排気作用**: 通水時や水に溶存する空気が集まってくると、フロートが下がって排気孔が開き、空気を外部へ自動排出する。水が満ちるとフロートが浮上して排気孔を塞ぎ、止水する。
  * **吸気作用（最重要）**: 管路の破断事故や急激な排水により **管内が負圧（真空状態）になった瞬間、フロートが急降下して外気を大量に吸入** する。
* **吸気作用がない場合の大事故**:
  * 大口径薄肉鋼管等では、負圧により大気圧に押し潰される **「管の座屈（圧潰）事故」** が発生する。また、継手隙間からの汚水吸い込み事故を招く。
* **配置場所（出題ポイント）**:
  * 管路の縦断勾配において **最も高い位置（頂部・山部）**。
  * **水管橋の中間頂部**。
  * 平坦地であっても、概ね $500 \sim 1{,}000\,\text{m}$ 間隔で設置する。

## 7. 【想定問題集（ドリル実装用プロトタイプ問題）】

『問題作成ガイドライン.md』の基準に完全準拠した、即時実装可能なプロトタイプ設問セットです。

### 設問1（4択：耐震継手構造）
* **問題形式**: `choice`
* **問題文**: ダクタイル鋳鉄管の耐震継手（NS形・GX形）が地震時の引き抜けを防止するメカニズムとして、最も適切なものはどれですか？
* **選択肢**:
  1. 挿し口の突部が受口内のロックリングに機械的に噛み合うことで阻止する
  2. 押輪のボルトを最大トルクで締め付けることでゴム輪の摩擦力を高める
  3. 受口と挿し口の隙間に高強度エポキシ樹脂を注入して完全硬化固着させる
  4. 管の継手部外周に高張力炭素繊維シートを幾重にも巻き付けて一体化する
* **正解**: 1（インデックス: 0）
* **解説**: 耐震継手は、挿し口外周に設けられた「突部（ビード）」が受口内に組み込まれた「ロックリング」に機械的に噛み合うことで、地震時の大きな引張力に対しても管の抜け出しを確実に阻止します。ボルトとゴム輪の摩擦力のみに頼っていたのが旧式のK形継手です。
* **日常のたとえ**: 登山用ザイルのカラビナやシートベルトと同じで、通常時は自由に動きますが、強い引張力がかかった瞬間に金属フック（突部とリング）がガチッと噛み合って離脱を完全にロックする安全機構です。
* **出典**: 講義テキスト 導送配水施設 p.285

### 設問2（4択：重要数値・動水圧基準）
* **問題形式**: `choice`
* **問題文**: 水道施設の技術的基準省令で定められている配水管の動水圧の最低基準値として、最も適切なものはどれですか？
* **選択肢**:
  1. 0.15MPa以上
  2. 0.05MPa以上
  3. 0.30MPa以上
  4. 0.74MPa以上
* **正解**: 1（インデックス: 0）
* **解説**: 水道施設の技術的基準を定める省令において、配水管の末端等の動水圧は原則として「0.15MPa（150kPa）以上」を確保することが義務付けられています。これは直結直圧式で2階建て住宅まで安定して給水できる圧力です。なお最大動水圧は0.74MPa以下と規定されています。
* **出典**: 講義テキスト 導送配水施設 p.285〜286

### 設問3（4択・否定形：水理・構造基準）
* **問題形式**: `choice`
* **問題文**: 配水管路の埋設基準および水圧管理に関する記述として、**誤っているもの**はどれですか？
* **選択肢**:
  1. 火災時に消火栓から放水する場合でも配水管の動水圧は最低0.15MPa以上を保持する
  2. 道路下における水道管の標準土被りは交通荷重から管を保護するため1.2m以上とする
  3. 地下埋設物が輻輳している場所では道路管理者との協議により土被りを0.6mまで緩和できる
  4. 路線水理計算では経年劣化や屈曲部を見込みヘーゼン公式の流速係数を一律C=110とする
* **正解**: 1（インデックス: 0）
* **解説**: 火災時（消火栓使用時）の最低動水圧基準は「0.10MPa以上」です。これは消防ポンプ車が大量放水した際に管内が負圧（大気圧未満）になり、管外の汚水や泥水を吸い込むのを防止するための特別基準です。平常時の最低動水圧（0.15MPa以上）とは異なります。
* **出典**: 講義テキスト 導送配水施設 p.286

### 設問4（4択：スラスト力対策）
* **問題形式**: `choice`
* **問題文**: 有圧管路の曲管部や分岐部において発生するスラスト力（不平均力）への対策として、最も適切なものはどれですか？
* **選択肢**:
  1. 曲管部等の外側にコンクリートスラストブロックを打設し背後地盤で支持する
  2. 水流の衝撃を緩和するため曲管部の直前に減圧弁を設置して水圧をゼロにする
  3. 曲管部の内周側にゴム製の伸縮継手を挿入して水流の遠心力を吸収させる
  4. 露出掘削時にはスラスト力が消滅するため防護工をすべて撤去して施工する
* **正解**: 1（インデックス: 0）
* **解説**: 曲管部や分岐部では水圧と流動の運動量変化により管を外側へ押し出そうとするスラスト力が発生します。抜け出しを防ぐため、コンクリート防護ブロック（スラストブロック）を打設して背後地盤で支えるか、離脱防止性能を持つ耐震継手を採用します。露出掘削時は周囲の土圧拘束がなくなるため、むしろ厳重な仮防護が必要です。
* **日常のたとえ**: 消防ホースで放水する際にホースの曲がり角が外側へ激しく跳ね飛ばされそうになるのと同じ力であり、後ろからガッチリと壁（コンクリートブロック）で押さえつけて支える必要があります。
* **出典**: 講義テキスト 導送配水施設 p.286

### 設問5（4択：バルブ機能・安全対策）
* **問題形式**: `choice`
* **問題文**: 配水池の流出口等に設置される「緊急遮断弁」の主たる設置目的として、最も適切なものはどれですか？
* **選択肢**:
  1. 大地震時に市街地の管路破損による配水池内飲料水の流出枯渇を防止するため
  2. 浄水場からの送水量が急増した際に配水池からの溢水を防止するため
  3. 夜間の低需要時間帯に配水管内の動水圧が異常上昇するのを防止するため
  4. 水道料金を長期滞納している給水区域全体への給水を遠隔で一斉遮断するため
* **正解**: 1（インデックス: 0）
* **解説**: 緊急遮断弁は、地震動（震度5強以上等）や下流管路破断による異常大流量を感知して自動急速閉止する装置です。市街地の管路破損箇所から配水池内の水が流出し尽くすのを防ぎ、避難所等への応急給水用水を配水池内に確実に温存・確保することを目的とします。
* **日常のたとえ**: 地震の揺れでガスメーターの安全弁が自動遮断してガス爆発を防ぐのと同様に、配水池という巨大な「水筒のフタ」を地震直後にガチッと自動で閉めて、中の命の水を守る装置です。
* **出典**: 講義テキスト 導送配水施設 p.287
