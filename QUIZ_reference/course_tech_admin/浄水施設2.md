## 1. 浄水場の運転管理の基本と4大構成要素（テキスト p.364〜365）

### (1) 浄水場運転管理の目的
浄水場における運転管理の対象は、個々の施設・設備・機械装置である。しかし、それらを単独で動かすのではなく、**浄水システム全体としていかに効率的・経済的かつ安全に安定運転を継続できるか**が核心である。  
これは、目標とする「水量」「水質」「薬品使用量」「電力・動力」をいかに高い水準でコントロールできるかによって決定される。

```
【浄水場の運転管理を構成する4大要素】
┌──────────────────┬──────────────────┬──────────────────┬──────────────────┐
│ ① 水量管理       │ ② 水質管理       │ ③ 施設管理       │ ④ 薬品管理       │
│ (Water Quantity) │ (Water Quality)  │ (Facility)       │ (Chemicals)      │
└──────────────────┴──────────────────┴──────────────────┴──────────────────┘
```

---

### (2) 運転管理の4大構成要素の具体的実務

#### ① 水量管理（水管理）
* **目的**: 計画給水量を過不足なく安定供給するため、各処理工程の流量を常時把握・制御する。
* **実務**:
  * 季節・曜日・天候や過去の実績データに基づく**需要予測**を行い、目標給水量・目標浄水量を決定する。
  * 原水量、沈殿水流量、ろ過水量、送水量をリアルタイムで計量・把握し、水位変動や送配水系統の要請に追従して各設備を流量制御する。

#### ② 水質管理
* **目的**: 水道水質基準に完全に適合した、衛生的で安全かつおいしい水道水を生産する。
* **実務**:
  * 原水から着水井、沈殿、ろ過、浄水池、給水栓（蛇口）に至る各段階で、水質基準値および管理目標値を達成しているか連続計器および手分析で確認する。
  * 水質測定データを統計的に整理・解析し、運転操作の改善や薬品注入率のフィードバックに反映させる。

#### ③ 施設管理（★最重要点検ポイント）
* **目的**: 各施設・設備・装置の状態を**巡視点検**し、異常箇所を早期に発見して適切な整備・補修を行う。
* **実務**:
  * ポンプ、電動弁、攪拌機、かき寄せ機などの機械設備や、受変電・計装設備の健全度を維持する。
  * 燃料（自家発電機用重油・軽油）や試薬・消耗品を常に補充し、**常時万全の状態で稼働できる体制**を整備する。

#### ④ 薬品管理
* **目的**: 浄水処理に必要な薬品の在庫と注入を途切れることなく適正に維持する。
* **実務**:
  * 凝集剤（PAC等）、消毒剤（次亜塩素酸ナトリウム等）、アルカリ剤（苛性ソーダ等）、粉末活性炭の受給計画を策定し、必要量を発注・備蓄する。
  * 納入時には**受入検査（比重、外観、主成分濃度、不純物等）**を厳格に実施して規格適合を確認する。
  * 原水水質の変動に応じて適正な注入率を決定し、過不足のない注入管理を行う。

## 2. 浄水場の省力化・自動化・委託化のあり方（テキスト p.365〜367）

人口減少と熟練技術者の大量退職に伴い、水道界では省力化が急速に進展している。省力化を推進する際は、**万一の事故や災害時にも給水の安全性と安定性が損なわれない体制**を前提としなければならない。

```
【浄水場省力化の3大形態】
［① 自動化］ ── 各種センサー・計器と連動したSCADA・シーケンス・PID自動制御
［② 無人化］ ── 遠隔監視制御技術による遠隔無人運転（小規模浄水場・膜ろ過等）
［③ 委託化］ ── 水道法第24条の3（第三者委託）、官民連携（PPP/PFI、指定管理者等）
```

### (1) 自動化の判断基準
自動化を導入する範囲は、立地条件、取水条件、原水水質の特性と変動幅、採用している浄水処理方式、送配水管網の複雑さ等を総合的に勘案して慎重に決定しなければならない。全自動化が困難な水質変動の激しい河川表流水では、手動介入の余地を残す設計が重要となる。

### (2) 無人化の必須要件（安全対策）
小規模施設や膜ろ過施設等で無人化を導入する場合、以下の条件整備が不可欠である。
* **不法侵入防止対策**: 防犯カメラ、赤外線センサー、二重フェンス、電子施錠システム等のセキュリティ強化。
* **遠方監視制御設備**: 水質異常や停電・故障を親局（統括浄水場・中央管理室）へ即時伝送するテレメータ・SCADA設備の二重化。
* **緊急出動・監視体制**: 警報発令時に直ちに現場へ急行できる緊急待機輪番制と、巡視点検ルートの確立。

### (3) 委託化における留意点（★責任の所在）
* **丸投げの禁止**:
  * 水道法第24条の3に基づく技術業務の第三者委託やPFI等を進める場合であっても、水道事業者および水道技術管理者は最終的な安全責任を免れない。
  * 非常時の指揮命令系統、災害協定、緊急時対応マニュアルを明確に整備し、事業体と受託者が一体となった危機管理体制を維持しなければならない。

## 3. 処理工程のタイムラグと注入制御方式（テキスト p.367）

### (1) タイムラグ（遅れ時間）の発生要因
原水水質が急変した際、薬品注入率を変更してもその効果が処理水質として現れるまでには必ず**「タイムラグ（むだ時間＋時定数）」**が生じる。
* **主な要因**:
  1. 薬品混和・凝集・沈殿・ろ過の各池における**水理学的滞留時間**（数十分〜数時間）。
  2. 薬品の化学反応・フロック成長に要する**反応時間**。
  3. 各工程から水質測定計器（濁度計・pH計等）までサンプリング水を送る**配管内の移送時間**。
* **タイムラグ短縮策**:
  * 薬品注入点と採水箇所の幾何学的最適配置、サンプリング水移送管の小口径化・短縮、移送流速の向上。

---

### (2) 自動注入制御の2大方式（フィードバック vs フィードフォワード）

```
【フィードバック制御 vs フィードフォワード制御の対比】
┌───────────────────────────────┬───────────────────────────────┐
│ ① フィードバック制御 (Feedback) │ ② フィードフォワード制御 (Feedforward)│
├───────────────────────────────┼───────────────────────────────┤
│ 【原理】                      │ 【原理】                      │
│ 処理工程の「出口水質測定値」と │ 「流入原水水質（濁度・水温等）」│
│ 目標値との偏差を検出し、その差│ を測定し、水質変動の影響をあらか│
│ を縮めるよう薬品注入率を修正。│ じめ予測して偏差が生じる前に先行│
│                               │ して薬品注入率を自動修正する。  │
├───────────────────────────────┼───────────────────────────────┤
│ 【長所】                      │ 【長所】                      │
│ 確実であり、未知の外乱があって│ タイムラグによる制御遅れを排除│
│ も最終的に目標値へ収束する。  │ でき、急激な水質変化に対応可能。│
├───────────────────────────────┼───────────────────────────────┤
│ 【短所】                      │ 【短所】                      │
│ タイムラグが大きいと過剰注入や│ 予測モデル（計算式）の精度に依│
│ 制御のハンチング（周期的な発振│ 存し、想定外の外乱には対応でき│
│ ・乱高下）を起こしやすい。    │ ない（単独ではオフセットが残る）。│
└───────────────────────────────┴───────────────────────────────┘
```
* **実務での運用**:
  * 原水の急変には**フィードフォワード制御で先行追従**させ、後段の微少なズレを**フィードバック制御で微調整**する「複合制御（ハイブリッド制御）」が最も優れている。

## 4. 異常水質発生時の運転管理（テキスト p.367〜368）

### (1) 低水温・低濁度時の処理（冬期の凝集不良対策）
* **現象**:
  * 水温が低下（概ね $10^\circ\text{C}$ 以下、特に $5^\circ\text{C}$ 以下）すると、水の粘性が高まり粒子の沈降速度が低下する。
  * アルミニウム系凝集剤（PAC・硫酸バンド）の加水分解・重合反応が著しく遅延し、**フロックが微細化（ピンポイントフロック）して沈降しなくなる**。
  * この結果、沈殿池上澄水濁度が下がらず、ろ過池に濁質が流出して閉塞や濁質漏出を招く。
* **対策技術**:
  1. **凝集補助剤・アルカリ剤の併用**: 苛性ソーダや消石灰を添加してフロックの形成を助ける。
  2. **直接ろ過法（マイクロフロック法）の適用**: 沈殿処理をあえて省き、微細フロックのまま急速ろ過池の砂層内部で直接捕捉する。

---

### (2) 高濁度原水への対策（豪雨・出水時）
* **現象**:
  * 台風や集中豪雨により河川上流が荒れ、原水濁度が急激に数千〜数万度に跳ね上がる。
* **対策技術**:
  1. **上流情報の早期収集**: ダム放流情報や上流観測局の雨量・濁度データを把握し、高濁度水到達前に初動体制を確立する。
  2. **アルカリ剤の注入**: 凝集剤（PAC）を大量に注入すると原水のアルカリ度が消費されて著しくpHが低下するため、**アルカリ剤（苛性ソーダ等）を併注してpHを最適凝集域（pH 6.5〜7.5程度）に維持**する。
  3. **取水停止・減量（ピークカット）**: 原水調整池や配水池の容量に余裕がある場合は、高濁度ピーク時間帯の取水を一時停止または減量する。
  4. **排水処理設備の運転強化**: 沈殿汚泥が急増するため、排泥頻度を高め、汚泥濃縮槽・脱水機の連続運転を行う。

## 5. 水質測定の4大目的と最適採水（テキスト p.368）

浄水場における水質測定は、目的に応じて最適な採水地点と測定方式（手分析または自動計器）を設定しなければならない。

```
【浄水場における水質測定の4大目的】
① 薬品適正注入判定 ── 凝集剤・アルカリ剤・塩素等の適正注入率を決定（ジャーテスト、原水濁度・アルカリ度）
② 各処理工程の監視 ── 着水井・沈殿池・ろ過池等の各段階で処理が正常に機能しているか連続監視
③ 水道水質基準適合 ── 最終浄水が法定水質基準（51項目）を満たしているか確認（浄水出口・給水栓）
④ 排水処理・放流監視 ─ 排泥上澄水等の場外排出水が「水質汚濁防止法」の排水基準に適合しているか確認
```

* **採水上の厳格な注意点**:
  * 原水の水質を正しく評価するため、**採水地点は薬品が混和する前の地点を選定**しなければならない。
  * 水質計器への配管途中で水温変化や気泡混入、スライム（生物膜）付着が生じないよう、定期的に採水管の洗浄を実施する。

## 6. 浄水場の運転停止・再開における11大留意事項（テキスト p.368〜370）

場内工事、法定点検、施設更新等により浄水場の全部または一部を停止・再開する際は、重大事故や水質汚染を防ぐため、以下の11項目を厳格に遵守しなければならない（★試験超頻出）。

```
【浄水場の運転停止・再開における11大留意事項】
┌────┬──────────────────────────────────────────────────────────────────┐
│ 番号│ 点検・保守留意事項                                               │
├────┼──────────────────────────────────────────────────────────────────┤
│ ①  │ 停止期間を利用した計画的保全（平常運転中は不可能な清掃・補修の実施）│
│ ②  │ 薬品注入機・配管の「水洗浄（フラッシング）および水抜き」（閉塞防止） │
│ ③  │ 電気設備の「防湿ヒーター通電・乾燥措置」（絶縁劣化・漏電防止）    │
│ ④  │ 沈殿池の「水抜きまたは腐敗・藻類繁殖防止措置」（死水・異臭味防止） │
│ ⑤  │ フロキュレーター（フロック形成機）の「堆積汚泥による過負荷防止」    │
│ ⑥  │ 傾斜板・傾斜管沈殿池の「水位低下速度制限」（偏荷重による装置破損防止）│
│ ⑦  │ 緩速ろ過池の排水時における「砂面・生物膜保護」                    │
│ ⑧  │ マンガン砂ろ過池の「湛水保持（水没維持）」と「遊離残留塩素の置換維持」│
│ ⑨  │ 活性炭吸着池の「無酸素化防止」と再開時の「入念な逆洗浄」          │
│ ⑩  │ 生物処理・生物活性炭（BAC）設備の「微生物保護」と再開時の「ならし運転」│
│ ⑪  │ 運転再開時における「空気抜き・充水確認・注油（グリース）・緩速起動」│
└────┴──────────────────────────────────────────────────────────────────┘
```

### 【超重要項目の詳細解説】
* **② 薬品配管の水抜き（フラッシング）**:
  * PACや消石灰等の薬品液が配管内に残留したまま長期間放置されると、水分蒸発や結晶化によって固化し、配管や注入ノズルを完全に閉塞させる。必ず清水で配管をフラッシングし、水抜きを行う。
* **⑤ フロキュレーター（凝集機）の起動時破損事故**:
  * 沈殿池や凝集池を停止すると、底部に高密度のスラッジ（重い汚泥）が堆積する。
  * **スラッジに羽根やパドルが埋もれた状態でいきなりモーターを起動すると、過大なトルク負荷がかかって減速機、駆動チェーン、パドル軸が破断・破損する**。必ずスラッジを排泥・除去した後に起動する。
* **⑧ マンガン砂ろ過池の長期停止管理（★最頻出）**:
  * マンガン砂の表面には二酸化マンガン（$\text{MnO}_2$）の触媒活性皮膜が形成されている。
  * **ろ材面を空気に晒して乾燥させるとマンガン被膜が剥離してしまうため、必ず水面をろ材上面より上に維持（湛水保持）しなければならない**。
  * また、水中の残留塩素が消失して嫌気状態になると、**固定化されていたマンガンが2価のイオン（$\text{Mn}^{2+}$）に還元されて水中に再溶出する**。これを防ぐため、定期的に通水して塩素水を置換・補充しなければならない。
* **⑩ 生物処理・生物活性炭（BAC）設備の再開**:
  * 停止中に微生物群集が弱まるため、運転再開直後から100%の負荷をかけることはできない。事前にならし通水を行い、生物活性が回復するまでの助走期間を見込む。

## 7. 施設点検基準と保全手法（テキスト p.370〜371）

### (1) 施設点検の4分類
浄水場は多数の土木構造物、機械、電気・計装設備から構成される総合システムである。点検基準に基づき、チェックリストを用いて標準状態（基準値）との比較評価を行う。

## 8. 既存施設の更新・改良計画（テキスト p.371〜372）

### (1) 背景：施設の経年化と平準化の必要性
* 日本の大規模浄水場の多くは、昭和30年代後半〜40年代の高度経済成長期に一挙に建設された（現在の能力の約7割を占める）。
* これらが一斉に通水50年を超えて法定耐用年数を迎え、更新時期が重複している。一斉に更新しようとすると**一時的に事業体の浄水能力が大幅にダウンし、財政的にも莫大な負担が集中する**ため、長期アセットマネジメントに基づき**投資と工事の平準化**を図らなければならない。

### (2) 更新・改良計画における必須検討事項
1. **工事中の代替能力確保（片肺運転対策）**:
   * 既存施設を取り壊して新設する場合、その間の浄水能力低下分を**他浄水場からの融通送水や仮設設備でいかにカバーするか**の給水計画を事前に確立する。
2. **水理解析と水位関係の整合性**:
   * 浄水場内は基本的に「自然流下」で水が流れる設計が多い。新設設備を割り込ませる場合、水位差（損失水頭）の関係が狂って溢水や流下不能を起こさないよう水理解析を厳密に行う。
3. **ダウンサイジングと付加価値**:
   * 人口減少に伴う水需要減少を見据え、既存の過大能力を適正規模に縮小（ダウンサイジング）する。併せて、耐震化（レベル2耐震）、省エネルギー機器の導入、複数系列化（冗長性確保）を同時に盛り込む。

## 10. 着水井の機能と構造基準（テキスト p.373〜375）

### (1) 着水井（Receiving Well）の定義と基本的役割
* **定義（テキスト p.373）**:
  * 導水施設から流入する原水の水位変動や流入動圧を吸収して水流を安定させ、**原水量の正確な測定と調整を行って、後続の薬品注入、混和、沈殿、ろ過等の一連の浄水処理が正確かつ容易に行えるようにする**ために浄水場の最上流部に設置される施設である。

```
【着水井が果たす4大機能】
① 水位・動圧の安定化 ── 導水管からの動水圧・サージを吸収し、大気開放して水位を安定化
② 水量の測定と調整   ── 浄水場への流入原水量を正確に計量し、各処理系列へ均等分配
③ 水質監視・緊急遮断 ── 原水の水質監視（濁度・pH・毒物）、油膜検知、バイオアッセイ
④ 各種薬品の注入     ── 凝集剤、前塩素、粉末活性炭、アルカリ剤等の受入注入点
```

---

### (2) 着水井の構造基準と設計諸元（『水道施設設計指針』）

```
【着水井の構造基準一覧（★試験必出数値）】
┌──────────────────┬────────────────────────────────────────────────────┐
│ 項目             │ 構造・設計基準                                     │
├──────────────────┼────────────────────────────────────────────────────┤
│ ① 池数（系列分割）│ 原則として「2池以上（2系列以上）」に分割する。     │
│                  │ ※やむを得ず単一池とする場合は「バイパス管」を併設。 │
├──────────────────┼────────────────────────────────────────────────────┤
│ ② 滞留時間       │ 「1.5分以上」とする。                              │
├──────────────────┼────────────────────────────────────────────────────┤
│ ③ 有効水深       │ 「3.0 〜 5.0 m」程度とする。                       │
├──────────────────┼────────────────────────────────────────────────────┤
│ ④ 形状・整流     │ 水の短絡（ショートカット）を防止するため、         │
│                  │ 導流壁や越流堰（整流設備）を設ける。               │
├──────────────────┼────────────────────────────────────────────────────┤
│ ⑤ 付帯設備       │ ・粗大夾雑物を除去する「スクリーン」               │
│                  │ ・正確な流量を測る「流量測定装置（堰・流量計等）」 │
│                  │ ・水質異常時に備える「粉末活性炭注入設備」         │

└──────────────────┴────────────────────────────────────────────────────┘
```

* **池数を2池以上とする理由**:
  * 着水井底部に堆積する土砂の清掃、機器補修、点検時であっても、**片池運転を行うことで浄水場全体の給水を一切停止させずに維持管理を継続できる**ようにするため。
* **洗浄排水（返送水）の受け入れ**:
  * ろ過池の逆洗浄排水や沈殿池の上澄水を回収・リサイクルする場合、着水井へ返送して原水と混合することが多い。返送水の急激な流入による水質変動を抑えるため、返送割合を厳密に管理する。

---

### (3) バイオアッセイ（魚類による連続水質監視）
* **原理**:
  * 上流工場からの化学物質・シアン等の有害物質流出事故や、意図的な毒物混入テロを24時間体制で早期検知するため、**着水井に「魚類水質監視水槽」を併設**する。
* **監視手法**:
  * 毒物に敏感な淡水魚（タナゴ、ヒメダカ等）を飼育し、魚の遊泳行動をCCDカメラ画像解析やセンサーで常時監視する。
  * 毒物が混入すると魚の狂騒遊泳や呼吸停止、沈降等が発生するため、これを自動検知して警報を発報し、取水ゲートの緊急閉止や粉末活性炭注入を即時起動する。

## 12. 【想定問題集（ドリル実装用プロトタイプ問題）】

### 設問1（4択：浄水場の運転管理と制御方式）
* **問題形式**: `choice`
* **問題文**: 浄水場の薬品注入制御およびタイムラグに関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. フィードフォワード制御は、流入原水の水質変動を測定し、処理水質に偏差が生じる前に先行して薬品注入率を自動修正する方式である
  2. フィードバック制御は、流入原水の濁度のみを測定し、出口水質の測定値は一切フィードバックしない方式である
  3. 処理工程におけるタイムラグは、水質計器の通信回線遅延のみによって生じ、池内の水理学的滞留時間は影響しない
  4. 原水水質が急激に変動した場合でも、タイムラグを考慮せず出口水質のみを見て手動操作するだけで常に適正な処理水質が得られる
* **正解**: 1（インデックス: 0）
* **解説**: フィードフォワード制御は、外乱である原水水質（濁度、水温等）の変動を測定し、出口水質にズレ（偏差）が生じる前にあらかじめ予測して先行制御する方式であり、タイムラグによる制御遅れを排除できます。フィードバック制御は出口水質の測定値と目標値の偏差を検出して修正する後追い制御です。タイムラグは混和・凝集・沈殿・ろ過各池の滞留時間や配管移送時間に起因して発生します。
* **日常のたとえ**: 車の運転で、前方の急カーブ（外乱）を見てあらかじめハンドルを切るのがフィードフォワード制御、曲がりきれずに車体が傾いてから慌ててハンドルを修正するのがフィードバック制御です。
* **出典**: 講義テキスト 浄水施設 p.367

---

### 設問2（4択：浄水場の運転停止・再開時の維持管理）
* **問題形式**: `choice`
* **問題文**: 浄水場内の施設・設備の運転停止および再開時における維持管理上の留意事項として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. マンガン砂ろ過池を2〜3週間停止する場合、マンガン被膜の剥離を防ぐためろ材面の上まで水を残し（湛水保持）、残留塩素が消失しないよう適宜通水する
  2. 凝集剤や消石灰の注入機および薬品配管を長期停止する場合、薬品液を満たしたままバルブを密閉して保管するのが基本である
  3. フロック形成池（フロキュレーター）を停止した後の再起動時は、堆積スラッジを除去せずに直ちに最高回転数で起動するのが望ましい
  4. 電気設備を長期間停止する場合、湿気による影響は生じないため防湿ヒーターへの通電や乾燥措置は不要である
* **正解**: 1（インデックス: 0）
* **解説**: マンガン砂ろ過池を停止する場合、マンガン触媒被膜の乾燥剥離を防ぐため「ろ材面の上まで水を残す（湛水保持）」とともに、嫌気化によるマンガンの再溶出を防ぐため「遊離残留塩素が消失しないよう適宜通水（置換）」を行う必要があります。薬品配管は固化閉塞を防ぐため水洗浄・水抜きが必須です。フロキュレーターは堆積泥による過負荷破損を防ぐため排泥後に起動します。電気設備は絶縁劣化を防ぐ防湿対策が不可欠です。
* **出典**: 講義テキスト 浄水施設 p.368〜370

### 設問3（4択：異常水質発生時の運転管理）
* **問題形式**: `choice`
* **問題文**: 低水温時および高濁度時における浄水場の運転管理に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 冬期などの低水温・低濁度時にはアルミニウム系凝集剤の反応が遅延するため、アルカリ剤の併用や直接ろ過法（マイクロフロック法）の適用が有効である
  2. 豪雨等による高濁度原水が流入した際、凝集剤（PAC）を多量に注入するとpHが急上昇するため、酸性薬品を注入して中和しなければならない
  3. 低水温時には水の粘性が低下するため、沈殿池におけるフロックの沈降速度は夏期よりも著しく速くなる
  4. 豪雨による原水の急激な濁度上昇に対しては、取水停止やピークカットを行ってはならず、常に全量取水を維持しなければならない
* **正解**: 1（インデックス: 0）
* **解説**: 冬期などの低水温時には水の粘性増大と凝集剤の加水分解遅延によりフロックが微細化して沈殿不良を起こすため、苛性ソーダ等のアルカリ剤併用や、直接ろ過法（マイクロフロック法）の適用が有効です。凝集剤（PAC等）を多量注入するとアルカリ度が消費されてpHが低下するため、アルカリ剤を添加してpHを維持します。高濁度ピーク時には取水停止や減量（ピークカット）を行うことが有効です。
* **出典**: 講義テキスト 浄水施設 p.367〜368

### 設問4（4択：着水井の機能と構造基準）
* **問題形式**: `choice`
* **問題文**: 『水道施設設計指針』等に基づく「着水井」の機能および構造基準に関する記述として、**最も適切なもの**はどれですか？
* **選択肢**:
  1. 着水井の容量は、原水の流量・水位を安定化させるため、滞留時間を「1.5分以上」とし、水深は「3.0〜5.0m」程度を標準とする
  2. 着水井は清掃や点検補修を容易にするため、いかなる大規模浄水場であっても必ず単一の池（1池構造）で築造しなければならない
  3. 着水井の主な目的は、急速ろ過池から流出した浄水を受け入れて最終的な残留塩素濃度を測定することである
  4. 着水井の内部には水流を激しく攪拌させるため、導流壁や越流堰などの整流設備を一切設けてはならない
* **正解**: 1（インデックス: 0）
* **解説**: 着水井の標準的な設計諸元は、滞留時間「1.5分以上」、有効水深「3.0〜5.0m」程度です。着水井は清掃や補修時にも給水を継続できるよう、原則として「2池以上（2分割以上）」に分割（分割不可時はバイパス管設置）します。着水井は導水施設から流入する「原水」を受け入れる最上流の施設であり、水流の短絡を防ぐための導流壁や整流設備を設けます。
* **出典**: 講義テキスト 浄水施設 p.373〜375／『水道施設設計指針』

### 設問5（4択：安全管理と保全手法）
* **問題形式**: `choice`
* **問題文**: 浄水場の施設保全および安全工学に関する記述として、**最も不適切なもの（誤っているもの）**はどれですか？
* **選択肢**:
  1. 浄水場の基幹設備（送水ポンプや受変電設備等）においては、故障が発生してから修理を行う「事後保全」を基本方針とする
  2. 機器の故障や停電が発生した際、自動的に安全側（停止や全閉等）へ移行する設計思想を「フェールセーフ」と呼ぶ
  3. 人間が誤操作を行っても重大な事故に至らないよう、注入口の形状を物理的に変えるなどの設計を「フールプルーフ」と呼ぶ
  4. 日常点検は毎日から1週間程度の周期で実施し、運転員の五感（外観、異音、振動、異臭、発熱）や計器指示により健全度を確認する
* **正解**: 1（インデックス: 0）
* **解説**: 浄水場の送水ポンプや薬品注入機、受変電設備などの基幹設備は、突発故障が直ちに断水や重大な水質事故に直結するため、故障する前に計画的に点検・整備・部品交換を行う「予防保全（Preventive Maintenance）」が絶対原則です。事後保全を基本方針とする記述は誤りです。フェールセーフ、フールプルーフ、日常点検の五感点検の記述はすべて適切です。
* **出典**: 講義テキスト 浄水施設 p.370〜371
