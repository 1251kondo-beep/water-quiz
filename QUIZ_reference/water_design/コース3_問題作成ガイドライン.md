## 1. 基本理念と学習ゴール

### 🎯 ターゲット層（ペルソナ）
- **水道事業体の給水装置工事審査担当者、配水管理・工務担当者**
- **指定給水装置工事事業者の主任技術者・設計実務者**

### 💡 コース3の設計思想
1. **「計算作業」ではなく「水理現象の本質理解と審査判定眼」を養う**
   - 単なる電卓計算の反復ではなく、「管径を半分にすると流速や摩擦損失はどう跳ね上がるか」「動水勾配や損失水頭が実務審査でなぜ重要か」「水頭不足が起きると現場でどんな問題（出水不良・騒音・ウォーターハンマー）が生じるか」を直感的に腹落ちさせます。
2. **普遍的な工学原則と法令基準に基づく出題**
   - 特定自治体のローカル内規に限定されることなく、全国標準である『水道施設設計指針（JWWA）』『改訂 給水装置工事技術指針』『水道法施行令第5条』、および『参考設計資料（半田市水道部・ジオックス提供）』に基づく普遍的な設計水理解析・審査実務をマスターします。
3. **1レッスン10問のスナックラーニング**
   - 全5セクション × 各5レッスン（計25レッスン / 全250問）でステップバイステップにステップアップできる構成とします。

## 2. 問題形式と形式別JSONスキーマ仕様

設問の教育意図に応じて、以下の形式を使い分けます。

### ① 標準4択問題 (`type: "choice"`)
- **太字ルール**: 
  - 肯定形（「最も適切なものはどれですか？」） ➔ **太字にしない**
  - 否定形（「**誤っているもの**はどれですか？」「**適切でないもの**はどれですか？」） ➔ 必ず **太字** で注意喚起

```json
{
  "id": "wd_1_5_07",
  "type": "choice",
  "question": "中大口径管（φ75以上）のヘーゼン・ウイリアムス公式：\nh ＝ 10.666 × C⁻¹·⁸⁵ × D⁻⁴·⁸⁷ × Q¹·⁸⁵ × L\n\n上記の公式における摩擦損失水頭hと各要素の関係として、**誤っているもの**はどれですか？",
  "options": [
    "管口径Dが大きいほど、摩擦損失水頭hは大きくなる",
    "管延長Lが長いほど、摩擦損失水頭hは大きくなる",
    "流量Qが大きいほど、摩擦損失水頭hは大きくなる",
    "流速係数Cが大きいほど、摩擦損失水頭hは小さくなる"
  ],
  "answerIndex": 0,
  "explanation": "ヘーゼン・ウイリアムス公式において、管口径Dの指数は「-4.87」であり分母に位置するため、管口径Dが大きくなるほど摩擦損失水頭hは急激に小さくなります（口径を太くすると管路の抵抗は激減します）。\n\n※流速係数Cも指数が-1.85のため、管内面が滑らかでC値が大きいほど摩擦損失は小さくなります。",
  "analogy": "細いストローで飲むと強い力（大きな圧力損失）が必要ですが、太いタピオカ用ストローにするとほとんど抵抗なく楽に吸い込める物理現象と同じです。",
  "referenceSection": "『参考設計資料』1.(11)② 水理演算公式（管口径がφ75以上） P.8"
}
```

### ② 一問一答 ⚪︎×問題 (`type: "true_false"`)
- `options` は常に `["正しい", "間違い"]`

```json
{
  "id": "wd_1_1_02",
  "type": "true_false",
  "question": "水道管内の水理計算において、水は「粘性を持つ非圧縮性流体」として扱われる。",
  "options": ["正しい", "間違い"],
  "answerIndex": 0,
  "explanation": "気体と異なり、水は外圧を加えても体積がほとんど変化しないため「非圧縮性流体」として扱います。一方で、管の内壁と水分子との間には摩擦（粘性）が働くため、完全流体ではなく「粘性流体」として水理計算を行います。",
  "analogy": "スポンジや空気のようにギュッと押し縮められないけれど、管の壁との間には摩擦ブレーキがかかる流体です。",
  "referenceSection": "『参考設計資料』1.(1) 水の重さ、1.(2) 流体の流れ P.1"
}
```

### ③ 語句の穴埋め問題 (`type: "fill_in_the_blank"`)
- `blankText` に `【空欄1】`, `【空欄2】` を指定。

```json
{
  "id": "wd_1_1_03",
  "type": "fill_in_the_blank",
  "question": "管内の水流の様態について、文中の空欄に適する語句を選択肢から選んでください。",
  "blankText": "流体分子が規則正しく整然と流れる状態を【空欄1】と呼び、壁面摩擦等で渦が生じ不規則に流れる状態を【空欄2】と呼ぶ。この流れの遷移判定には【空欄3】が用いられる。",
  "blanks": [
    { "id": 1, "answer": "層流" },
    { "id": 2, "answer": "乱流" },
    { "id": 3, "answer": "レイノルズ数" }
  ],
  "options": ["層流", "乱流", "レイノルズ数", "動水勾配"],
  "answerIndex": 0,
  "explanation": "管中央に障害物がなく整然と流れる状態を「層流」、壁面摩擦や障害物により渦が生じて乱れた流れを「乱流」と呼びます。層流から乱流に移行する境界の数値を臨界レイノルズ数（管水路では約2,320）と呼びます。",
  "referenceSection": "『参考設計資料』1.(2) 流体の流れ P.1"
}
```

### ④ 並び替え問題 (`type: "ordering"`)
- 給水装置の設計計算手順や審査フローを問う場合に使用。

```json
{
  "id": "wd_2_2_04",
  "type": "ordering",
  "question": "直圧直結給水方式における給水管口径の設計計算手順として、正しい順序に並び替えてください。",
  "items": [
    "建物の用途・規模から設計使用水量（計画瞬時最大流量）を算定する",
    "配水管の最小動水圧から末端給水栓までの有効水頭（許容損失水頭）を算出する",
    "流量図（ノモグラム）を用いて仮管径を選定し流速が2.0m/s以下であることを確認する",
    "直管損失および継手・メーター等の局所損失を合算して余裕水頭が正（プラス）であることを検証する"
  ],
  "answerOrder": [0, 1, 2, 3],
  "explanation": "給水装置設計の基本フローは、①設計使用水量の算出 ➔ ②利用可能水頭（許容損失水頭）の割り出し ➔ ③仮管径の選定と流速チェック ➔ ④詳細な総損失水頭の計算と余裕水頭の最終判定、の手順で進めます。",
  "referenceSection": '『参考設計資料』2.(1) 給水装置の設計計算手順 P.11'
}
```

## 3. コース3 厳格特化ルール【最重要】

### 3-1. 数式・物理式のスマート表示ルール（Unicode上付き指数の徹底）
スマートフォンやPC画面での可読性を最大限に高めるため、以下のルールを厳守します。

1. **数式の独立行配置（改行 `\n` の挿入）**:
   - 問題文の文章中に数式をインラインで埋め込まず、前後に改行を挟んで単独の行として表示します。
   - ⭕ **推奨**:
     ```text
     中大口径管（φ75以上）のヘーゼン・ウイリアムス公式：
     h ＝ 10.666 × C⁻¹·⁸⁵ × D⁻⁴·⁸⁷ × Q¹·⁸⁵ × L

     上記の公式における摩擦損失水頭hと各要素の関係として、**誤っているもの**はどれですか？
     ```
   - ❌ **禁止**: 「中大口径管（φ75以上）に適用されるヘーゼン・ウイリアムス公式「h ＝ 10.666・C^(-1.85)・D^(-4.87)・Q^(1.85)・L」において、摩擦損失水頭hと各パラメーターの関係に関する記述として最も適切なものはどれですか？」
2. **墨カッコ（【 】）の排除**:
   - 穴埋め問題の空欄（`【空欄1】`）を除き、数式の前後に `【 h ＝ ... 】` のような墨カッコを付けないでください。
3. **べき乗・指数の上付き文字（Unicode）徹底**:
   - プログラミング記法・ハット記法（`C^(-1.85)`, `D^(-4.87)`, `Q^1.85`, `v^2`, `m^3`）は視覚的ノイズになるため**完全禁止**です。
   - 必ず Unicode の上付き文字（`⁻¹·⁸⁵`, `⁻⁴·⁸⁷`, `¹·⁸⁵`, `²`, `³` 等）を使用してください。
   - 例: `m³`（立方メートル）、`v² / 2g`（速度水頭）、`D⁻⁴·⁸⁷`、`N⁰·⁴⁷⁵`

### 3-2. 図・表・テーブル（table, explanationTable）の特例緩和と活用基準
コース1・2で定めている「図表原則禁止ルール」を**コース3では大幅に緩和**します。給水装置工事図面の審査や水理計算書の検算実務では、データ表や対比表が理解に不可欠となるため、積極的に活用します。

#### ① 問題用テーブル (`table`)
- **用途**: 提示された区間データや水理計算条件を読み取らせて判定・計算させる場合。
- **禁止事項**: 答えがそのまま表内に書かれている「ネタバレ表」は禁止。
```json
"table": {
  "title": "ウエストン流量線図による読み取りモデルケース",
  "headers": ["設計項目", "読み取り数値・単位", "実務上の判定根拠"],
  "rows": [
    ["計画流量 Q", "100.0 L/min（1.667 L/sec）", "設計使用水量より算出"],
    ["摩擦抵抗値 R", "55 ‰（動水勾配 I）", "許容損失水頭と延長から設定"],
    ["管口径 D", "φ40 mm", "流量QとRの交点より仮決定"],
    ["平均流速 v", "1.35 m/sec", "流速2.0m/sec以下を満足"]
  ]
}
```

#### ② 解説用比較表 (`explanationTable`)
- **用途**: 複数の公式の適用管径の違い（ウエストン vs ヘーゼン）、給水方式の長所短所（直圧 vs 増圧 vs 受水槽）、器具給水負荷単位の対比など、文章では整理が困難な対比を提示する場合。
```json
"explanationTable": {
  "title": "管径別 水理演算公式の比較対比",
  "headers": ["公式区分", "標準適用口径", "流量・口径の指数特性", "主な用途"],
  "rows": [
    ["ウエストン公式", "φ13 〜 φ50 mm", "流速vの1.75〜2乗に比例", "一般住宅・中小型給水引込管"],
    ["ヘーゼン・ウイリアムス公式", "φ75 mm 以上", "Q¹·⁸⁵、D⁻⁴·⁸⁷ に比例", "配水本管・支管・大型引込管"]
  ]
}
```

### 3-3. スマホ最適化！図・グラフ・ノモグラムの完全描画仕様 ＆ 一発生成プロンプト

スマートフォンで学習する受講生が、**「スクロールなしで一目で理解でき、文字が潰れず、論点がシャープに伝わる」** 高精度なテクニカルイラスト・解説図を一発で生成するための完全設計仕様です。

#### 📱 スマホ最適化 5大設計原則（完全数値仕様）
1. **完全ホワイト背景 & ノイズ完全排除（`#FFFFFF`）**:
   - 背景は純白（`#FFFFFF`）のみ。背景グラデーション、3Dシャドウ、リアルな管の質感加工、背景グリッド（ノモグラム本体以外の不要な網掛け）は完全禁止。
   - アプリのライト/ダーク両モードのカード内（白地コンテナ）で美しく収まるようにします。
2. **機能的3色限定カラーパレット**:
   - **ベース（管・地面・基準線・矢印）**: 漆黒〜ダークグレー（`#1A1A1A` または `#1E293B` / 線幅 2.0〜3.0px の太線）
   - **水流・圧力水頭・適合要素**: 水道ブルー（`#0284C7` または `#2563EB`）
   - **損失・摩擦・注目ポイント・NG**: 警告ローズ・レッド（`#E11D48` または `#DC2626`）
   - **許容・完了・ステップ番号**: エメラルド・グリーン（`#10B981`）
   - ※装飾的な多色使いを厳禁とし、色自体に物理的・論理的意味を持たせます。
3. **スマホ縮小に耐えうるフォントサイズ & 白フチ処理【最重要】**:
   - 横幅360〜400px前後のスマートフォン画面に縮小された場合でも瞬時に読めるよう、**文字サイズは通常の1.5〜2倍（太字ゴシック: Noto Sans JP Bold / Inter Bold）** を指定。
   - 目盛り線や配管と文字が重なる箇所には、必ず**強力な白フチ（`paint-order: stroke fill; stroke: #ffffff; stroke-width: 4px;`）**を付与。
4. **黄金アスペクト比（16:9 または 4:3）**:
   - 縦長画像はスマホの画面全体を占領し、選択肢が画面外に押し出されて学習テンポを崩すため**縦長は禁止**。
   - `16:9`（1920×1080px推奨）または `4:3`（1200×900px推奨）の横長構図で作成する。
5. **情報の構造化（サイドパネル方式）**:
   - 図本体の内部に長文の解説や手順を書き込まず、**「左側に図面・グラフ本体」「右側（または下部）に手順1・2・3の整理カード」** を配置する構造とする。

#### ⚡ 一発生成プロンプトテンプレート（コピペ用完全版）

##### 【プロンプト1: 水理・物理概念図用（パターンA）】
```markdown

以下の水理条件に基づき、スマートフォン画面で最高の一目でわかる視認性を持つ、極めてシンプルで端正なテクニカルイラストを生成してください。

【対象テーマ】: [例: 円形配管における流量Q・内径D・流速vの連続の式関係図]
【アスペクト比】: 16:9（横長）
【描画スタイル・絶対厳守ルール】:
1. 完全ホワイト背景（#FFFFFF）。余計な背景色・陰影・テクスチャ・3D装飾は一切入れない。
2. 配管と境界線は、2.5pxのくっきりとした漆黒の太線（#1A1A1A）で描く。

5. 配管や矢印と文字が重なる部分には、4pxの白フチ（ホワイトアウトライン）を付与して視認性を100%確保する。
6. 冗長な装飾やキャラクターは一切排除し、工学教科書のように端正で無駄のないベクトル線画とする。
```

### 3-4. 単位換算と数値丸め・有効数字の統一ルール

給水工学実務では、様々な単位系（SI単位、工学単位、実務慣用単位）が混在します。問題文・選択肢・解説では以下の整合性を徹底します。

| 物理量 | 標準単位（SI） | 実務慣用単位 | 換算ロジック・丸め基準 |
| :--- | :--- | :--- | :--- |
| **流量 $Q$** | $\text{m}^3/\text{sec}$ | $\text{L/min}$、$\text{m}^3/\text{h}$ | $1\text{m}^3/\text{sec} = 60,000\text{L/min} = 3,600\text{m}^3/\text{h}$<br>選択肢は有効数字3桁（例: $100\text{L/min}$, $1.67\text{L/sec}$） |
| **流速 $v$** | $\text{m/sec}$（$\text{m/s}$） | - | 標準基準: $2.0\text{m/sec}$ 以下<br>小数第2位まで表記（例: $1.35\text{m/sec}$） |
| **水圧 $P$** | $\text{MPa}$, $\text{kPa}$ | $\text{kgf/cm}^2$, $\text{mAq}$ | $0.1\text{MPa} = 100\text{kPa} \fallingdotseq 1.02\text{kgf/cm}^2 \fallingdotseq 10.2\text{mH}_2\text{O}$<br>実務概算: 水頭 $10\text{m} \fallingdotseq 0.1\text{MPa}$ |
| **動水勾配 $I$** | - | ‰（パーミル） | $1‰ = 1\text{m} / 1,000\text{m}$（管長1,000mあたりの損失水頭m） |
| **損失水頭 $h$** | $\text{m}$ | - | 小数第2位まで表記（例: $3.45\text{m}$） |

- **数値選択肢の均一化**:
  - 選択肢の数値は、不揃いな桁数にせず、同一の有効数字・丸め単位（例: すべて小数第1位まで、すべて10の位まで）に統一します。

## 4. 問題文・選択肢・解説・出典の作成基準

### 📝 問題文のスリム化
- **形式ばった前置きの排除**: 「第○章において〜」「資料の〜〜に基づき」等の前置きは一切排除し、**40〜60文字程度**で論点をシャープに問います。
- **出典・章節番号は問題文内に入れず**、`referenceSection` に記載します。

### ❌ 7大禁止パターン（選択肢の品質基準）
1. **ネタ・幼稚な造語・極端な荒唐無稽の完全禁止**（「配管をすべて撤去する」「水圧を無限にする」等）。
2. **選択肢内の補足説明・カッコ書きの完全禁止【最重要】**:
   - 選択肢は問われている語句・数値のみをシンプルに記述し、`（〜のため）` `（最大の損失）` などのカッコ書きを一切入れない。
3. **ヒントの抱き合わせ（ネタバレ併記）の禁止**:
   - 選択肢に「口径」と「流速値」を両方書くなど、複数の情報を抱き合わせて消去法で正解が推測できる状態を禁止。
4. **文字数・熱量の不均衡禁止**:
   - 正解だけ詳しく、誤答が短い現象を防止（4選択肢の文字数差は±20%以内）。
5. **選択肢の文字数制限**:
   - 軽快な解答体験のため、4択の選択肢は**原則36文字以内（目安25〜35文字）**に収める。
6. **文末表現の統一**:
   - 4選択肢すべての語尾（名詞止め、動詞止め）を完全に揃える。
7. **問題文の不要な太字禁止**:
   - 通常の肯定形は太字にせず、否定形（「**誤っているもの**」「**適切でないもの**」）のみ太字にする。

### 📖 解説文の「ピンポイントフォロー方式」
- 正答の物理的理由や法令根拠を丁寧に解説します。
- 誤答選択肢すべてを「・Aの解説」「・Bの解説」と機械的に網羅することを禁止し、実務上勘違いしやすい急所のみ**「※〜〜」として1〜2点ピンポイントで注記**します。

### 📌 出典（referenceSection）の整合性
- 資料（『参考設計資料』『水道施設設計指針』等）の節見出し・図表番号・ページ番号と100%合致させて記載します。
- 形式例: `『参考設計資料』1.(11)① ウエストン公式流量図 P.7, P.9`
