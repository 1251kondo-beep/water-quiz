# 投資財政計画　用語解説

対象ファイル：`投資財政計画（企業債利息4.5％_除却率2%_老朽管更新調整） 20260806 (1).xlsx`

初めて水道事業の企業会計・財政計画に携わる職員向けの用語ガイドです。  
「この言葉が出てきたら、何を意味しているか」を、日常のたとえと具体例を交えて説明します。

---

## はじめに：このExcelは何をするものか

水道事業は、毎日の水の供給（運営）と、管路・施設の建設・更新（投資）の両方を同時に回しています。  
このファイルは、**将来の設備投資とお金の収支を一体で見通すための中長期計画**です。

入力シートに前提条件（料金・工事費・金利など）を置くと、出力シートで損益・借入・手元資金・経営指標が自動計算されます。

経営戦略の主な分析期間は **令和7〜16年度（2025〜2034年）** です。

| ファイル名の語句 | 読み方・意味 |
|---|---|

「老朽管更新調整」は、更新を一気に進めると建設改良費→企業債→利息・償還→内部留保減少の連鎖が起きるため、**必要な更新を見つつ赤字や資金不足が出ないよう工事水準を調整した前提**を意味します。

## 2. まず押さえたい全体像（3条と4条）

### 2-1 何の法律・規則の「3条」「4条」か

実務でいう **3条・4条** は、地方公営企業法そのものの条文名ではなく、**予算書の様式上の条番号**です。

| 呼び方 | 中身 | 根拠 |
|---|---|---|
| **3条（収益的収支）** | 1年間の経営活動の収益と費用（損益） | **地方公営企業法施行規則**の予算様式 **第3条**（収益的収入及び支出） |
| **4条（資本的収支）** | 建設改良・借入・元金返済など（投資と資金調達） | 同規則の予算様式 **第4条**（資本的収入及び支出） |

上位法は **地方公営企業法**（昭和27年法律第292号）で、企業会計方式・独立採算の枠組みを定めます。  
「3条＝損益、4条＝投資と借入返済」と覚えると実務上は十分です。

```
【3条＝収益的収支】日常の運営の損益
  収入：水道料金など
  支出：受水費・人件費・減価償却費・支払利息など
  → 黒字／赤字（当年度純損益）が分かる

【4条＝資本的収支】設備投資と借入・返済
  収入：企業債・補助金など
  支出：建設改良費・企業債の元金返済など
  → ほぼ毎年「不足」が出る（異常ではない）
  → 不足は内部留保（貯金）で補てんする
```

| 用語 | たとえ | このファイルでのシート |
|---|---|---|
| **3条（収益的収支）** | 家計の「毎月の給料と生活費」 | `3条_case2` |
| **4条（資本的収支）** | 家計の「家のリフォームと住宅ローン」 | `4条_case2` |
| **内部留保** | 貯金通帳の残高 | 財政シミュレーションの「現金預金残高／内部留保資金残高」 |

### 2-2 目指すのは「3条も4条もトータル黒字」か

**いいえ。4条まで毎年黒字にすることを目標にはしません。**

| 区分 | 目標のイメージ |
|---|---|
| **3条** | 中長期で黒字（少なくとも大幅赤字の常態化を避ける）。料金で運営コストと資本費を賄う |
| **4条** | 支出＞収入の「不足」がほぼ毎年出るのが標準。**不足を内部留保で埋め続けられること**が目標 |
| **事業全体** | 「3条の健全性」＋「内部留保で4条不足を補てんできる資金繰り」の両立 |

たとえ：給料（3条）は黒字でも、家のリフォームとローン返済（4条）は貯金を取り崩すのが普通です。  
「リフォームもローン返済もその年の給料だけで賄い切る」ことは目指しません。

### 2-3 4条の赤字は、3条で直接補填するのか／内部留保で補填するのか

**会計上、4条不足を「3条の黒字額でそのまま相殺する」わけではありません。**  
不足の穴埋めに使うのは **補てん財源（主に内部留保＝損益勘定留保資金など）** です。

流れのイメージ：

1. 3条で、減価償却費などの**現金が出ない費用**を計上する  
2. その分、現金が事業内に残り、**内部留保の源泉**になる  
3. 4条で建設改良・元金返済の不足が出る  
4. その不足を、貯めておいた**内部留保で補てん**する  

つまり、3条の黒字（とくに非資金費用）が**間接的に**4条不足を支える構造です。  
「3条黒字をその場で4条に振り替える」のではなく、「いったん貯金として蓄積し、4条不足に充てる」イメージです。

### 2-4 3条の黒字は内部留保に積み上がるのか

**基本的に、はい。** 特に次の2つが重要です。

| 要因 | 説明 |
|---|---|
| **現金収益 − 現金費用** | 料金収入などが現金支出を上回れば、手元資金が増える |
| **非資金費用（減価償却費・資産減耗費など）** | 損益上は費用だが現金は出ていないので、その相当額が内部に残る（損益勘定留保資金） |

注意点：

- 3条が黒字でも、4条不足の補てん・企業債償還・工事の自己負担が大きければ、内部留保は減り得る  
- 逆に、3条がわずかな赤字でも、減価償却が大きい年は「損益は赤字でも現金は残る」ことがある  
- だから **損益（3条）と現金残高（内部留保）はセットで見る**

### 2-5 4条の赤字が毎年ほぼ発生するのに、なぜ経営上許容できるのか

理由は大きく4つです。

1. **構造上そうなる**  
   4条支出の中心は「建設改良費」と「過去の企業債元金返済」です。収入側の企業債・補助金は、通常その全額を賄いきれません。差額は自己資金で埋める設計です。

2. **異常ではなく標準**  
   全国の水道事業でも、資本的収支は不足が出るのが一般的です。予算書にも「不足額は損益勘定留保資金等で補てんする」と書くのが通例です。

3. **資産が残り、将来のサービスにつながる**  
   4条で使ったお金は「消える浪費」ではなく、管路・施設という資産になります。将来の給水を支える投資です。

4. **問題は不足そのものではなく、補てんできるか**  
   許容できる条件は、**(a) 内部留保が枯渇しないこと**、**(b) 企業債残高が過大にならないこと**、**(c) 3条が中長期で料金原価を賄えること**です。

### 2-6 基準内繰入金・基準外繰入金とは

一般会計などから水道事業会計へお金を入れることを **繰入（くりいれ）** といいます。  
総務省の **繰出基準**（毎年の地方財政対策で示される基準）との関係で、次のように呼び分けます。

| 区分 | 意味 | 性格 |
|---|---|---|
| **基準内繰入金** | 繰出基準に沿って一般会計等が負担すべきとされる経費への繰入 | 制度上想定された負担（例：消火栓設置・維持管理負担、災害復旧の一部、高料金対策など、該当する場合） |
| **基準外繰入金** | 繰出基準に該当しないのに繰り入れるお金 | 政策判断による支援。独立採算の例外に近く、一般会計側の負担増になる |

水道事業の原則は **独立採算**（地方公営企業法第17条の2第2項：経営に伴う収入で経費を賄う）です。  
料金改定を避けるために安易に基準外繰入へ頼ると、一般会計の財政を圧迫し、説明責任も重くなります。  
本計画でも、基本は **料金・企業債・補助金・内部留保** で回す前提です。

### 2-7 具体例：これは3条か4条か

| 支出・調達の例 | 原則の帰属 | 考え方 |
|---|---|---|
| **配水池のメンテナンス業務委託**（点検・清掃・通常修繕の委託） | **3条**（委託料など） | 日常の維持管理。資産を新たに作る・大きく価値を上げる工事ではない |
| **配水池の大規模改修・耐震補強・更新工事** | **4条**（建設改良費） | 効果が長期間残り、固定資産として計上される投資 |
| **クラウドのオンライン施設台帳システム**（利用料・SaaS・運用委託） | **3条**（委託料・使用料など） | 毎年・毎月のサービス利用料は経常経費 |
| **施設台帳システムの新規構築・機器購入で資産計上するもの** | **4条**（または資産計上に応じて整理） | 自前のソフト・機器を取得し固定資産化する場合は投資側 |
| **給水車の購入** | **4条**（建設改良費・車両購入） | 固定資産の取得 |
| **給水車の燃料・点検・運行委託** | **3条** | 取得後の維持運営費 |
| **給水車のリース料**（契約形態による） | 多くは **3条** | ただしファイナンス・リース等で資産計上する場合は整理が異なる |

迷ったときの目安：**「その支出で長持ちする資産が残るか」→ 残るなら4条寄り、「その年の運営のためだけか」→ 3条寄り**。

| 営業費用 | 受託工事費 | **給料・工事請負費など** | 受託工事収益に対応する原価。収益と費用を対応させて見る。 |

| 営業費用 | **減価償却費** | 既存施設／新規施設 | 施設・管路の取得費を耐用年数で割り、毎年費用化する額。**現金は出ない**が、料金原価の重要な構成要素であり、内部留保の源泉でもある。 |
| 営業費用 | **資産減耗費** | 配水管／配水管以外 | 更新・撤去で残っていた帳簿価額を費用化したもの。更新が進む年は増えやすい。現金は通常出ない。 |
| **営業外費用** | 支払利息 | **企業債利息** | 借入残高に対する利息。元金返済は4条、利息だけが3条。金利上昇・残高増で給水原価を押し上げる。本計画は新規分を利率4.5％前提。 |
| 営業外費用 | 雑支出 | **不用品売却原価など** | 雑多な費用。計画上の主因にはなりにくい。 |
| **特別損失** | 固定資産売却損など | ― | 臨時・例外的な損失。 |

たとえ：3条は「水道屋さんの年間損益計算書」です。

### 3-2 4条_case2（資本的収支）

#### 収入側

| 大きな区分 | 目・節の例 | 解説 |
|---|---|---|
| **企業債** | 企業債 | その年に借りた建設資金。将来の元金返済（4条）と利息（3条）の負担を生む。充当率・内部留保水準と一体で調整する。 |

| **国県補助金** | 国補助金／県補助金 | 建設・更新に対する補助金。採択の確度が低い場合、計画では見込まない（安全側）ことがある。 |

#### 支出側

| 大きな区分 | 目・節の例 | 解説 |
|---|---|---|
| **建設改良費** | **工事請負費** | 管路更新・耐震化・施設整備など、業者へ発注する工事の中心。老朽管更新の多寡がここに直結する。 |
| 建設改良費 | **委託料** | 実施設計など、建設改良に直接必要な委託。日常メンテ委託（3条）とは区別する。 |
| 建設改良費 | **給料など** | 建設改良に直接従事する職員給与など、投資に紐づく人件費。 |
| 建設改良費 | **修繕費・量水器など** | 資産形成・更新に整理されるもの。量水器（メーター）更新などもここに入ることがある。給水車購入も車両取得として建設改良側。 |
| **企業債償還金** | 企業債償還金（既存＋新規） | 過去の借入の**元金**返済。利息は3条。据置なし・30年なら、借りた翌期から長い期間にわたって元金が出ていく。 |
| **国県庫補助返還金** | 県補助金返還金など | 補助条件の変更・不用額などで返すお金。通常は例外的。 |
| **投資** | 国債等購入費 | 資金運用としての有価証券購入。手元資金の置き場所の話で、管路投資とは別。 |

たとえ：4条は「家の建て替えと住宅ローン」です。  
新しい管を入れる費用（建設改良費）と、過去のローン返済（企業債償還）が支出の中心で、その財源が新規借入・補助金・貯金（補てん財源）です。

`3条_case2` の「推計方法」列は、その節をどう将来推計するかを示しています（例：物価上昇ケース連動、実績平均、見込まない）。

| `減価償却費(既存)` / `減価償却費(新規)` | 既存資産・新規投資の償却推計 |
| `長期前受金戻入(既存)` / `(新規)` | 補助金に対応する収益の戻し入れ |

## 5. 財政シミュレーションの用語（最重要）

単位は多くの項目が **千円** です。

### 5-1 収益的収支（3条）

| 用語 | 意味（やさしい説明） |
|---|---|
| **給水収益** | 利用者からいただく水道料金収入。最大の収入源 |
| **長期前受金戻入** | 過去に受けた補助金を、施設の償却に合わせて少しずつ収益として戻す額（現金は入ってこない） |
| **その他収益** | 受託工事収益、雑収益など、料金以外の収入 |
| **収入計** | 上記を合わせた収益的収入の合計 |
| **受水費** | 愛知県企業庁などから買う水の費用。支出の大きな柱 |
| **減価償却費** | 施設・管路の価値を耐用年数で割り、毎年費用計上する額（現金は出ていかない） |
| **資産減耗費** | 更新・撤去などで資産価値が失われたときの費用（現金は出ていかないことが多い） |
| **支払利息** | 企業債残高に対する利息。この計画では利率4.5％前提 |
| **その他費用** | 人件費・動力費・修繕費・委託料などの運営コスト |
| **支出計** | 収益的支出の合計 |
| **当年度純損益** | 収入計 − 支出計。プラス＝黒字、マイナス＝赤字 |

### 5-2 資本的収支（4条）

| 用語 | 意味（やさしい説明） |
|---|---|
| **企業債（企業債収入）** | その年度に新たに借りたお金 |
| **国県補助金** | 国・県からの建設補助金 |
| **工事負担金等** | 工事に伴う負担金など、上記以外の資本的収入 |
| **資本的収入計** | 設備投資に充てる収入の合計 |
| **建設改良費** | 管路更新・施設整備など設備投資の支出額 |
| **企業債償還金** | その年度に返済する企業債の**元金**（利息は3条） |
| **資本的支出計** | 投資と元金返済などの合計 |
| **差引（不足額）** | 収入計 − 支出計。ほぼ毎年マイナスになる |
| **補てん財源合計** | 不足を埋める財源の合計（内部留保など） |

```
資本的支出 100
  ├ 建設改良費 60（今年の工事）
  └ 企業債償還 40（過去の借入返済）

資本的収入  60
  ├ 企業債収入 50（今年の借入）
  └ 補助金等   10

不足額 △40  ← 毎年ほぼ発生
   ↓
補てん財源 40  ← 内部留保（貯金）で穴埋め
```

### 5-3 経営指標（高すぎ・低すぎの影響）

| 指標 | 意味 | 低いとき | 高いとき |
|---|---|---|---|
| **給水原価（円/m³）** | 水1m³を届けるのにかかる費用 | 効率的に見えるが、必要な更新・維持を削って低く見えている可能性もある。安全性・管路健全性が伴うかが重要 | 料金圧力が強まる。受水費・減価償却・利息・修繕委託のどれが増えているかを分解して見る |
| **供給単価（円/m³）** | 水1m³あたり実際に得られる収入 | 料金水準が原価に追いついていない可能性。料金回収率が下がりやすい | 利用者負担は重い。ただし原価高の団体では必要な水準であることも多い。改定後はここに表れる |
| **料金回収率（%）** | 供給単価 ÷ 給水原価 | **100％未満は原価割れ**。内部留保を食いつぶし、将来の更新財源が細る。改定検討の中心指標 | 100％超は原価を料金で賄えている状態。高すぎる場合は、過剰な料金か、原価側の一時的低下の可能性も点検する。目標の目安は **100％以上** |
| **内部留保資金残高** | 年度末の手元資金＝事業の体力 | 4条不足を埋められず、工事先送り・急な料金改定・基準外繰入依存に追い込まれやすい | 厚すぎると「値上げ不要では」と見られやすいが、更新投資の山・災害・金利上昇への備えとして必要な水準がある（第10-2節） |
| **企業債残高** | まだ返していない借入の残り | 借入が少なく自己財源中心なら利息負担は軽いが、更新を先送りしている可能性も確認する | 将来の元金償還と利息が重くなり、給水原価・料金を押し上げる。世代間負担の先送りにもなる |
| **企業債残高対給水収益比率** | 企業債残高 ÷ 給水収益 | 借入負担は相対的に軽い。ただし投資不足との見合いで評価する | 類似団体平均 **222％**、全国平均 **247％**（R6）を大きく超えると、利息・償還が経営を圧迫しやすい。明確な強制基準はないが監視指標 |

## 6. 企業債（くわしい解説）

### 6-1 企業債とは

**企業債**は、地方公営企業が施設の建設・改良などの資金を調達するために起こす地方債です。  
水道事業における「長期の借入金」と考えてください。

- **起債（きさい）**：企業債を借りること
- **企業債収入**：その年に借りた額（4条の収入）
- **企業債償還金**：元金の返済（4条の支出）
- **支払利息（企業債利息）**：利息の支払い（3条の費用）

住宅ローンに例えると、

| 企業債の用語 | 住宅ローンのたとえ |
|---|---|
| 企業債収入 | その年に借りたローン額 |
| 企業債償還金 | 毎月返す元金 |
| 支払利息 | 毎月払う利息 |
| 企業債残高 | ローン残高 |

### 6-2 どのような種類があるか（分け方の見方）

実務では、次の切り口で種類を理解します。

#### （1）事業別（何のための借入か）

地方債計画上、公営企業債は水道事業・下水道事業・病院事業などに分かれます。  
水道では主に **水道事業の建設改良等の財源** としての企業債です。

#### （2）資金の調達先（誰から借りるか）

| 種類 | 内容 | 特徴 |
|---|---|---|
| **財政融資資金（政府資金）** | 国の財政融資資金からの借入 | 長期・比較的低利で安定調達しやすい |
| **機構資金** | 地方公共団体金融機構からの借入 | 公営企業向けに広く使われる |
| **民間等資金** | 銀行等からの借入、市場公募など | 市場金利の影響を受けやすい |

発行には、原則として総務大臣または都道府県知事との**協議・同意（または許可）**が必要です（地方財政法）。  
利率・償還方法・資金も、協議事項に含まれます。

#### （3）償還方法の違い／「据置なし・償還年数30年」とは

| 方法 | 内容 |
|---|---|
| **元金均等償還** | 毎回の元金返済額が一定。初期の利息負担は大きい |
| **元利均等償還** | 元金＋利息の合計が毎回ほぼ一定。水道のような長期投資向きとされることが多い |
| **据置期間** | 借りてから元金返済を始めるまでの猶予期間 |

本計画の **据置なし・償還年数30年** の意味：

| 語句 | 意味 |
|---|---|
| **据置なし** | 借りたあと、元金返済を先送りしない。比較的早い時期から元金返済が始まる（利息だけ払って元金据え置き、ではない） |
| **償還年数30年** | 元金をおよそ30年かけて返し終える前提 |

たとえ：3,000万円の住宅ローンを「据置なし・30年」で組むと、最初の年（または直後）から元金返済が始まり、約30年で返し終わるイメージです。  
据置があると「最初の数年は利息だけ」になり、その分、後年の元金負担や総利息の出方が変わります。

管路の耐用年数（例：40年）より償還が短いと、償却で内部に残る資金と返済キャッシュアウトのタイミングがずれやすい点にも注意が必要です。

### 6-3 何に充てられるか（用途・工事・資産）

企業債は、原則として **建設・改良など、効果が長期間残る支出（資本的支出）** の財源です。  
日々の維持管理費（電気代・通常の修繕・一般人件費など）には、原則として充てられません。

#### 充てられるものの例（水道）

| 区分 | 具体例 |
|---|---|
| **管路工事** | 老朽管の布設替え、耐震管への更新、配水管の延伸・ループ化 |
| **施設整備** | 浄水場・配水場・配水池の整備・更新、ポンプ・電気計装設備の更新 |
| **地震・安定供給対策** | 緊急遮断弁、応急給水拠点、バックアップ機能の整備 |
| **設計業務委託など** | 上記建設改良に**直接必要な**実施設計・詳細設計などの委託料（工事と一体の資本的支出として認められる範囲） |
| **関連事務費の一部** | 建設改良に直接従事する職員給与など、建設改良費に整理されるもの |

本ファイルの `４条工事費・起債額` では、地震対策事業・安定供給対策事業の工事費を置き、そのうち起債対象分に充当率を掛けて起債額を算出します。

#### 充てられない／原則対象外の例

| 区分 | 理由 |
|---|---|
| 維持管理の電気代・薬品費 | 経常経費で資産形成にならない |
| 小規模修繕（原状回復のみ） | 資産価値の向上がない |
| 通常の総務・料金徴収の人件費 | 建設改良に直接結びつかない |
| 既存借入の単なる借換 | 原則として新たな建設改良財源ではない |

たとえ：「家を建てる・大規模リフォームする費用はローン可。毎月の食費・電気代はローン不可」です。  
設計料も、「建てるための設計図代」なら建設費の一部としてローン対象になり得ますが、「日常の点検報告書だけ」なら対象外、という感覚です。

### 6-4 金利はどのように決まるか／傾向

金利は、次の要素で決まります。

1. **調達先**（財政融資資金・機構・民間）ごとの貸付条件  
2. **償還期間・据置・償還方法**  
3. **発行時点の市場金利・長期金利の水準**  
4. 必要に応じた **協議・同意の枠組み**

傾向の捉え方：

- 長期金利が低い時期は、企業債利率も低水準になりやすい  
- 金利上昇局面では、新規借入の利息負担が増え、給水原価・料金圧力につながる  
- 本計画の **4.5％** は、金利上昇リスクを意識した**推計上の前提**（保守的な置き方）です。実際の約定利率そのものではありません

支払利息の目安：

```
支払利息 ≒ 企業債残高 × 利率
例：残高 100億円 × 4.5％ ＝ 年間利息 4.5億円
```

### 6-5 安定経営のための「起債の比率」目安

**国が「この％以下なら安全」と一律に定めた強制基準はありません。**  
実務では、複数の指標を組み合わせて見ます。

| 見方 | 内容 | 本計画での参考 |
|---|---|---|
| **企業債残高対給水収益比率** | 残高 ÷ 給水収益。借入の重さ | 類似団体平均 **222％**、全国平均 **247％**（R6）。明確な基準値はないが、これらを目安に管理 |
| **企業債充当率** | 建設改良費のうち企業債で賄う割合 | 団体により異なる。自己財源（内部留保）とのバランスで設定。他都市事例では建設改良の **おおむね3〜4割程度** を目安にする議論もある |
| **内部留保の水準** | 不足補てんと将来更新の備え | 本計画は内部留保 **約21億円** を目安に起債額を手調整 |
| **料金回収率** | 原価を料金で回収できているか | **100％以上** が目標 |

安定経営の実務的な考え方：

1. 更新投資を止めない（老朽化の先送りを避ける）  
2. ただし企業債に依存しすぎない（将来の利息・償還で料金を押し上げない）  
3. 内部留保で資本的収支の不足を埋め続けられる  
4. 残高対給水収益比率が類似団体・全国平均から大きく乖離しないよう監視する  

本ファイルの懸念事項でも、同比率が将来大きく上昇し得ることが指摘されており、**起債額・工事水準・料金**を一体で調整する必要があります。

### 6-6 安定経営のために重視すべき予算配分

優先順位の考え方（上から順に「崩すと致命傷になりやすい」）：

1. **料金水準（給水収益）と料金回収率**  
   収入の土台。ここが割れていると、どれだけ支出を削っても中長期は持たない。

2. **内部留保の維持**  
   4条不足の補てん財源。枯渇すると更新も償還も一気に厳しくなる。

3. **必要不可欠な更新投資（建設改良費）**  
   先送りは一時的に収支を良く見せるが、漏水・事故・将来の工事単価高騰でツケが大きい。

4. **企業債充当の抑制（自己財源とのバランス）**  
   全部借金にすると、利息と元金償還が後年の3条・4条を圧迫する。

5. **経常経費の効率化（受水費以外の委託・動力・修繕）**  
   受水費は制度単価の影響が大きく削減余地が限定的なことが多い。その他の維持管理は、安全を損なわない範囲で効率化の余地を見る。

6. **支払利息・償還の平準化**  
   工事の山をなだらかにし、起債の集中を避ける。

予算配分の実務イメージ：  
「まず回収率と内部留保の下限を死守 → その範囲で更新量を最大化 → 足りない分を起債で補い、残高比率を監視」です。

## 7. 除却（くわしい解説）

### 7-1 「帳簿上の価値を費用として落とす」とは

水道管は、買った・埋設したときに「固定資産」として帳簿に載ります。  
その後、毎年の減価償却で価値を少しずつ減らしていきますが、更新で管を撤去する時点でも、まだ帳簿に価値が残っていることがあります。これを **帳簿価額（簿価）** といいます。

```
帳簿価額 ＝ 取得価額 − これまでの減価償却累計額
```

たとえ：30万円で買ったパソコンを4年使って帳簿上まだ6万円残っているとき、廃棄すると「残りの6万円分の価値が消えた」ことになります。  
この「消えた価値」を、その年の費用として認識するのが **除却（じょきゃく）** に伴う会計処理です。

### 7-2 落とした価値は、どの費用になるのか／どう清算するのか

管を入れ替えたとき、古い管の残っている帳簿価額は、通常 **資産減耗費（固定資産除却費）** という営業費用になります（3条の費用）。

重要なポイント：

- **現金はあらためて出ていきません**（すでに過去に工事費として支払済み）
- 会計上、「まだ残っていた価値を費用にした」だけです
- 貸借対照表では、固定資産（資産）が減り、損益計算書では資産減耗費（費用）が増えます
- その結果、純損益は悪化しますが、**現金支出を伴わない費用**なので、損益勘定留保資金の要素にもなります

#### 数値例

```
古い配水管
  取得価額           1,000万円
  減価償却累計額       800万円
  帳簿価額（残り）     200万円  ← これが残っている

今年、布設替えでこの管を撤去
  → 資産減耗費 200万円 を計上（現金は出ない）
  → 固定資産から 200万円分を抹消（清算）
```

「清算」とは、借金を現金で払う清算ではなく、**帳簿上の資産を消し、対応する費用を認識して帳尻を合わせること**です。

### 7-3 「除却率2％」は何の基準か

**法令で定められた全国一律の除却率ではありません。**  
この投資財政計画における**推計上の簡便な仮定**です。

`減価償却費(既存)` シートでは、次のように使っています。

```
③除却分 ＝ 前年の投資額 × 2％
減価償却費（既存） ＝ 現有資産の減価償却費 − 除却分
```

意味：

- 管を更新すると、除却された資産については**今後の減価償却が発生しなくなる**
- 将来の既存資産償却額を、過去実績を踏まえて「前年工事費の2％分」だけ減らして見込む
- ファイル名の「除却率2％」はこの推計前提を指します

一方、**資産減耗費そのもの**は、本計画では別途「前年工事費の **2.8％**」（過去5年実績）で計上しています。  
つまり、

| 用語 | このファイルでの使い方 |
|---|---|
| **除却率2％** | 既存の減価償却費を減らすための推計係数 |
| **資産減耗費2.8％** | 除却損失（費用）そのものを見込む推計係数 |

の二段構えです。混同しやすいので注意してください。

### 7-4 よくある誤解への答え

| 疑問 | 答え |
|---|---|
| 除却すると現金が減る？ | 原則いいえ。現金は過去の建設時に出ていて、今回は帳簿上の処理が中心 |
| 「費用になる」とは何の科目？ | 主に **資産減耗費（固定資産除却費）** |
| 除却率2％は国の基準？ | いいえ。本計画の推計仮定（過去実績に基づく簡便法） |
| なぜ減価償却からも差し引く？ | 除却した資産はもう償却しないため、将来の償却額を過大に見積もらないようにするため |

## 8. 減価償却費（くわしい解説）

### 8-1 基本の考え方／なぜ後年に分配するのか

水道施設（管路・ポンプ場・浄水場など）は、買った年に全額を費用にしません。  
使える期間（耐用年数）にわたって、少しずつ費用に配分します。その毎年の額が **減価償却費** です。

#### 目的とメリット

| 観点 | 内容 |
|---|---|
| **期間損益の適正化** | 40年使う管の費用を初年度に全部載せると、その年だけ大赤字・翌年以降は費用が過少になる。使う世代に費用を割り振る |
| **料金原価への反映** | 施設を使う今の利用者にも、建設コストの一部を負担してもらう（世代間の公平） |
| **内部留保の源泉** | 費用計上しても現金は出ないので、その分が更新財源の種銭になる |
| **経営状態の見える化** | 資産がどれだけ「すり減っているか」を損益と貸借対照表で示せる |

除却（資産減耗）も同様に、「消えた資産価値を損益に反映し、帳簿を実態に合わせる」ための整理です。  
メリットは、**(1) 実態に近い損益、(2) 料金議論の根拠、(3) 更新財源（内部留保）の形成** です。

#### 「現金はもう出ていないのに、なぜ毎年費用にするのか」―分かりやすいたとえ

**たとえA（サブスクの前払い）**  
10年分の雑誌購読料を、初月に一括30万円払ったとします。  
財布からは初月に30万円出ていきますが、家計簿上は「毎月2.5万円分読んだ」と記録した方が、各月の生活実態に合います。  
減価償却も同じで、**現金の動き（建設時）** と **費用の認識（使用期間）** を分けています。

**たとえB（パンを冷凍保存）**  
大きな食パンを買った日に代金は払い済みです。でも「今日食べたのは2枚だけ」なら、今日の食費は2枚分と見る方が自然です。残りは冷凍庫（固定資産）にあり、食べる日ごとに費用化します。

**たとえC（世代間の公平）**  
今年埋設した管は、今の利用者だけでなく、20年後の利用者も使います。  
費用を今年に全部載せると、今の世代だけが負担し、将来世代はタダ乗りになります。  
毎年少しずつ費用化することで、**使っている世代が少しずつ負担する**形になります。

### 8-2 具体的な計算例

```
配水管を 1億円 で布設、耐用年数 40年（定額法）
→ 毎年の減価償却費 ＝ 1億円 ÷ 40年 ＝ 250万円
```

40年後には、帳簿上の価値はほぼ償却し終わります（有形固定資産は取得価額の95％まで償却、などのルールあり）。

### 8-3 現金との関係（ここが最重要）

減価償却費は **非資金費用** です。

| 見方 | 何が起きるか |
|---|---|
| 損益（3条） | 費用が増える → 純損益を押し下げる |
| 現金 | **その年は出ていかない**（建設時にすでに支出済み） |
| 資金繰り（4条の補てん） | 減価償却費相当は内部に残るイメージ → **補てん財源（損益勘定留保資金）の源泉** |

### 8-4 水道事業でよく使う耐用年数の例示と出典

耐用年数は、各団体が自由に決めるのではなく、原則として国が定めた **法定耐用年数** に従います。

**出典：**  
**地方公営企業法施行規則**（昭和27年総理府令第73号）**別表第二号**（有形固定資産の耐用年数）、別表第三号（無形固定資産）  
（総務省・e-Gov法令検索などで確認できます）

| 資産の種類（例） | 耐用年数の目安 | 備考 |
|---|---|---|
| 配水管・配水管附属設備 | **40年**前後（規則上も管路は長期） | 本計画の新規償却も **1/40** で管路中心とみなしている |
| 取水・導水・浄水・配水設備などの構築物 | **おおむね50〜60年台** | 構造・材質で細分化 |
| ポンプ・電気・薬品注入・滅菌設備など | **おおむね10〜20年台** | 機械・電気は管路より短い |
| 車両（給水車など） | **おおむね4〜6年** | 短期間で償却が終わる |
| 建物 | 構造により **十数年〜数十年** | 鉄筋コンクリート造など区分あり |
| 土地 | **減価償却しない** | 価値が減らない前提 |

※上表は理解用の概数です。実際の計上は、取得資産の区分ごとに施行規則別表の年数・償却率を適用します。  
※会計上の法定耐用年数と、アセットマネジメント上の「実際に更新する年数」は一致しないことがあります（実使用がより長い／短い場合あり）。

### 8-5 このファイルでの計算前提

| 区分 | 前提 | 意味 |
|---|---|---|
| **減価償却費（既存）** | 現有資産償却 − 除却分（前年工事費×2％） | 更新で資産が減る効果を反映 |
| **減価償却費（新規）** | 償却率 **0.025（1/40）** | 新規投資を管路中心とみなし、40年定額で償却 |

新規分のイメージ：

```
前年の工事請負費（投資額）が 4億円
→ その翌年以降、毎年 4億円 × 1/40 ＝ 1,000万円 が償却に上乗せ
（実際のシートでは、過去の投資分の償却が積み上がっていく）
```

厳密には機械設備なども含まれますが、計画上は大部分を管路とみなして40年償却で扱っています。

## 9. 資産減耗費（くわしい解説）

### 9-1 基本の考え方

**資産減耗費**（固定資産除却費）は、耐用年数を待たずに資産の価値がなくなったときの損失です。

- 減価償却費 … **計画的・毎年少しずつ**減る  
- 資産減耗費 … **更新・廃棄のタイミングでまとめて**減る  

たとえ：  
減価償却は「靴が毎日少しすり減る」、資産減耗費は「まだ使えるはずの靴を買い替えて古い靴を捨てたとき、残っていた価値を一気に捨てる」イメージです。

### 9-2 いつ発生するか（具体例）

| 発生場面 | 具体例 |
|---|---|
| 管路の布設替え | 古い鋳鉄管を耐震管に入れ替え、古い管を撤去 |
| 施設の廃止・撤去 | 使わなくなったポンプ場を解体 |
| 災害等 | 地震・水害で使用不能になった設備 |
| 売却損 | 簿価より安く売った場合の差額（売却損として整理されることも） |

### 9-3 数値例（管路更新）

```
残耐用年数 10年、帳簿価額 500万円 の配水管を今年撤去
→ 資産減耗費 500万円 を一括計上
→ 損益はその分悪化
→ ただし現金支出はない（非資金費用）
```

新しい管の工事費（例：2,000万円）は、別途 **建設改良費（4条）** として支出し、新しい固定資産として計上されます。  
「古い管の除却損失」と「新しい管の投資」はセットで起きるが、会計上の科目は別、と覚えると分かりやすいです。

### 9-4 減価償却費との比較

| | 減価償却費 | 資産減耗費 |
|---|---|---|
| 性格 | 計画的・毎年ほぼ定額 | 更新・廃棄時に発生 |
| 原因 | 時間経過による価値低下 | 除却・撤去・災害など |
| 予測可能性 | 高い | 工事計画に依存 |
| 現金支出 | なし（非資金費用） | なし（非資金費用）が多い |
| この計画での見方 | 既存は除却率2％で調整、新規は1/40 | 前年工事費の **2.8％**（過去5年実績） |

### 9-5 経営上の意味

資産減耗費が増える年は、更新が進んでいるサインでもあります。  
損益だけ見ると悪く見えますが、

- 現金は出ていない  
- 一方で建設改良費（現金支出）と企業債が増えている  

ので、**3条の損益と4条の投資・借入をセットで見る**必要があります。

## 10. その他の重要用語

### 10-1 長期前受金戻入

国や県から施設建設の補助金をもらっても、受け取った年に全額を「もうけ」にはしません。  
いったん **長期前受金** としておき、施設の減価償却に合わせて毎年少しずつ収益に戻します。

- 現金が毎年入るわけではない（会計上の収益）
- 補助金で作った部分の償却負担を、損益上で相殺する役割

| 区分 | 本計画の前提 |
|---|---|
| 既存 | 令和8年度予算値で一定 |
| 新規 | 国庫補助額の1/40（採択が不確実な場合は見込まない安全側もあり） |

### 10-2 内部留保／目標額の考え方

事業の中で蓄えた自己資金＝**貯金**です。  
主な役割は、(1) 資本的収支不足の補てん、(2) 将来更新への備え、(3) 緊急時のバッファです。  
本計画では、企業債充当額を内部留保が **おおむね21億円程度** になるよう手調整しています。

#### 目標額はどのような観点で設定すべきか

国が「何億円持て」と一律に決めた基準はありません。次の観点を組み合わせて決めます。

| 観点 | 内容 |
|---|---|
| **4条不足の補てん力** | 今後数年〜計画期間の資本的収支不足を、毎年埋め続けられるか |
| **更新投資の山** | 老朽管・施設更新が集中する年度でも底をつかないか |
| **災害・事故への備え** | 応急復旧、緊急調達に必要な短期資金 |
| **企業債償還の見通し** | 元金返済が重い局面でも、料金収入とあわせて資金ショートしないか |
| **料金改定のタイミング** | 改定まで時間が空くなら、その間の赤字・不足を吸収できる厚みが必要 |
| **説明可能性** | 「多すぎる貯金」と見られないよう、必要額の根拠（何年分の不足・何か月分の収益など）を示せるか |

実務的な置き方の例：

- 計画期末でも一定額（本計画では約21億円）を維持  
- 「年間の資本的収支不足の複数年分」や「給水収益の数か月〜1年程度」を目安にする議論もある  
- 重要なのは金額の絶対値より、**シミュレーション上で右肩下がりに枯渇しないこと**

### 10-3 県水・受水費／愛知県企業庁の単価

| 用語 | 説明 |
|---|---|
| **県水** | 愛知県企業庁から購入する浄水（用水供給＝卸売り） |
| **受水費** | その購入費用。基本料金＋使用料金（水量料金） |
| **基本承認水量** | 県との契約水量（1日あたり）。本計画ではR8まで **43,600 m³/日**、R9以降 **42,400 m³/日** |
| **有収水量** | 料金対象となった水量 |
| **有収率** | 給水量のうち料金対象になった割合 |

#### 愛知県企業庁の料金単価（県営水道）

県営水道は **二部料金制** です（愛知県企業庁水道事業課の公表資料）。

| 区分 | 単価 | 何に応じてかかるか |
|---|---|---|
| **基本料金（基礎水量）** | **年額 10,800円／（m³/日）** | 承認基本給水量のうち基礎水量分 |
| **基本料金（その他水量）** | **年額 15,360円／（m³/日）** | 承認基本給水量のうちその他水量分 |
| **使用料金（水量料金）** | **28円／m³**（※） | 実際に使った（受水した）水量 |

※使用料金は **2026年4月1日から 32円／m³** に改定（愛知県公表）。  
本ファイル `県水受水費予測` でも、水量料金は概ね次のとおり推移しています。

| 年度 | 水量料金（円/m³） |
|---|---|
| R3〜R5 | 26 |
| R6〜R7 | 28 |
| R8以降 | 32 |

基本料金単価（10,800円・15,360円）は、本計画の推計期間では一定として置かれています。  
一方、**使用料金単価は改定により変わります**（毎年必ず変わるわけではないが、県の料金改定があれば改定後単価に切り替わる）。

出典：愛知県「県営水道の料金について」  
https://www.pref.aichi.jp/soshiki/kigyo-suiji/0000006946.html

#### 基本承認水量は、受水量によって単価が変わるのか

**単価表そのものが、その年の受水量に応じて自動で変わる仕組みではありません。**

| 項目 | 決まり方 |
|---|---|
| **基本料金の単価** | 県が定める年額単価（基礎 10,800円、その他 15,360円）。受水量の多寡で単価がスライドするわけではない |
| **基本料金の総額** | **基本承認水量（契約水量）× 単価** で決まる。契約水量を増減すると総額は変わる |
| **使用料金の単価** | 県が定める従量単価（現行28円→2026年4月から32円）。これも受水量で単価が変わるのではなく、**水量×単価** |
| **使用料金の総額** | **実際の受水量（使用水量）× 使用料金単価** |

整理すると、

- 受水量が増えれば → **使用料金の支払総額**は増える（単価×水量）  
- 基本承認水量を増やせば → **基本料金の支払総額**は増える（契約水量×年額単価）  
- 「たくさん受水した日は単価が安い／高い」といった従量逓減・逓増が、県営水道の基本料金単価に自動適用されるわけではない  

半田市の計画でR9以降に基本承認水量を42,400 m³/日としているのは、**契約水量の見直し前提**であり、それにより基本料金総額の見通しが変わる、という意味です。

### 10-4 水道料金関連／改定の目安

| 用語 | 説明 |
|---|---|
| **口径（mm）** | メーターの大きさ。大きいほど基本料金が高い |
| **基本料金** | 使用量に関係なく毎月かかる固定料金 |
| **従量料金** | 使用水量に応じた料金（段階別単価） |
| **料金改定率** | 現行料金を何％改定するか |

#### 改定の目安・スパン・どんなときに改定するか

| 観点 | 目安 |
|---|---|
| **制度上の考え方** | 水道法施行規則では、料金は概ね **3年を通じ財政の均衡** を保てるよう設定する、とされる（総括原価方式の考え方） |
| **経営戦略の見直し** | 総務省の経営戦略では、毎年度の進捗管理に加え、おおむね **3〜5年ごと** の改定・見直しが想定される |
| **現場の実務** | 3〜5年スパンで収支を点検し、必要な場合に料金改定案を議会・住民に諮る、が一般的 |

**改定を検討すべき経営状況の例：**

1. **料金回収率が100％を割り、中期でも回復見込みがない**  
2. **当年度純損益の赤字が常態化し、内部留保が減少トレンド**  
3. **資本的収支の不足を補てんできず、更新投資を先送りせざるを得ない**  
4. **企業債残高対給水収益比率が類似団体・全国平均から大きく上振れし、利息・償還負担が増える**  
5. **受水費改定・物価上昇・金利上昇で給水原価が構造的に上がる**  

逆に、単年度の一時的な赤字や、工事集中年の内部留保減少だけで即改定、とは限りません。  
**中長期シミュレーションで「回収率・内部留保・償還負担」が持つか**を見て判断します。
