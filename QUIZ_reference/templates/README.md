## 1. 問題形式一覧とJSONスキーマ（全5形式）

各問題は、出題の意図に応じて以下の5つの形式（`type`）から選択します。

### ① 標準4択問題 (`type: "choice"`)
```json
{
  "id": "courseId_unitId_01",
  "type": "choice",
  "question": "水道事業における「独立採算制の原則」の基本的な考え方として最も適切なものはどれですか？",
  "options": [
    "事業運営に必要な経費は原則として税金ではなく利用者の水道料金収入によって賄う原則",
    "施設の建設改良費を含むすべての支出を毎年度の一般会計からの繰入金のみで賄う原則",
    "各自治体が独自に法令を制定し国や県の指導を受けずに自由に料金設定を行える原則",
    "将来の人口減少に関わらず過去の最大給水量を維持する規模で施設更新を継続する原則"
  ],
  "answerIndex": 0,
  "explanation": "地方公営企業法第17条の2に基づき、公営企業は経費を利用者からの料金収入で賄う「独立採算制」が基本原則となっています。",
  "analogy": "家計や民間企業と同じで、日々の生活費を他人の援助（税金）に頼らず自分自身の稼ぎで賄って自立運営する大原則です。",
  "referenceSection": "第1章 1-1 水道事業の経営基本原則 P.5"
}
```

### ② 一問一答 ⚪︎×問題 (`type: "true_false"`)
- `options` は常に `["正しい", "間違い"]`。正解が「正しい」なら `answerIndex: 0`、「間違い」なら `answerIndex: 1`。
```json
{
  "id": "courseId_unitId_02",
  "type": "true_false",
  "question": "水道事業の会計において、日々の給水活動に伴う日常的な損益（収益的収支）を管理するのは「地方公営企業法第4条」である。",
  "options": ["正しい", "間違い"],
  "answerIndex": 1,
  "explanation": "日常的な損益（収益的収支）は第3条で管理します。第4条は施設整備や企業債償還などの長期投資（資本的収支）を扱います。",
  "analogy": "毎月の生活費家計簿が第3条、マイホームのリフォームやローン口座が第4条です。",
  "referenceSection": "第2章 2-1 3条と4条の区分 P.12"
}
```

### ③ 語句の穴埋め問題 (`type: "fill_in_the_blank"`)
- **UI動作上の最重要ルール**:
  - `blankText` に必ず `【空欄1】`, `【空欄2】` を配置する。
  - `blanks` に各空欄の正解単体語句を定義する。
  - **🚫 選択肢に「A / B」のようなペア文字列を入れてはならない**（各空欄をタップして1語ずつ埋める仕様のため進行不能バグとなる）。
  - **⭕ `options` は全正解を含む「単体語句のプール」とする**。
  - **⭕ 空欄直後の助詞・単位と選択肢の語句が重複しないようにする**（例: 「【空欄1】日分」に対して選択肢を「30日分」にして「30日分日分」としない）。
```json
{
  "id": "courseId_unitId_03",
  "type": "fill_in_the_blank",
  "question": "公営企業会計の基本構造について、以下の空欄に適する語句を選択肢から選んでください。",
  "blankText": "日々の給水サービスに伴う損益を管理するのが【空欄1】であり、将来の施設整備や企業債償還などの長期投資を管理するのが【空欄2】である。",
  "blanks": [
    { "id": 1, "answer": "収益的収支（第3条）" },
    { "id": 2, "answer": "資本的収支（第4条）" }
  ],
  "options": [
    "収益的収支（第3条）",
    "資本的収支（第4条）",
    "一般会計繰入金",
    "企業債残高"
  ],
  "answerIndex": 0,
  "explanation": "地方公営企業法において、経常的な損益は第3条、資本的投資は第4条として明確に区分経理されます。",
  "analogy": "毎月の食費などの生活費家計簿が第3条、住宅ローン返済などの大型投資口座が第4条です。",
  "referenceSection": "第2章 2-1 公営企業会計の仕組み P.15"
}
```

### ④ 並び替え・手順問題 (`type: "ordering"`)
```json
{
  "id": "courseId_unitId_04",
  "type": "ordering",
  "question": "浄水場における一般的な浄水処理工程を、正しい順番に並べてください。",
```

## 2. 厳格品質基準（作問ルール）

1. **問題文の太字ルール**:
   - 肯定形（「最も適切なもの」「正しいもの」等） ➔ **太字にしない**（通常テキスト）
   - 否定形（「**適切でないもの**」「**誤っているもの**」等） ➔ **必ず太字**にする
2. **日常のたとえ (`analogy`) のラベル排除**:
   - UI側でデザイン表示されるため、本文先頭に `【日常のたとえ】` という文字は**付けない**（直感的なたとえ文のみを記述する）。
3. **選択肢内の補足説明・カッコ書きの排除**:
   - 選択肢の中に `（最大の費用項目）` や `（税金）` などのヒント・補足カッコ書きを入れない。対象そのものをシンプルに記述する。
4. **選択肢の長さとトーンの均一化**:
   - 原則36文字以内（目安30〜35文字）。正解だけが長くなったり詳しかったりしないよう、最長と最短の差を±20%以内に揃える。
5. **誤答（ディストラクター）の3大実務パターンと極端・ネタ語の完全排除**:
   - 🚫 **禁止語彙**: `株式`, `配当`, `政党`, `警察`, `逮捕`, `爆破`, `金（ゴールド）`, `ブラックホール`, `巨大な岩石`, `完全滅菌`, `地下水沸騰`, `氷点下冷却`
   - 🚫 **極端表現**: `強制的に`, `永久に`, `全廃`, `未来永劫`, `永久遮断`, `永久停止`, `ゼロにするため`
   - ⭕ **実務トラップの作成**:
     1. **隣接実務の混同型**（施設計画に対して財務会計の「資金不足比率」「総括原価方式」等を配置）
     2. **パラメーター反転型**（「自然流下」に対して「ポンプ圧送」、「水温低下による沈降速度低下」に対して「フロック形成異常加速」）
     3. **主体・要件のズレ型**（事業者の責任と需要者の責任の混同、事業者が独自に立ち入り操業停止を命じる等の権限ズレ）

## 3. コピペ用 AI 作問プロンプト

```markdown
以下の資料を元に、自治体の上水道事業職員向けの学習クイズ問題（1レッスンあたり8〜12問）を作成してください。
出力はJSON配列形式のみを出力してください。

【厳格ルール】
1. 4択（choice）を基本とし、一問一答（true_false）、穴埋め（fill_in_the_blank）、並び替え（ordering）、線結び（matching）を適宜配分すること。
2. 肯定形問題は太字にせず、否定形問題（「**適切でないもの**」「**誤っているもの**」）のみ太字で強調すること。
3. 穴埋め問題（fill_in_the_blank）の options は必ず「単体語句のプール」とし、「A / B」のようなペア文字列を絶対に作らないこと。
4. 誤答選択肢は「実務でありがちな混同・パラメーター反転・権限ズレ」で作成し、「強制的に」「永久に」「全廃」や荒唐無稽なSF・ネタ語を絶対に含めないこと。
5. 日常のたとえ（analogy）の先頭に「【日常のたとえ】」というラベルは付けず、本文のみを記述すること。
6. 選択肢の中にカッコ書き補足（（最大の費用項目）等）を一切入れず、36文字以内で文字数を揃えること。

【対象資料】
（ここに資料テキストまたはPDF内容を貼り付け）
```

## 4. 単元の追加と自動品質検証手順

1. `src/data/courses/<course_id>/` に新しい単元ファイル（例: `unit_4.ts`）を作成し、`src/data/courses/<course_id>/index.ts` の `UNITS` 配列に追加します。
2. **自動品質検証を実行**:
   ```bash
   npm run check:quiz
   ```
   ※禁止語、ネタ・極端表現、穴埋めプレースホルダー不備、否定形太字漏れが自動検出されます。
3. **ビルド検証**:
   ```bash
   npm run build
   ```
   エラーがなければ完了です。
