# クイズ問題作成ガイドライン & テンプレート

このフォルダには、水道事業ステップアップドリルの新しい単元や問題を追加する際のフォーマットと作成手順がまとめられています。

---

## 1. 問題データの構成要素（スキーマ）

各問題は以下の形式で作成します。

| 項目名 | 型 | 説明 | 例 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 重複しないユニークなID | `"wf_1_1_01"`, `"asset_1_1_01"` |
| `question` | `string` | 問題文（4択で解答できる問い） | `"実務で呼ばれる「3条」と「4条」の名称の直接の根拠規定は？"` |
| `options` | `[string, string, string, string]` | 4つの選択肢（配列） | `["選択肢1", "選択肢2", "選択肢3", "選択肢4"]` |
| `answerIndex` | `number` | 正解のインデックス（0, 1, 2, 3 のいずれか） | `1`（2番目の選択肢が正解） |
| `analogy` | `string` | **日常のたとえ**（初心者がイメージしやすい例え） | `"【日常のたとえ】毎月の家計簿（3条）と住宅ローン・リフォーム（4条）の違いです。"` |
| `explanation` | `string` | **実務・会計解説**（正解の理由・根拠・注意点） | `"地方公営企業法施行規則の予算様式第3条・第4条に由来します..."` |
| `referenceSection` | `string` | 参照元の解説セクション・項目名 | `"3条・4条の基本概念"` |

---

## 2. わかりやすい問題作成のポイント

### ① 「日常のたとえ（analogy）」の作り方
新任職員や初学者が専門用語のハードルを感じないよう、身近な生活に置き換えます。
* **企業会計（3条・4条）**: 「毎月の生活費」と「マイホーム購入・リフォームローン」
* **企業債**: 「長期の住宅ローン」
* **減価償却費**: 「サブスク前払い」「冷凍パンを毎日少しずつ食べる考え」
* **県水二部料金**: 「スマホの基本料＋使ったギガ数の従量料金」
* **基準内・外繰入金**: 「正当なお手伝い代（基準内）」と「親からの仕送り（基準外）」

### ② 「実務・会計解説（explanation）」の構成
1. **結論**: なぜその選択肢が正しいのか（法令や数値を明示）
2. **実務ポイント**: 実際の現場（予算要求、シミュレーション、議会対応）でどう使われるか

## 3. AI（ChatGPT / Gemini等）を使って問題を自動生成するプロンプト例

以下のプロンプトをAIに貼り付けることで、手持ちの資料や解説文から即座に4択ドリルを量産できます。

```markdown
以下の資料を元に、自治体の上水道事業職員向けの4択ドリルを【5問】作成してください。
出力は以下のJSONフォーマット（配列形式）で出力してください。

【出力フォーマット】
[
  {
    "id": "courseId_unitId_01",
    "question": "問題文",
    "options": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
    "answerIndex": 0,
    "analogy": "【日常のたとえ】初心者が直感的に理解できる生活の例え",
    "explanation": "実務的な根拠と結論の解説",
    "referenceSection": "テーマ名"
  }
]

【問題作成の要件】
1. 異動したての職員でも理解できるよう、「日常のたとえ」を必ず入れること。
2. 誤答の選択肢も、初心者が迷いやすいリアルな選択肢にすること。
3. 正解のインデックス（answerIndex: 0〜3）は適度にバラけさせること。

【対象の資料】
（ここに手引書、要綱、解説文などを貼り付け）
```

## 4. 新しい単元・レッスンの追加手順

1. `src/data/courses/<course_id>/` に新しい単元ファイル（例: `unit_4.ts`）を作成します。
2. 作成した単元を `src/data/courses/<course_id>/index.ts` の `UNITS` 配列に追加します。
3. `npm run build` を実行してエラーがないか確認すれば、自動的にアプリへ反映されます。
